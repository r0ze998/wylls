# Wylls

**エージェント経済を、遊ぶ。（Play the agent economy.）** Wylls は Solana 上のストラテジーゲームです。人とAI市民が、一つの地図と賞金プールをめぐって争います。地図は六つの国が分け合っています。国を選び、村を育て、行き先を封印した軍を進め、砦を守り抜いて州を取ります。AI市民は、運営の手元のマシンで動く言語モデルが判断し、同じ世界で、人と同じルールで遊びます。ストラテジーが好きな人と、エージェントを作る人のためのゲームです。Wylls は独自のトークンを持ちません。

> **このビルド：** ローカルのテスト用チェーンで、テスト用トークン（「テストUSDC」、価値なし）だけを使って動きます。devnet にも mainnet にも載っていません。本物のお金は動いていません。プロジェクト外の人はまだ遊んでいません。
> **以前の版：** 別のビルドで、devnet 上の記録は別に残っています。過去の記録であり、このビルドの証拠ではありません（[以前の版](#以前の版)）。

## このビルドでできること

以下はすべて、2026-10-10 と 10-11 にローカルのテスト用チェーンで実行したものです。実行結果は、動かしたマシンの `.local/` に書かれ、コミットはしていません。そのため各項目に、同じことを再現できるコマンドを添えています。

**A. 土地を取る。** 参加するとすぐに村がもらえます。建設し、兵を訓練し、軍を編成して、敵の州の砦へ封印した進軍を送ります。砦に守備がいれば戦います。自分の国だけで砦を72ターン保つと、砦の持ち主が変わります。この変化はチェーン上の取引で、画面では五か所に表れます。地図の領土の色、国の州の数、砦のパネルの履歴、年代記、フィードです。
*証拠：* 実行 `ai-cq-season-3`（項目E）。二つの砦が、それぞれ72ターン保たれたあと、第84ターンと第85ターンに国0（Aster）へ移り、Aster の州は9から11になりました。最初に確認したのは実行 `cq-demo-1` です。州 (4,-1) の砦が第84ターンに国5から国0へ移りました（ヘラルドの砦の記録に署名 `1LDUBihs…`）。

**B. 人とAI市民が一つの世界に。** 実行 `ai-cq-demo-1` では、AI市民6、スクリプトボット6、プロジェクトの人1人が、一つの征服の世界に入りました。判断の記録は353件です。そのうち52件でモデルに尋ね、52件すべてが有効な答えでした。各ターンの記録のルートは、すべてチェーンに刻まれています（85ターン中85）。

**C. 参加費を払ったプレイヤーの行動を、AIの判断まで追う。** 実行 `ai-cq-season-3` の第7ターンに、有料参加者のウォレット（国 Aster。スクリプトが動かした `6oWvAmAJ…`）が、州 (2,0) から兵500を出しました。コードがこの公開の出来事（イベント1021）を、国 Ember のAI市民の記憶の一行にしました。第8ターンにそのAI市民が起こされ、モデルが予備の兵を軍に編成することを選び、この一行を引用しました。編成（Muster）の取引が送られました。そのあと、同じプロンプトから、この一行と状況欄の同じ事実を取り除いて、もう一度尋ねました。記録された1件のプロンプトからイベント1021の記憶の行を取り除いても、選ばれた候補は変わりませんでした（再実行：同じ。対照：同じ）。違ったのは、モデルが書いた理由の文だけです。この理由はモデルが書いたもので、検証していません。同じ一行を引用したもう一つの判断（第13ターン、別のAI市民、通常の運営で進軍なし）も、変わりませんでした。このシーズンで、有料参加者の進軍についての一行を引用したモデルの判断は2件です。実行 `ai-cq-demo-1` では0件でした。そちらでは、行は示されましたが引用されず、取り除いても選択は変わりませんでした。

## 1ターンの仕組み

ゲームは実時間で進みますが、戦い、進軍、偵察の結果は、押した瞬間には決まりません。10分ごとに、世界がまとめて解決します。この一区切りが**ターン**です（プログラムの記録では `bell` というフィールド名ですが、この文書ではターンと呼びます）。1分ずれて出した二つの命令は同じターンで解決するので、先に出しても有利になりません。建設と生産は途切れずに進みます。

進軍は封印されます。出発地、兵の数、到着ターンは公開され、行き先は到着して初めて開きます。進軍は取り消せません。また、越えられるのは4州までなので、どの村からでもすべての砦に届くわけではありません。画面に、自分の軍が届く砦の一覧が出ます。

## 人とAI市民

**AI市民の判断のしかた。** コードが、ルール上できる候補を短い一覧にします。モデル（Gemma 4、26B。llama.cpp でローカルに動かします。有料のAPIは使いません）がその中から選びます。コードが選択を検証し、通ったものだけを取引として送ります。モデルを呼ばないとき、または答えが無効なときは、ルールで動く**自動運転**が代わりに、経済と日々の務めを続けます。

**モデルと自動運転は分けて示します。** 判断の記録には必ず `by: model` か `by: autopilot` と書かれます。実行 `ai-cq-demo-1` では、353件のうち292件が自動運転、61件がモデルでした（モデルの判断52件と、振り返り9件）。モデルが選んだ進軍は15回です。

**スクリプトボットはAIではありません。** ルールで動くテスト用のプレイヤーで、モデルは使っていません。

**記憶。** 記憶の行は、コードが公開記録から書きます。モデルは書きません。引用は、その行がモデルに見せられ、モデルがその行を挙げた、ということを示します。その行が選択の原因だったことは示しません。記憶あり・なしの比較は、「差はなかった」も含めて、出た結果のまま報告します（項目C）。

**判断を追うページ。** 評議会ページ（`council.html`）の「この判断を追う」は、四つの段で示します。人が何をしたか（取引の署名つき）。AI市民に見せた記憶の行と、それぞれが引用されたかどうか。何が選ばれたか、誰が選んだか。そして結果です。ページ自身も、段は記録の順に並べたもので、なぜその選択になったかは述べない、と注記しています。

**`ai-cq-demo-1` の実行記録。** この実行で最初に公開した `verify-minds` の判定は、2項目で不合格（FAIL）でした（征服版の初村の取引と、登記係の封のあとにチェーンが進んだ1ターン）。その後、検証器がこの二つを扱えるようにし、再検査では7項目すべて合格しています。

## 参加費と賞金

**決まっているルール。**

- 参加費は 25 テストUSDCで、x402 で払います。80% が賞金プール、20% が運営です。1人あたり 20 と 5 になります。
- 勝つのは、シーズン終了時に最も多くの州を持っている国です。数えるのはチェーン上で、ゲーム自身の州のアカウントから、別の賞金プログラムが行います。このプログラムは誰でも実行できます。運営が順位を書き込むことはできません。
- AI市民とスクリプトボットは、運営の招待で参加します。参加費は払わず、賞金の対象にはなりません。ただし、取った土地は、その国の州の数に入ります。

**設計。記録はするが、精算はまだ。** 勝った国の中での一人ひとりの取り分は、貢献に応じて決める設計です。このビルドは、二種類の実績を、根拠となる取引の署名とともに記録します。

- **奪取：** 砦が最後に奪われたとき、その守備隊になった軍の持ち主。
- **兵の増援：** シーズン終了時に、自国が持つ砦の上にいる兵。

残りの二種類は、いまの記録からは導けません。防衛は、争奪の記録に守った軍のIDが必要です。資源の補給は、資源を渡す命令が必要ですが、ゲームにまだありません。

**暫定。** 配点、1位が同数のときの決め方、該当者がいないときの扱いは暫定です。ツールの出力にもそう表示されます。

**試算であり、送金ではありません。** 表示される取り分はすべて試算です。貢献による精算と賞金の送金は、テスト済みの経路としてはあります（`prize-e2e.mjs` の `PRIZE_E2E_CLAIM=1`）。ただしデモには含めず、完成したとは主張しません。

## 自分で確かめる

三つの検証器はどれも私たちが作ったもので、第三者による監査ではありません。コマンドは、基準ポート 41900 のスタックを前提にしています（[動かす](#動かす)）。

**1. 衝突を、ブラウザで。** 画面で衝突の報告を開き、「このブラウザで確かめる」を押します。ページがゲームのルールのコード（WebAssembly 版）を実行し直し、チェーンの記録と比べます。

**2. 州の集計と、独立した数え直し。** シーズン終了後に実行します。

```sh
cd permutation-gateway
# すべての州を集計して確定し（誰でも送れます）、実績の台帳と試算を書く
node scripts/prize-settle.mjs --rpc http://127.0.0.1:41910 --relay http://127.0.0.1:41933 --herald http://127.0.0.1:41940 --out ../.local/prize/season
# （AIシーズンのあと、スタックはローカルのチェーンを一時停止のままにします。先に再開してください。docs/RUNNING.md の5節）
# 州のアカウントから国ごとの州の数を数え直し、プールの結果と比べる。何も送らない
node scripts/prize-settle.mjs --rpc http://127.0.0.1:41910 --relay http://127.0.0.1:41933 --herald http://127.0.0.1:41940 --check
# 台帳の各行を、そこに書かれた取引とアカウントから導き直す
node scripts/prize-settle.mjs --rpc http://127.0.0.1:41910 --relay http://127.0.0.1:41933 --herald http://127.0.0.1:41940 --verify ../.local/prize/season/ledger.json
```

**3. AIの判断（`verify-minds`）。** AIの実行で公開したファイルを、チェーンと照らし合わせます。事前の約束、名簿、ターンごとのルートと刻印、AIのすべての取引が判断の記録に載っているか、発言、保存した問い合わせのモデルへの再送、記憶の行の再生、を調べます。

```sh
node permutation-gateway/citizens/verify-minds.mjs --herald http://127.0.0.1:41940 --rpc http://127.0.0.1:41910 \
  --ai-dir .local/frontier/ai/<run id> --repo . --stack .local/frontier/ai/<run id>/stack.toml \
  --citizens-config permutation-gateway/citizens/config/smoke.json --llm http://127.0.0.1:41901
```

## 動かす

すべてローカルで動きます。詳しい手順とテストのコマンドは [docs/RUNNING.md](docs/RUNNING.md) にあります。

**必要なもの**（自分で入れます）：`rustup` で入れる Rust と、固定した二つのツールチェーン（1.89.0 と 1.95.0。各 `rust-toolchain.toml` に書いてあります）。二つのプログラムのビルドに `cargo-build-sbf` 3.1.9。Node 20 以上。AIを動かす場合は、llama.cpp と Gemma 4 の GGUF ファイルも必要です。

**ビルド。**

```sh
rustup toolchain install 1.89.0 1.95.0 --profile minimal
scripts/build-frontier.sh --features test-beacon     # ゲームのプログラム（テスト用の乱数ビーコン。本番には配備できない版）
scripts/build-prize.sh                               # 賞金プールのプログラム
npm ci --prefix permutation-gateway
(cd frontier-node && cargo build --locked --release --workspace)
```

**人が遊ぶ世界（賞金プールつき）。** このコマンドは前面で動き続けます。

```sh
S=frontier-node/target/release/frontier-stack
$S up --conquest --mode accel --beacon test-key --preseason-scale 2000 --scale 10 \
  --game-hours 16 --season-end-at-play-end --bots 0 --personas off \
  --prize-so permutation-prize/target/deploy/permutation_prize.so --entry-fee 25000000 \
  --run-id try-cq --base-port 41900 --season 90
# 開く： http://127.0.0.1:41940/frontier/frontier/        （止める： $S down --run-id try-cq）
```

ブラウザは、内蔵のローカル用テストウォレットで参加します。同じアドレスをプライベート（シークレット）ウィンドウで開くと別のウォレットになるので、1台で2人目として参加できます。

**すべてを一つにしたAIシーズン**（10倍速で約1時間40分。AIのスタックは同時に一つだけ。保護対象のパスに未コミットの変更があると、開始前の検査で止まります）：

```sh
export AI_MODEL=/path/to/gemma-4-26B-A4B-it-Q4_0.gguf
export AI_LLAMA_DIR=/path/to/llama.cpp
export AI_RUNS_MD=$PWD/.local/frontier/ai-RUNS.md
permutation-gateway/citizens/llama/start-pinned.sh /tmp/gemma-41901.log &     # llama-server を 127.0.0.1:41901 で起動
permutation-gateway/citizens/bin/ai-citizens-run.sh \
  --stack permutation-gateway/citizens/stack/ai-cq-season.toml \
  --citizens-config permutation-gateway/citizens/config/smoke.json \
  --deck deck-1 --run-id my-season --hold 7200
# ゲーム：         http://127.0.0.1:41940/frontier/frontier/
# 評議会ページ：   http://127.0.0.1:41902/council.html
```

## このビルドにまだないもの

- **devnet / mainnet。** このビルドが動いたのは、ローカルのテスト用チェーンだけです。
- **外部のプレイヤー。** 参加者はすべて、プロジェクトの人か、プロジェクトが動かしたものです。
- **ステークで動くエージェント。** AIエージェントのステーク確認は設計です（図の「次の段階」）。
- **完成した機能としての貢献の精算。** 取り分は試算です。防衛と資源の補給は記録されていません。
- **実時間と本来の長さ。** テストでは時計を10倍〜20倍で進めています。デモ動画では72ターンの待ち時間を飛ばします（「time skipped」と表示）。すべてを一つにしたシーズンは96ターンで、14日の標準設定ではありません。各タイマーはシーズンの長さを上限にしています。
- **本物の乱数。** 使ったのはテスト鍵の乱数ビーコンだけで、本物の drand ではありません。封印した行き先が秘密のまま保たれるかは、試していません。
- **評議会ページのアドレスからの支払い。** x402 の支払いは、ポート 41940 のゲームのアドレスで動きます。41902 の評議会ページ側の中継は、まだ支払いのヘッダーを渡しません。参加は 41940 から行ってください。
- **第三者の監査。** 検証器は私たちが作ったものです。

## リポジトリの地図

フォルダ名は昔のままです（`permutation-*`、`frontier-*`）。Wylls への改名では変えていません。

| パス | 内容 |
|---|---|
| `permutation-frontier/` | ゲームのプログラムとそのテスト（`svm-tests/`） |
| `permutation-prize/` | 賞金プールのプログラム（テスト用資産）とそのテスト |
| `permutation-rules/src/frontier/` | プログラム・シミュレーター・ブラウザが共有するルールのコード |
| `frontier-abi/`、`frontier-wasm/` | プログラムのABIと、WebAssembly にしたルール |
| `frontier-node/` | チェーン外のサービス：キーパー、ヘラルド、検証器、スクリプトボット、ローカルチェーン、スタック起動 |
| `permutation-gateway/` | リレー（x402、配布口、プール表示）、JS SDK、`scripts/`（賞金のツール）、`citizens/`（AI市民、`verify-minds`） |
| `permutation-server/web/frontier/` | Webクライアントと評議会ページ |
| `scripts/`、`docs/` | ビルド用スクリプトと文書（[動かす](docs/RUNNING.md)、[デモ台本](docs/pitch/DEMO_SCRIPT.md)、[以前の版](docs/earlier-prototype/INDEX.md)） |
