## 3. 推論の費用の契約で、④にそろえてほしい形

⑤の mock が実際に使っている呼び方です（テスト 34 件で確認）。

| 操作 | いつ | 規則 |
|---|---|---|
| `check(amount)` | 呼ぶ前（何も変えない） | 1回・1日・総額の上限と利用可能額 |
| `reserve(key, amount)` | 送る直前 | 同期で確認と確保を1度に。同じキーは2度確保できない |
| `settle(key, measured)` | 使用量が返った時 | 確保額まで。超えた分は運営の記録 |
| `release(key)` | 送っていないことが確かな時だけ | 未確定は解放できない |
| `undecided(key, why)` | 使用量が返らない時（429・4xx・5xx・時間切れ・切断） | **0 として扱わない** |
| `decide(key, {by, amount/outcome, note})` | 提供者の記録、または運営の判断 | 根拠のメモが必須 |
| `restart()` | プロセスの再起動 | 呼び出し中は未確定、送る前は解放 |

試行のキーは `<判断キー>#<試行番号>` です。GPT には同じ値を `X-Client-Request-Id` で送ります（照合に使う）。Claude にはクライアント側のIDが資料になく、時間切れの呼び出しは照合できません。
