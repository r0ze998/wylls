## 4. 既知の不一致の候補

| 項目 | ⑥の仮置き | 起こりうる不一致 |
|---|---|---|
| 単位 | ⑥の「効果」は複数の命令の組（荷車＝送る＋精算） | ③が命令ごとに型を付けるなら、⑥側に「組」の定義が残る |
| 準備の操作 | 倉を建てる・札を出す・引き換えは、定義の手順に入れない（`SETUP`） | ③がこれらも組み合わせ可能な型にするなら、⑥の手順の範囲が広がる |
| 合図（段階3） | ⑥の `trigger` は書けるが、`manual` 以外は未実装として扱う | ③が「決まり」を命令の一種として型を付けるなら、⑥の `trigger` は③の型を参照する形に変える |
| 新しい世界効果（D） | 当面コアだけが足す（決定 2026-10-30）。⑥は表にない効果をすべて拒否 | ③の型の追加は、コアの新しい版として、動いている世界に④の移行で入る前提（世界は作り直さない。docs/10） |
