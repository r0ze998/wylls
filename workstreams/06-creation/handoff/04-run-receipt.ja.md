# ④ Run/Receipt へ：⑥が実行と記録について必要とすること

**位置づけ：** ⑥の仮置きと、⑥が問いたいことの一覧です。④の決定が優先します。④の成果物は 2026-10-30 時点で未提供のため、対応はすべて未確認です。⑥の `src/adoption.mjs`・`src/execute.mjs`・`src/ledger.mjs` は **模擬** で、チェーンにも中継サーバーにも何も送りません。

## 1. ⑥が必要とすること

### 1.1 実行の認可

| 要素 | ⑥の模擬 | 必要な性質 |
|---|---|---|
| 採用（固定版の確認） | 利用者の署名つきの計画を、確認が通ったときに記録。版と内容ハッシュに固定。作者の公開停止の影響を受けない | 作者・運営から書き換えられない記録 |
| 更新の確認 | 新しい計画が `supersedes` で古い計画を名指しして採用されると、古い計画は動かなくなる | 同じ利用者・同じ定義名だけが置き換えられる |
| 実行の依頼 | 利用者の署名、計画のハッシュ、使い捨て番号、その回に消費する束 | 使い捨て番号の記録が原子的（同じ依頼で二度動かない） |
| 1日の回数 | 実行の開始で数える（途中で止まった回も数える） | 依頼の検査と数え上げの間に割り込みがない |

### 1.2 実行

- 手順ごとに、その時点の状態で、権利・場所・自由在庫・束・残高・容量を検査し、通れば変更する。検査と変更の間に割り込みがないこと。
- 確認（preflight）の結果を、実行の条件にしない。
- 失敗した手順で止まり、それまでの手順の結果は残る。失敗の記録を残す。

### 1.3 記録（過去の出来事の証明）

| 問い | 模擬の台帳の欄 |
|---|---|
| この id の記録はあるか | `receipts[id]` |
| 確定したか／結果 | `final`／`outcome`（`delivered`・`made`・`raided`・`failed`） |
| どの定義のどの版・ハッシュの、どの計画の、どの実行から出たか | `manifest`・`planHash`・`run`（実行番号。同じ計画の同じ日の二回が別の記録になる） |
| どの出力か | `outputs`（作り手が公開した出力の名前）・`port` |
| 受け取り手・場所・物 | `beneficiary`・`at`・`goods` |

記録は **消費されません**。何度でも引用でき、物を生みません。

### 1.4 消費する権利（束）— ⑥からの要望

配達で届いた物のうち、公開された出力にあたる分を、受け取り手のために倉の中で押さえ（`held`）、一度だけ消費できる「束」にしています。C（確定した成果を使う）は、記録ではなくこの束を消費します。

**これは今の S1/S2 にない仕組みです。** S2 の預かり（2e）の `HELD` に近いですが、配達一般には適用されていません。④（またはコア）で持つかの判断が要ります。持たない場合の代わりの案：C を「記録を条件に、倉の自由在庫から取る」に下げる。この場合、記録の偽造と二重引用は防げますが、「その配達の物そのもの」を使う保証はなくなります（[docs/07](../docs/07-guarantees.ja.md) §3）。

## 3. 既知の不一致の候補（⑥の模擬の限界）

| 項目 | ⑥の模擬 | 本番との差 |
|---|---|---|
| 記録を書ける者 | 台帳を持つ者は誰でも `record` を呼べる | 本番では実行だけ。⑥は「記録だけで物が動かない」形にして、この差に頼らないようにした |
| 確定 | `final` の真偽 | チェーンの確定と検証器の判定 |
| 到着 | 依頼の直後に着く。襲撃は指定時のみ | S1 の経路・州の枠・襲撃・精算 |
| 原子性 | 一つのプロセスの中の同期ブロック | チェーンの取引 |
| 署名の権限 | 模擬の鍵。「ウォレットが要る」は知らせるだけ | S1 の署名の規則 |
| 実行できる効果 | 荷車と工房だけ | 持ち分・受け取りの引き出しも要る |

## 4. ④に決めてほしいこと

1. 採用・実行の依頼・使い捨て番号・1日の回数を、どこに記録するか（チェーンの上か、④のサービスか）。
2. 記録の id を、チェーンの記録の位置にするか、内容のハッシュにするか。
3. 束（配達の物の押さえ）をコアで持つか。持たない場合、C を自由在庫から取る形に下げてよいか。
4. 1日の回数を「開始」で数えるか「成功」で数えるか。
5. 緊急停止の受け口を④の実行の入口に置くか（[docs/08](../docs/08-emergency-stop.ja.md)）。
