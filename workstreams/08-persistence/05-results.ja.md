**用語の例：**

- **途中参加の7日貢献比が 0.45 から 0.20 に下がる**：同じ1日2回の接続でも、新人の7日間の働きが、初日からいる人の45%から20%に下がる、という意味です。新人の働きそのもの（分子）は、ほぼ変わりません。下がるのは、古参が、持ち越した畑と兵の分だけ多く働くからです（9-2）。「新人が関われない」という意味ではありません。最初の貢献までの時間は、どの案でも同じでした。

- **首位の連続率 0.44**：4単位の間の3回の切り替わりのうち、平均1.3回で、前の単位の首位国が再び首位になった、という意味です。6国が無作為に勝つなら、約0.17です。

## 5-6. 敗北・離脱・復帰の格子：A と B2 の比較は、なぜ人がやめるかの仮定で決まる

**設定（すべて仮定。実測値ではない）：**

| 項目 | 値 |
|---|---|
| 敗北のときにやめる確率（qd） | 0、0.25、0.5 |
| やめた人が7〜21日後に戻る確率（r） | 0、0.5 |
| やめる理由の家族 | 下の7つ |

| 家族 | やめる理由 |
|---|---|
| none | 敗北のときだけ |
| flat | 誰でも1日1% |
| rel05、rel15 | 中央値の村よりどれだけ貧しいか（他人との比較）。1日あたり最大5%、15% |
| dec05、dec15 | その単位の中で、自分の最高からどれだけ落ちたか（自分の損） |
| dec15k | dec15 と同じ。ただし、世界の作り直し（P0、A）も自分の損と数える |

**接続の頻度の低下：** 1日の接続回数を半分にする確率。やめる確率と同じ割合と式を使う。

**A が B2 を上回ったと判定する規則**（格子を回す前にコードに固定。`sim/run.mjs` の `REVERSAL_RULE`）：

- B2−A の平均が、許容幅を超えて A に有利。
- かつ、95%区間が0を含まない。

| 指標 | 許容幅 |
|---|---|
| 首位の連続率 | +0.10 |
| 最下位国の次のシェア | −0.03 |
| 新規の継続率 | −0.10 |
| 人間の継続率 | −0.10 |
| 途中参加の7日貢献比 | −0.10 |

**結果（6家族×qd 3×r 2＝42条件、各30 seed、`results/retention/RESULTS.md` 5節）：**

| 家族 | A の継続率（人間／新規） | B2 の継続率（人間／新規） | A が上回った指標（条件数） |
|---|---|---|---|
| none、flat | 0.55〜1.00 ／ 0.72〜1.00 | 0.55〜1.00 ／ 0.73〜1.00（ほぼ同じ） | 7日貢献比だけ（12/12） |
| rel05 | 0.63〜0.79 ／ 0.61〜0.78 | 0.57〜0.71 ／ **0.29〜0.47** | 新規の継続率（6/6）、首位の連続率（3/6）、7日貢献比（6/6） |
| rel15 | 0.35〜0.49 ／ 0.18〜0.35 | 0.27〜0.39 ／ **0.01〜0.14** | 新規の継続率（6/6）、人間の継続率（2/6）、首位の連続率（1/6）、7日貢献比（6/6） |
| dec05 | 0.89〜0.98 ／ 0.95〜0.99 | 0.85〜0.93 ／ 0.96〜0.98 | 7日貢献比だけ（人間の継続率の差 −0.04〜−0.06 は許容幅の内） |
| dec15 | 0.86〜0.94 ／ 0.90〜0.96 | 0.79〜0.83 ／ 0.93〜0.94 | 人間の継続率（3/6）、7日貢献比（6/6） |
| dec15k | **0.04〜0.18** ／ 0.17〜0.30 | 0.79〜0.83 ／ 0.93〜0.94 | 7日貢献比だけ。**継続率では B2 が大きく上回る**（人間 +0.64〜+0.75） |

**読み取れること：**

1. **やめる理由が、成績と関係しない（none、flat）なら、A と B2 の継続率は同じ。** 差は、新人の貢献の重み（7日貢献比）だけ。これは離脱なしの場合と同じ、既知の取り引きです。
2. **人が他人と比べてやめる（rel）なら、A が新人を多く残す。** B2 では、新人の多くがやめます（rel15 で、最後まで残る新人は1〜14%）。続く世界では、新人は必ず中央値より下から始まるからです。**この結果は、仮定（他人と比べる）の帰結そのもの**です（9-4）。
3. **人が自分の損でやめ、世界の作り直しを損と感じない（dec）なら、A がやや多く残す。** 続く世界の方が、襲撃などで自分の最高から落ちる機会が多いからです。
4. **世界の作り直しを自分の損と感じる（dec15k）なら、結論は逆になり、A は人を大きく失う。**
5. **B2 と B1 の継続率の差は、どの条件でも ±0.02 以内でした**（10章）。

**B2 が A に逆転される条件（この格子の範囲で）：**

- **人が他人との比較でやめる場合（rel）**：新規の継続率で、必ず逆転された。
- **人が自分の損で強くやめ（dec15）、かつ世界の作り直しを損と感じない場合**：人間の継続率で、一部の条件（3/6）で逆転された。
- **逆転されなかった場合**：やめる理由が成績と無関係な場合（none、flat）と、弱い自分の損の場合（dec05）。この場合、両案の差は「新人の貢献の重み」と「先行者の固定」だけになる。そして固定は区別できない。
- **世界の作り直しを損と感じる場合（dec15k）**：A の方が大きく劣る。

**どの仮定が現実に近いかは、このモデルでは決められません。** 試遊の場面1〜3（15章）で、「なぜやめたくなるか」を直接尋ねます。

## 5-9. この結果から言えないこと

- 実際のプレイヤーの数・割合・行動・やめる理由。
- 本番の資源量・戦闘・期間の妥当さ。モデルの数値は抽象的です。
- 「築いた歴史に意味がある」という手応え、物語、楽しさ。モデルは持ち越した量しか数えません。
- 兵への愛着、解散への不満の大きさ。
- 代理（AI）の費用の大きさと、その分配。
