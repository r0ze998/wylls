## 5-2. 読み取れること（強さの順）

1. **蓄積を残すと、資産の偏りはほぼ倍になる。**
   - 結果：ジニ係数は 0.16 から 0.29 になった。
   - 頑健さ：すべての行動モデル、すべての感度の条件、2組の seed で同じ向きだった。30 seed のうち P0 より偏りが小さかった seed は、B も C も 0 本。
   - 弱めた条件：施設の費用の伸びを緩めた（1.35→1.2）ときだけ、差は 0.23 と 0.22 まで縮んだ。
2. **新人の重みは、蓄積を残すと半分以下になる。**
   - 結果：途中参加の人の最初の7日の貢献は、初日組を1として、P0 で0.45、A で0.55、B と C で0.20〜0.21。
   - 最初の貢献までの時間は、どの案でも約37時間で変わらない。
   - つまり、新人が「関われるか」は案で変わらず、「関わった量が全体の中でどれだけの重みを持つか」が変わる。
3. **最初の貢献までの時間を決めるのは、世界の構造ではなく、作戦の時刻と本人の接続時刻の重なり。**
   - 作戦の受付を3時間にすると、最初の貢献までが約92時間に延びた。12時間にすると約16時間に縮んだ。
   - 予約の送り（段階3の発想）があると、約18時間になった。
   - これは①（国の作戦と参加）の担当範囲。7章と同じく、要件として渡す。
4. **区切りなしの案（C）では、先に勝った国が勝ち続けやすい。**
   - 結果：
     - 首位の連続率は、2組の seed で 0.63 と 0.64。
     - 先に強い国がある条件では 0.77。
     - さらに新人が勝ち馬に乗る条件では 0.80。
     - 最下位の国の次の単位のシェアは 0.03〜0.05 で、全条件で最も低い。
   - 頑健さ：どの行動モデル、どの感度でも、C の首位の連続率は P0 を上回った（0.48〜0.73）。
5. **文書23の案（世界は続き、砦を中立に戻し、守備兵を家に帰す）だけでは、固定は減らなかった。**
   - 結果：
     - 軍を家に帰すだけで解散させない B（感度の「B-noDemob」）では、首位の連続率が 0.68 で、C（0.63）と同じ水準だった。
     - 先に強い国がある条件では 0.64（C は 0.77）。
     - 区切りで**軍を本拠の守り（畑1つにつき兵2）まで解散させる**と、0.40 まで下がった。
   - 頑健さ：ただし再現の seed では、B は 0.51 で P0（0.34）より高かった。解散を入れても、**P0 と同じ水準になるとは言えない。P0 と C の間**と読む。
   - 新しい地域を最下位の国の近くに開く工夫：単独では、効果がはっきりしなかった（0.40 から 0.32、先に強い国がある条件では 0.44 から 0.49）。
6. **敗北の後に「関わる」までの時間は、本拠が残るかで決まる。**
   - P0、A、B では、本拠が残る（今のコードと同じ）。再び作戦に貢献するまでは約38時間。
   - C では村が消えて建て直す。約56時間かかる。
   - 能力の50%に戻るまでは、蓄積が大きい案ほど長い（B 161時間、C 113時間）。これは、失う前の能力そのものが大きいからである。
7. **長い不在から戻ったときの差は小さく、seed の組で入れ替わる。**
   - C は、1組目では損失が最も少なかった（0.51）。2組目では P0 より多かった（0.59 と 0.55）。
   - 確かなのは、世界が続く案（B、C）の方が、復帰後に早く作戦へ加われること（43〜51時間 対 56〜58時間）。
   - 5日を超える不在は、どの案でも休眠になる（今のコードと同じ）。休眠では生産が半分になり、保護が消える。
8. **接続頻度。**
   - 結果：1日1回の人は、1日12回の人の約10%しか貢献できない。1日2回で約49%、1日4回で約90%。
   - 案による差はなかった。
   - 1日1回の人の比を約0.2に倍増させた条件は、次の3つ：
     - 予約の送り（P0 と A で 0.20。B と C では 0.12〜0.13）
     - 未回収の生産を24時間分まで貯められる（0.22〜0.23）
     - 作戦の受付を12時間にする（0.16〜0.21）
   - 常時稼働 AI（1日24回）の貢献は、1日12回の人の0.73〜0.92。行動の上限が人間と同じなら、AI だけが極端に勝つことはなかった。
9. **区切りの瞬間の権利。**
   - 区切りの瞬間に輸送中・預け入れ中の物があるのは、毎回のこと。
   - 世界を作り直す案（P0、A）では、それが失効する（1回の実行で約44,000）。
   - B は、砦に預けた物を送り主に返す（約124,000）。返す仕組みが、B を実装するときの最大の作業になる。

## 5-3. 壊れる条件（反例）

| 試したこと | 結果 | 何が壊れるか |
|---|---|---|
| **複数アカウント**：同じ人が別の村を3つ持つ | 本人が持つ資産の合計は、別の村を持たない場合の約4.5倍（P0：10,135 対 2,215）。どの案でも同じ | **保護の悪用よりも、別の村そのものが強い。** 保護中の別村に退避する分の上乗せは、P0 と A でほぼ0、B で約3%、C で約3%（10,767 対 10,418、9,429 対 9,160）。<br>「受け取ると保護が切れる」で、別村の保護時間は 27時間から7時間に減った。資産の上乗せも小さくなった。<br>本当の歯止めは、村ごとの参加費（文書14）や本人確認。⑧の範囲外だが、どの案でも前提になる |
| **退出と再参加の繰り返し** | 初期物資を受け取った回数：A で17回、B で14回、C で13回。ただし終わりの資産は、繰り返さない場合の 1/4〜1/19（A 762 対 2,871、B 1,524 対 8,259、P0 153 対 2,871） | このモデルでは得にならない。畑を捨てる損が大きいからである。<br>**初期物資の価値が、捨てる村の価値を超えると逆転する。** A の追いつき用の上乗せは、単位の終わりほど大きい（最大4倍）。そのため、終盤に繰り返す型の悪用に弱い。<br>C の建て直しの保護は、アカウントごとに1単位1回。そのため、繰り返す人の保護時間は123時間（繰り返さない人は63時間）。複数アカウントと組み合わせると、制限が効かない |
| **区切りの直前に、負けている国が勝っている国へ全部送る** | P0 と A：首位の連続率は変わらない（0.44 と 0.40）。物は区切りで消える。<br>C：0.63 から 0.69。B：0.40 から 0.49。ジニ係数は B と C で 0.29 から 0.36 | **世界が続く案ほど、意図的な移転が次の単位に残る。** 対策の候補：<br>・区切りの前の移転を、記録に目立たせる<br>・国をまたぐ大量の移転に時間をかける（荷車で運ばせて、襲える） |
| **AI の6アカウントが、1つの村に貢ぐ** | 貢がれた村の資産は、どの案でも約3倍。資産の順位は 74位前後から5位前後へ。<br>その国の砦のシェアは変わらなかった。ただし、このモデルの貢がれる人が、兵を目標より多く作らないためである | 仕組みとしては、どの案でも壊れる（6アカウントは、6つの参加費で止めるしかない）。<br>世界が続く案では、貢がれた量が次の単位にも残る（P0 4,923 → C 15,127） |
| **先に強い国＋新人が強い国を選ぶ＋負けた人の30%が強い国へ移る** | C：首位の連続率 0.80、最下位の国のシェア 0.03。<br>B：0.50 と 0.06。<br>P0：0.37 と 0.09 | 移籍を認める案（A、B、C）では、勝ち馬に乗る動きが固定を強める。特に C で強い。移籍のときの無防備な期間と、再び移るまでの間（文書14）が要る |
| **少人数の国**（人間3人） | どの案でも、砦のシェアは 0.05〜0.06 | 案では救えない。国の人数の偏りを、新人の入国先の案内で直す必要がある。<br>ただし「人数の少ない国へ入る」設定は、全体の固定をほとんど変えなかった（感度の「balanced」） |
| **常時稼働 AI が多い国**（人間2人、AI 8体） | 砦のシェアは 0.27〜0.33 で、人数の割には強い。AI の比率に上限がない案では、そのまま強さになる | AI の数を、国ごとに上限で抑えるか（文書29 E1）を判断する |

## 5-4. 結果が変わる仮定

| 仮定 | 変えたとき | 結果がどう変わるか |
|---|---|---|
| **人はやめない** | 負け続けた人がやめるモデルにすると、C と B の偏りは、さらに広がる見込み（未検証） | 推奨を最も大きく動かしうる。試遊で確かめる（8章 D1、W2） |
| 区切りでの軍の解散（B） | なし（B-noDemob） | B の固定が C と同じ水準に戻る。**B の利点の大半は、この一項目にかかっている** |
| 施設の費用の伸び（1.35） | 1.2 | B と C の偏りが約3割縮む（0.29 → 0.22〜0.23） |
| 作戦の受付時間（6時間） | 3時間／12時間 | 最初の貢献までの時間が、約92時間／約16時間になる。案どうしの順位は変わらない |
| 単位の長さ（14日） | 7日／28日 | 28日では、P0 と A の偏りが増えて（0.23）、B・C との差が縮む。7日では、P0 と A で新人の比が上がる（0.70〜0.88） |
| 保護の長さ | 0時間／168時間 | 固定と偏りへの影響は小さい。168時間にすると、P0 と A で不在中の損失が減る（0.54 → 0.36） |
| 規模の維持費 | なし／全案にあり | このモデルの値では、影響は小さい。維持費が効くのは、資産がもっと大きく偏った後と見られる |
| 襲撃の強さ | 半分／2倍 | 2倍で、C の固定が 0.71 になる。順位は変わらない |
| AI の行動回数 | 1日8回 | 首位の連続率は P0 で 0.31、C で 0.68。順位は変わらない |
| 行動モデル（mixed、coop、raider） | — | 順位は変わらない。協力型が多いと、P0 と A の固定がさらに低い（0.28〜0.31） |

## 5-5. この結果から言えないこと

- 実際のプレイヤーの数・割合・行動。
- 本番の資源量・戦闘・期間の妥当さ。このモデルの物資・兵の数は抽象的で、本番の値とは対応しない。
- 経済の楽しさ、物語、「築いた歴史に意味がある」という感覚。モデルは、持ち越した量しか数えない。A は持ち越しが0になるが、それが嫌われるかどうかは分からない。
