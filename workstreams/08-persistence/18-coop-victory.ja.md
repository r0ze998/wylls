# 18. 協力型の勝利条件：検査器と、仮の規則での確認（採用ではない）

> **注記（2026-10-30）：** この章の結論の範囲、勝利条件と賞金の分け方、二重計上の定義、配送と貢献の区別、統計の数え方は、[20章](20-coop-corrections.ja.md)で狭め、訂正しました。食い違うところは20章が優先します（読み替えの表は 20-6）。

## 18-1. 位置づけと、この章で言えること・言えないこと

**目的：** 協力型（共同達成＋各国・各人の目標）にすると、本当に選択肢が増えるのか、それとも強い集団への従属や作業分担になるだけなのかを確かめる。

**状態：**

- ①の「小さな国際供給網」と「協力型の勝利条件の候補」は届いていません（19章）。
- そのため⑧は、①の仕様を推測で補っていません。代わりに、次の2つを用意しました。
  1. **検査器**（`sim/coop.mjs`、`sim/coop-run.mjs`）：別々に所有された機能（採掘・施設・輸送）を組み合わせて需要に届ける、1日単位の小さな模型。依頼の7つのケースと、参加者ごとの費用と利益、退出、代替、独占度、新規参加者の役割、実際の成果を測る。
  2. **仮の規則（probe）**：検査器が各ケースで正しく反応するかを確かめるための、一般的な代用品。①の候補ではない。

| 記号 | 仮の規則 |
|---|---|
| **CMP** | 競争型の写し：自国の需要は、自国の人だけで満たす |
| **TRD** | 国をまたぐ取引を許す。共同の報酬はない |
| **COOP** | TRD＋届いた1単位ごとの共同の報酬。分け方は `allocation` で切り替える |

**言えること：**

- どんな条件で協力が「選択肢の増加」になり、どんな条件で「従属」「排除」「水増し」になるかの**構造的な条件**。ただし、仮定した行動の下でのもの。
- 検査器が、それぞれの失敗を数字で捉えられること。

**言えないこと（未評価）：**

- ①の候補が良いかどうか。
- 実際の人の交渉、信頼、裏切り、満足、面白さ。
- 共同の報酬が人の行動を変えるかどうか（18-5 の3）。

世界の継続のルールと配置は固定しています。検査器は1つの単位（28日）の中だけを扱い、配置は6国が輪になって隣り合う形（現行の PL-W に相当）です。中央の塔、特定の国の専用資源・必須の役割は、入れていません。

## 18-2. 模型の中身（仮定の一覧）

| 要素 | 中身 | 出どころ |
|---|---|---|
| 参加者 | 6国×6人。各人は3つの機能のうち1つを主に担う（容量10／日、費用1）。ほかの2つも少しだけ持つ（容量1／日、費用2.2） | 仮定 |
| 国の偏り | 国 n の5人は機能 n mod 3、1人は別の機能。だから各国は2つの機能が足りない（「互いの不足」）。対照の `balanced` では、どの国も3機能を持つ | 仮定 |
| 需要 | 各国が1日20単位。1単位は自国にとって価値10 | 仮定 |
| 1単位の作り方 | 採掘→施設→輸送を1人ずつ。輸送の費用は、採掘の国→施設の国→買い手の国の距離（輪の上の距離）に比例 | 仮定 |
| 価格 | 費用×（1＋0.1＋1.5×その人が持つ「選べる空き容量」の割合）。独占するほど上乗せが大きい | 仮定 |
| 選び方 | 買い手は、各段で最も安い担い手を選ぶ。合計が価値10を超えたら買わない | 仮定 |
| 国の得 | 価値10と支払いの差は、その国の人に等しく配る（国の事業として） | 仮定 |
| 外部の選択肢 | 取引しない人は、自分の主な機能の容量×0.3／日を得る（軍事・農業など、取引以外の遊びの代用） | 仮定 |
| 共同の報酬（COOP） | 届いた1単位ごとに2。分け方は価格の割合（`value`）、等分（`equal`）、記録された取引件数（`trades`） | 仮定。**出どころ（誰が払うか）は決めていない** |
| 他国を助けるためらい | 既定ではなし。感度だけで、「利ざや（COOP なら共同報酬の見込みを含む）が費用の60%に届かないと、他国の買い手に売らない」 | **仮定した行動。発見ではない** |
| 退出・離脱 | 5-6 の家族（flat、relative、decline）を再利用 | 仮定 |

**組み込まれていること（発見ではない）：**

| 組み込み | 帰結 |
|---|---|
| 国が偏っている | 国をまたぐ取引で成果が増える。`balanced` では、取引を許しても成果は同じだった |
| 共同の報酬は外から来る | COOP の人の利益が上がるのは、報酬の額そのもの |
| ためらいがなければ、誰も共同の報酬で判断を変えない | COOP と TRD の実際の成果は同じになる |

## 18-3. 測るもの（人数や取引件数を成功の物差しにしない）

| 依頼の項目 | 指標 |
|---|---|
| 実際の成果 | 需要のうち届いた割合（`delivered`） |
| 各参加者の費用と利益 | 1単位の費用と利ざや。**自分の役割の稼ぎ ÷ 外部の選択肢**（`producerRel`）。役割の稼ぎだけで外部の選択肢を上回った人の割合（`producerBenefitShare`）。国の得を含めた比も別に出す |
| 選択肢 | 1回の選定で選べた担い手（本人）の数（`breadth`）。組んだ相手の数 |
| 従属 | 最も多く組んだ相手への集中（`dependency`）。自分の単位のうち、最も稼いだ本人を通った割合（`viaTopOwner`）。最も稼いだ本人の取り分（`topOwnerShare`） |
| 独占度 | 機能ごとの担い手の HHI（本人ごとに合算） |
| 退出できるか・代替 | 退出・値上げの直後の成果の比、回復までの日数、価格の比 |
| 新規参加者の役割 | 最初の取引までの日数、一度も取引しない割合、容量の使われた割合、得 ÷ 外部の選択肢 |
| 水増し | 素朴な数（取引件数、国をまたぐ取引件数）と、堅い数（別の本人どうしで国をまたいで届いた単位）を並べる。往復取引の割合。往復取引をした人が得た共同報酬の割合。同じ本人の別アカウントだけで組んだ単位。1単位あたりの計上数 |

## 18-4. ケースごとの結果（30 seed、seed 101〜130 で再現）

表の値は seed 1〜30 の平均です。

- 全表は `results/coop/RESULTS.md` にあります（各値の10〜90%点と、TRD−CMP・COOP−TRD の対の差の95%区間つき）。
- どちらかの seed の組で有意だった対の差1,501件のうち、1,479件が両方の組で同じ符号・有意でした。一方だけで有意だった22件は、どれもその指標の水準の5%未満でした。数え方・検定・多重比較の扱いは 20-5（当初の「どれも大きさ0.01未満」は誤りで、1件は 0.117）。

| ケース | 主な結果 |
|---|---|
| **1 対等な参加者が互いの不足を補う**（`equal`） | 届いた割合：CMP 0.30 → TRD 1.00。<br>選べた担い手：3.9 → 30.5。<br>最も多く組んだ相手への集中：0.54 → 0.10。<br>役割の稼ぎ ÷ 外部の選択肢：0.96 → 1.02（TRD）。<br>対照の `balanced` では、取引を許しても成果は同じ（1.00）。競争で売り手の利ざやが下がった（2.33 → 1.02） |
| **2 独占：1人が施設を持つ**（`monoOwner`） | TRD で、最も稼いだ本人の取り分 0.52、施設の HHI 0.70。ほかの人の単位の76%が、その本人を通った。<br>COOP（価格の割合で分ける）では、取り分が 0.38 に下がるが、通る割合は変わらない（0.76）。<br>他国を助けるためらいを仮定すると、通る割合 1.00、HHI 1.00（完全な従属） |
| 2' 1国が施設を持つ（`monoNation`） | 施設の担い手は6人いるので、本人の独占にはならない（HHI 0.08）。ただし、施設の容量が足りず、届いた割合は 0.75 |
| **3 退出・条件変更**（`exitKey`、`exitMono`、`raiseKey`） | 主な施設の担い手（国1の5人）が退出：直後の成果は CMP 0.83、TRD 0.78。どちらも18日間で戻らない（代わりの容量が足りない）。<br>独占者が退出：TRD は 0.29 まで落ちる。CMP は 0.94。独占者はもともと自国にしか売れなかったため。<br>値上げ（上乗せ×4）：TRD は他の担い手に移って 1.00 のまま（価格+9%）。CMP は 0.86 |
| **4 新規参加者・少人数国**（`newcomers`、`newcomersGap`、`smallNation`） | 途中参加者は、どの仮の規則でもすぐに使われた（容量の100%）。得 ÷ 外部の選択肢：CMP 2.3 → TRD 10.1。<br>**ただし、買い手が前の相手を15%優遇すると、CMP では途中参加者が一度も取引できなかった。** TRD では、すぐに使われた（`newcomers-incumbency`）。<br>2人の国：自国の需要の届いた割合は、CMP 0.05 → TRD 0.94 |
| **5 軍事・協力に参加しない人**（`optOut`、`haulOnly`） | 各国2人が取引しないと、全体の成果は 0.77 に下がった。取引しない人の得 ÷ 外部の選択肢は、TRD でも COOP でも 4.51（国の得を含む）。取引する人は TRD 5.10、COOP 7.65。**COOP で差が広がった**。<br>輸送だけの人を足すと、輸送の利ざやが下がった。取引する人のうち、役割の稼ぎだけで外部の選択肢を上回った人は、TRD でわずか1%。COOP では、報酬の分（組み込み）で全員が上回った |
| **6 水増し**（`inflate`） | 2組の往復取引で、取引件数の5%が往復になった。実際の成果は変わらない（テストで確認）。<br>共同報酬を**取引件数で分けると、往復取引をした人が 15% を得た**（人数比なら 10%）。価格の割合なら 7%、等分なら 10%。<br>同じ本人の別アカウント3つ（国0〜2）で、1日3.9単位が「国をまたぐ協力」に見えた。素朴な「国をまたぐ取引件数」（321）には入るが、堅い「別の本人どうしの国をまたぐ単位」（116）には入らない。<br>1単位を共同・国・各人（3人）の目標にそれぞれ数えると、計上数は1単位あたり5になる |
| **7 固定連合**（`cartel3`、`cartel4`） | 国0〜2の連合（外の3国も3機能を持つ）：外の国の需要は 0.85 届いた。外の人は 92% 使われた。<br>国0〜3の連合（外の国4・5は採掘の主力を持たない）：外の国の需要は 0.47 しか届かない。外の人の得 ÷ 外部の選択肢は 3.07（連合の人は 6.02） |

## 18-5. 選択肢が増えたのか、従属や作業分担になったのか

1. **国をまたぐ取引を許すこと（TRD−CMP）は、対称な条件では、選択肢を大きく増やし、従属を減らした。** 選べる担い手は約8倍、特定の相手への集中は 0.54 → 0.10 になりました。2人の国や途中参加者も、すぐに役割を持てました。
2. **ただし、所有が偏ると、同じ取引が従属に変わる。**
   - 施設を1人が持つと、ほかの人の単位の76%がその人を通り、その人が全体の稼ぎの52%を取りました（TRD）。
   - 他国を助けるためらいを仮定すると、通る割合は100%になりました。
   - 独占者が抜けると、全体の成果は29%まで落ちました。
   - CMP（自国で完結）は、この独占の影響を自国の中に閉じ込めるので、独占者が抜けても強かった（0.94）。**効率と、1人への依存の強さが、取り引きになっている。**
3. **共同の報酬は、それだけでは選択肢を増やさない。**
   - ためらいのない模型では、報酬は利益を配り直すだけで、成果も、選べる担い手も、依存も変わりませんでした（COOP−TRD がすべて0）。
   - 他国を助けるためらいを仮定したときだけ、報酬が判断を変えました。そのときも、報酬の大きさしだいでした。

   | 共同報酬の大きさ | 届いた割合 |
   |---|---|
   | 0.5 | 変化なし（0.30） |
   | 2 | 0.81 |
   | 5 | 1.00 |

   **報酬が「他国を助けるためらい」を上回るかどうかが、成立の条件です。** そのためらいの大きさは、人で確かめるしかありません。
4. **作業分担（役割はあるが稼ぎが薄い）が起きた。**
   - 輸送だけの人が増えると、取引する人の役割の稼ぎは外部の選択肢を下回りました（TRD）。
   - 外部の選択肢を倍にすると（`equal-solo0.6`）、TRD で役割の稼ぎが外部の選択肢を上回る人は0でした。
   - 役割が用意されていても、**その役割を選ぶ理由（取引以外の遊びより得か）は保証されません。** COOP で全員が上回ったのは、外から来る報酬の分だけです。
5. **共同の報酬は、協力しない人との差を広げた。** 取引しない人の得は変わりませんが、取引する人との差は 5.10 対 4.51 から 7.65 対 4.51 になりました。「協力しなくてもよい」が、相対的に損な選択肢になります。

## 18-6. 成立条件と破綻条件（仮定した行動の下で）

| 協力が「選択肢の増加」として成り立つ条件 | 破綻する条件 | 決め手となった仮定 |
|---|---|---|
| どの機能にも、複数の本人の担い手がいる | 1つの機能を1人（または1つの連合）が持つ | 価格の上乗せが、持つ容量の割合で増える |
| 国をまたいで買い手が選べる | 自国で完結する規則（CMP）、または他国を助けるためらいが報酬より大きい | ためらいの大きさ |
| 抜けた担い手の代わりの容量がある | 主な担い手の退出で、容量そのものが失われる | 副の機能の容量（1／日） |
| 新規参加者が値段で選ばれる | 買い手が前の相手を優遇し、かつ市場が国の中に閉じている | 優遇の強さ（15%） |
| 連合の外にも、全ての機能がある | 連合が、外に1つの機能も残さない | 機能の分布 |
| 共同の報酬を、実際に届いた単位と価格で分ける | 取引件数や参加人数で分ける | 分け方の規則 |
| 1単位を1回だけ数える | 共同・国・各人の目標にそれぞれ数える | 計上の規則 |
| 役割の稼ぎが、ほかの遊びより得 | 担い手が多すぎて利ざやが消える、または外部の選択肢が大きい | 外部の選択肢の大きさ |

## 18-9. 採用前に残る判断

1. **①の候補そのもの**：機能、組み合わせ、価格、共同達成、配り方、参加と退出（19章 I1〜I7）。これがないと、比較の本番はできません。
2. **既存の決定との関係**：文書28（採用済み）は、国の取り分に「国の外への商売」を数えないとしています。国際協力を報酬に入れるなら、この決定を変えるか、別の報酬として並べるかの判断が要ります。
3. **共同の報酬の出どころ**：報酬は誰が払うのか（賞金の倉、手数料、発行しない原則：文書25）。この検査器では外から来るとしたので、利益の増加は組み込みです。
4. **配り方の規則**：取引件数や参加人数で配ると、水増しされます。文書28の「消費されたものだけを数える」と同じ考え方（届いて使われた単位を、価格の割合で）を使うか。
5. **独占と連合への歯止め**：1つの機能の集中、連合の外への開放を、規則で扱うか、遊びに任せるか。
6. **退出の規則**：契約の途中の退出、預け物（7章）。主な担い手が抜けると、全体が止まりうる。
7. **新規参加者の入り方**：前の相手を優遇する仕組み（評判、長期契約）を入れるなら、新規参加者の締め出しへの対策。
8. **本人の見分け**：自己取引を「国際協力」から除くには、本人の見分けが要る。その負担（12章）。
9. **未決定のまま、足さないもの**：中央の塔を共同目標にすること、特定の国の専用資源・必須の役割。
