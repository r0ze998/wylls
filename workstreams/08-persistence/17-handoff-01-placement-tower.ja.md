# 17. ①への引き渡し：初期配置と中央の塔

**位置づけ：** ⑧の配置の比較（16章）は、抽象モデルの中の比較です。次の項目は、①の作戦・参加の設計と、①の中央の塔の調査がないと決まりません。①が試遊や調査で確かめられる形にしました。外部の参加者は募集しません。

## 17-1. 中央の塔について、⑧が知りたいこと

⑧はまだ、塔の効果をモデルに入れていません（16-2）。①の調査の結果に、次の対応が含まれていると、そのままモデルに移せます。

| # | 知りたいこと | なぜ⑧に要るか |
|---|---|---|
| T1 | 塔はチェーンの上に状態を持つか（誰の物か、段階、耐久など）。持つなら、どのアカウントのどの欄か | 状態がなければ、描画だけの目印で、配置の比較には距離の基準としてしか入らない |
| T2 | 塔は占領できるか。条件（包囲の時間、守備、免疫）と、占領した国が得るもの | 中央を取った国が有利になるなら、中央に近い配置ほど有利になる（配置運） |
| T3 | 塔の報酬：生産・視界・移動・賞金の取り分・勝利の点 | 先行者優位（取った国が勝ち続ける）と、逆転の機会（取り返せる）の両方を左右する |
| T4 | 勝利条件との関係：塔を持つことが勝敗に入るか、要塞（keep）の数だけか | 現行の賞金のプログラムは、要塞の数で勝者を決める（1-6）。塔が入るなら、勝敗の地理が変わる |
| T5 | 描画（Engine の段階、鐘の塔）とチェーンの状態の対応 | 画面が見せるものと、ルールが数えるものが食い違わないか |
| T6 | 塔が世界の区切り（戦期）をまたぐか：毎回中立に戻るか、持ち越すか | 世界の構造の案（B1・B2）の「砦を中立に戻す」と同じ扱いか、別か |

**⑧が検証する予定のこと（塔の機能が確認できたら）：**

| 項目 | 内容 |
|---|---|
| 先行者優位 | 塔を最初に取った国の、以後の勝率 |
| 包囲 | 塔を持つ国が、周りの国に囲まれやすいか。現行の集住型（PL-W）では、中央は6国の首都に囲まれている |
| 逆転 | 負けている国が、塔を取り返して逆転できる条件 |
| 国どうしの連携 | 塔を取るために、国どうしが組む必要があるか。⑧のモデルには外交がないので、ここは未評価のまま①・試遊に渡す |

**仮の塔の規則を試す場合：** 現行の規則と混ざらないよう、別の記号（例：`TW-hyp-1`）を付けます。その結果は、①の確認が出るまで、結論には使いません。

## 17-2. 配置について、①の作戦の設計と関わる点

16章で、配置の評価は**作戦の作り**で大きく変わりました。

| モデルの作戦の作り | 配置による差 |
|---|---|
| 1国1日1つの作戦（`single`） | 同国がまとまる配置（PL-W）が、協力の指標でほぼ全部有利になった。散った国の仲間は、同じ目標に着けない |
| 目標ごとに近い仲間が作戦を開く（`local`） | 協力の指標の差は大きく縮んだ。移動が遅い条件では、小集団型（PL-G3）の方が、作戦に着ける割合が高くなった（16-6） |

**①に確かめてほしいこと：**

| # | 課題 |
|---|---|
| O-P1 | 国の作戦は、国全体で1つか、地域ごとに複数か。複数なら、誰が開き、どう人を集めるか |
| O-P2 | 散った仲間が、遠くの作戦に参加する手段：荷だけを送る、代理、予約の送り |
| O-P3 | 近くにいる他国の村と、作戦で組めるか（同盟、通行、共同の攻撃）。⑧のモデルでは、他国は常に敵。近くの他国の数は「選択肢の数」としてしか数えていない |
| O-P4 | 新人が、自分の国の近くの仲間を見つける方法：画面の案内、集団への招待 |

## 17-3. 人で確かめる場面（試遊案。15章の4場面に追加できる形）

各場面で、PL-W（まとまる）と PL-G3（3人の小集団）を比べます。運営がカードと台帳で再現し、コードは作りません。

| 場面 | 用意 | 見ること・聞くこと |
|---|---|---|
| P1 国を選んで入る | 6国の説明と、各国の今の配置の地図を見せて、国を選んでもらう | 何を見て国を選んだか（強さ、仲間、場所）。選んだ後、出現した場所を見て、どう感じたか（1〜5） |
| P2 散った小集団に入る | 小集団（3人）の1人として、自国の他の集団が地図の各地にいる状態から始める | 自分の集団の役割を言えるか。遠くの自国の作戦に、どう関わろうとするか。近くの他国の村をどう見るか（取引相手、脅威、無関心） |
| P3 孤立して出現する | 近くに仲間がいない場所に出現する（PL-S の典型。PL-G でも集団が欠けると起きる） | 最初の30分で何をするか。孤立を不利と感じるか、自由と感じるか |
| P4 自国の補給を遠くへ送る | 自国の作戦の目標が、自分の場所から遠い（他国の勢力の中を通る） | 送るか、送らないか。危険をどう見積もるか。代わりに何をするか |
| P5 敗北した後の場所 | 小集団の中で、自分だけ前哨と倉を失った | 近くの仲間に助けを求めるか。集団から離れて国の中心に移りたいか |
| P6 配置の不公平 | 自国の集団が、たまたま他国に囲まれた地域にある | 配置の運を不公平と感じるか。引き直し（場所を選び直す）を望むか |

**この人数で言えること：** 迷い・誤解・不満・工夫の種類を集めるだけです。距離や勝率の数字を、面白さの証拠にはしません。
