# 20. 協力型の検査（18章・19章）の範囲の固定と訂正

**状態（2026-10-30）：** 18章・19章の結論の範囲を狭め、誤りを訂正します。新しい実験は回していません。数字は、保存済みの `results/coop/` と `results/coop/replication-seeds101-130/` から数え直したものです。18章の本文と食い違うところは、**この章が優先**します。

## 20-1. 結論の範囲

**今回の成果は、①の候補を評価するための検査器と、仮の規則による動作確認です。**

次のことは、この成果から言えません。

- 協力型の勝利条件を採用できる。
- 協力型が面白い。
- 国際協力が必ず起きる、または起きやすい。
- 仮の規則（CMP、TRD、COOP）のどれかが①の仕様である。①の成果物を受け取るまで、仮の規則は①の仕様に昇格させません。

### 仮定から直接生じた結果と、仮定を変えても残った傾向

| 結果 | 分類 | 根拠 |
|---|---|---|
| 国をまたぐ取引で、届いた割合が増えた（`equal` 0.30 → 1.00） | **仮定から直接**（専門化による利益） | 各国に2つの機能が足りないと置いた。3機能を持つ対照（`balanced`）では、増えなかった（1.00 → 1.00） |
| 選べた担い手が増えた（3.9 → 30.5） | **ほぼ定義から** | TRD は候補を全国に広げる規則。`balanced` でも同じように増えた（5.5 → 30.5）。選択肢の数え方で、選択肢が意味を持つかの証拠ではない |
| COOP で各人の利益が上がった | **仮定から直接**（外から足した共同報酬） | 報酬の額がそのまま上乗せされた。**外部からお金を足さない設計（20-2）には当てはまらない** |
| 共同報酬が判断を変えたのは、ためらいを上回ったときだけ | **仮定から直接**（他国を助けるためらい） | ためらいの形と大きさ（費用の60%）を置いた。ためらいがなければ、報酬は配り直しだけ |
| 輸送だけの人の役割が稼げない | **仮定に強く依存**（価格の式、外部の選択肢） | 上乗せの式と、外部の選択肢（容量×0.3）の値で決まる |
| 独占者を通る割合（76%） | **仮定を変えても残った** | 上乗せの強さを 1.5 → 0.3 にしても 0.76。ただし、独占者の取り分は 0.52 → 0.34 に下がった（取り分は価格の式に依存） |
| 届いた割合と依存の改善（TRD−CMP、`equal`） | **仮定を変えても残った** | 離脱の3家族、輸送費の倍、外部の選択肢の倍、前の相手の優遇で、向きは同じ。ただし、国の偏りという前提の上でのこと |
| 独占者が抜けると TRD が大きく落ちる（直後 0.29、期間の平均 0.54） | **構造から** | 容量を1人に集めると置いたので、その人が抜ければ容量が消える |
| 取引件数で配ると往復取引で水増しされる | **規則の算術**（行動の仮定によらない） | 記録された件数で配る規則なら、物を動かさない記録でも配分が増える |
| 別アカウントで素朴な「国をまたぐ件数」が膨らむ | **規則の算術** | ただし、見分けるには模型が持つ本人の情報が要る（20-4） |
| 連合の外の国の需要が届かない（`cartel4` 0.80、外の国だけで 0.47） | **仮定に依存**（機能の分布） | 外の国に採掘の主力がないと置いた。外に全機能が残る `cartel3` ではほぼ影響なし |
| 前の相手の優遇で、新規参加者が CMP で締め出された | **仮定に依存**（優遇15%、市場が国の中に閉じる） | TRD では起きなかった |

## 20-2. 勝利条件と金銭的な報酬を分ける

ここで進めたい方向は、**国をまたいで協力すること自体が、戦略と選択肢になる設計**です。外部からお金を足すことは前提にしません。

18章の COOP は「届いた1単位ごとに、外から報酬を足す」仮の規則でした。この方向の検査としては、**TRD（報酬なしで国をまたぐ取引を許す）**と、①が作る勝利条件の形のほうが近い。COOP の結果は「報酬の配り方で起きる問題（水増し、配り直し）」の確認としてだけ使います。

### 5つの項目を分ける

| 項目 | 何か | 既存の決まり | 協力型で変わりうること |
|---|---|---|---|
| **共同達成** | 複数の国・人が一緒に満たす勝利条件または目標 | なし（新規） | ゲームの目標として足せる。賞金の規則を変えなくても成り立つ |
| **国・個人の目標** | 各国・各人の、それぞれの目標 | 国の勝敗は「勝敗の砦をどれだけ長く持ったか」（文書23、25） | 国の目標を砦と並べるか、置き換えるか |
| **得点** | 目標の進み具合や順位を表す数 | 国の勝敗の数え方（文書23） | 得点を賞金につなげない表示だけにもできる |
| **資源の獲得** | ゲームの中の物・建物・権利・札 | 札は物と権利だけを表し、賞金の取り分を表さない（文書25、99） | 協力の成果として、ゲームの中の物や権利を得る。賞金とは別の得 |
| **賞金の配分** | 本物のお金の配り方 | 賞金の倉 → 戦期ごとに国へ（砦の保持時間で） → 国の中は文書28の5項目で（文書25、28、99） | 変えない、または変える（下の表） |

### 文書28などとの衝突：何を変えたら、どの決まりと衝突するか

| 変更 | 衝突する既存の決まり | 衝突しない理由・注記 |
|---|---|---|
| 共同達成・国際的な目標を、ゲームの目標や得点として足すだけ | **なし** | 文書28は国の中の賞金の取り分だけを決める。目標の追加は賞金の規則の変更を必須にしない |
| 協力の成果を、ゲームの中の資源・権利として与える | **文書28とはなし。** 文書25の守るべき線（札が賞金の取り分を表さない、発行で払わない）は守る必要がある | ゲームの中の物を作ることは、本物のお金の発行ではない。ただし、その物が賞金の取り分の代わりになる形は避ける |
| 他国の人への販売・輸送を、国の中の賞金の取り分に数える | **文書28 §3「国の外への武器商売」は数えない、§3「売った量・送った量」は数えない、§1「国の戦いで消費されたものだけ」** | 変えるなら文書28の採用済みの決定を変える |
| 他国から買った物が自国の勝敗の砦で消費された分を、その物を出した倉の持ち主に数える | **衝突しない（すでに文書28 §2 の3で数えられる）** | 最後に戦いへ物を出した倉で数える。他国の作り手は国の取り分を持たない（文書28 §3） |
| 国への賞金の配分に、共同達成を加える | **文書25「国への配分」（砦の保持時間で分ける）、文書23「国の勝敗」**。文書28ではない | 国どうしの配分の変更 |
| 共同達成に、国をまたいで賞金を配る | **文書25・99 の「戦期ごとに国へ、国の中は確かめられる行いで」**。国に属さない配り方になる | 新しい配分経路の追加 |
| 共同の報酬を外から足す（または発行する） | **文書99・25「発行で払わない」「価値の出どころを示す」**。このとき、外からお金を足さないという今回の前提とも食い違う | 18章の COOP はこれに当たるため、方向の検証には使わない |

## 20-3. 二重計上の定義の訂正

18章の「1単位を共同・国・各人の目標にそれぞれ数えると、計上数は1単位あたり5」を**二重計上の悪用として扱ったのは誤り**でした。同じ行為が複数の目標に寄与することは、設計によっては意図したものです。

| 区別 | 中身 | 扱い |
|---|---|---|
| **同じ資源・受取権の二重使用** | 同じ1つの物を2回消費する。同じ受取権（札、預かりの証）で2回受け取る | 常に不正。チェーンの状態で防ぐ必要がある |
| **同じ報酬枠からの重複支払い** | 1つの報酬枠が、同じ成果に別の名目で2回払う | 意図して定めた場合を除いて不正 |
| **複数の目標への正当な寄与** | 1回の配送が、共同の目標・国の目標・個人の目標を同時に進める | 設計の選択。それだけでは不正ではない |

模型が測った「1単位あたりの計上数」は3つ目だけを数えたものです。悪用になるのは、計上の数がそのまま別々の支払いになり、1回の行為で払いが目標の数だけ増える場合です。

**比較案（どれも採用ルールではない）：**

| 案 | 中身 | 得るもの | 失うもの |
|---|---|---|---|
| C1 全部に数える | 各目標の進み具合に、それぞれ全部を数える | 1つの行いが多くの目標をつなぐ。協力の動機がわかりやすい | 報酬が目標ごとに別の枠から出ると、払いが増える |
| C2 合計を1に分ける | 1単位の計上を、目標の間で分ける（模型の `creditMode: once`） | 払いが増えない | 1つの行いの手応えが薄くなる。分け方を決める必要がある |
| C3 進み具合は全部、払いは1回 | 進み具合には全部数え、報酬はどれか1つの枠から1回だけ払う | 両方の性質を持つ | どの枠から払うかの規則が要る |

## 20-4. 実際の配送と貢献を分ける

18章では「取引件数ではなく、実際に届いた単位で見分けられた」と書きました。これは**模型の中での区別**です。

- 模型では、買い手は価値が費用を上回るときだけ買い、需要には上限がある。だから届いた単位は、必要な物と同じになる。**これは仮定です。**
- 実際には、要らない物を送り合えば、配送量も水増しできます。配送量は取引件数より水増ししにくいだけで、貢献の証明ではありません。

**①への判断項目（21章にも載せる）：**

1. その配送は、**何の需要や目標**を満たしたのか。
2. **誰が依頼し、誰が受けた**のか（依頼と受諾の記録を残すか）。
3. 数えるのに、**消費または利用**が要るのか。要るなら、何を消費・利用とみなすか。
4. **同じ成果の再利用**（同じ物を何度も送る、同じ建物の利用を何度も数える）をどう扱うか。

消費の対象は、戦闘での消費だけに限りません。建設、施設の稼働、燃料、共同の目標の進み具合なども候補です。文書28は国の中の賞金の取り分について戦闘での消費に限ったが、協力の価値をそれだけにする理由にはなりません。

### 本人の見分けについて

- 18章の「別の本人どうし」で数える指標は、模型が全てのアカウントの持ち主を知っているから計算できる**評価用の情報**です。
- 本番で、ウォレットから本人を見分けられる保証ではありません。1人が複数のウォレットを持つことは、ふつうは見えません。
- 本人確認の導入を既定の路線にはしません（12章：本人確認には重い負担と抜け道がある）。本番では、本人を見分けなくても水増しの得が小さくなる規則（数える対象を消費・利用に限る、払いの上限など）を先に比べる必要があります。

## 20-5. 統計の説明の補足と、表現の訂正

### 何を1件と数えたか

| 項目 | 中身 |
|---|---|
| 1件 | 1つの条件（セル）× 1つの規則の組 × 1つの指標の、seed ごとの対の差の平均 |
| 条件 | 33（7ケースと、その変形・感度） |
| 規則の組 | TRD−CMP、COOP−TRD、COOP−CMP の3つ。COOP−CMP は `summary.json` にだけあり、`RESULTS.md` の表にはない |
| 指標 | 51種類（条件ごとに一部がない）。単位は指標ごとに違う（割合、人数、日数、HHI、比） |
| 比較の総数 | 2,493件 |
| 検定 | 30 seed の対の差の平均について、パーセンタイル・ブートストラップの95%区間（4,000回）。区間が0を含まなければ「有意」（両側でおよそ5%の水準に当たる） |
| 多重比較 | **補正していない。** 2,493件は互いに独立でもない（同じ seed、相関する指標）。偶然で有意になるものが含まれうる |
| ばらつきが0の差 | 有意とした差のうち 284件は、30 seed 全てで差が同じ値だった（模型がその条件では決定的）。区間は幅0で、「有意」に意味はない |

### 訂正：1,501件と22件

報告した「有意な差1,501件のうち1,479件が再現、食い違った22件はどれも大きさ0.01未満」は、数え方の説明が不足し、一部が誤りでした。

| 数 | 中身 |
|---|---|
| 1,487 | seed 1〜30 で有意 |
| 1,493 | seed 101〜130 で有意 |
| **1,501** | どちらか一方で有意（和集合） |
| **1,479** | 両方で有意で、向きが同じ。両方で有意で向きが逆のものは0件 |
| **22** | 一方だけで有意（seed 1〜30 だけ：8件、seed 101〜130 だけ：14件） |

- **誤り：** 22件のうち21件は大きさ0.01未満でしたが、1件（`equal-reluctant` の COOP−TRD、選べた担い手の数）は 0.117 でした。
- **訂正：** 22件はいずれも、その条件の指標の水準の5%未満でした（最大は `equal-leave-relative` の採掘の HHI で、水準 0.08 に対して 0.0039、約4.9%）。
- 「0.01未満なら小さい」は、指標の単位によって意味が変わります。人数の指標（約30人）と HHI（0〜1）を同じ基準で比べたのは不適切でした。

### 再現の意味

- 同じ模型と同じ仮定を別の seed で回した再現は、**模型の中で答えが乱数に左右されないこと**を示すだけです。実際の人の行動に対する妥当性は示しません。
- 18章の主な差の多く（例：`equal` の届いた割合 +0.70、依存 −0.44）は、30 seed 全てでほぼ同じ値でした（届いた割合は完全に同じ）。これも、その条件で模型がほぼ決定的だったことを意味し、頑健さの証拠ではありません。

### 実質的に重要な差の判断

- 協力の検査器では、**実質的に重要な差の基準を前もって決めていません。** 18章で結論に使ったのは、指標の水準に比べて大きい差（届いた割合 +0.70、依存 −0.44、独占者を通る割合 0.76 など）と、20-1 で仮定を変えても向きが変わらなかったものです。
- 有意でも水準の数%以下の差は、実質的な差がないものとして扱いました。
- ①の候補と比べる前に、指標ごとに「これ以下なら差がないとみなす大きさ」を決めておくことを、21章の手順に入れます。
