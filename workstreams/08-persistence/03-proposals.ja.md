# 3. 比較案（最大3案）と推奨

**この章の位置づけ：** 3案はどれも候補であり、採用済みではありません。P0 は比べるための現行の形で、案ではありません。数字は5章（30 seed、2組の seed）から引いています。

## 3-3. 推奨：B を、条件つきで次の検証の対象にする

**推奨の中身：** B「世界は続き、戦争・軍・地域を区切る」を、次の検証（試遊と、より詳しいモデル）の対象にします。C は推奨しません。A は、B が試遊で失敗したときの代わりとして残します。

**理由：**

1. **築いた物の意味を残せる案は、B と C だけ。** 方針（文書15、23）の核は、施設・倉・仕組みが積み上がることです。A はそれを捨てます。
2. **B と C のうち、先行者の固定を抑えられたのは B だけ。** ただしそれは、区切りで**軍を解散する**ときに限ります。
   - 解散なしの B では、首位の連続率が 0.68 で、C と同じでした。
   - 解散ありでも、seed の組によって、P0 と同じ（0.40 対 0.44）だったり、P0 より悪かったり（0.51 対 0.34）しました。
3. **敗者と復帰者の道が、P0 より悪くならない。**
   - 本拠が残るので、敗北から約37時間で作戦に戻れます。
   - 世界が続くので、復帰しても待たずに加われます。

**推奨の確からしさ：** 中程度です。順位は、行動モデル3種と感度の条件20種で、ほぼ変わりませんでした。一方で、B が P0 と比べて固定を「同じ程度」に抑えるのか「やや悪い」のかは、seed の組で変わりました。最も大きく結果を変えうる仮定は「負け続けた人はやめない」で、モデルでは確かめていません（5-4）。

## 3-6. 他の案を推さない理由

- **A を推さない理由：**
  - 新人・公平さ・固定の数字は最も良い。
  - しかし、施設と経済の持ち越しを毎回0にする。これは、設計の核（積み上がる世界）と正面から食い違う。
  - また、区切りのたびに輸送中・預け入れ中の物が失効する（7章）。
  - 試遊で、B の偏りが新人をやめさせると分かった場合の代わりとして残す。
- **C を推さない理由：**
  - 復帰と権利の扱いは最も単純で、最も良い。
  - しかし、先行者の固定がすべての条件で最も強い。先に強い国がある条件で 0.77、勝ち馬に乗る動きがあると 0.80。
  - 建て直しの保護は、複数アカウントと組み合わせると制限が効かない。
  - 「先行者だけで未来が決まらない」という目的を満たさない。

## 3-7. 決める前に確かめたいこと

1. 区切りで軍を解散させるのは、遊びとして受け入れられるか。築いた軍を失う不満と、次の単位を公平に始める利点のどちらが大きいか（8章 W2）。
2. 新人の重みが 0.20 でも、新人が「自分の貢献に意味がある」と感じるか（8章 N2、N3）。
3. 解散の強さ（畑1つにつき兵2）と、施設の費用の伸びを、フェーズ6でどう決めるか。モデルでは、伸びを1.2にすると偏りが約3割縮んだ。
