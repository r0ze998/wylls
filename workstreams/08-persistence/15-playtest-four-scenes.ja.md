# 15. 試遊案：新規参加・敗北・復帰・区切り直前の4場面

**目的：** 世界全体を長い期間動かす前に、4つの場面それぞれについて、人が次の3つを確かめます。

- 何が起きたかを**理解できる**か
- 何を**失ったと感じる**か
- 次に何を**自分で選べる**か

モデルは「人が負けてもやめない」と仮定しています。その仮定を人で確かめる、最初の機会でもあります。

**この文書がしないこと：**

- 外部の参加者は募集しない。参加者は、チームの内部と、すでに声をかけている協力者に限る。
- 本番の期間・資源量・ルールは変えない。
- 試遊甲（`docs/frontier/playtest-kou/`）の手順も変えない。この案は、試遊の担当がそのまま使うか、甲に追加の観察として組み込むかを選べる形にしてある。
- 採用・不採用を決めない。どの案（P0、A、B1、B2、C）の場面も、**運営がカードと台帳で再現する**。コードは作らない。

## 15-1. 形式

| 項目 | 案 |
|---|---|
| 人数 | 1場面あたり4〜6人。同じ人が複数の場面を体験してよい。ただし、同じ場面を案違いで続けて体験させない（順番の影響を避けるため） |
| 時間 | 1場面30〜45分（説明5分、操作15〜20分、聞き取り10〜15分） |
| 再現の方法 | 運営が、場面の直前の状態を、試遊甲の S1 の画面と、段階2のカード・台帳で用意する |
| 比べる案 | 各場面で2案。B2 と A を基本にし、場面によって B1（既存決定）または P0（現行）を加える。案の名前は参加者に見せない |
| 記録 | 画面の記録、運営のメモ、聞き取りの録音（本人の同意があるとき）。個人を特定できる情報は記録しない |
| 観察する人 | 運営とは別の人 |

## 15-2. 場面ごとの台本

### 場面1：新規参加（単位の途中から入る）

- **用意：**
  - 単位の5日目の世界。古参の村は、畑8〜12、兵60〜120（モデルの B 系での目安）。
  - 本人の村は、畑2、兵10、物資200。
  - 国は次の作戦を、2時間後に開く。
- **案の違い：**

  | | B2 | A |
  |---|---|---|
  | 古参の倉と軍 | 残っている | 少ない（同じ単位の5日目まで） |
  | 本人の初期物資 | 200 | 追いつきの上乗せあり（最大4倍） |

- **操作：** 自由に始めてもらう。作戦が開いたら、加わるかどうかは本人に任せる。
- **聞くこと：**
  1. 今、自分にできることは何だと思うか（自由回答。運営は選択肢を出さない）。
  2. 自分の荷や兵は、作戦に意味があったと思うか（1〜5）。その理由。
  3. 古参との差を見て、どう感じたか（1〜5：続けたい〜やめたい）。
  4. 明日もう一度入るなら、何をするか。
- **見ること：**
  - 最初の操作までの時間。
  - 作戦に加わったか。加わり方は5種類のうちどれか。
  - 画面のどこを見て迷ったか。

### 場面2：敗北（前哨と倉と守備兵を失った直後）

- **用意：** 本人の前哨が奪われ、倉が空になった直後の状態。本拠と畑2つ、兵の半分が残る。
- **案の違い：**

  | | B2 | B1 | A |
  |---|---|---|---|
  | 区切りまで | 2日 | 2日 | 2日 |
  | 区切りで相手の軍は | 解散する | 解散しない | 世界ごと消える |

  - B2 では、自分の兵も解散を受ける（畑1つにつき兵2まで）。
  - A では、自分の記録と身元だけが残る。
- **聞くこと：**
  1. 何を失い、何が残ったかを、自分の言葉で説明してもらう。運営の台帳と照らして、正しさを記録する。
  2. 次に何をするか。答えるまでの時間を測る。
  3. 区切りで相手の軍が解散する、または世界が消えることを、公平と感じるか、どうでもよいと感じるか（1〜5）。
  4. このまま続けるか、国を移るか、やめるか。
- **見ること：** 敗北から次の操作までの時間。最初の操作の種類（建て直し・作戦への参加・移籍・何もしない）。

### 場面3：復帰（10日ぶりに戻る）

- **用意：** 本人が10日いない間に、休眠（5日目から）と襲撃が起きた状態。
  - 用意する記録：Herald の出来事の一覧に相当するもの。誰に、いつ、何を奪われたか。
- **案の違い：**

  | | 戻った時点 |
  |---|---|
  | B2 | 同じ単位の終盤 |
  | A | 不在の間に区切りが来て、新しい世界の2日目 |

- **聞くこと：**
  1. 不在の間に何が起きたかを説明してもらう。台帳と照らして、正しさを記録する。
  2. 何を失ったと感じるか。それは「自分のせい」か「仕組みのせい」か。
  3. 戻った最初の30分で、何をするか。
  4. 世界が作り直されていた方が戻りやすいか（A を体験した人にだけ、終わった後に B2 の状態も見せて聞く）。

### 場面4：区切りの直前（残り6時間）

- **用意：** 区切りまで6時間。本人について、次の状態を用意する。
  - 作戦に向けた荷が道の上にある。
  - 砦に物資を積んである。
  - 段階2の預かりの札を1枚持っている。
  - 兵は、本拠の守りの上限の3倍いる（B2 の場合）。
- **案の違い：**

  | | 区切りでどうなるか |
  |---|---|
  | B2 | 解散があり、砦の物資は国の倉へ移る |
  | B1 | 解散はなく、砦の物資は国の倉へ移る |
  | A | 世界ごと消える。区切りをまたぐ出発は止められている |

- **聞くこと：**
  1. 区切りで、道の上の荷・砦の物資・預かりの札・兵が、それぞれどうなると思うか。運営のカードに書いた規則と照らして、正しく理解できたかを記録する。
  2. 残り6時間で何をするか。駆け込みの攻撃、物資の引き出し、他人への譲渡など。
  3. 区切りの後で、何を失ったと感じたか。それは予想どおりだったか。
- **見ること：**
  - 駆け込みの行動の種類と量（5章 rush48 の仮定と比べる）。
  - 他国への移転（5章の「区切り直前の移転」）が起きるか。

## 15-3. 結果の読み方（事前に決めておく）

- この人数では、統計的な差は出ません。「理解の誤り」「迷い」「不公平の感じ」「やめたいという発言」を、**種類ごとに数えて**記録します。
- 次のどれかが半数以上の人に起きた場面は、その案の設計を見直す材料にします。
  - 何を失ったかを誤解した。
  - 次の行動を、5分以内に言えなかった。
  - 「やめたい」と答えた（1〜5の1か2）。
- **モデルの仮定と照らす項目：**
  - 負けた人や遅れた人がやめるか。モデルの離脱の格子（5-7）のどの家族に近いか。
    - 他人と比べて遅れている（relative）
    - 自分の最高から落ちた（decline）
    - 世界のリセットを自分の損と感じる（dec15k）
  - 区切りの直前に駆け込むか。

## 15-4. 試遊の前に決めること（試遊の担当へ）

- 試遊甲の実施の後に置くか、甲の観察項目に混ぜるか。
- 用意する状態の数値（畑・兵・物資）。この文書の数値は、モデルの値から取った目安。
- 録音と記録の同意の取り方。
