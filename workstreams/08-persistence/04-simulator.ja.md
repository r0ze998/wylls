# 4. 小型シミュレーター

`sim/` にある、依存ライブラリなしの Node.js（ESM）のモデルです。リポジトリの既存の戦略シミュレーション（`permutation-state-prototype/*`）と同じく `node --test` でテストします。

**最初に断っておくこと：** エージェントは、**仮定した行動モデル**です。実際のプレイヤーがどう動くかの予測ではありません。結果は「この仮定の下で、案どうしの差がどちらに出るか」を見るためのものです。

## 4-1. なぜ既存の `frontier-sim` を使わないか

`frontier-sim`（Rust）は、本物のルールの部品を使って**1つのシーズン**を回すものです。⑧で比べたいのは、シーズンや戦期をまたぐ持ち越し・再参加・区切りの扱いです。これらは現在のコードにない（1章）ので、`frontier-sim` を変えないと表せません。他担当のコードを変えないため、構造だけを抽象化した別のモデルを作りました。そのため、資源量や戦闘の数値は本番と対応しません（6節）。

## 4-2. 再現手順

```sh
cd workstreams/08-persistence/sim
node --test ./*.test.mjs        # テスト 20件（約10秒）

# 結果の再生成（群ごとに別の出力。並べて走らせてよい。1群あたり数分〜約40分）
node run.mjs --seeds 30 --only core        --out ../results/core
node run.mjs --seeds 30 --only exploits    --out ../results/exploits
node run.mjs --seeds 30 --only sensitivity --out ../results/sensitivity
node run.mjs --seeds 30 --only retention   --out ../results/retention
node run.mjs --seeds 30 --first-seed 101 --only core --out ../results/replication-seeds101-130
```

**出力（群ごと）：**

| ファイル | 中身 |
|---|---|
| `summary.json` | 各指標の平均・分位点。対になった差の統計。逆転の判定 |
| `RESULTS.md` | 表 |
| `per-seed-core-standard-mixed.csv` | 主比較の seed ごとの値。core だけ |

同じ引数なら、同じ出力になります（テストで確認）。

シーズン終了時の再現テスト（11章）は、別の手順です：`repro/run.sh`。Agave 3.1.9 が要ります。

**初期配置の比較（16章）：** `placement.mjs` を使います。地理の層（`geo.mjs`）は、ここでだけ有効になります。

```sh
for g in main distance populations robustness interaction localops; do
  node placement.mjs --seeds 30 --only $g --out ../results/placement/$g
done
node placement.mjs --seeds 30 --first-seed 101 --only main     --out ../results/placement/replication-seeds101-130/main
node placement.mjs --seeds 30 --first-seed 101 --only localops --out ../results/placement/replication-seeds101-130/localops
```

## 4-3. 構成

| ファイル | 中身 |
|---|---|
| `rng.mjs` | 乱数。値は (seed, 用途, 鍵…) の関数で決まり、順番に引くことはない。だから同じ seed なら、案が違っても同じ出来事に同じ目が出る（共通乱数） |

| `paired.mjs` | 対になった差の統計（ブートストラップ） |
| `geo.mjs` | 初期配置の比較用の地理：州の格子（コードと同じ環とくさび）、配置の規則（PL-W、PL-G、PL-S）、道の危険、出現した時点の条件。既定では無効 |

## 4-4. 世界の動き（1ティック＝1時間）

1. **区切り**（単位の長さごと）：案ごとの処理をする（3章）。直前の状態を記録する。
   - B1 と B2 では、作戦や砦に届けた物は国の倉へ移る。道の上の荷は送り主へ戻る（7章）。
   - B2 では、そのうえで兵を解散する（10章）。
   - 国の倉の物資は、その国の次の攻撃の補給に使われる。
2. **参加と建て直し**：参加を予定していた人や、敗北して待っていた人が村を作る。場所は内側・国境・外の環。現在のコードと同じ形で、ある国の埋まり具合が θ（最初の3日は55%、その後は65%）を超えると、外の環が開く。
3. **経済**：畑が1時間ごとに生産する。集めないと12時間分で止まる。兵の維持費と、案によっては規模の維持費を、まず未回収分から、次に倉から払う。5日間何もしないと休眠し、生産が半分になって保護が消える（現在のコードと同じ）。
4. **国の共同作戦**：各国は1日1回、決まった時刻に作戦を開く。6時間の受付の間にオンラインの人が加わる。加わり方は5種類：
   - 補給の荷車（40以上）
   - 兵（5以上）
   - 護衛（兵3以上。荷車が奪われにくくなる）
   - 見張り（塔がある）
   - 工作（工房がある）
   
   荷と兵は移動時間をかけて届く。作戦は、最も遠い村からの行軍が着いた時点で決着する。攻撃なら砦の守備と比べ、守りなら守備隊に加える。
5. **襲撃**：オンラインの人が、行動モデルの確率で他国の村を襲う。保護中の村は襲えない。現在のコード（P0、A）では、保護中の村からは襲えない。設計文書19（B1、B2、C）では、襲うと自分の保護が切れる。成功すると、運べる量か、守られていない在庫の半分の少ない方を奪う。守備兵がいなくなるまで負けると、確率で「敗北」になる。敗北の扱いは2種類：
   - 本拠は残り、前哨・在庫・兵の半分を失う（P0、A、B1、B2）
   - 村ごと消え、建て直す（C）
6. **荷車の横取り**：オンラインの襲撃者の多さに応じて起きる。護衛の数で確率が下がる。
7. **砦の保持**：保持した国に1時間ごとに得点が入る。守備隊は補給を消費し、補給が尽きると少しずつ減る。
8. **やめる・戻る・接続を減らす**（仮定。既定ではどれも0）：
   - 1日1回、人間ごとに判定する。
   - やめた人は接続しない。続く世界では、村は残って休眠する。
   - 戻る人は、7〜21日後に戻る。村がなければ建て直す。
   - やめる理由の家族は、5-6 を参照。

**行動モデル**（`BEHAVIOURS`）：

| 型 | 作戦に出す兵 | 襲撃の確率 | 畑あたりの兵 | 作戦に出す物資 |
|---|---|---|---|---|
| 協力型（coop） | 50% | 4% | 6 | 40% |
| 襲撃型（raider） | 25% | 35% | 10 | 15% |
| 籠城型（turtle） | 10% | 1% | 5 | 10% |

型の混ざり方は3通りで試す：

- mixed：協力60%、襲撃25%、籠城15%
- coop：協力85%、襲撃5%、籠城10%
- raider：協力35%、襲撃50%、籠城15%

人間の接続は1日1〜12回で、毎日±2時間ずれ、15%の確率で休む。AI と代理つきの人は、毎時間行動する。チェーン上の上限（1時間30回）は人間と AI で同じで、このモデルではどちらも上限に届かない。

## 4-5. 測るもの

定義・分母・期間・集計単位は9章にまとめました。比べ方は次のとおりです。

- 全案を、同じ seed 30本で回します。
- 平均と10%点〜90%点に加えて、**同じ seed どうしの差**の分布と、95%ブートストラップ区間を示します。
- 一つの seed や一つの行動モデルでは判断しません。

## 4-6. このモデルが表さないもの（限界）

- 資源の種類、兵の種類、戦い方の型、地形、封じた進軍、見張り塔の zk、札の細かい規則。物資は「物」の一種類にまとめた。
- 国の中の投票、追放、外交の構え。国どうしは常に敵対している。
- 本物の地図の距離。距離は「内側・国境・環」の3段階と、地域ごとの国の倍率で表す。
- 人の学習、怒り。離脱・復帰・接続低下は、**仮定の家族を入れ替えて**試しただけです（5-6）。どの家族が現実に近いかは分からず、それによって A と B2 の順位が動きます。
- 兵への愛着。このモデルでは、兵は資産の小さな部分です（兵1＝物資5）。そのため、解散が「自分の損」として効きにくい（10章）。
- 代理（AI）の費用。代理つきの人は、無料で毎時間動ける（14章）。
- 賞金・お金。このモデルには通貨も報酬もない。「国の勝ち」は砦を持った時間だけで測る。

## 4-7. テスト（`sim.test.mjs`、25件）

| テスト | 確かめること |
|---|---|
| 決定性 | 同じ seed なら測定結果が完全に同じ。違う seed なら違う |
| 乱数 | 鍵で決まること、偏りがないこと |
| 保存則 | 毎時間、世界にある物資（村・道・作戦・砦・国の倉）＝帳簿。帳簿は次の合計：<br>初期配布＋払い戻し＋生産−消費−維持費−失効−区切りでの消去<br>全5案×6シナリオ。離脱・復帰・駆け込み・別村の費用・払い戻しを入れた状態で確かめる |
| 保護 | 保護中の村は襲われない |
| P0 の攻撃制限 | 保護中の村からは襲えない（`Shielded` と同じ） |
| P0 の締切 | 10.5日目以降に参加を決めた人は、次の単位の開始まで待つ |
| P0 の保護時間 | 初日は24時間。12時間より後に来た人は24＋36時間 |
| 敗北 | P0、A、B1、B2 では本拠が残る。C では村が消え、12時間後に保護48時間つきで建て直す |
| 区切り | P0 は全員が作り直す。B1 と B2 は砦が中立になり、守備兵が帰り、施設は残る。B1 は解散しない。B2 は本拠の守りまで解散する。C は砦の持ち主がそのまま |
| 履歴 | 世界が戻る案でも、履歴は区切りを越えて残る |
| 接続 | AI は毎時間、人間は予定の回数だけオンラインになる |
| 境界の権利 | P0 は失効する。B1 は道の上の荷を送り主へ戻す。C は失効しない |
| 砦の物資の所有 | 4つの扱いが、それぞれ書いたとおりに動く：<br>・国の倉へ<br>・中立の砦に残す<br>・失われる<br>・送り主へ |
| 離脱と復帰 | 敗北でやめた人は、建て直さない。戻る人は7〜21日後に戻って、建て直す。やめた人はオンラインにならない |
| 露出 | 接続の多い人ほど、受付中に接続している |
| 対の統計 | ブートストラップが決定的で、区間が平均を含む |
| 資産の数え方 | 畑を建てても資産が変わらない（建て直しの費用で数える） |
| 別村の費用 | 費用を全額払えるまで、別の村は作られない |
| 集計 | ジニ係数、分位点（∞を含む）、HHI |
| 表 | 小さな実験から表を書き出せる |
| 地理：州の格子 | 環 d に 6d 州、環2〜3の各くさびに5州、sextant がコードと同じ、目標が6つのくさびに1つずつ |
| 地理：配置の規則 | PL-W は自国のくさび、PL-G は同国の集団（k 人以下）、PL-S は1国が複数のくさびに散る。州の定員を守る |
| 地理：保存則と配置し直し | 3つの配置×3つの世界の構造で物資が保存される。世界を作り直す案では、全員が配置し直される |
| 地理：局地の作戦 | 局地の作戦では追加の作戦が開かれ、1国1作戦では開かれない |
| 地理なし | 既定の実行では、どの村も州を持たない（既存の結果に影響しない） |
