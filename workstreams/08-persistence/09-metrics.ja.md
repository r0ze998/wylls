# 9. 指標の定義、不確実性、組み込みと結果の区別

この章では、モデルの数字が「何を数えたか」を、分子・分母・期間・集計単位まで書き下します。そのうえで、その数字が何を意味しないかも書きます。

- コードの場所は `sim/metrics.mjs` と `sim/run.mjs` の `measure()`。
- 例の数値は説明のために作った値で、結果ではありません。結果は 5章と `results/` にあります。

## 9-1. 共通の前提

| 項目 | 内容 |
|---|---|
| 1回の実行 | 56日（14日×4単位）。1時間ごとに進める。6国 |
| 人口 | 各国に人間8人と AI 2体（初日から）。ほかに観察用の集団が各国4人：<br>・途中参加1<br>・終盤参加1<br>・10日不在1<br>・強制敗北1 |
| seed | 乱数の種。1つの seed＝1回の実行。全案が同じ seed の列（1〜30）を使う |
| 集計単位 | **seed ごとに1つの値**を作る（集団の平均、中央値、率など）。30個の値から、平均と10%点・90%点を出す |
| 差 | 同じ seed の2案の値の差。平均、95%ブートストラップ区間（seed を4,000回引き直す）、差の10%点・90%点、正・負・同じの本数を出す |
| 「資産」 | 倉の物資＋兵×5（訓練の値段）＋畑の建て直しの費用（n番目の畑は 60×1.35ⁿ）＋塔150＋工房250。<br>**改訂（2026-10-30）：** 前の版は畑を一律80と数えていた。そのため、畑を建てると資産が減って見えた。いまは、建てても資産は変わらない（テストで確認） |
| 「貢献」の値 | 届いた補給1につき1、届いた兵1につき5、護衛10、見張り10、工作40 |

## 9-2. 指標の定義

### 新規参加

**途中参加の最初7日の貢献比**（`mid.contrib7dRel`）

| 項目 | 内容 |
|---|---|
| 対象 | 途中参加の集団：各国1人、計6人。1日2回接続。第2単位の5日目（456時間目）に参加を決める |
| 分子 | その6人が、参加を決めた時刻から7日間（日単位で、その日の始まりが期間に入る日）に記録した貢献の値の、平均 |
| 分母 | 同じ7日間に、**初日から参加している1日2回の人**（各国2人、計12人）が記録した貢献の値の、平均。その時点でゲームをやめている人は除く |
| 単位 | seed ごとに、分子÷分母 |
| 例 | 新人が7日で、補給40を2回と兵5を1回出した：40＋40＋25＝105。同じ期間に、初日組が補給200を3回と兵30を2回出した：600＋300＝900。比は 105÷900＝0.12 |
| 意味すること | 新人の働きが、同じ接続回数の古参と比べて、量としてどれだけか |
| 意味しないこと | 新人が作戦に「関われたか」や「役に立ったと感じたか」。0.45 が 0.20 に下がるのは、新人の働きが減ったからではない。**古参の働きが、持ち越した畑と兵の分だけ大きくなったから**である（B1、B2、C では、分子はほぼ同じで、分母が大きい） |

**途中参加：参加を決めてから最初の貢献まで**（`mid.firstOpH`）

| 項目 | 内容 |
|---|---|
| 定義 | 参加を決めた時刻から、最初に貢献が記録されるまでの時間 |
| 単位 | 6人の中央値（seed ごと） |
| 打ち切り | 実行の終わりまでに貢献がなければ∞。中央値が∞の seed は「有限 k/30」で示す |

**途中参加：24時間後に実行できる貢献の種類**（`mid.kinds24`）

| 項目 | 内容 |
|---|---|
| 定義 | 参加から24時間後の在庫で、実行できる貢献の種類を数える（0〜5）：<br>・補給：物資40以上<br>・兵：5以上<br>・護衛：兵3以上<br>・見張り：塔がある<br>・工作：工房があり、物資40以上 |
| 注意 | オンラインかどうかは問わない。「やろうと思えばできること」の数 |

**終盤参加：村を持てるまでの待ち**（`late.waitToFoundH`）

| 項目 | 内容 |
|---|---|
| 定義 | 第2単位の12日目に参加を決めた人が、実際に村を作るまでの時間 |
| 例 | P0 では、締切（10.5日目）の後なので、次の単位の開始まで48時間待つ |

### 敗北

**敗北：失った資産の割合**（`defeated.lostFrac`）

| 項目 | 内容 |
|---|---|
| 対象 | 強制敗北の集団：各国1人、計6人。1日2回、協力型。第2単位の4日目に、強制的に敗北させる |
| 定義 | （敗北の直前の資産 − 直後の資産）÷ 直前の資産。6人の平均 |
| 例 | 直前：物資400、兵30（150）、畑6（建て直し費用 約560）、塔150 → 計 約1,260。<br>直後（本拠は残る）：物資0、兵15（75）、畑2（約141）→ 計 約216。<br>失った割合は (1,260−216)÷1,260 ≈ 0.83 |
| 意味すること | 敗北の瞬間に、自分の物のうちどれだけを失うか |
| 意味しないこと | 取り戻す難しさ。蓄積が大きい案ほど、分母が大きく、割合も上がりやすい。**同じ割合でも、蓄積が大きい案では、失う絶対量が大きい** |

**敗北：再び作戦に貢献するまで**（`defeated.toContribH`）

| 項目 | 内容 |
|---|---|
| 定義 | 敗北の時刻から、次に貢献が記録されるまでの時間 |
| 単位 | 6人の中央値 |

**敗北：以前の能力の50%に戻るまで**（`defeated.to50H`）

| 項目 | 内容 |
|---|---|
| 能力の定義 | 畑の数＋兵÷10＋物資÷100 |
| 定義 | 能力が、敗北の直前の半分に戻るまでの時間。中央値 |
| 注意 | 分母（直前の能力）が案ごとに違う |

### 復帰

**10日不在：不在中に失った資産の割合**（`returner.lossFrac`）

| 項目 | 内容 |
|---|---|
| 対象 | 各国1人。第2単位の2日目から12日目まで、接続しない |
| 定義 | （不在の始まりの資産 − 終わりの資産）÷ 始まりの資産。0未満は0とする |
| 注意 | P0 と A では、不在の途中で区切りが来ない（12日目に戻る）ので、世界の作り直しの影響は入らない |

### 集中と固定

**前の単位の首位国が、再び首位になる率**（`conc.winnerRepeat`）

| 項目 | 内容 |
|---|---|
| 首位 | 単位の中で、勝敗の砦を持っていた時間（国×時間）の合計が最も多い国 |
| 定義 | 4単位の間の3回の切り替わりのうち、前の単位と同じ国が首位になった回数 ÷ 3 |
| 値 | 1つの seed では 0、1/3、2/3、1 のどれか。粗い |
| 例 | 首位が 国2 → 国2 → 国5 → 国5 なら、2/3 ≈ 0.67 |
| 意味すること | 前の勝者が、次も勝つ傾向。6国が毎回無作為に勝つなら、期待値は約0.17 |
| 意味しないこと | 個人の固定。同じ国の中で、誰が働いたかは見ていない。また、国の顔ぶれは案にかかわらず続く。そのため、**世界を作り直す案でも0にはならない**（国の構成と、作戦の時刻の合い方が続くから） |

**最下位の国の、次の単位の砦シェア**（`conc.bottomNextShare`）

| 項目 | 内容 |
|---|---|
| 定義 | 単位 k で砦の時間が最も少なかった国が、単位 k+1 で持った砦の時間の割合。3回の切り替わりの平均 |
| 目安 | 均等なら 1/6 ≈ 0.17 |

**最初の単位の勝者の、以後のシェア**（`conc.firstWinnerLaterShare`）

| 項目 | 内容 |
|---|---|
| 定義 | 単位1の首位国が、単位2〜4で持った砦の時間の割合の平均 |

**資産のジニ係数**（`conc.lastGini`）

| 項目 | 内容 |
|---|---|
| 定義 | 最後の単位の終わりに、活動中のすべての村（人間と AI）の資産から計算する |
| 目安 | 0＝全員同じ、1＝一人がすべて |

### 接続と露出

**接続の貢献比**（`conn.relK`）

| 項目 | 内容 |
|---|---|
| 定義 | 初日組で、もともと1日 K 回接続する人の、全期間の1日あたり貢献 ÷ 1日12回の人の同じ値 |

| 単位 | 初日組、もともとの接続回数ごと |

**露出あたりの貢献**（`expo.perK`）

| 項目 | 内容 |
|---|---|
| 定義 | 全貢献 ÷ 露出の回数 |

## 9-3. 不確実性：何が独立で、何が独立でないか

| 比べ方 | 何を表すか | 何を表さないか |
|---|---|---|
| 30 seed の10%点〜90%点 | モデルの乱数（接続の時刻、行動の型、戦闘の目）が変わったときの、1回の実行のばらつき | 実際のプレイヤーのばらつき |
| 対になった差の95%区間 | 「このモデルとこの仮定の下で、2案の差の平均が、乱数を引き直してもどの範囲に入るか」 | 現実の差の範囲。区間が0を含まなくても、それは**モデルの中で安定している**というだけ |
| 正・負・同じの本数 | 30回のうち何回、片方が上回ったか。首位の連続率のような粗い指標では、「同じ」が多くなる | 個々の村の勝ち負け |
| 別の seed の組（101〜130）での再現 | 同じモデルを違う乱数で回しても、同じ向きの差が出るか（モデルの中での再現性） | 現実での妥当性。**同じ仮定を使う限り、何度回しても、仮定の誤りは消えない** |
| 行動モデル（mixed、coop、raider）と感度の条件 | 仮定を変えたときに結論が動くか（頑健さの確認） | 独立したプレイヤーの標本。同じ seed を使い回しているので、条件どうしは独立ではない。条件の数を「試行の数」として数えてはいけない |
| 1つの seed の中の村どうし | 同じ世界で互いに影響する | 独立な観測ではない。だから、村ごとの値を1つの seed の中で平均し、seed を単位にしている |

## 9-4. 組み込まれた規則と、相互作用から出た結果

### 接続の回数による貢献の差（1日1回の人は、1日12回の人の約1割）

**組み込みの部分（規則から直接決まる）：**

| 規則 | どう効くか |
|---|---|
| 貢献できる時間 | 自国の作戦の受付（6時間）の間に接続しているときだけ（予約の送りを入れた感度の条件を除く） |
| 接続の時刻 | 1日 K 回、毎日±2時間ずれる。15%の確率で休む |

この2つから、受付中に一度でも接続している確率は、ほぼ計算で決まります。

- 1日1回なら、約 6/24×0.85 ≈ 0.21。
- 1日2回なら、約0.43。
- 1日12回なら、ほぼ1。

モデルの露出の率は、この計算とほぼ一致します（実測：0.20、0.44、0.97）。つまり、**露出の差は、規則として組み込んだもの**です。発見ではありません。

**相互作用から出た部分：**

標準の条件で、露出1回あたりの貢献を比べました。

| 接続 | P0 | B2 |
|---|---|---|
| 1日1回 | 123 | 314 |
| 1日2回 | 261 | 723 |
| 1日4回 | 289 | 781 |
| 1日12回 | 242 | 664 |

- 1日2回以上なら、露出1回あたりの貢献は、1日12回の人とほぼ同じか、それ以上です。
- 1日1回の人だけが、約半分になります。生産は集めないと12時間分で止まるので、1日1回の人は生産の一部を捨てます。在庫も兵も少なくなります。
- これは、規則（12時間で止まる）と行動（集めて、建てて、訓練する）の組み合わせから出た部分です。

**合計の比の内訳：**

| 接続 | 露出の比 | 露出あたりの比 | 合計の比 |
|---|---|---|---|
| 1日1回 | 0.20÷0.97 ≈ 0.21 | 約0.5 | 約0.10 |
| 1日2回 | 0.44÷0.97 ≈ 0.45 | 約1.1 | 約0.49 |

**どう読むか：**

- 1日2回の人の差は、ほぼ全部が露出の差、つまり**組み込みの部分**です。
- 1日1回の人だけに、保管12時間の規則から出る追加の差があります。
- 「1日1回では1割しか貢献できない」は、受付6時間・保管12時間という**仮定の帰結**です。
- 仮定を変えると、比は変わりました（5章の感度。例：受付12時間で約0.2、保管24時間で約0.22、予約の送りで P0 は0.20、B2 は0.12）。
- この数字は、①の作戦の設計を検討する材料として渡します（13章）。案（A、B1、B2、C）の比較には使いません。案による差は、ほとんどありませんでした。

### 最初の共同作戦までの時間（約37時間）

**組み込みの部分：**
- 初期物資（物資200、兵10）で、最初から補給・兵・護衛の3種類ができる。
- そのため、最初の貢献は「最初に受付と接続が重なる時刻」でほぼ決まる。
- 1日2回の人では、重なる確率が1日あたり約0.44。だから、待ちは1〜2日になる。

**相互作用の部分：**
- 補給は届いた時点で数えるので、移動時間と横取りで遅れたり、失われたりする。
- 内側の村ほど遠い。

**どう読むか：** 案によって変わらなかった（5章）のは、この時間が、主に接続と受付の規則で決まるからです。案の効果ではありません。

### 先行者の固定（首位の連続率）

**組み込みの部分：**
- 国の顔ぶれと、作戦の時刻は続く。
- 世界を作り直す案でも、構成の強い国が勝ち続けることは起きる。

**相互作用の部分：**
- 持ち越した兵・畑・国の倉が、次の単位の最初の砦の取り合いに効くかどうか。
- これは、案の規則（解散するか、砦を中立にするか）と、行動（作戦に兵を出す割合）の組み合わせで決まる。

**粗さ：** 1つの seed には3回の切り替わりしかないので、値は 0、1/3、2/3、1 です。30 seed でも、区間は ±0.1〜0.15 の幅になります。

### 新規の継続率と人間の継続率

**組み込みの部分：** やめる理由そのもの（下の表）。

| 家族 | やめる理由 | 帰結 |
|---|---|---|
| relative | 中央値より貧しいほどやめやすい | 続く世界では、新人は必ず中央値より下から始まる。だから、**新人が多くやめるのは、この仮定の帰結** |
| decline | 自分の最高から落ちるほどやめやすい | 世界の作り直しを「自分の損」と数えるかで、結論が逆になる（dec15 と dec15k） |

**どう読むか：**
- どちらの仮定が現実に近いかは、モデルでは決められません。試遊で確かめます（15章）。
- 結論が「どの家族を仮定したか」で決まってしまう点そのものを、5章の主な発見として報告します。
