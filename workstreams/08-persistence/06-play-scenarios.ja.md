# 6. 新人・敗者・復帰者のプレイシナリオ

**目的：** 本人が「何が残り、何を失い、次に何を選べるか」を判断できるように、案ごとの筋書きを書きます。

- 筋書きは、次の検証の候補 B2（3章）で書き、ほかの案（P0、A、B1、C）で違う点を表に並べます。
- どの案も採用していません。
- 時間や割合は、抽象モデルの中央値・平均です（5章）。実際のプレイヤーで起きることの予測ではありません。

この章の「単位」は、競争の一区切り（いまは14日のシーズン、B 系では戦期）を指します。

---

## 6-1. 新人：ミナ（単位の5日目に参加、1日2回ログイン）

### 筋書き（B2）

- **0時間：** ミナは北の国を選ぶ。
  - 村は国の内側に置かれる。72時間は攻められない。ただし、自分から攻めるか、畑が6つになると、守りは切れる。
  - 画面には、自分の国がいまどの砦を狙っているか、その作戦が何時に開くかが出る（13章の要件）。
- **最初の作戦（モデルの中央値で約37時間後）：** ログインした時刻に作戦の受付が開いていた。初期の兵10のうち5を出し、荷車で物資40を送る。
  - この時間は、案ではほとんど変わらず、作戦の時刻と自分のログインの重なりで決まる（9-4）。
- **最初の7日：** ミナの貢献は、同じ1日2回の古参の約2割（モデルの7日貢献比 0.21）。
  - ミナの働きが少ないからではない。古参が、前の単位から持ち越した畑と兵の分だけ、多く働くから。
  - それでも、補給・兵・護衛の3種類の役目には、最初から加われる。
- **区切り（14日目）：** 砦は中立に戻る。古参の大軍も、ミナの兵も、本拠の守り（畑1つにつき兵2）まで解散する（10章）。
  - ミナの畑と倉は残る。古参の畑と倉も残る（資産の偏りは残る）。
  - 次の単位は、どの国の軍も小さい所から始まる。

### ミナが判断できること

| | 内容 |
|---|---|
| **残るもの** | 村・畑・倉。行い（貢献・取引・約束）の記録。所属 |
| **失うもの** | 72時間の守り（3日たつか、攻めるか、畑が6つになったとき）。区切りで、本拠の守りを超えた兵 |
| **次に選べること** | 1. 補給と護衛で、国の作戦に加わる（最初から可能）<br>2. 塔を建てて見張り役になる（モデルでは畑3つ以上、費用150）<br>3. 古参の工房に材料を売る（段階2の札があれば、見返りの約束を記録できる）<br>4. 国を移る（移る間は無防備。しばらくは再び移れない） |
| **判断の材料に示すべきもの** | 作戦の時刻と自分のログイン時刻の重なり。自分の貢献が作戦の結果にどう効いたか。区切りまでの時間と、解散の上限 |

### ほかの案では（モデルの値）

| | P0 現行 | A | B1 | C |
|---|---|---|---|---|
| 参加 | 10.5日目までなら可能。それより後は、次のシーズンまで待つ（終盤に来た人の最初の貢献まで107時間） | いつでも。単位の終盤ほど多い初期物資 | いつでも（B2 と同じ） | いつでも（B2 と同じ） |
| 最初の7日の重み（初日組＝1） | 0.45 | 0.55 | 0.20 | 0.21 |
| 区切りで | 全部消え、全員がやり直す | 全部消え、記録と身元だけが残る | 砦は中立、守備兵は家に帰る。古参の軍はそのまま | 何も戻らない |

## 6-2. 敗者：ケン（単位の4日目に、前哨と倉と守備兵を失った）

### 筋書き（B2。本拠は残る＝今のコードと同じ）

- **0時間：**
  - ケンの前哨は奪われ、倉は空になり、兵は半分になる。資産の約94%を失う（モデルの平均）。
  - 本拠の村と畑2つは残る。本拠は国の中心地にあり、攻められない。
- **約37時間（中央値）：** 残った兵で、国の次の作戦の護衛に加わる。「自分の作戦に、まだ役目がある」状態に戻る。
- **約163時間：** 敗北前の能力（畑＋兵＋物資）の半分に戻る。前の蓄積が大きかった分だけ、時間がかかる。
- **区切り：** ケンを負かした国の軍も、本拠の守りまで解散する。
  - 次の単位の砦の取り合いでは、兵の差は小さくなる。
  - ただし経済の差（畑と倉）は残る。

### ケンが判断できること

| | 内容 |
|---|---|
| **残るもの** | 本拠の村と畑2つ。兵の半分。負けたという記録（誰に、いつ）。国の仲間との関係。創作定義（仕組みの設計図） |
| **失うもの** | 前哨。倉の中身。守備兵。その単位の勝ち点への貢献。砦に積んでいた物資は国の倉に移り、ケンには戻らない（7章） |
| **次に選べること** | 1. 残った兵で、国の作戦の護衛・補給に加わる<br>2. 本拠で畑を建て直し、次の単位に備える（区切りで相手の軍も解散する）<br>3. 前哨を別の場所に建て直す（費用は戻らない）<br>4. 国を移る（移る間は無防備）<br>5. 自分の仕組みの設計図を、他人に使ってもらう |
| **判断の材料に示すべきもの** | 失った物の一覧。次の区切りまでの時間。区切りで相手の軍がどこまで減るか |

### ほかの案では（モデルの値）

| | P0 現行 | A | B1 | C |
|---|---|---|---|---|
| 失う割合 | 0.76 | 0.76 | 0.94 | 1.00（村が消える） |
| 再び作戦に加わるまで | 38時間 | 38時間 | 38時間 | 56時間（12時間後に建て直す。保護48時間。以前の畑の25%を引き継ぐ） |
| 次の単位 | 全員がまっさら | 全員がまっさら（記録は残る） | 相手の軍は解散しない。前の勝者が再び勝ちやすい（首位の連続率 0.59） | 何も戻らない（0.63） |

## 6-3. 復帰者：サラ（単位の2日目から10日間いなかった）

### 筋書き（B2）

- **不在の5日目：** 休眠に入る（今のコードと同じ）。生産が半分になり、保護も効かなくなる。
- **不在の間：** 前哨と倉が襲われる。モデルでは、不在の間に失う資産は平均で約66%。本拠と、倉の守られた半分は残る。
- **戻った日：** 世界は続いているので、すぐに自分の国の作戦が見える。戻ってから約53時間（中央値）で、作戦に加わる。
- この単位の砦の取り合いは、もう終盤になっている。次の区切りまでに、畑を立て直すか。今の作戦に残りの物で加わるか。

### サラが判断できること

| | 内容 |
|---|---|
| **残るもの** | 本拠の村。倉の守られた分。畑（襲われた前哨の分を除く）。所属。記録 |
| **失うもの** | 不在の間に襲われた物。休眠中に半分になった生産。この単位で砦を取り合う機会の一部 |
| **次に選べること** | 1. 今の単位の作戦に、残りの物で加わる<br>2. 次の区切りまで畑を立て直す（区切りで軍の差は小さくなる）<br>3. 休眠中に何が起きたかを記録で確かめ、誰に襲われたかを踏まえて、頼る相手を選び直す |
| **判断の材料に示すべきもの** | 不在の間の出来事の一覧（Herald の記録）。今の単位の残り時間 |

### ほかの案では（モデルの値）

| | P0 現行 | A | B1 | C |
|---|---|---|---|---|
| 不在をまたいで区切りが来た場合 | 新しい世界で、全員と同じ条件から始められる（**この点では P0 と A が有利**） | 同左 | 世界は続く | 世界は続く |
| 不在の間の損失 | 0.56 | 0.59 | 0.62 | 0.44（地下倉） |
| 戻ってから作戦に加わるまで | 58時間 | 56時間 | 52時間 | 43時間 |

## 6-4. 3人に共通して画面が示すべきもの（要件。実装は他担当）

1. **区切りまでの残り時間と、区切りで何が戻るか**：砦、守備兵、解散の上限。
2. **自分の失った物と、残った物の一覧**（敗北や不在の後）。届けた物が誰の物になったか（7章）も含める。
3. **自分の国の次の作戦の時刻**と、自分が加われる役目。補給・兵・護衛・見張り・工作のうち、今できるもの。
4. **区切りで自分の権利がどうなるか**（7章）：輸送中の荷、預けた物、予約。

---

## 6-5. やめるかどうか（モデルでは答えが出ない点）

この3人が、この後も続けるかどうかを、モデルは決められません。

- 「他人との差」でやめる人が多い世界なら、ミナのような新人は、B2 では A より多くやめます（5-6）。
- 「世界の作り直しは自分の損」と感じる人が多い世界なら、A でケンやサラの多くがやめます。

15章の試遊で、3人の立場に立った人に、直接たずねます。
