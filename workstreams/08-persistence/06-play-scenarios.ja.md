# 6. 新人・敗者・復帰者のプレイシナリオ

この章の目的は、本人が「**何が残り、何を失い、次に何を選べるか**」を自分で判断できるようにすることです。主な筋書きは推奨案 B で書き、ほかの案で違う点を表に並べます。時間の目安は、モデルの中央値（5章）です。実際の値ではありません。

この章の「単位」は、競争の一区切り（いまは14日のシーズン、B では戦期）を指します。

---

## 6-1. 新人：ミナ（単位の5日目に参加、1日2回ログイン）

### 筋書き（B）

- **0時間：** ミナは北の国を選ぶ。
  - 村は国の内側に置かれる。72時間は攻められない。ただし、自分から攻めると守りは切れる。
  - 画面には、自分の国がいまどの砦を狙っているか、その作戦が何時に開くかが出る。
- **〜37時間（モデルの中央値）：** ログインした時刻に作戦が開いていた。初期の兵10のうち5を出し、荷車で物資40を送る。
  - これが初めての共同作戦になる。
  - 内側の村からは、砦まで遠い。荷が着くのは決着の直前になる。
- **3日目：** 畑が6つになり、守りが切れる。
  - この頃のミナの貢献は、同じ時期の初日組の約2割。古参は畑も兵も多い。
  - それでも、補給の荷・護衛・見張りなど、5種類のうち3種類の役目には、最初から加われる。
- **14日目（区切り）：** 砦は中立に戻る。古参の大軍も、本拠の守りまで解散する。
  - ミナの畑と倉は残る。
  - 次の単位は、どの国の軍も小さい所から始まる。

### ミナが判断できること

| | 内容 |
|---|---|
| **残るもの** | 村・畑・倉。行い（貢献・取引・約束）の記録。所属 |
| **失うもの** | 72時間の守り（3日たつか、攻めたとき） |
| **次に選べること** | 1. 補給と護衛で、国の作戦に加わる（最初から可能）<br>2. 塔を建てて見張り役になる（モデルでは畑3つ以上、費用150）<br>3. 古参の工房に材料を売る（段階2の札があれば、見返りの約束を記録できる）<br>4. 国を移る（移る間は無防備。しばらくは再び移れない） |
| **判断の材料に示すべきもの** | 作戦の時刻と自分のログイン時刻の重なり。自分の貢献が作戦の結果にどう効いたか |

### ほかの案では

| | P0 現行 | A | C |
|---|---|---|---|
| 参加 | 10.5日目までなら可能。それより後は、次のシーズンまで待つ（モデルでは、最初の貢献まで107時間） | いつでも。単位の終盤ほど多い初期物資 | B と同じ |
| 最初の7日の重み（初日組＝1） | 0.45 | 0.55 | 0.21 |
| 区切りで | 全部消え、全員がやり直す | 全部消え、記録と身元だけが残る | 何も戻らない。古参の軍はそのまま |

## 6-2. 敗者：ケン（4日目に、前哨と倉と守備兵を失った）

### 筋書き（B、本拠は残る＝今のコードと同じ）

- **0時間：** ケンの前哨は奪われ、倉は空になり、兵は半分になる。資産の約86%を失う。
  - 本拠の村と畑2つは残る。本拠は国の中心地にあり、攻められない。
- **〜37時間（中央値）：** 残った兵で、国の次の作戦の護衛に加わる。
  - 「自分の作戦に、まだ役目がある」状態に戻る。
- **約161時間：** 敗北前の能力の半分に戻る。
  - 蓄積が大きかった分だけ、取り戻すのに時間がかかる。
- **区切り：** ケンを負かした国の軍も、本拠の守りまで解散する。
  - 次の単位の砦の取り合いでは、相手との差は軍の差ではなく、経済の差だけになる。

### ケンが判断できること

| | 内容 |
|---|---|
| **残るもの** | 本拠の村と畑2つ。兵の半分。負けたという記録（誰に、いつ）。国の仲間との関係。創作定義（仕組みの設計図） |
| **失うもの** | 前哨。倉の中身。守備兵。その単位の勝ち点への貢献 |
| **次に選べること** | 1. 残った兵で、国の作戦の護衛・補給に加わる（約37時間で可能）<br>2. 本拠で畑を建て直し、次の単位に備える（区切りで相手の軍も解散する）<br>3. 前哨を別の場所に建て直す（費用は戻らない）<br>4. 国を移る（移る間は無防備）<br>5. 自分の仕組みの設計図を、他人に使ってもらう |
| **判断の材料に示すべきもの** | 失った物の一覧。次の区切りまでの時間。区切りで相手の軍がどこまで減るか |

### ほかの案では

| | P0 現行 | A | C |
|---|---|---|---|
| 失う割合 | 0.68 | 0.68 | 1.00（村が消える） |
| 再び作戦に加わるまで | 38時間 | 38時間 | 56時間（12時間後に建て直す。保護48時間。以前の畑の25%を引き継ぐ） |
| 次の単位 | 全員がまっさら | 全員がまっさら（記録は残る） | 何も戻らない。勝った国の固定が最も強い（首位の連続率 0.63） |

## 6-3. 復帰者：サラ（単位の2日目から10日間いなかった）

### 筋書き（B）

- **不在の5日目：** 休眠に入る（今のコードと同じ）。生産が半分になり、保護も効かなくなる。
- **不在の間：** 前哨と倉が襲われる。モデルでは、不在の間に失う資産は平均で約66%。
  - 本拠と、倉の守られた半分は残る。
- **戻った日：** 世界は続いているので、すぐに自分の国の作戦が見える。
  - 戻ってから約51時間（中央値）で、作戦に加わる。
- この単位の砦の取り合いは、もう終盤になっている。
  - 次の区切りまでに、畑を立て直すか。今の作戦に残りの物で加わるか。

### サラが判断できること

| | 内容 |
|---|---|
| **残るもの** | 本拠の村。倉の守られた分。畑（襲われた前哨の分を除く）。所属。記録 |
| **失うもの** | 不在の間に襲われた物。休眠中に半分になった生産。この単位で砦を取り合う機会の一部 |
| **次に選べること** | 1. 今の単位の作戦に、残りの物で加わる<br>2. 次の区切りまで畑を立て直す（区切りで軍の差は小さくなる）<br>3. 休眠中に何が起きたかを記録で確かめ、誰に襲われたかを踏まえて、頼る相手を選び直す |
| **判断の材料に示すべきもの** | 不在の間の出来事の一覧（Herald の記録）。今の単位の残り時間 |

### ほかの案では

| | P0 現行 | A | C |
|---|---|---|---|
| 不在をまたいで区切りが来た場合 | 新しい世界で、全員と同じ条件から始められる（**ここだけは P0 と A が有利**） | 同左 | 何も戻らない |
| 不在の間の損失 | 0.54 | 0.56 | 0.51（地下倉。seed の組によっては P0 より多い） |
| 戻ってから作戦に加わるまで | 58時間 | 56時間 | 43時間 |

## 6-4. 3人に共通して画面が示すべきもの（要件。実装は他担当）

1. **区切りまでの残り時間と、区切りで何が戻るか**（砦、守備兵、軍の解散の上限）。
2. **自分の失った物と、残った物の一覧**（敗北や不在の後）。
3. **自分の国の次の作戦の時刻**と、自分が加われる役目（補給・兵・護衛・見張り・工作のうち、今できるもの）。
4. **区切りで自分の権利がどうなるか**（7章。輸送中の荷、預けた物、予約）。
