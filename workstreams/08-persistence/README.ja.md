## 結論の要約（詳しくは3章・5章）

1. **既存決定（B1：砦の中立化と守備兵の帰還）は、現行（P0）より、前の勝者が再び勝ちやすかった。**
   - 首位の連続率は 0.44 → 0.59。
   - 感度31条件のすべてで、同じ向きだった。
2. **⑧が加えた軍の解散（B2）は、その傾向を下げた。**
   - B2−B1 は −0.23（95%区間 −0.39〜−0.07）。感度31条件のすべてで、同じ向きだった。
   - B2 と A の差は、区別できなかった。
3. **蓄積を残すと、資産は偏り、新人の重みは下がる。** これは、すべての条件で起きた。
   - ジニ係数 0.23 → 0.35。
   - 途中参加の7日貢献比 0.55 → 0.21。
4. **A と B2 のどちらが人を残すかは、人がやめる理由の仮定で決まった。**
   - 他人と比べてやめるなら、A。
   - 世界の作り直しを自分の損と感じるなら、B2。
   - どちらが現実に近いかは、試遊で確かめる（15章）。
5. **接続回数による貢献の差は、大部分が作戦の受付の規則から直接決まる**（組み込み）。①の作戦の作りで変えられる（13章）。
6. **シーズン終了時の2つの疑いは、LiteSVM で再現した**（11章）。
7. **初期配置（16章）：このモデルでは、小集団型（PL-G）が現行型（PL-W）より良いとは言えなかった。**
   - 1国1作戦なら、まとまる配置が協力のほぼ全指標で有利だった。作戦が地域ごとなら、差の多くは消えた。
   - 散る配置は、国ごとの配置運（最も弱い国のシェアの低下）を生んだ。区切りのない世界（C）では、勝ち続けを弱めた（0.86 → 0.64）。
   - 中央の塔の効果は未確認のため、入れていない。
8. **協力型の勝利条件（18章、範囲と訂正は20章）：①の候補が未着のため、検査器と仮の規則で動作を確かめただけ。** 採用の可否、面白さ、国際協力が起きるかは言えない。下の多くは模型の仮定から直接生じた結果（20-1）。
   - 国をまたぐ取引で届いた割合が増えたのは、国の偏りを仮定したため。選べる担い手の増加（3.9 → 30.5）は、ほぼ規則の定義から。所有が偏ると、同じ取引が従属に変わった（独占者を通る割合 76〜100%）。
   - 外から足した共同の報酬は、仮定したためらいを上回るときだけ判断を変えた。外部からお金を足さない方向には当てはまらない（20-2）。
   - 取引件数で報酬を配ると、往復取引で水増しされた（規則の算術で、行動の仮定によらない）。
