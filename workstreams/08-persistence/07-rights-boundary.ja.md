# 7. 権利と更新の境界（②・④への要件と未決定事項）

⑧は、②の権利の仕様と④の Run を変更しません。ここに書くのは、世界や単位が切り替わるときに**満たしてほしい条件**と、**まだ決まっていないこと**です。

## 7-1. 原則：残すことと、使えることは別

- **履歴**（誰が何を預け、何を約束し、何を受け取ったか）は、切り替えをまたいで必ず残す。変えない、消さない。
- **行使**（その権利で物・兵・施設を受け取ること）は、権利が指している物が、新しい世界でも同じものとして続いている場合に限る。
- 世界が新しくなる場合（P0、A）、昔の権利で新しい世界の物を取れてはならない。新しい世界では、全員が同じ条件から始めるはずだからである。

## 7-2. いまのコードで起きていること（1-7章から）

| 対象 | 現在の動き | 問題 |
|---|---|---|
| 軍の移動 | 到着がシーズン内でないと出発できない | なし（終了をまたがない） |
| 隊商 | 出発時に終了の確認がない。終了をまたぐと決着できない［推定］ | 荷が宙に浮く。持ち主には「失った」とも「戻った」とも示されない |
| 倉・建物 | 終了後に閉じる命令がない［推定］ | 賃料（rent）と中身が閉じ込められる |
| 段階2の札（預かり・受け取り・使用権） | コードにない。試遊ではカードと台帳 | 試遊のたびに、運営の手作業の判断になる |

シミュレーションでの規模（標準・mixed、30 seed の平均。結果の表は `results/RESULTS.md`）：区切りの瞬間に、輸送中の物資・砦に預けた物資・進行中の作戦があることは**例外ではなく、毎回起きる**。世界を作り直す案（P0、A）では、それらがすべて失効する。B では、砦に預けた物を送り主に返す量が最も大きくなる。

## 7-3. 対象ごとの要件

| 対象 | 世界を作り直す区切り（P0、A） | 世界が続く区切り（B） | 区切りなし（C） |
|---|---|---|---|
| **進行中の輸送**（隊商・荷車） | **R1**：区切りのN時間前から、区切りをまたぐ出発を拒む（Depart と同じ確認を隊商にも）。<br>**R2**：それでも宙に浮いた荷の扱いを、一つに決めて表示する（送り主に戻す／失効）。どちらでも、履歴には残す | **R3**：行き先が中立に戻る砦なら、着いた時点で送り主に戻す。それ以外は、そのまま届ける | 変更なし |
| **預けた材料**（倉・砦・国の倉・預かり） | **R4**：区切りの前に、持ち主が引き出せる期間を置く。区切りで消える物は、何が消えたかを本人に一覧で示す | **R5**：砦に預けた物は、預けた割合で送り主に返す（モデルの B はこの形）。国の倉は残す | 残す。砦に預けた物は、砦の持ち主が変わると奪われる（現在の奪取と同じ） |
| **予約**（決まった時刻の送り・繰り返しの送り・段階3の決まり） | **R6**：区切りで全部止める。新しい単位で、本人が確認してから再開する | **R7**：中立に戻る砦や、終わった作戦を指す予約は止める。それ以外は続ける。止めたことは本人に知らせる | 続ける |
| **施設の使用権**（段階2） | **R8**：使用権は、その施設が新しい世界にないので行使できない。履歴として「どの単位で何回使ったか」を残す | **R9**：施設が残るなら、権利も続く。ただし、国どうしの構えに依存する権利（関所の通行など）は、構えが戻るときに見直す | 続ける |
| **保証金・賃料**（チェーン上の rent、参加の預け入れ） | **R10**：区切りの後に、本人または誰でも閉じられる命令を用意し、元の支払元に返す（CloseSeason が閉じない倉・建物・隊商のアカウントも含める） | 続く物は返さない。閉じられた物は返す | 同左 |

## 7-4. ②（権利の仕様）への要件

1. 権利には**有効な世界・単位**を記録する。単位をまたいで行使できるかを、権利の種類ごとに決めておく。
2. **履歴を消さない**。失効した権利も「いつ、なぜ失効したか」とあわせて残す。
3. 区切りの処理は**誰でも送れる**ようにする。運営だけが送れる形にしない（EndSeason と同じ考え方）。
4. 失効と返却は、送り主・預け主が**本人の画面で確かめられる**ようにする。

## 7-5. ④（Run）への要件

1. Run を区切りの前後で切らない。区切りの瞬間に宙に浮く物の量を、Run の記録から数えられるようにする。モデルでは数えられることを確かめたが、本番の記録で数えられるかは未確認。
2. 区切りの前の受付停止（R1）を入れるなら、その時間の長さを Run の設定として持てるようにする。

## 7-6. 未決定事項（⑧では決めない）

- R1 の「N時間」をどれだけにするか。モデルの作戦の決着には、受付6時間に行軍約7時間が加わる。
- 宙に浮いた荷を、「戻す」と「失効」のどちらにするか。戻すと、区切りの直前に荷を出して守る抜け道になる。失効にすると、送った人が損をする。
- B で砦の預け物を返すとき、返す先の村がすでにないときの扱い。モデルでは失効にした。
- 創作定義（仕組みの設計図）を新しい世界で建て直すとき、昔の「元にした仕組み」の表示を引き継ぐか。
- 評判を、区切りでどれだけ薄めるか。
