# 3. 誰が目標を出し、決め、動かすか（制度の比較と推奨の仮案）

**この文書の役割：** 目標の提案と採択、参加、提案者と持ち主の権限、退出、方針変更、持ち主の不在を決める。制度は3案を比べ、推奨を**仮案**として示す（決定は本人、8章）。

## 3-1. 守る線（3案に共通）

依頼と、決定済みの方針から、次はどの案でも変えない。

1. **国は財布ではない。** 国は物を持たず、誰も他人の物を動かせない。採択も、調整役も、投票も、物の持ち主を変えない。
2. **命令しない。** 国の目標は「呼びかけ」と「知らせ」。参加は任意で、断っても罰はない（14 の「国は命令しない」、決定済み）。
3. **徴収・通貨・報酬はない。** 目標に出した物の見返りを、仕組みは払わない。
4. **軍は自動で出ない。** 目標の成立や補給の到着で、軍は出発しない（決定 2026-10-23）。
5. **新しいチェーンの命令を前提にしない。** S1 の今の命令（隊商・倉・建物・投票）で遊べること。卓の記録は評議会と同じオフチェーンの署名つき記録でよい（7章 ⑤へ）。

## 3-2. 3つの案

| | A：呼びかけだけ | B：議会で採択 | **C：賛同で採択（推奨・仮案）** |
|---|---|---|---|
| 提案 | 誰でも | 投票権のある村（入って288ターン） | 誰でも（追放中は除く） |
| 採択 | なし。申し出が集まれば始まる | 今の国の議会で投票（1日・賛成>反対・賛成3以上） | 提案者を含む**賛同3**で「国の目標」になる。賛同は約束ではない |
| 調整役 | 提案者 | 提案者 | 提案者。不在なら賛同した人が引き継げる |
| 卓での扱い | すべての呼びかけが並ぶ | 可決した目標だけが「国の目標」 | 国の目標が上、未採択は下 |
| 速さ | 最も速い | 遅い（投票権2日＋締め切り1日。作戦の期限に間に合わない） | 速い（賛同が集まった時点） |
| 荒らし・乱立 | 多い。卓が埋まる | 少ない | 中。1村1件の提案、36ターンで不成立になる |
| 新しく来た人 | 出せる | 2日出せない | 出せる。採択には仲間3人が要る |
| 国の議会との関係 | なし | 議会の議題が増える（今の枠は国に4つ） | なし。構え・追放の議会はそのまま |

| 失うもの | 「国として」の重みがない。誰の呼びかけに乗るかで割れる | 作戦の速さ。議会の枠の取り合い | 3人いれば国の名を使える（国の総意ではない） |

## 3-3. 推奨の仮案：C（賛同で採択）

**理由：**
- 作戦は数時間〜1日で動く（試作の作例は期限48ターン＝8時間）。B の投票は「入って2日」「締め切り1日」で、目標の期限より遅い。
- A は手軽だが、卓に呼びかけが並ぶだけで、「国として何をするか」が見えない。
- C は、今の議会の定足数（3）にそろえた軽い採択で、**国の議会（構え・追放）とは役割を分ける**。国全体を縛る決定（構え・追放）は議会、持ち物の組み合わせ（目標）は卓。

**C の弱点と手当て：**
- 「3人いれば国の名を使える」→ 卓に賛同した人の名前を出す。国の目標は、国の総意ではなく「3人以上が賛同した呼びかけ」と表示する。
- 乱立 → 1村が同時に出せる提案は1つ（今の議会と同じ）。採択されなければ36ターンで不成立［仮］。
- 対立する目標が両方採択される → それでよい。持ち主がどちらに出すかを選ぶ（2-7「競合する目標」）。

**提案者と持ち主の権限の分け方：** 提案者・調整役が持つのは「計画（何が・どこに・いつまでに要るか）」だけ。物の持ち主が持つのは「自分の物をどうするか」のすべて。調整役が計画を変えても、誰の物も動かない。試作では、調整役が他人の申し出を発送しようとすると「持ち主しか動かせない」で断られる（テスト「提案者・調整役でも、他人の物は動かせない」）。

## 3-5. 退出

- **目標から抜ける：** いつでも。未発送の申し出は取り下げになる。**発送済みの荷は行き先へ届き、受け取った人の物になる**（呼び戻しは S1 にない。7章 ④へ）。記録に「抜けた」が残る。罰はない。
- **調整役が抜ける：** 次に賛同した人に調整役が移る。
- **国を出る：** S1 には命令がない（1章）。国を移れるようになったら、移った人の申し出は自動で取り下げ、建物と在庫は本人の物のまま（14 の決定どおり）とする［提案］。

## 3-6. 方針変更

- 期限・必要量・目的を変えられるのは調整役だけ。変えると**新しい版**になる。
- **未発送の申し出は、すべて「再確認待ち」**。本人が「続ける」か「取り下げる」を選ぶまで、申し出の量として数えない。理由：申し出は「その版の計画」に対する約束で、計画が変われば約束し直すのが筋。
- 発送済みの荷は、行き先が同じならそのまま届く。行き先が計画から外れた場合も、届いた物は受け取った人の物（返すかは受け取った人が決める）。
- 構えの投票の可決など、**目標の外で前提が変わったとき**は、卓に「前提が変わった」を出し、調整役に「目的を変える／このまま続ける／中止」を、参加者に「自分の申し出をどうするか」を出す。

## 3-7. 持ち主の不在

- 不在の人の村・倉・荷車・建物・申し出は、**その人の物のまま、誰も代わりに動かせない**。鍵を共有する仕組みは作らない（依頼の境界）。
- 卓では、最後に動いてから一定ターン［仮：6］で「しばらく動いていない」、本人が不在と明示したら「不在」と出す。**不在の人の未発送の申し出は、期限までの見込みから外して別に見せる**（当てにしない）。
- 建物の自動の守り（砦・塔・柵）は、持ち主が不在でも働く（S1 のまま）。
- 調整役が不在なら、賛同した人が引き継げる（計画の編集だけ）。
- 代理（AI の代理）に任せる道は、決定済みの「代理の札」の範囲で扱う。代理に投票は任せない（決定 E2）。目標への申し出・発送を代理に任せられるかは本人の判断（8章）。

## 3-8. 卓の見える範囲（守ること）

- 卓は**国の仲間だけ**に見せる。ただし、隊商の出発・行き先・中身はヘラルドの公開データから誰でも読める（今の事実）。卓で隠せるのは「誰が何を約束したか」と「計画」だけで、物の動きは隠せない。
- **護衛は封のまま。** 卓には「護衛の申し出が何件」だけを出し、誰が・どこに・何人かは出さない（試作のテスト「護衛は封」）。封じた進軍の行き先を、卓が漏らさないこと（handoff の未検証事項5）。
