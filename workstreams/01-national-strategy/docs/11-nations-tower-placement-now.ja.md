### 国で違わないもの

- **開始の資源・生産：** 全国同じ（調査の報告：`citizen.rs:1408-1420` の `founded_holding` は国を見ない）。村ごとの違いは、周りの地形から決まる鉱石だけ。
- **開始の場所：** 自国の扇形のリング2〜3。扇形は回転で同じ形（地形は扇形0を回して作る：`terrain.rs`、調査の報告）。
- **バランス：** 文書 `docs/frontier/stage1a/J3-NOTES.md` によると、5国は平均の ±0.28% 以内、国1（潮）は約 −0.7%（目標は ±0.2%）。「バランスの帯に入っていない」とコード自身が書く ✔（`doctrine.rs:222-226`）。

### テスト

- `doctrine.rs` の単体テスト（`s1_table_fields_the_strong_units` など）、`permutation-rules/tests/frontier_s1.rs`、`frontier_world.rs:2671`、`catalog.rs:436`（城壁の費用）、`frontier_conquest.rs`（占領の城壁）。**国ごとの隊商・行軍・到着の値を、プログラムの段で確かめるテストは見当たらなかった**（調査の報告）。

## 11-2. 中央の塔

**正体：** 地図の中心の州（Concord、(0,0)、リング0）の中央のマスに描かれる**鐘楼**。プレイヤーが建てる見張り塔（物見櫓、`KIND_TOWER`）とは別物。

| 区分 | 確認できたこと | 根拠 |
|---|---|---|
| 描画 | 中心の州の中央のマス（`t.centre && t.ring === 0`）に、まず「Engine」の絵（`art/specials/engine_<段階>.webp`）を置き、段階0のときはその輪の中に鐘楼を描く | ✔ `map/sprites.mjs:1352-1366`、`map/belltower.mjs` |
| 描画の段階 | 本番の画面では段階は常に0（`ART_ENGINE` は `?art=1&engine=N` の見本表示のときだけ変わり、「表示だけ」と書かれている） | ✔ `app.mjs:110`、`app.mjs:3581` |
| 他の使い道 | 参加前のカメラが鐘楼を写す、紹介の場面でも描く | 調査の報告（`map/opening.mjs`、`intro/scene.mjs`） |
| ゲームの状態 | 中心の州はチェーン上の本物の州だが、**リング0〜1の拠点はすべて予約済み**。野営地も砦（キープ）も置かれない | 調査の報告（`proc/map.rs:505-515,567,574`、`keep.rs:270`） |
| 占領・包囲 | **できない。** 中心と首都の包囲は拒否される | ✔ `siege.rs:686`、✔ `conquest.rs:772-776` |
| 入植 | **できない。** 最初の村はリング2以上 | ✔ `citizen.rs:1180` |
| 支配 | 中心は常に中立 | 調査の報告（`control.rs`、ヘラルド `control.rs:320`） |
| 生産・報酬・勝利 | **S1 では何もない。** S1 の得点は州の領地 | ✔ `lib.rs:188-194`（「the S1 score is the Provinces' territory」） |
| 別の場所にだけあるもの | 「Engine の段階」で市民の取り分が増える計算（`pools.rs:338-342`、`payout.rs:440-450`）はあるが、段階を上げる命令はない | 調査の報告 |
| 設計だけ | 「中心に、文明全体で建てる Engine が立つ［設計、M3］」 | `docs/frontier/DESIGN.md:21,145,227`（調査の報告） |
| 確認できず | 中心の州を軍が通れるか・中に入れるか。中心の州の土地が領地の得点に入るか | — |

**結論：** 中央の塔は、今の S1 では**描画だけの目印**。占領・利用・報酬・勝利条件はない。設計文書の「Engine」は M3 の構想で、実装されていない。決定済みの「勝敗の砦」（23、戦期の作業）も、中心とは結びつけられていない。
