## 1-2. 国の数と作り方

- **［実装＋テスト］** 国は6つで固定（`permutation-rules/src/frontier/structure.rs:54` `NATIONS = 6`）。プレイヤーが国を作る命令はない。
- 国の口座（PDA `na‖faction`、384バイト）は、その国で最初の議題が出たときに作られる（`permutation-frontier/src/proc/nation.rs:174-189`、配置は `frontier-abi/src/v2/layout/s1.rs:65-79`）。中身は国の番号・次の議題番号・議題4つ分の枠だけ。
- **今の国の口座には、在庫・倉・財布の欄がない**（実装の事実。「国の取り分」は段階2の設計として残っている）。テスト：`g13_s1_a_passed_stance_is_written_into_the_season`（`permutation-frontier/svm-tests/tests/nation.rs:153`）。

## 1-3. 所属

- **［実装＋テスト］入る：** `Join`（0x30、`proc/citizen.rs:317-332`）。国（0〜5）を選び、`FACTION` と `JOIN_BELL`（入ったターン）を書く。1シーズンに1回、2回目は `AlreadyDone`。国は故郷の土地の範囲も決める（`wedge_allowed`）。
- **［なし］出る・移る・無所属：** 命令がない。S1 契約の「範囲外」（`docs/frontier/stage1e/S1-1E-CONTRACT.md` §0）。
- **［設計のみ］** 「村はいつでも国を移れる」「移ると宣言した時点で無防備」「無所属を認める」（14 の5章、決定済み）。作るのは戦期の作業（31 の K2）。

## 1-4. 投票

- **［実装＋テスト］** 規則は `permutation-rules/src/frontier/nation.rs`（プログラム・検証ツール・ヘラルドで共有）。
  - `ELIGIBLE_BELLS = 288`（国に入って2日、1ターン10分）、`WINDOW_BELLS = 144`（1日）、`READMIT_BELLS = 432`（3日）、`QUORUM = 3`、議題の枠 `PROPOSALS = 4`。すべて［フェーズ6］の仮の値。
  - `passes(yes, no) = yes > no && yes >= QUORUM`（:58）。1村1票（持っている村の数によらない）。一人が同時に出せる議題は1つ。同じ議題には1回だけ（やり直しは `AlreadyDone`）。
  - 議題の種類は3つだけ：`KIND_STANCE`（他国への構え）・`KIND_EXPEL`（追放）・`KIND_READMIT`（戻す）。
- 命令：`Propose` 0xBB（`proc/nation.rs:133`）、`Vote` 0xBC（:263）、`SettleProposal` 0xBD（:324、締め切り後に誰でも呼べる。キーパーが自動で呼ぶ：`frontier-node/crates/keeper/src/nations.rs`）。ヘラルドは `h/nations.json` に結果を出す。検証ツール V25 が全部を再判定する。
- **テスト：** `nation.rs:171,193`（規則）、`svm-tests/tests/nation.rs`（`g13_s1_a_passed_stance_is_written_into_the_season`、`..._a_failed_proposal_changes_nothing`、`..._propose_and_vote_refusals`、`..._expel_and_readmit_a_village`、`..._an_expulsion_that_no_longer_applies_fails`）、キーパー `due_proposals_and_their_holdings`、ヘラルド `folds_a_stance_and_an_expulsion_and_round_trips`、検証ツール `v25_nations.rs:434,481,536`。
- **画面：** `permutation-server/web/frontier/screens/s1.mjs`（国の議会の折りたたみ、賛成・反対、追放の提案）と `controller.mjs:1507-1514,1583-1594,1825`。画面側のテスト `permutation-gateway/test/web-frontier-s1.test.mjs`（「the village offers … its nation's votes」:438、追放と戻す :695）。
- **［設計のみ］** 国の土地での建設と、国の取り分の投票は段階2（S1 契約 §0）。

## 1-5. 同盟（構え）

- **［実装のみ・効果なし］** 構えの値は `STANCE_WAR=0`・`STANCE_PASS=1`・`STANCE_ALLY=2`（`structure.rs:49-52`）。シーズンの口座に6×6の表で持つ（片側ずつ。始めは全部「戦争」）。可決した構えの議題だけが書き換える。
- 構えを読むのは `stops()`（`structure.rs:139-146`）だけ。**塔が削るか・柵が止めるか**を決める。戦い（clash）は構えを見ない。「戦いに同盟はない」（S1 契約 §2.6、2026-10-24 決定）。**砦は他のすべての国と戦う。**
- **S1 では「同盟」＝「通行を許す」。** 相手の承認の手順も、同盟の集まりもない。テスト：`g13_s1_a_palisade_stops_whom_its_nation_stops`（`svm-tests/tests/structure.rs:777`、PASS と ALLY の両方を回す）。
- **［実装＋テスト・別系統］** V5 の `diplomacy.rs` には、宣戦・和平・不可侵・同盟（承認・離脱の遅れ）・金の移転がある（`tests/diplomacy.rs` 18件）。Frontier では使われていない。

## 1-6. 追放

- **［実装＋テスト］** 可決すると `C::EXPELLED_SINCE` を記録し、生きている村すべてに `FLAG_EXPELLED` を立てる。追放された村は議題を出せず、投票できず、**自国の塔と柵に止められる**。国の印は残る（無所属にはならない）。432ターン後に「戻す」議題を出せる。
- **［実装のみ］** 村の持ち主が変わったときに印を付け直す `mark_holding`（`proc/nation.rs:118`。建設・入植・占領から呼ばれる）を直接通すテストは見当たらない。
- 国の賞金の取り分を失う、という設計（S1 契約 §10.6）はあるが、賞金のコードはない。

## 1-7. 国内の襲撃

- **［実装＋テスト］** `RaidDomestic` 0xBE（`proc/caravan.rs:1563`）。同じ国の、自分以外の荷車を、そのターンにそのマスに軍が立っていたことを示して襲える（追放された相手に限らない）。テスト：`g13_s1_raid_domestic_opens_a_raid_the_raider_settles`、`..._refusals`（`svm-tests/tests/caravan.rs:1289,1356`）、検証ツール `judge_raid_domestic`。

## 1-8. 物資移転（隊商）

- **［実装＋テスト］** `BuildVault` 0xB0、`SendCaravan` 0xB1（`proc/caravan.rs:677`）、`SettleCaravan` 0xB2、`RaidCaravan` 0xB3、`SeizeVault` 0xB4、`CloseVault` 0xB5、`DefaultRaid` 0xB6。
  - **送り元**は自分の村か倉だけ（`NotOwner`）。**行き先**は、誰の村・倉でもよい。国の確認も、同盟の確認もない。
  - **他人へ送るにはウォレットの署名**が要る（`WalletRequired`、:726-728）。セッションの鍵で動かせるのは自分の場所どうしだけ。
  - 荷は**送った時点で送り元から引かれ**、**到着の確定（Settle）で行き先に足される**（:965-1010）。倉は上限 `VAULT_CAP`。**行き先がなくなっていれば荷は失われる（LOST）**。行き先の村が占領の決着待ちなら、確定が待たされる（`CapturePending`）。
  - 道の途中の塔に削られる。**襲撃は荷車ごと奪う**（決定 J2：分けない。`caravan.rs:16-18`）。
  - 数：`CARAVAN_SLOW_BPS = 15000`（歩きの1.5倍）、県ごとに荷車の枠5、`CARAVAN_FEE = 50000` lamports（預けて、確定させた人に払う）、倉は一人3つまで、倉の費用 木材200・石材200・金50。
- **テスト：** `svm-tests/tests/caravan.rs`（`g13_s1_send_caravan_refusals` :607 で `WalletRequired` と、他人への送りが通ること、自分の倉への送りと確定、行き先を失った荷、襲撃・既定の襲撃・戦い）、`frontier-abi/tests/s1_caravan_clash.rs`（5件）、ヘラルド3件、検証ツール2件、画面 `web-frontier-s1.test.mjs`（:551 他人の行き先、:580「他人への隊商はウォレットで署名」）。
- **テストの穴：** 他人の村へ送った荷が**確定して相手の在庫に入る**ところまでを確かめるテストは見当たらない（「送れる」までは確かめている）。キーパーの `caravans.rs` に単体テストは見当たらない。
- **画面：** 他人への隊商は PR #20（2026-10-29）で画面に入った。近い24か所まで、ウォレット署名。試遊の甲の手順で、p1 が p2 へ木材50を送る確認がある。

## 1-9. 砦・柵・塔（拠点に関わるもの）

- **［実装＋テスト］** 建物は一人の持ち主（`OWNER_CITIZEN`）と国の印を持つ。費用（S1 契約 2.3、［フェーズ6］）：塔 木材300・石材400・兵器20・金100（一人2つ）、柵 木材200・石材100・金20（一人4つ）、**砦 木材500・石材800・兵器50・金200（一人1つ、県に2つ）**。1マスに建物1つ。
- **砦の守備兵は、砦の持ち主だけが置ける**（`FortGarrison` 0xBA：持ち主の、砦と同じ県にある村から、予備の槍兵を払う。上限2000）。**他人の兵は他人の砦に入れない。**
- 兵器：長槍兵・弩兵・騎士の訓練に、100人あたり 50・70・40（`arms.rs` `TRAIN_ARMS_PER_100`）。包囲の宣言で50を使い切る。工房1基は毎時 鉱石8・木材4 → 兵器4。

## 1-10. 評議会と国の議会（画面）

- **S1 の国の議会**（構え・追放）：チェーンの命令。上の1-4。村の画面の「交易と防備 → 国の議会」の中にある。
- **評議会**（`permutation-server/web/frontier/council.html`、`council/*.mjs`、`permutation-gateway/citizens/social/council.mjs`）：［実装＋テスト］だが**オフチェーン**。署名つきの投票と伝言を、ゲートウェイの外部記録（JSONL）で数える。議題は AI 住人の「攻撃の指令」（攻める・野営・襲う）。画面自身が「議会はオフチェーンで、プログラムには統治がなく、指令をチェーンは何も強制しない」と書いている（`council/lang.mjs:479`）。鍵は手で貼る。テスト：`citizens-page-council.test.mjs`、`citizens-social-council.test.mjs`、`citizens-watcher-council-gen.test.mjs` ほか。
- AI 住人の頭脳が S1 で選ぶのは隊商・待ち伏せ・護衛だけで、投票はしない（`docs/RUNNING.md:71`）。

## 1-12. この作業での「事実」の使い方

試作（`prototype/`）は、上の事実のうち次を写した。写した数字の出典は `prototype/scenario.mjs` の各行に書いた。

- 砦・塔・倉の費用、一人あたりの数、砦の守備兵は持ち主だけ、長槍兵の兵器、包囲の兵器、工房の産出の比率。
- 投票の可決条件（賛成>反対、賛成3以上）。締め切りは試作では短くした（実際は144ターン、試作は6ターン）。
- 隊商：送ると送り元から引かれ、着いたら受け取り側の物。行き先がなければ失われる。襲撃は荷車ごと。
- 構え：塔と柵は構えに従い、砦は構えを見ずに戦う。
- 今の国の口座には在庫がない（実装の事実として）。
