## 12-1. 3案の定義

| | A：同国がまとまる | **B：同国が小集団で散る（試作候補）** | C：国に関係なく散る |
|---|---|---|---|
| 国の選択 | プレイヤーが選ぶ | プレイヤーが選ぶ | プレイヤーが選ぶ |
| 出現する場所 | 自国の扇形のリング2〜3（**現行**） | 同国の数人（小集団）がまとまり、小集団どうしは地図の各地に離れる。一つの地域に複数の国の小集団が入る | 一人ずつ、地図の各地へ。国を見ない |
| 場所を決めるもの | 現行はプレイヤーが指定（先に通った者が取る） | 試作では仕組みが割り当てる（12-6 で検討） | 同左 |
| 模型での置き方 | 自国の本拠の中で、中心に近く・豊かな州から | 国ごとに参加順で `groupSize` 人ずつ小集団にし（1人の小集団は作らず前に足す）、同じ国の小集団が二つ入らない地域のうち空いている所へ | 参加順に、いちばん空いている地域のうち乱数で一つへ |
| 地域 | — | 6の倍数の地域を、回転対称にリング2〜(rMax−1)に置く。数は「一つの地域におよそ3か国」になるように決める | 同左 |

**国の選択と場所の選択は別のもの。** 3案とも国はプレイヤーが選ぶ。違うのは「場所を誰がどう決めるか」と「同国がどれだけ近いか」。

## 12-2. 模型で測った数字（例）

`placement.mjs` の `summary` で、各国6人（36人）・小集団3人・乱数7のとき：

| 数字 | A | B | C |
|---|---|---|---|
| 中心（Concord）までの州の数 | 全員2 | 全員3 | 全員3 |
| 隣の州までに同国がいない人 | 0 | 0 | **15** |
| 自分の小集団の外の同国まで（州） | — | 3 | — |
| 隣の州までにいる他国の人数（平均） | 0 | 3 | 3.9 |
| **自国の本拠の外にいる人（今の S1 では包囲されうる）** | **0** | **18** | **33** |
| 国の間の差（中心までの距離・豊かさ） | 0 | 0 | 0 |

人数が偏るとき（12・8・6・4・2・1人）：A は1人の国が孤立（隣に同国なし1人）、B も小集団を作れない国で1人が孤立し、C は11人が孤立する。各国20人（120人）では、A でも本拠が埋まって境で他国と接する（隣の他国 平均9.6人）。B は中心までの距離が2〜4に広がり、国の間の差は0.45（許容0.5以内）だが、**豊かさの国の間の差が1.2で許容（0.5）を超える**（地域の割り当てが国ごとに偏るため）。**どれも模型の数字で、本番の地図・地形の数字ではない。**

## 12-3. 配置が生む選択（場面）

### 近くの同国との協力

- **A：** 隣はほぼ同国。拠点の材料を「隣から贈る」のが速い（作例の移動は2〜3ターン）。協力は簡単だが、**誰と組むかの選択は少ない**（隣にいるのは同国だけ）。
- **B：** 小集団（2〜4人）の中で、すぐ組める。小集団の外の同国は遠い（模型では3州＝約9ターン）。**「近くの数人と組む」と「遠くの同国のために送る」が別の判断になる。**
- **C：** 隣に同国がいないことが多い（各国6人で15人が孤立）。協力の相手は、遠くの同国か、近くの他国。

### 遠くの同国への補給

- **場面（B）：** ハル（国0、別の小集団、拠点まで12ターン）は、ケイの小集団の「国境の共同拠点」に食料を出すか。出せば、期限には間に合うが、道中の襲撃と時間のぶん自分の守りが薄くなる。出さずに、自分の近くの他国と取引するか。→ `placement.html` の「この配置の距離で試す」で、B ではハルの荷が A の4倍遅いことを確かめられる。
- **A：** 遠くの同国がいないので、この判断はほぼ生まれない。
- **C：** 同国は全員遠い。国の目標は「遠い仲間へ送る」ことばかりになる。

### 近隣の他国との取引・対立

- **A：** 他国と接するのは扇形の境だけ。境の村だけが他国と向き合う。
- **B：** どの小集団の隣にも他国の小集団がいる（各国6人で平均3人）。**近くの他国と取引するか、襲うか、構えの投票でどう振る舞うか**の判断が、ほぼ全員に生まれる。構えが「戦争」のままだと、隣の他国の塔と柵に削られ止められる（構えの規則は今の S1 のまま）。
- **C：** さらに多くの他国に囲まれる。国としてまとまった方針を持ちにくい。

### 中央への移動

- 3案とも、中心（Concord）は今の S1 では**入植も包囲もできず、得るものがない**（11章）。中央へ行く理由は、今は「通り道」だけ。
- B・C では、中心との距離が小集団ごとに変わりうる（各国20人で2〜4州）。中央に意味を持たせるなら、この差が配置運になる（12-5）。

## 12-4. 小集団の人数と、人数の変化への強さ

小集団の人数は**未決定**。模型では2〜5を切り替えて比べられる。

| 状況 | B で起きること（模型） | 成り立たせる条件の案［提案］ |
|---|---|---|
| **少人数で始まる国**（1〜2人） | 小集団を作れず、1人の小集団になる（孤立） | 国の人数が小集団の人数未満のうちは、**自国の本拠に置く（A に戻す）**。人数がそろってから散らす |
| **人数の多い国** | 小集団が増え、同じ地域に入れないので遠くの地域へ。中心までの距離の差が広がる | 一つの国が持てる地域の数に上限を置き、超えたら小集団を大きくする |
| **途中参加** | 人数の足りない同国の小集団があればそこへ、なければ同国のいない地域に新しい小集団（1人）として。すでにいる人は動かない | 1人の新しい小集団は孤立する。**途中参加は既存の小集団に足す**を優先し、足りなければ自国の本拠に置く |
| **仲間の離脱** | 2人の小集団から1人抜けると、残った人は孤立 | 小集団の人数を3以上にする。孤立した人に「近くの同国の小集団へ移る」道を用意するか（村は動かせないので、2つ目の村＝前哨で） |

**同国が近くにいない期間が長くなる負担（B・C）：**
- 協力の相手が、遠くの同国か、近くの他国しかいない。国の目標に出す荷は、遠く・遅く・襲われやすい（作例では A の約4倍の道のり）。
- **今の S1 では、自国の本拠の外の村は包囲から守られない**（`siege.rs:711-713`）。B の各国6人で半数（18人）、C ではほぼ全員が対象になる。**これは配置だけでなく、守りの釣り合いを大きく変える。** B を本番で試すなら、「本拠の守りを、扇形ではなく小集団の場所に与えるか」を先に決める必要がある（⑧へ、12-8）。
- 新しく来た人の守り（決定済み：期間つきの守り、国の内側に置く）と食い違う。B・C の「国の内側」が何を指すかを決め直す必要がある。

## 12-5. 配置運と戦略を分ける

### 比べる条件

| 条件 | 模型での測り方 | 揃えられるか |
|---|---|---|
| 中心までの距離 | 州の数（リング） | A は揃う（全員リング2〜3）。B・C は地域の位置で変わる |
| 利用できる資源 | 州の豊かさ（仮）。本番は周りの地形の鉱石 | 地形は扇形ごとに回転対称なので、**国の間**は揃えられる。**同じ国の中の村の間**は揃わない |
| 移動できる経路 | 模型では距離だけ（道路・山・水・柵は見ていない） | 未確認。本番の地図で測る必要（⑧） |
| 近隣の人数 | 隣の州までの同国・他国の人数 | B は小集団の人数で決まる。C は乱数しだい |
| 同国との距離 | いちばん近い同国、小集団の外の同国 | B は地域の配り方で決まる |

### 許す偏り［提案］

完全に同じ条件にはできない（村の数が地形と人数で変わるため）。そこで、**国の間の差**と**個人の間の差**を分ける。

| 項目 | 国の間（国ごとの平均の最大差） | 個人の間 |
|---|---|---|
| 中心までの距離 | 0.5 州以内 | 揃えない（散らす案の性質）。ただし中心に得るものを置くなら、1州以内 |
| 州の豊かさ | 0.5（5段階）以内 | 揃えない。代わりに「交換で埋められる」ことを確かめる |
| 隣の他国の人数 | 1人以内 | 0人の人を作らない（B） |
| 隣の同国の人数 | 1人以内 | B では小集団の人数−1以上 |

模型は、この許容を超えた項目を表示する（`summary().over`）。

### 国の選択と場所の選択を混同しない

- **国の選択：** どの国にするか（教義・方角・仲間）。プレイヤーの戦略。
- **場所の選択：** どの州・どの拠点か。現行（A）はプレイヤーが指定でき、**先に参加した人ほど良い場所を取れる**（中心に近い・鉱石の多い拠点）。これは戦略ではなく、参加の早さの運。
- B・C を試すなら、**場所は仕組みが割り当て、プレイヤーは割り当てられた地域の中の拠点だけを選ぶ**（候補を3つ見せる、など）を推奨［提案］。

### 引き直し（複数アカウント・参加し直し）

| 手 | 現行（A） | B・C で仕組みが割り当てる場合 |
|---|---|---|
| 一つのウォレットで二度参加 | できない（`AlreadyDone`） | 同じ |
| 村を捨てて置き直す | 命令がない（放置で10日後に解放、その後は旧い抽選の道だけ） | 同じ |
| **複数のウォレット** | **止められない。** 各ウォレットが好きな場所を指定できる | 割り当てが参加順だけで決まると、参加の順を操って良い地域を取れる。**割り当てに公開の乱数（ビーコン）を混ぜ、結果が出る前に参加を確定させる**と、引き直しは「新しいウォレットの参加費」を払う運試しになる［提案］ |
| 小集団を選ぶ | — | 友人と同じ小集団に入りたい、が出る。**招待（同じ小集団で始める）を許すか**は本人の判断（12-10） |

## 12-6. 中央の塔との相性（役割は決めつけない）

- **現行：** 中央の塔は描画だけ。中心の州は入植も包囲もできない（11章）。
- **A：** 中心は6か国の首都に囲まれ、どの国からも等しく遠い。集まる理由はない。
- **B・C：** 小集団によって中心までの距離が違う。**中心に何かを置くと、近い小集団が得をする**（配置運が勝敗に入る）。
- **中央に集める目的が本当に必要か：** 決定済みの設計は「勝敗の砦」（戦期ごとに争う砦、23）で、中心とは結びつけていない。国の戦略（国の卓）は、境・峠・鉱脈のような**各地の要所**で協力を生む作り。中央に集める仕組みがなくても、B では各地で他国と接するので、対立と協力の理由はすでにある。
- **この文書では、中央塔に役割を足さない。**「塔を取った国が勝つ」「全員が塔へ集まる」は提案しない。本人が中央に役割を持たせると決めたときに検討すべき点だけを置く：
  1. 中心までの距離の偏り（B・C）を、どこまで許すか。
  2. 中心は今、包囲も入植もできない（`ReservedSite`）。役割を足すなら、この決まりを変えることになる。
  3. 設計の「Engine」（M3、文明全体で建てる）は「国が奪い合う」ではなく「全体で建てる」構想だった。

## 12-7. 小集団型（B）の利点と欠点

**利点（仮説。人間で確かめる）：**
- 協力に**二つの距離**ができる：近くの数人と組む（速い）、遠くの同国に送る（遅い・危ない）。国の卓の「誰の物を、どこへ組み合わせるか」に、距離という重みが加わる。
- ほぼ全員が他国の隣にいるので、取引・対立・構えの判断が一部の境の村だけのものでなくなる。
- 国の中で、小集団ごとに利害が分かれる（守りたい場所が違う）。決定済みの「国の中の利害の違い」を地図の上で起こせる。
- 国全体が一か所で潰されにくい。

**欠点：**
- **今の S1 の本拠の守り（扇形）と合わない。** 自国の扇形の外の村は包囲されうる（B の各国6人で半数）。守りの規則を変えずに B を入れると、散った小集団が真っ先に狙われる。
- 少人数の国・途中参加・離脱で孤立する人が出る（12-4）。
- 遠くの同国への補給は遅く、襲われやすい。協力が「近くの数人だけ」に閉じるかもしれない。
- 国の扇形・首都・本拠・「国の内側に置く新人」など、扇形を前提にした決まりと画面（国の名前を扇形の上に出す、など）を作り直す範囲が大きい。
- 場所を仕組みが割り当てるなら、友人と一緒に始めたい人の希望とぶつかる。

## 12-8. 国の能力と配置

- 今の S1 で効いている国の補正（11章）のうち、配置で効き方が変わるもの：**国1の隊商 ×0.8**（B・C で遠くへ送るほど得が大きい）、**国4の行軍 ×0.75**（B・C で散った仲間のところへ速く行ける）、**国0の城壁 ×0.95**（本拠の外の村で効く）。
- **画面の説明どおりに効いていない補正**（国3の補給の消耗、国5の維持費など）は、配置の比較の前に⑦（表示の正確性）へ渡す。

## 12-9. 人間の試遊で確かめる質問（面白さは仮説）

既存の試作で、`placement.html` から A と B を開き、同じ作例（国境の共同拠点）を遊ぶ。進め方は 10章の形を使う。

**理解：**
1. 「あなたの近くにいる同国は誰ですか。遠くの同国は誰ですか。」
2. 「あなたの村は、他国から包囲されますか。」（B で、本拠の外にいるかを分かっているか）

**選択（観察）：**
3. A と B で、遠くの同国の目標に出す量は変わったか。
4. B で、近くの他国との取引や構えについて話したか。

**面白さ（本人の言葉だけ）：**
5. 「近くの仲間と遠くの仲間がいる」ことで、迷う場面はあったか。それは楽しかったか、面倒だったか。
6. 一人で離れて始まったら（少人数・途中参加の役）、どう感じたか。
7. A と B のどちらでもう一度遊びたいか。それはなぜか。

**捨てる目安：** B で遠くの同国への申し出がほぼ出ない（協力が小集団の中だけに閉じる）、または孤立した人が「何もできない」と答える。
