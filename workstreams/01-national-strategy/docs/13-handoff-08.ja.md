# 13. ⑧への引き渡し：配置案・比較条件・国の能力・中央の塔

**状態：** ①から⑧へ渡す資料。**⑧の成果物はこの作業の手元にない**（この worktree・ブランチの中に見当たらず、⑧の担当範囲もこの作業では受け取っていない）。だから、⑧の作業と**接続済みとは扱わない**。下の「受け渡し項目」を、⑧が受け取れる形で並べる。

**この資料の根拠：** 11章（現状の確認）、12章（比較）、`prototype/placement.mjs`（模型）、`test/placement.test.mjs`（模型のテスト）。

## 13-1. 渡すもの（一覧）

| # | 項目 | 中身 | 場所 |

## 13-2. ⑧に確かめてほしいこと（検証の要求）

| # | 要求 | なぜ |
|---|---|---|
| V1 | **本物の S1 の地図**（地形の種、道路、山・水、柵が建たない状態）で、H2 の条件を A・B・C について測る。特に「移動できる経路」と「利用できる資源（拠点ごとの鉱石）」 | 模型は距離だけ・豊かさは乱数で、経路と地形を見ていない |
| V2 | B の地域の数・置き方を、本物の地図の大きさ（S1 の `r_max`、開いたリング、`genesis_ring`）に合わせて決め直す | 模型は rMax=5 の小さな地図 |
| V3 | **本拠の守り**（`siege.rs:711-713`：持ち主の国の扇形のリング2〜3だけが包囲から守られる）を、B・C でどう扱うかの案と、その影響 | B の各国6人で半数が守りの外。守りの釣り合いが大きく変わる |
| V4 | 場所の決め方（プレイヤーの指定／仕組みの割り当て／割り当ての中で選ぶ）と、乱数（ビーコン）を使った割り当ての案。複数ウォレットで有利な場所を引き直せるかの評価 | 現行は先に参加した人ほど良い場所を取れる |
| V5 | 途中参加と離脱で、孤立する人がどれだけ出るか（人数の分布を変えて） | 12章 12-4 |
| V6 | 中央の州（Concord）に、軍が入れるか・通れるか、中心の土地が領地の得点に入るか | 11章で確認できなかった |
| V7 | 国の補正のうち、画面の説明どおりに効いていないもの（国3の補給、国5の維持費、国1の道標 など）の扱い（説明を直すか、実装するか）。⑦（表示の正確性）と分担 | 配置の比較で国の能力を前提にできない |
