# 10. 人間の試遊の準備（既存のクリックできる試作を使う）

**状態：** 準備だけ。**試遊者の募集も、外部への送信もしていない。** 実施するかと日程は本人が決める。

**目的：** 国の目標が、人が自分の物を組み合わせる理由になるかを、人間で確かめる。試作の自動テスト・AI のロールプレイ・この準備そのものは、その証拠にならない。

**分けて記録すること（混ぜない）：**
1. **理解：** 誰の物か、送っただけか着いたか、次に何を決めるかを、プレイヤーが正しく言えるか。
2. **選択：** 遅延・退出などのあとに、待つ以外を選んだか。
3. **面白さ：** 本人の言葉。観察者の解釈と分ける。

---

## 10-1. 形

| 項目 | 内容 |
|---|---|
| 人数 | 人間3〜5人＋進行役1人（＋記録係1人がいるとよい） |
| 道具 | 既存の試作（`prototype/`）を1台の画面で開く。`node workstreams/01-national-strategy/prototype/serve.mjs` |
| 役 | 人物（ケイ・ミラ・ソウタ・ハル）を1人1つ。4人なら全員、3人ならハルなし、5人なら1人は「観察して助言だけする仲間」（物を持たない） |
| 役割の割り振り | **しない。** 持ち物と場所だけを伝える。何をするかは本人が決める |
| 時間 | 45分（説明5分・遊び30分・聞き取り10分） |
| 進め方 | 1台の画面を順番に使う（ホットシート）。各自は自分の番に、上の人物の切り替えで自分の人物を選び、「次に必要な判断」から選ぶ。全員の番が終わったら、進行役が「1ターン進める」を押す（1巡で2〜3ターン） |
| 始め方 | 「最初から（ケイの提案の直後）」 |
| 出来事 | 進行役が、10分・20分の時点で一つずつ起こす。1回目は「物流の遅延」、2回目は「参加者の退出」か「方針の対立（構えの投票）」。回ごとに変えて記録する |

**試作の制約（参加者に先に伝える）：**
- 1台の画面なので、他の人の判断は見えてしまう。秘密の相談はできない（本番の卓は国の仲間だけに見せる予定）。
- 数字は仮。台本の仲間（ユキ・リオ・レン）は進行役が動かすもので、AI ではない。
- 護衛の損得は評価しない（9章）。

## 10-2. 進行役の台本

1. **説明（5分）：** 「これは国の目標に、自分の持ち物をどう組み合わせるかを試す試作です。何をしても、しなくてもかまいません。出した物は相手の物になることがあります。送っただけでは着いていません。終わったあとにいくつか聞きます。」
2. **観察だけする：** 進行役は「何をすればいいか」に答えない。画面の言葉の意味を聞かれたら、聞かれた言葉と時刻を記録してから答える（理解の記録になる）。
3. **出来事を起こす前後：** 起こす前に、全員の「次に必要な判断」の数を記録する。起こしたあと、各自の次の番で何を選んだかを記録する。
4. **終わり：** 期限（ターン48）か、30分のどちらか早いほう。

## 10-3. 記録（観察の事実）

記録用紙：`playtest/observation-sheet.csv`（1行＝1つの出来事か行動）。

| 列 | 中身 |
|---|---|
| `session` | 回の番号 |
| `minute` | 開始からの分 |
| `turn` | 画面のターン |
| `player` | 人物（ケイ・ミラ・ソウタ・ハル・助言役） |
| `kind` | 申し出／発送／取り下げ／賛同／依頼／応答／方針変更／出来事／質問／発言 |
| `detail` | 何を（量・相手） |
| `after_event` | 直前の出来事（なし／遅延／退出／…） |
| `chose_non_wait` | 出来事のあとの最初の番で、待つ以外を選んだか（yes/no/—） |
| `question_or_confusion` | 画面の言葉について聞いたこと、迷ったこと |
| `note` | その他（解釈は書かない） |

数えるもの：申し出の数と量、依頼に応じた割合、取り下げの数、出来事のあとに選び直した人数と待つだけだった人数、自給・ただ乗りを選んだ人数、成立したか。

## 10-4. 理解の確認（遊びの途中、出来事の直後に一度だけ）

進行役が、画面の一つのカードを指して聞く。答えは正誤だけを記録する。

1. 「この荷は今、誰の物ですか。着いたら誰の物になりますか。」
2. 「この食料は、もう倉に着いていますか。送っただけですか。」
3. 「あなたが次に決めることは何ですか。待つ以外に何ができますか。」
4. 「賛同したら、何かを出さなければいけませんか。」

（⑦の「操作と理解の検証」と同じ質問。同じ回で行うときは記録を分ける。）

## 10-5. 終わったあとの聞き取り（一人ずつ）

1. 自分の物を出した／出さなかった理由は何か。
2. 遅延（または退出）のとき、何を考えたか。待ったか、何かを選び直したか。
3. 「送った物は相手の物になる」は、出すのをためらう理由になったか。
4. 調整役は負担だったか（調整役だった人に）。
5. 「採択」の表示は、出すかどうかに影響したか。
6. もう一度やりたいか。それはなぜか。（面白さはこの質問の本人の言葉だけで記録する）

## 10-6. 判断の目安（事前に決めておく）

- **続ける目安：** 出来事のあと、半数以上が待つ以外を選ぶ。依頼の半数以上に誰かが応じる。
- **見直す目安：** 理解の質問1〜2で、半数以上が間違える（表示の問題として⑦に渡す）。
- **捨てる目安（Eternum UX 調査の候補3にそろえる）：** 2回の試遊で依頼に誰も応じない。または、調整役や依頼が「作業の押しつけ」として嫌われる。

## 10-7. 倫理と取り扱い

- 参加は任意。いつやめてもよいと伝える。
- 名前は記録しない（人物名と回の番号だけ）。
- 記録は公開リポジトリに入れる前に本人の確認をとる。この作業では記録用紙の空の雛形だけを置いた。
