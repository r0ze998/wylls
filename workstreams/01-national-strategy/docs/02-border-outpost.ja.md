# 2. 作例：国境の共同拠点を準備する

**この文書の役割：** 「国の戦略が協力の目的を生み、各人の持ち物を組み合わせる理由になる」を、一つの作例で最後までたどる。提案 → 参加 → 役割分担 → 準備 → 成果 → 失敗後。**これは作例の一つで、唯一の遊び方ではない**（他の目標の形は 4 章の最後）。

**数字：** 費用・兵器・投票は S1 の事実、手持ち・移動ターン・期限は試作の仮の値（`prototype/scenario.mjs`）。時系列は、試作のルールで実際に回した結果（`test/model.test.mjs` と同じルール）。1ターン＝10分。

**人物（架空）：** ケイ（国境の村。北の国の軍が最初に来る）、ミラ（丘の村。鉱石と工房3基）、ソウタ（平地の村。食料が多い）、ハル（川の村。工房2基を持つが、ふだんは自給）。台本で動く仲間：ユキ・リオ・レン（東の港町。北の国との交易を望む）。

---

## 2-1. なぜこの目標が生まれるか（国の戦略 → 協力の目的）

- 北の峠は「境の外」。北の国の軍は峠を越えて、まずケイの村に来る。
- 峠の向こうには豊かな鉱脈がある（決定済みの「境の外の豊かな鉱脈」）。ミラは鉱石の荷車を出したいが、峠の手前は護衛なしでは危ない。
- **一人では作れない。** 砦は 木材500・石材800・兵器50・金200（S1 の事実）。ケイの手持ちは石材300・兵器0。兵器を作れるのは工房を持つ人だけ。
- 今の S1 の国の口座には在庫がなく（実装の事実）、この試作でも国の共有資産は作らない（範囲の限定。既存の「国の取り分」の決定は別の未統合事項として残る）。だから作例では「国が建てる」ことはしない。砦を建てるのは誰か一人で、その人の物になる。協力とは、**それぞれの持ち物を、一つの場所に組み合わせること**。

## 2-2. 提案

| 誰が | 何を | 卓に出るもの |
|---|---|---|
| ケイ | 「国境の共同拠点を準備する」を出す。場所＝北の峠の手前、期限＝ターン48（8時間後）、目的＝北の国の軍と荷車を止め、峠の向こうの鉱脈へ出る足場にする | 目標のカード、必要なものの一覧、参加の条件 |

**必要なもの**（誰が満たせるかが、それぞれ違う）：

| 必要 | 誰が満たせるか | 成立の判定 |
|---|---|---|
| 石材500をケイの村へ（砦の材料） | 石材を持つ人なら誰でも | **材料**：到着の累計で進み具合だけ見る。成立の条件にはしない（砦になって消えるため） |
| 兵器50をケイの村へ（砦の兵器） | 兵器を持つ人、工房で作れる人 | **材料**（同上） |
| 拠点に倉1つ | 材料を持つ人（一人3つまで） | 倉が**稼働**している |
| 食料400を拠点の倉へ（守備兵の食料） | 食料を持つ人。倉の持ち主なら「自分の倉に置く」、他人なら「倉の持ち主に贈る」 | **期限のターンに倉に今ある量**（届いた累計ではない。他の目標と二重に数えない） |
| 拠点に砦1つ | 材料がそろった人（一人1つまで） | 砦が稼働している |
| 砦の守備兵300 | **砦の持ち主だけ**（S1 の `FortGarrison`）。他の人は、持ち主が兵を訓練する食料を送ることで手伝える | 砦にいる兵の数 |
| 峠の見張り | 峠に見張り塔を建てる人、**または**偵察を出す人（知らせは12ターン有効） | 塔が稼働、または新しい偵察の知らせ |
| 荷車の護衛（任意） | 予備の兵がいる人。封じた進軍なので、卓には件数だけ。12ターン［仮］待ち構えたあと村へ戻る | 成立の条件にしない。**護衛の費用と得の評価、護衛の面白さの検証はこの作業の対象外** |

## 2-3. 参加

- **採択（試遊の仮説）：** 判断する人3人の賛同で「採択」と表示する（C案、3章）。ミラとソウタが賛同した。**国の正式な決定ではない。賛同は資源を出す約束でも、発送の権限でもない。** 採択の前でも申し出と発送はできる。
- **参加は任意。** 何を・どれだけ・いつまでに出すかは、各自が「提供の上限」と一緒に申し出る。申し出は発送するまで、いつでも取り下げられる。取り下げは記録に残るが、罰はない。
- **参加の条件：** この国の仲間（追放中でない）なら誰でも。投票権（入って288ターン）は要らない。新しく来た人も、短い参加ができる。

## 2-4. 役割分担（固定の職業ではない）

役割は「誰が何を持っているか」と「誰が申し出たか」で決まる。同じ人が別の目標では別の役をする。

| 人 | 申し出 | 持ち物と道筋 | 協力する本人の得 | 代わりにできたこと（機会費用） |
|---|---|---|---|---|
| ミラ（生産） | 石材500・兵器50をケイへ | 手持ちの兵器40を先に送り、残り10は工房で作ってから送る | 峠の向こうの鉱脈へ出る道が、砦の後ろを通る。自分の鉱石の荷車が襲われにくくなる | 兵器50＝長槍兵100人の訓練、または包囲の宣言1回。石材500＝見張り塔1.25基 |
| ソウタ（輸送・補給） | 拠点に自分の倉、食料400を自分の倉へ | 倉は**ソウタの物**。食料も到着後**ソウタの物のまま**。ケイの守備兵へ送るかは、そのときソウタが決める | 前線の受け渡しの場所を自分が持つ。砦の持ち主との関係ができる | 倉の材料（木材200・石材200・金50）と、食料400＝自分の槍兵400人分の訓練 |
| ケイ（軍事） | 砦を建て、守備兵300を置く | 砦は**ケイの物**。兵もケイの物 | 北の国の軍が、自分の村より先に砦とぶつかる | 予備の兵が村の守りから外れる。石材・木材・金を自分の村の壁に使えない |
| ハル（情報・短い参加） | 偵察を1回 | 兵10を20ターン出すだけ | 渡しの村も北から攻められにくくなる。記録に「応じた」が残る | ほとんどない。**自給を選べば、手伝わなくても守りの得は受ける（ただ乗り）** |

**ただ乗りを正直に書く：** 砦ができると、手伝わなかったハルも守りの得を受ける。仕組みでこれを罰しない（徴収も報酬もないため）。協力の理由は、「得が自分に来る場所に自分の持ち物を置く」ことと、記録（誰が応じ、誰が取り下げたか）だけ。これで人が動くかは、人間の試遊でしか分からない。

## 2-5. 準備（試作で回した時系列）

| ターン | 起きたこと | 卓の見え方 |
|---|---|---|
| 0 | 採択。ミラが石材500と兵器40を送る。ソウタが拠点に倉を建て始める。ケイが槍兵80を訓練 | 石材：輸送中500／到着済み0。**送信済みは到着済みではない** |
| 3 | ソウタの倉が完成し、食料400を自分の倉へ送る | 食料：輸送中400 |
| 5 | ミラの工房で兵器10がそろい、残りを送る | 兵器：輸送中10 |
| 10 | 石材と兵器40がケイの村に着く。**今からケイの物** | 石材：到着済み500（そろった） |
| 15 | 兵器がそろい、ケイが砦を建て始める（6ターン） | 砦：建設中（持ち主ケイ） |
| 16 | 食料がソウタの倉に着く。**ソウタの物のまま** | 食料：到着済み400 |
| 21〜22 | 砦が完成。ケイが自分の兵300を置く（次のターンから数える） | 守備兵：300 |
| 20〜40 | ハルが偵察を出し、ターン40に戻る | 見張り：偵察の知らせ（ハル）。ここで条件が「今そろっている」になる |
| 40〜48 | 期限まで保つ。この間に倉を奪われる・食料を出す・砦を失うと、条件が崩れる | 「成立はターン48に判定。今そろっている（期限まで保つ必要）」 |
| 48 | **成立。** 期限のターンに、条件が使える状態でそろっていた | 「軍をどうするかは各持ち主が決める（自動では出ない）」 |

**気づいたこと（試作のルールで、人の評価ではない）：** 砦と兵はターン22にそろったが、見張りを偵察で満たす場合、知らせの有効期間（12ターン）のため、偵察をいつ出すかが待ちを生む。塔を建てる人がいれば早くそろう。ここは「情報の役を、建物で持つか、一回の行動で持つか」の判断になる。また、成立を期限で判定するため、早くそろっても期限まで「保つ」時間がある。これが守る緊張になるか、ただの待ちになるかは、人間の試遊で見る。

## 2-6. 成果

- **成立は、期限のターンに、条件が実際に使える状態でそろっているかで判定する。** 倉の物は「今ある量」（他の目標と二重に数えない）、建物は稼働、兵は砦にいる数。届いた累計や送信済み・輸送中・建設中では成立しない。材料（ケイへの石材・兵器）は条件にしない。
- **成立しても軍は動かない。** 砦の兵を峠へ出すか、砦で守るかは、砦の持ち主（ケイ）が決める。補給がそろったことを合図に軍が出発することはない（依頼の境界、決定 2026-10-23「軍を出して攻めるのは自動にしない」）。
- 拠点の働き（今の S1 のルールのまま）：砦は砦のマスの戦いに守り手として加わる。砦のマスにいる荷車は守られる（S1 契約 2.6）。倉はソウタの物で、ソウタが送るときだけ中身が動く。
- **持ち主のまとめ：** 砦＝ケイ、守備兵＝ケイ、倉と食料＝ソウタ、ケイの村に着いた石材・兵器＝ケイ（使って砦になった）、偵察の兵＝ハル。国は何も持たない。

## 2-7. 失敗と、失敗の後

失敗は「誰かが待つだけ」にならないように、それぞれの人に選び直しを出す。試作で全部起こせる（`出来事` の選択）。

| 失敗 | 何が起きるか | 誰に、どんな選択が出るか |
|---|---|---|
| **物流の遅延**（ソウタの食料が期限を越えて遅れる） | 遅れた荷は、なお**ソウタの物**で、行き先も変わらない。見込みは「期限後に着く」として別の色 | ケイ（調整役）：ハル・ミラ・ソウタに依頼／期限を延ばす（全員の再確認）／縮小案（食料250・守備兵200・見張り任意）。ソウタ：手元から追加で送る／近い人に頼む／遅れを受け入れる。ミラ・ハル：食料を申し出る（倉の持ち主に贈る） |
| **送信が確定しない** | 送信済みの荷は確定せず、**送り主の手元に戻る**。進み具合に数えない | 送り主：送り直す／取り下げる |
| **襲撃** | 護衛がいなければ荷車ごと北の国の物（決定 J2）。「失った」に移る | 調整役：不足を誰かに頼む／縮小。荷の持ち主：追加で送るか |
| **そろった後に倉を奪われる** | 中身は奪った人の物（S1 の事実）。向かっていた荷は届かず失われる。食料の条件は「今ある 0」に戻る | ソウタ：拠点に倉を建て直す。食料を持つ人：申し出直す。調整役：期限を延ばす／縮小 |
| **そろった後に砦を失う** | 砦と守備兵の条件が崩れる | ケイ：砦は一人1つまで（建て直しは材料と時間が要る）。調整役：縮小か中止 |
| **そろった後に倉の食料を出す（消費）** | 倉の持ち主が期限前に食料を出すと、条件が崩れる。出すかどうかは持ち主の判断で、仕組みは止めない | 倉の持ち主：戻す／期限後に出す。調整役：期限を延ばして追加を頼む |
| **参加者の退出**（ミラの村が攻められ、ミラが抜ける） | 未発送の申し出は取り下げ。**輸送中の兵器40はそのまま届き、ケイの物になる**。記録に残る | ケイ：兵器の不足10をハルに依頼／縮小。ハル：受ける（自分の兵器10）／断る。ミラ：後で戻って申し出ることもできる |
| **施設を失う**（ミラの工房が奪われる） | 兵器の申し出の残りが「供給元を失った」 | ミラ：手元の分だけ送る／**鉱石をハルに贈る**（着いたらハルの物）＋**ハルに兵器づくりを頼む**（作るのも送るのもハル）／取り下げる。「ハルの工房を借りる」は**使用権がないので閉じている**と明示（②の担当） |
| **方針の対立：構えの投票**（ユキが「北の国に通行を許す」を出す） | 可決すると、塔と柵が北の国を削らず止めなくなる（`stops()`）。砦は構えを見ずに戦う。目標の前提が変わる | ケイ：目的を「交易の中継拠点」に変える（守備兵200・見張り任意）／目的の書き方だけ変えて続ける／中止。参加者：方針変更のあと、続けるか取り下げるかを各自が決める（決めるまで申し出は数えない） |
| **方針の対立：競合する目標**（ユキが「東の砦攻め」に兵器120を求める） | 兵器の持ち主（ミラ・ハル）は、どちらに出すか、出さないかを選ぶ。申し出の合計が手元を超えると「準備中」 | ミラ：拠点へ／東へ／分ける／自分の長槍兵へ |
| **所有者の不在**（ソウタがいなくなる） | ソウタの倉・食料・申し出は**ソウタの物のまま、誰も動かせない**。卓では「不在の人の申し出」として見込みから外す | ケイ：ハルやミラに食料を頼む／期限・量を見直す。ソウタが戻れば続きから |
| **調整役の不在**（ケイがいなくなる） | 計画の見直しが止まる | 賛同した人（ミラ・ソウタ）が**調整役を引き継げる**。引き継ぐのは計画の編集と依頼だけで、ケイの物は動かせない |
| **期限切れ** | 目標は「期限切れ」。未発送の申し出は終わる。**届いた物は受け取った人の物のまま** | 受け取った人（ケイ）：送り主に返す（任意・荷車で返す）／自分の守りに使う。次に頼むとき、相手は記録を見て判断する |

## 2-8. この作例で確かめたいこと（人間の試遊で）

試作のテストで確かめたのは「ルールが書いたとおりに動く」ことだけ。次は人間の試遊でしか分からない（9章の試遊案）。

1. 人は、自分の得のために、自分の持ち物を他人の目標に組み合わせるか。それとも待つか、ただ乗りするか。
2. 遅延や退出が起きたとき、人は選び直すか、離れるか。
3. 「送った物は相手の物になる」ことが、協力を止めるか、信頼の読み合いとして面白いか。
4. 調整役は、仕事の押しつけとして嫌われるか。
