# 16. ⑧への引き渡し：勝利条件の候補 0／X／Y を評価するための入力

**状態（2026-10-30）：** ①から⑧へ渡す**一つの資料**。国際供給網（14章）と整合確認（15章）から、⑧が 0／X／Y を同じ条件で比べるのに要るものだけを集めた。**勝利条件は何も採用していない。報酬・賞金は付けない。**

**⑧との接続の状態：** ⑧の最新の報告は `4a359a03`。①の候補が届いていなかったため、⑧は一般的な仮の規則 CMP／TRD／COOP で止まっている、と共有された。**`4a359a03` は、この worktree・`git fetch`・GitHub の API のどれでも取得できなかった**（2026-10-30）。だから、⑧の CMP／TRD／COOP の中身は読んでおらず、下の対応は報告の言葉だけに基づく。

| ⑧の仮の規則 | ①の候補との関係（未検証） |
|---|---|
| COOP | **X ではない。** ⑧の COOP は外からの報酬を足すと報告されている。X は報酬を付けず、共同・国・個人の記録を分けるだけ。COOP の結果を X の結果として扱わない |
| CMP | 競争の基準として 0a（今の S1）に近い見込み。ただし、定義を読んでいないので同じとは扱わない |
| TRD | 交易を数える規則と報告されている。X の「使われた交易」（15章 15-3 の帳簿）と同じ数え方かは未確認。**取引の回数や送った量で数える規則なら、X とは違う** |

**未決定のものは未決定のまま渡す。** 特に、**中央塔（Concord の鐘楼）は共同目標に入れない。** 中央塔を共同事業・勝利条件に組み込むかは本人の判断を待つ事項で、①だけでも⑧だけでも足さない（11章 11-2、14章 14-15 S6）。

## 16-4. 入力：交換の条件

| 条件 | 試作 | ②（報告からの読み、未検証） |

| 物の種類 | 片方が兵器、もう片方が素材（鉱石・木材・石材・食料） | 素材と、すでに生産済みの武具 |

比較のときは、**②の実装の条件で作例が成り立つか**を先に確かめてほしい（成り立たない操作があれば、その候補の評価に入れない）。

## 16-5. 入力：共同成果

- 作例：「三国の交易路が使われる」。他の人から④で確定して届き、受け取った人が帳簿の上で自分の物では足りずに使った量（15章 15-3）が **50 以上** の人が、**3か国・3人（判断する人）以上**、期限 **96 ターン**［すべて仮］。
- **50 の単位：** 資源の種類を区別しない生の数の合計。鉱石・木材・兵器は同じ値打ちではない（S1 では兵器1＝鉱石2＋木材1 の材料：`arms.rs:48-54`）。比べ方は未決定：(a) 生の合計（今の試作）(b) 資源ごとの基準 (c) 目標の一段の達成で判定 (d) 換算（15章 15-2）。⑧の比較では、**少なくとも (a) と (b) の2つで結果が変わるか**を見てほしい。
- 「自分の物から先に使う」は帳簿の帰属の規則で、必要性・有用性の証明ではない（15章 15-3）。
- 一つの行為が共同・個人の両方に効くのは二重計上ではない（15章 15-4）。

## 16-7. 入力：参加と退出

- 国籍で参加を強制も禁止もしない。物を動かせるのは持ち主だけ。交換は両方の同意。
- どの人にも「今は組まない（自給）」「別の相手と組む」「条件を変えて返す」「抜ける」がある（14章 14-4）。
- 抜けると、自分の申し出は取り下げ、自分あての申し出は断る。**成立済みの荷車は届き、受け取った人の物。**
- 国の頼みに応じるかは持ち主が決める。国ができるのは S1 の議会（構え・追放）だけ。
- 判断する人（`controller`）は試作では台本で与える。**本番で一人をどう判定するか（複数ウォレット）は決めていない**（8章 Q3、15章 15-3）。

## 16-8. 入力：失敗したときの代わりの手

| 失敗 | 代わりの手（試作） | 比較で見ること |
|---|---|---|
| 一人の遅れ（荷車が8ターン遅れる） | 待つ、または同じ物を別の相手から得る | 代わりの相手が使われるか（14-13 の H7） |
| 条件の変更（断って1.5倍で返す） | 受ける・断る・別の相手 | 交渉が遊びになるか、面倒か |
| 施設の喪失（工房を奪われる） | 別の工房の持ち主と組む。加工の貸出は閉じた選択肢 | 閉じた選択肢を求める声の数（H4） |
| 到着が未検証 | 数えない。確かめられたら到着の時点にさかのぼって数える | ④の確定の遅れが共同成果の時点をどれだけ動かすか |
| 持ち主の不在 | 誰も動かせない。不在の人あての申し出は受けられない | 不在が全員の待ちになるか |
| 期限切れ | 「期限切れ」の記録。届いた物・建てた物は持ち主の物のまま | 期限切れの後に、人が続けるか |
