# 4. 貢献のしかた（固定の職業にしない）

**この文書の役割：** 国の目標に、いろいろなやり方で手を貸せるようにする。職業を選ばせず、「何を持っているか」と「どれだけ時間を使えるか」で、その場の役割が決まる。自給する選択と短時間の参加も、正当な選択として成り立たせる。

## 4-1. 貢献の型

役割の名前は説明のためのもので、画面で選ぶ職業ではない。同じ人が、目標ごとに違う型で手を貸す。

| 型 | 具体的な行動（S1 の命令） | 誰の物のままか | 手間 | 作例での例 |
|---|---|---|---|---|
| **生産** | 工房で兵器を作る、鉱石・石材を掘る（村の生産） | 作った物は作った人の物。送れば着いた先の人の物 | 続けて少し（産出を待つ） | ミラの兵器 |
| **材料を贈る** | 他人の村へ隊商（`SendCaravan`、ウォレット署名） | 着いたら受け取った人の物 | 1回 | ミラの石材をケイへ |
| **自分の場所に置く** | 自分の倉を前線に建て、自分の物を運び込む | 最後まで自分の物。使わせるかも自分が決める | 1〜2回 | ソウタの倉と食料 |
| **輸送** | 自分の荷を、自分の判断で、時期と道を選んで送る | 自分の物（着くまで） | 1回ずつ | ソウタの発送の時期 |
| **建てる** | 砦・塔・柵・倉を自分の名前で建てる | 建てた人の物（奪われうる） | 1回＋材料 | ケイの砦 |
| **軍事** | 自分の砦に兵を置く（`FortGarrison`）、護衛の封じた進軍 | 自分の兵 | 1回〜続けて | ケイの守備兵、護衛 |
| **情報収集** | 偵察を1回出す、峠に見張り塔を建てる、見たことを卓に書く | 偵察の兵・塔は自分の物 | 1回（偵察）／建物（塔） | ハルの偵察 |
| **仲立ち** | 依頼を出す、遅れたときに代わりを探す、計画を見直す（調整役） | 何も持たない | 判断の手間 | ケイの依頼 |
| **加工の受け手** | 他人の材料を受け取り、自分の施設で加工して送る | 受け取った材料も、作った物も自分の物 | 続けて少し | ハルの工房（ミラの工房が奪われたとき） |

**決まりごと：**
- 同じ人が複数の型を同時に持てる（ケイは「建てる」「軍事」「仲立ち」）。
- どの型にも「提供の上限」を付ける。上限は自分で決め、発送までは変えられる。
- 他人の施設を自分で動かす型（借りる・使用権）は**入れない**。S1 にないため（②の担当。試作では閉じた選択肢として「使用権が要る」と表示）。

## 4-2. 自給という選択

**自給は「何もしない」ではない。** 自分の持ち物を自分の村に使う、という戦略の選択として扱う。

- 卓の判断には、どの必要にも「自給を選ぶ（これには出さない）」があり、選ぶと**その人にとって何が起きるか**を書く（例：ミラ「兵器を自分の長槍兵に回せる。ただし峠の向こうの鉱脈へは、護衛なしで行くことになる」）。
- 自給を選んでも、記録に罰は残らない（「断った」「出さない」は残る。依頼を断った場合だけ）。
- **ただ乗り：** 国の目標の得（砦の守り）は、手伝わなかった人にも届く。仕組みはこれを止めない。止めない理由：徴収と報酬を入れないため。協力の理由を「本人の得が、その場所に自分の物を置くことで生まれる」ように作例を組む（砦の後ろを自分の荷車が通る、前線の倉を自分が持つ、など）。

## 4-3. 短時間の参加

- **1回で終わる申し出：** 偵察1回、荷車1台、依頼に1回応じる。卓は「1回で済む必要」を「短い参加」と書いて出す。
- **途中で抜けても、出した分は無駄にならない：** 発送済みの荷は届く。届いた物は受け取った人が使う。記録には「応じた量」が残る。
- **時間の目安：** S1 は1ターン10分。偵察は往復で数時間、荷車は1〜2時間かかる。在席時間の短い人でも、出して離れればよい行動を中心にする。在席が長い人やAIが得をしすぎない（決定済みの「眠らないAIに人間が負けない守り」）よう、**卓の行動に「張り付いて押し続けると得」な操作を作らない**。

## 4-4. 協力の得と機会費用を、数字で見せる

卓の判断には、申し出のたびに次の2つを出す。

1. **協力するあなたの得**（その人の場所・持ち物から決まる。作例では `BENEFITS`）。報酬ではなく、ゲームの中で起きること。
2. **代わりにできたこと**（S1 のルールから計算できるものだけ）：
   - 兵器 n → 長槍兵 2n 人の訓練、または包囲の宣言 n/50 回（`arms.rs`）
   - 石材 n → 見張り塔 n/400 基、倉 n/200 つ（S1 契約 2.3、`VAULT_COST`）
   - 食料 n → 槍兵の訓練（食料の値は試作の仮）
   - 兵 → その間、村の守りや護衛に使えない

## 4-5. 国境の拠点以外の目標（作例を唯一にしない）

同じ卓の仕組みで、次のような目標が作れる。どれも「国が持つ」のではなく「誰かの物を組み合わせる」。

| 目標の例 | 必要の組み合わせ | 主に生まれる判断 |
|---|---|---|
| 東の砦攻めの兵器を集める（試作の「競合する目標」） | 兵器を攻める人の村へ、護衛 | 兵器をどちらの目標に出すか |
| 鉱脈の前哨を守る | 前哨の倉、柵、見張り塔、補給の荷車 | 誰の倉に置くか、誰の柵か |
| 補給路の塔をつなぐ | 道に沿った塔（各自の物） | 塔をどこに、誰が建てるか（一人2つまで） |
| 新しく来た村の立ち上げ | 食料・木材を新しい村へ（贈る） | 誰が、どれだけ、何を見返りに期待するか（仕組みは払わない） |
| 交易の中継拠点（構えが「通行」に変わった後） | 前線の倉、守備兵少し | 戦争の構えでなくなったとき、拠点を何に使うか |
| 包囲を受けている仲間の村への補給 | 食料・兵器を仲間の村へ、護衛 | 間に合う道を誰が持っているか |

試作では、目標の中身は `scenario.mjs` のデータで持つ。進み具合・成立・持ち主の計算（`model.mjs`）は作例に依存しない（必要の種類は deliver・build・garrison・watch・escort の5つ）。ただし、判断の文言の一部（構えが変わったときの代わりの目的、縮小案）と出来事の台本は作例に合わせて書いてあり、他の目標に使うときはデータに移す必要がある。
