## 3. 予測（[02](02-preregistration.ja.md) §4）の当たり外れ

| 仮説 | 予測 | 観察 | 判定 |
|---|---|---|---|
| H1 荷の保存で往復は効かない | 効かない | 寄与は消費された 100 だけ | 予測どおり |
| H2 B は受取国を変えない | 変えない | 15 シナリオすべてで A と同じ | 予測どおり |
| H3 C：一国だけでは早く終われない | 終われない | rush-solo：多様性で未達、予定どおり 480 | 予測どおり |
| H4 C：一国＋従う2国なら終われる（防げない） | 防げない | 送った材料なら防げた（出どころの規則）。自分の材料＋食料の見返りなら 96 で閉じ、n0 が勝つ | 一部は予測より良く、一部は予測どおり。防げたのは出どころの規則のおかげで、`holder` で数えると防げない（試験で確認） |
| H5 印のない別アカウントは防げない | 防げない | 印なし：達成、96 で閉じる。印あり：未達 | 予測どおり |
| H6 独立した選択が残る | 残る | 残る（戦期が閉じた後を除く） | 予測どおり |
| H7 C では妨害が終わりの時刻を動かす | 動かす | 144 → 480、受取国 n1 → n0 | 予測どおり |
| H8 欠落があれば断定しない | 断定しない | 判定できない。要塞の流れに欠落があれば、賞金も判定できない | 予測どおり |

予測が外れて悪い方に出たものはありません。ただし、予測が当たったことは C が安全という意味ではありません。H4・H5・H7 は、**C の弱さを予測し、そのとおりになった**ものです。

## 4. 書いている途中で見つけて直したこと

- A でも計画を開けず、隊商が全部拒否されていた。目標を判定しない案でも、世界の中の物は動くように直した。
- 別アカウントが自分の砦を使って「他国の建物の利用」になっていた。建物の持ち主と同じ人（cluster）を除いた。
- 隊商の荷の確かさを、途中の荷の確かさで下げていなかった（未検証の荷を送り直すと、確かめられた扱いになっていた）。最も低い確かさを引き継ぐように直した。

### 独立した見直しで見つかり、直した不具合

評価器の中心部を別の目（下調べなしの見直し役）に読ませ、再現できた不具合を直した。直したものは `test/review-fixes.test.mjs` に再現の入力ごと残した。

| # | 不具合 | 直し方 |
|---|---|---|
| R1 | 欠けた記録そのものが判定を決める場合（2回目の利用が欠けた）に、`not_achieved` と断定していた | 欠落の規則を強めた。欠落の直前に見えた記録の鐘より後に、判定を決める鐘があり、しかも欠けた流れがその判定に関わる種類を運びうるなら、判定しない。流れが運ぶ種類は `state.streams[s].kinds` で狭められる |
| R2 | 同じ番号の別の `sub` が残ると、衝突の穴が欠落にならなかった | 穴を番号の単位で欠落に数える |
| R3 | 拒否した記録の一覧が、重複や並び順で hash を変えていた | 中身で重複を除き、全順序で並べる |
| R4 | 投入の記録そのものが未検証でも、荷が確かなら数えていた | 荷と記録のうち、低いほうの確かさを使う |
| R5 | 「計画を開いた」個人目標が欠落を見ていなかった | 他の目標と同じ欠落の規則を使う |
| R6 | 自分の材料を他人に送って入れさせると、「他人の材料」になった | 他人は荷の出どころで数える。「材料を入れた」個人目標も、自分の荷だけを数える |
| R7 | C で区切りが判定できないのに、賞金は「決まった」としていた | 区切りが判定できなければ、賞金も判定しない。別の計画が判定できず、早く達成していたかもしれない場合も同じ |
| R8 | ①の adapter：caravan の「先着の link」を、依頼の時刻の順で決めていた | link 自身の時刻で決める |
| R9 | ④の adapter：同じ鍵で中身の違う受領書は、入力の順で片方が残った | 両方を同じ id で出し、評価器の記録の検査で衝突として外す |
| R10 | 建物の種類が違う完成の記録を受け付けていた | `wrong_structure` で拒否する |

あわせて、可能性が低いとされた指摘も直した。
- 共同の報酬枠も、人（cluster）ごとに1つにした。
- S1 で持ち主の分からない建設は、計画の責任者として扱わない。
- adapter が解決できない記録は、番号の位置を埋めず、欠落として残す。
- 積荷の分からない焼き討ちを、解決できない記録に入れる。
- `#` を含む荷の名前を拒否する。
- 途中で現れた国も判定する。

直さず限界として残すもの：④の受領書には欠落を知る番号がない（④の判断 I3）。

これらを直した後、比較表で変わったのは一か所だけ。unverified-storehouse の C で、賞金が「判定不能」になった。区切りの時刻が決まらないため。

## 5. 確かめていないこと

- 本物のチェーンの記録での実行。S1 の adapter は、ABI の記録表から組み立てた本物の形のバイト列で試しただけ。
- ①・④・⑭の実物の出力。adapter は伝え聞いた形の合成データで試しただけ。
- 戦期をまたぐ持ち越し（次の戦期の判定）。
- 人間による理解・面白さ・判断のしやすさ。
