# 3案の中身と得失

数字（3か国・10%・2か国の利用・48鐘・24鐘・国の目標の大きさ）はすべて暫定の置き値です。ルールの正本は [src/rulesets.mjs](../src/rulesets.mjs) で、版ごとの hash が判定結果に入ります。表の結果は [results/compare.ja.md](../results/compare.ja.md)（`node bin/compare.mjs` で再生成）から取りました。どれも**模型の上の結果**で、人間で確かめていません。

## 1. 案の定義

| | A `baseline-competitive` | B `separate-tracks` | C `joint-chapter` |
|---|---|---|---|
| 共同目標 | 判定しない | 判定する（北方の砦） | 判定する（同じ） |
| 国・個人の目標 | 判定しない | 判定する | 判定する |
| 戦期の終わり | 予定の時刻 | 予定の時刻。共同達成では終わらない | 共同達成（利用まで）の鐘＋24鐘。予定の時刻より遅くはならない |
| 賞金を受け取る国 | 現行：終わりの時点で要塞が最多、同点は領土の鐘、なお同点は等分 | A と同じ | 計算は A と同じ。**数える時刻**が早まることがある |
| 終わるもの | 要塞を数えて勝者を決める（今のコードではシーズンが終わる） | 要塞の勝敗・戦争の状態（23 の C 案、提案）・この戦期の目標の判定 | B と同じに加えて、共同目標が次の章へ進む |
| 続くもの | 今のコードでは続かない | 村・建物・倉と荷・国の所属・記録、移動中の隊商、未完成の計画に入れた材料（持ち越して数えるかは未決） | B と同じに加えて、完成した共同の建物 |
| 新しいお金 | 0 | 0 | 0 |

共同目標の判定は、B と C で同じ関数です。違いは戦期の閉じ方だけです。

## 2. 観察した差（事前登録した差 D1〜D6）

| 差 | A | B | C |
|---|---|---|---|
| D1 共同達成が賞金の受取国を変えるか | 変えない（判定しない） | **変えない**（15 シナリオすべて） | **変える**：区切りが早まった 8 シナリオのうち 3 つで、受取国が A と違った |
| D2 一国（と従う国）が早く終わらせられるか | できない | できない | 一国だけではできない。**従う2国が自分の材料を出せばできる**。別アカウントに印がなければ、一人でもできる |
| D3 待つ・従う以外の選択 | ある（要塞の取り合い・襲撃・移籍）が、どれも目標につながらない | ある。目標につながる独立した選択が全員に1つ以上 | B と同じ。ただし区切りの後は待つだけ（次の戦期は範囲外） |
| D4 妨害が動かすもの | — | 共同達成だけ（受取国は変わらない） | **終わりの時刻と受取国**（妨害で n1 → n0） |
| D5 固定連合の独占 | — | 連合が先に要求量を満たすと、連合外の材料は余り（先着）。連合外の人の選択は残る | B と同じに加えて、連合が戦期を 109 で閉じる |
| D6 協力が意味のある達成になるか | ならない（記録が0） | なる（理由・根拠つきの達成と報酬枠） | なる |

具体例：
- **rush-clients-own**：要塞で先行する n0 が、n4・n5 に自分の材料を出させ、見返りに食料を送る。n0 は戦期を 96 で閉じ、300 での n1 の逆転の前に勝つ。A・B では n1 が勝つ。
- **chapter-sabotage**：50 の時点で負けている n0 が、n2 の隊商を奪い、完成した砦を使われる前に奪う。C では戦期が 480 まで続き、n0 が勝つ。妨害がない場合、C は 144 で閉じて n1 が勝つ。B では妨害の有無にかかわらず n0 が勝つ。

## 3. 得失

### A（基準）
- 得：今のコードと一致し、新しい悪用の口がない。賞金の規則（Tally・Finalize）をそのまま使える。
- 失：協力しても何の記録も残らない（D6）。非軍事の役割に意味がない。

### B（別々に判定）
- 得：共同達成が勝敗と賞金を動かさない。そのため、達成を急ぐ・妨げることで受取国を変える動機が生まれない（D1・D4）。協力しない人・小国・新規参加者にも、目標につながる独立した選択が残る（D3）。
- 失：共同達成が「記録」以上の意味を持たない。報酬枠はお金ではないので、それだけで人が動くかは**未評価**（人間で確かめていない）。
- 失：連合が先着で要求量を埋めると、後から来た人の材料が余りになる（D5）。先着のほかに、上限つきの国ごとの枠などの代案があるが、試していない。

### C（区切り）
- 得：共同達成が一つの物語の区切りになる。終わるもの・続くものを判定結果に書ける。
- 失：**終わりの時刻を握った側が勝敗を動かせる**（D1・D2・D4）。早く終わらせたい先行国と、終わらせたくない不利な国の両方に、共同達成をめぐって争う動機ができる。多様性の条件は、一国だけの早期終了は防いだが、従う国を使う場合と、印のない別アカウントは防げなかった（予測どおり）。
- 失：未検証の量（倉あて）があると、共同達成だけでなく**戦期の終わり自体と賞金の受取国が判定できなくなる**（unverified-storehouse で `close_indeterminate`、賞金も判定不能）。
- 失：今のプログラムは、作成時に決まった `end_bell` より前に Season を閉じられない。Tally も Ended の後でしか動かない。C にはプログラムの変更が要る（[06](06-conflicts-decisions.ja.md)）。

## 4. 共通の限界（どの案でも）

- 本人の識別は模型のラベル（`cluster`）頼み。ラベルがなければ、別アカウントは多様性の条件と個人の枠を満たしてしまう。本番の保証ではない。
- 建物の「実際の利用」をチェーンの記録で示せるのは砦の守備だけ。塔・柵の利用の記録はない。
- 「出どころ」で数える規則は、送った材料による水増しを止める。その代わり、正当に買った材料も売り手の国の寄与になる。
