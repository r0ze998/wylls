# ⑬ プレイヤーの代理ではない、独立したAI住民（最小実装）

作業日 2026-10-30。基準 commit `4cd901de9f8e0d6c0b2016851d30595c4a70aa46`（統合候補 `integrate/claude-consolidation-20261029` の handoff 文書。`main` 9214293 に試遊キット文書を足したもの）。作業ブランチ `claude/eager-cerf-k74z5s`（この担当専用。`main` から 4cd901de へ早送り）。この担当の成果物はすべてこのディレクトリにあり、**共有コード（`permutation-gateway` ほか）は一行も変えていない**。共有コードへの変更は [patches/](patches/) に未適用の差分として分けた。

> **読み方。** 各文書は「実行して確かめた事実」「コードを読んだ結果（未実行）」「提案」を分けて書く。結果はすべて**ローカルの模擬試験世界**での値で、Frontier プログラム・チェーン・実モデルでの動作を意味しない（下の「どこが模擬か」）。

## 結論

| 求められたこと | 判定 | 根拠 |
|---|---|---|
| 目的の異なる2人のAI住民が、人間の命令なしに状況を読み、依頼・協力を選び、結果を確かめ、次の行動を変える | **模擬世界で確認** | 200ターンの実行で Asa（自分の村の発展）45回・Ren（余剰物資の活用）49回の判断。Ren は約束を破られた（Mio が引き受けて届けない）後、依頼先を Kou→Mio→Asa→Kou と変え、破った相手には二度と頼まない（`test/demo.test.mjs`）。襲撃に遭った道は一定期間断る（`abuse.test.mjs`） |
| 人間の依頼を目的・予算・条件に合わないため断り、代替経路を残す | **模擬世界で確認** | 目的（`goal`：自分の計画が要る）、条件（`deadline`：道が間に合わない、最短の期限を提示）、予算（`budget`：贈与の日枠超え、送れる量を提示）の3種。断られた依頼は全員に開き直り、Kou の木材依頼は Ren が届け、Kou は約束の金を返した |
| 各住民が独立した資産・許可・記憶・予算を持ち、人間の鍵を共有しない | **確認** | 住民ごとに自分で作る ed25519 鍵（0600、所有者の鍵とも人間の鍵とも別）、自分の村（参加時の初期資源のみ）、自分の記憶ファイル、自分の予算台帳（エージェント財布の `AgentLedger` をそのまま使用） |
| 参加・初期資源は既存ルール、AIだから無料で増やさない | **模擬世界で確認** | 参加は人間と同じ関数・同じ初期資源（`catalog.rs STARTER_KIT`）。二度目の参加は拒否。**実環境の既存経路（運営招待で参加費なし）は設計の決定と食い違う**（下の食い違い 3） |
| 行動回数・推論費用・待機間隔・再試行・停止条件を設け、無限に繰り返させない | **確認** | 既定値と試験は [04-safety-limits.ja.md](04-safety-limits.ja.md) |
| 共謀、贈与の循環、互いの依頼への無意味な反応、同じ操作の重複を試す | **確認（7件の試験）** | 試験の途中で実際の欠陥を2件見つけて直した：失敗した建設を3ターンごとに選び直し推論を浪費する、再試行待ちの同じ建設を重ねて選ぶ（[04](04-safety-limits.ja.md) §3） |
| 所有者・資金提供者・停止できる者の明示 | **確認** | 住民ごとの `charter.json`。永久に生きるとは書かない（「所有者がこのプロセスを動かし、世界がある間だけ動く」） |
| 人間と同じ可視情報・規則、管理権限で勝たせない | **模擬世界で確認** | 公開部分は閲覧者によらず同一の関数。住民の ports に運営の操作はない。AI/人間の表示はしない（表示方針は未決のまま） |
| 機械的な成功と、人格・自律性・面白さの評価を分ける | **分けた** | `summary.json` の `mechanical` と `observed`。後者は評価ではなく人が判断する材料（[06-evaluation.ja.md](06-evaluation.ja.md)） |

## どこが模擬か（実チェーンには通していない）

| 段階 | この担当で動かしたもの | 実物との関係 |
|---|---|---|
| 世界（状態・規則・時間） | **模擬**：`world/testworld.mjs`。数値はゲームの値を Rust から読み戻して固定（`test/rules-pinned.test.mjs`）。省いた規則は `world/rules.mjs SIMPLIFIED` | Frontier プログラムではない。上限（30/時の行動バケット、中継の1日40回）は同じ値で模擬 |
| 依頼の掲示板 | **模擬**：`world/board.mjs`（署名・送信者ごとの上限は citizens の social と同じ値） | 既存の social 層に「依頼・返答」の記録種はない（提案：[03](03-contracts.ja.md) §5） |
| 参加 | 模擬世界の参加（署名・初期資源） | 実環境の AI は運営招待で参加（`relay.mjs /f/join`）。未実行 |
| 観測 | 模擬世界の `view()` | 実環境は herald の `/h/*`。未実行 |
| 実行・取消（④） | 模擬世界のアダプター（エージェント財布の ActionRequest/ActionResult の形） | relay・AgentGateway に未接続。S1 の SendCaravan を Node で組む builder がゲートウェイにない（[01](01-existing-surface.ja.md) §3） |
| 判断（⑤） | **fixture provider**（モデルなし・通信なし・課金なし） | Claude/GPT は `fromChatProvider` の契約まで。呼んでいない |
| 記憶（⑫） | ローカル adapter（既存 `citizens/memory/retrieve.mjs` を使用） | ⑫が来たら差し替え。差し替えても判断が同じことを試験済み |
| 予算台帳 | **実物のコード**（`AgentLedger`、`owner-auth.mjs`）。入金は模擬 ID | 試験単位のみ。実資金なし |

**実チェーンに通せなかった理由（事実）：** ローカル実チェーン（`frontier-stack`）には Agave 3.1.9 の `cargo-build-sbf` が要る。その導入（公式の install スクリプトの実行）を自動承認の審査が拒否した。権限拒否は回避していない。導入が許可されれば、[05-results.ja.md](05-results.ja.md) §4 の順で実チェーン段階に進める。

## 実行手順

```sh
npm ci --prefix permutation-gateway      # 住民は gateway のモジュールを（変更せず）読み込む
workstreams/13-citizens/run.sh           # 試験35件、デモ（200ターン）、再起動ありのデモと経過の比較 → results/
node workstreams/13-citizens/demo/run-demo.mjs --out /tmp/ws13 --bells 200 --crash after-submit
```

Node 20 以上。チェーン・モデル・ネットワーク・鍵の設定は不要。有料 API の鍵が環境にあると起動を拒否する（citizens の `assertNoApiKeys`）。

| 停止できる者 | 所有者（署名した mode コマンド）、世界の運営（HALT ファイル、世界側の拒否）、住民自身の上限（maxTurns、予算、provider 失敗での一時停止） | 同左の仕組みは既存コードを流用 |

## 担当の境界

- ④の実行・取消、⑤の Autopilot と provider、⑫の記憶は作り直していない。それぞれ差し替え口（`ports/`）と、既存コードの形に合わせた契約だけを置いた。既定の fallback（`safeFallback`）は「宛てられた依頼への返答・自分の建設・待機」だけで、新しい約束をしない。⑤の Autopilot に置き換える前提。
- 共有コードの変更は [patches/](patches/) に分離し、適用していない。
- push・merge・deploy、実資金、鍵の設定、権限拒否の回避はしていない。
