# 07 継続する世界への対応（2026-10-31、方針訂正を受けて）

方針：世界は期間で終わらず、リセットしない。戦期は世界の寿命とは別で、区切り方・集計・賞金は未決（⑬では決めない）。⑬の担当範囲は「住民の目的・記憶・保留中の行動を継続し、再起動や戦期切替で二重行動を起こさない」。World／Period の正本と移行処理は④（横断設計は⑧から④）に集約するため、⑬は自分で期間の型を作っていない。試験に使う境界は、模擬世界の**試験用の印**（`world.operator.markBoundary`、規則は何も付いていない）だけ。

## 2. 変更した挙動（⑬、すべて実装済み）

1. **停止は一時停止**：運営の停止と所有者の停止は、新しい判断も送信もしないが、何も取り消さない。再開すると journal の続きから送る。所有者が明示的に `withdraw` を求めた場合でも、取り消すのは誰にも約束していない送り（建設など）だけで、引き受けた配達と約束の返送は残る。停止中も `owed()` で負っている約束を報告する。
2. **判断回数の上限は「新しい判断」だけを止める**：上限に達しても、約束の返送は code の義務として続ける。所有者は署名した `policy {extendTurns}` で上限を延ばせるが、1 回に最大 1,000 で、無期限にはならない（⑤の方針：世界が続くことを理由に認可を永久化しない）。予算（総額・日額・回数）はそのまま。
3. **相手は財布アドレスで覚える**：信頼・冷却期間・襲われた道・兄弟の照合・記憶の関係者を財布アドレスにした。citizen id は「どこで見たか」として事実の欄に残す。状態の版を 2 にし、版 1 の住民は開いたときに移行する：その時点の公開の村一覧から「この id はこのアドレス」の対応表を一度だけ記録し、現在の状態（冷却期間の鍵）だけを変換する。**記憶の履歴ファイルは書き換えない**（古い記録は対応表を通して読む）。
4. **遅れた返済を数える**：債務は時間では消えない。返送の期限を過ぎた依頼は「未返済」のまま表示に残り、住民は再開後に遅れて返す。掲示板はそれを `returned-late` と記録する（期限内の `returned` とは区別し、期限切れの時点の「約束破り」の記憶も消さない）。
5. **読む量を差分にする**：観測は「前回読んだイベントの続き」と「ある時刻以降に動いた依頼（＋贈与の循環を調べる 1 日分）」だけを読む。模擬の掲示板は索引を持ち、確定した依頼の状態を覚える。
6. **状態ファイルは現在だけ**：判断は直近 10 件の要約だけを持ち（全文は `decisions.jsonl`）、終わった約束の目印・期限の過ぎた冷却と失敗の保留を消す。未完了のものは消さない。履歴（記憶・判断記録）は追記のみで、減衰は想起の規則であってリセットではない。

## 4. 移行や仕様判断が残る点

1. **世界の識別子**：口座が Season を基点に導かれる限り、「Season を作り直さない」ことが継続の前提になる。既存の Season をそのまま続けるのか、新しい基点に移すのかは④⑧の判断。⑬の住民は財布アドレスで覚えているので、どちらでも記憶は続く（村の口座の対応は移行側が公開する必要がある）。
2. **AI の判断の証拠の公開周期**：今はシーズン終了時だけ。区切り（戦期・一定期間）ごとの公開に変える必要があるが、周期は未決。
3. **住民の参加と賞金**：運営招待（参加費なし・賞金対象外）か参加費か、NFT 参加パスとの関係は未決。毎戦期の買い直しを前提にしない、という方針だけ守っている（⑬の住民は一度参加すれば続く）。
4. **エージェント台帳の履歴**：500 行を状態ファイルに持つため、長く生きる住民では保存のたびの書き込み量の大半になる。履歴を追記専用のファイルに移す案を④へ（差分にはしていない）。
5. **遅れた返済の評価**：`returned-late` を信頼でどう数えるか（今は期限切れで −2、遅れて返して +1）。評判の規則は⑫の担当。
6. **実チェーンでの確認**：境界の通過も長期運用も模擬世界でのみ。隊商以外（加工・預かり・封印進軍）は模擬世界にないので、⑨⑩⑱と⑯の通し試験で確かめる必要がある。
