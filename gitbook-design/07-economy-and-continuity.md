# 第7章 経済と世界の継続

この章で分かること：

- 世界は続き、戦争だけを 2 週間の「戦期」で区切ること
- 新しく来た住人が参加する理由と、古参の独占を防ぐ仕組み
- 資源がどこから入り、どこで消えるか（決定済みと提案の境目）
- 賞金の原資、国の中の取り分、不正への対策

## 7.1 世界は続き、戦争だけを区切る

【決定済み】世界は続き、戦争だけを「戦期」で区切ります（再設計の文書の C 案）。戦期は、戦争の勝敗と賞金を区切る 2 週間の期間です。勝敗の砦は、国の勝敗を決める砦です。世界ごと消すシーズン制はやめます。これは、2026-09-30 の古い決定「すべてはシーズンで終わる」（T1）を置き換えるものです。

| 続くもの【決定済み】 | 戦期の終わりに戻るもの【決定済み】 |
|---|---|
| 村、建物、倉、札、仕組み、記録 | 勝敗の砦（どの国のものでもない状態に戻り、守備の兵は家に帰る） |
| 国の所属、国の設定 | 国どうしの戦争の状態 |


| 項目 | 内容 | 状態 |
|---|---|---|
| 戦期の長さ | 2 週間で始め、フェーズ6で調整する | 【決定済み】 |
| 戦期の間の休み | 置かない。境目で、勝敗の砦が中立に戻るだけ | 【決定済み】 |
| 賞金 | 戦期ごとに配る | 【決定済み】 |
| 勝ち点を 0 に戻すことなど、その他の細部 | ― | 【提案】 |
| 片付け | 下の注を参照 | 【決定済み】 |
| 段階 1 を試す場所 | 新しいシーズンで試す。戦期は別の作業で後から作る（決定 J5） | 【決定済み】 |

注（片付け）：

- 前払いが尽きた仕組みは止まり、一覧から外れます。
- 燃料が切れた建物は止まります。
- 止まったまま長く放置された建物は、廃墟になります。廃墟は誰でも取り壊して、材料の一部を得られます。

### 遊びとしてどうなるか

世界と戦期の文書（23 の 3 章）は、次のように描いています。

- 戦期の初め、勝敗の砦は全部中立です。
- どの国も、前の戦期で築いた補給の仕組みと倉を持っています。だから砦の取り合いは、「どの国の補給の仕組みが強いか」の勝負になります。
- 戦期が終わっても、経済と仕組みは残ります。次の戦期の準備は、終わった瞬間から始まります。

### 今の実装との差

今のゲームは 14 日のシーズンで、終わると精算して終わります。14 日の走行を最後まで動かした記録があります（2026-10-18、征服の版。main に入った）。S1 のルールでも、480 ターンのシーズンを人・ボット・AI で最後まで遊び、集計まで通しました【実地で確認】（2026-10-26。詳しくは [第10章](10-gap.md)）。

次の処理は、まだありません（[第10章](10-gap.md)）。

- 世界を次の戦期へ持ち越す処理
- 砦と戦争の状態だけを戻す処理
- 戦期ごとの賞金の精算

## 7.2 新しい住人が参加する理由

| 理由 | 中身 | 状態 |
|---|---|---|
| すぐ役に立つ仕組みが使える | 古参の組合や工房を、最初の日から使える。最初の 30 分の目標は、他人の仕組みを使って達成できる | 【決定済み：最初の30分】 |
| 自分が使われる | 新参の村の食料と木材には、最初から買い手がいる（古参の工房と軍が大量に使うため） | 【決定済み：詰まない】 |
| 守られる | 期間つきの守り。国の内側に置く | 【決定済み】 |
| 追いつける | 最初の建物は早く建つ。大きいほど維持が重い。取り分は、いた間の行いで数える | 【決定済み】 |
| 途中から入っても対等に競える | 勝敗の砦は戦期ごとに中立に戻る。取り分は、その戦期の中の行いだけで数える | 【決定済み】 |
| 古参が新参を育てる理由がある | 古参が新参の村に資源を送り、見返りに「その村の木材を週 10 まで」の受け取りの札をもらう（段階 2） | 【提案】 |
| 参加の基本分 | その戦期に一定日数以上動いていた村に、同じ額を少しずつ配る | 【決定済み：取り分の 5 項目】 |

注：「古参が新参を育てる」は、段階 2 の札の想定外の使い方の例として出している案です。

## 7.3 古参への依存と独占

| 危険 | 対策 | 状態 |
|---|---|---|
| 値段の独占 | 写すのは自由（費用はかかる）。誰でも同じ部品で競合の仕組みを作れる。自給の道も残る（注 1） | 【決定済み】 |
| 大きい者が勝ち続ける | 大きいほど重い（維持、長い補給の道）。勝敗の砦が戦期ごとに中立に戻る | 【決定済み】（燃料と維持費の細部は【提案】） |
| 運営が特定の仕組みを推す | 推奨の印は、近さと実績だけで機械的に決める | 【決定済み】 |
| 古参が新参を襲う | 新参の守りは、国内の襲撃からも守る。国内の襲撃は記録に残り、国は追放できる | 【決定済み】 |
| 地図が使われない仕組みで埋まる | 前払いが尽きた仕組みは一覧から外れる。廃墟の片付け | 【決定済み】 |
| 要所の独占 | 要所は境の外に置き、取り合いの対象にする（注 2） | 【決定済み】 |
| 依存の連鎖 | 遊びの一部として残す（注 3） | 【決定済み】 |

注：

1. 自給の道：普通の兵は兵器なしで訓練できます。平地でも鉱石は少し採れます。
2. 要所は、豊かな鉱脈、勝敗の砦、峠や浅瀬です。遠くへ建てるほど、燃料の運搬が重くなります。1 マスに建物は 1 つです。
3. 一か所の出来事が、何人もの仕組みを通って広がります。これは中心に置く仕組みの一つです。

## 7.4 資源の供給と消費

資源の流れは、供給・変換・消費・移転の 4 つです。同じ項目の中でも決定済みと提案が混ざるものが多いので、流れごとに書きます。

### 供給

村の生産、地形による鉱石（丘と山）、境の外の豊かな鉱脈です。境の外の鉱脈は、前哨（2 つ目・3 つ目の村）を置いて採ります。

- 供給の形：【決定済み】
- 地形の鉱石と、前哨での計算：【実装あり：S1】
- 境の外の鉱脈の配置：【照合待ち】

### 変換

工房で、鉱石と木材を兵器に変えます【決定済み】【実装あり：S1】。

### 消費

- 建設、昇格、訓練：【main で確認】。強い兵の訓練に兵器を使うことは【実装あり：S1：強い兵の兵器】。
- 砦攻めの兵器：【決定済み】【実装あり：S1】。包囲の宣言で兵器 50 を使い切ります（段階 1e の手順 4）。
- 建物の燃料と維持費、倉の維持費：状態が分かれます（下の表）。
- 襲撃で焼かれた荷：【決定済み】【実装あり：S1】。
- 塔に削られた荷：塔が荷車を削ることは、実装計画と S1 の実装にあります【実装あり：S1】。決定にあるのは、塔が軍を削ることだけです。

燃料と維持費は、決まったことと提案が混ざっています。

| 主張 | 状態 |
|---|---|
| 建物に燃料が要る（建物の共通の決まり） | 【提案】 |
| 燃料が切れた建物は止まる | 【決定済み】 |
| 遠くへ建てるほど、燃料の運搬が重い | 【決定済み】 |
| 倉の維持費 | フェーズ6で決める数字の一覧にある |

### 移転（総量は変わらない）

交換、札の代金、荷車ごと奪う襲撃です【決定済み】。

### S1 の数値

S1 の実装の数値は、すべて仮です【実装あり：S1】。

- 工房 1 つで、兵器 4/時。
- 兵器 1 に、鉱石 2 と木材 1。

## 7.5 戦闘の意味

| 意味 | 中身 | 状態 |
|---|---|---|
| 国の勝敗 | 戦期の間、勝敗の砦を長く持つ | 【決定済み】 |
| 補給を断つ | 荷車を襲い、奪うか焼く。燃料の道を断てば、砦は止まり、奪いやすくなる | 分かれる（下の注） |
| 奪う | 荷車ごと、倉ごと奪える。倉が奪われると、その倉の札は無効になる | 【決定済み】 |
| 情報 | 見張り塔で公開の出来事を知り、範囲を通る軍を削る | 【決定済み】（注） |
| 取り分 | 砦にいた、砦を取った・守った、戦いで消費された補給が、国の中の取り分になる | 【決定済み】 |

注：

- 補給を断つ：荷車を襲い、奪う・焼くことは【決定済み】。燃料が切れた建物が止まることも【決定済み】。建物に燃料が要ること、止まると奪いやすくなることは【提案】です。
- 情報：塔が荷車も削ることは、実装計画と S1 の実装にあります【実装あり：S1】。

### 戦わない住人の役割

自分の倉から出た兵器や食料が、国の砦の戦いで消費されると、その分が取り分になります。組合の倉を通した作り手や、上流の生産者がどう報われるかは【未決定】です（Q-M3）。

## 7.6 賞金の原資と不正への強さ

### お金の流れ

【決定済み】（割合、金額、トークンの数字はフェーズ6で決めます）

```
[入る]                                  [出る]
村の参加費の返らない部分   ──┐
取引の手数料（札の引き換え）──┼─→ 賞金の倉 ─→ 戦期ごとの賞金 ─→ 国 ─→ 国の中の村
接続口の預け入れの利回り   ──┘          └─→ 運営の取り分（一定の割合）
```

- 村の参加費は、村ごとに一度払います。返る部分は、村が世界を去るときに返る預け入れにします。偽の村を大量に作る費用として働きます【決定済み：お金の流れ】。割合はフェーズ6で決めます。
- 決まりの実行の手数料は、実行役（キーパー）の費用です。賞金には回しません【決定済み：お金の流れ】。
- 国への配分は、勝敗の砦をどれだけ長く持ったかで決めます【決定済み：お金の文書（25 の 1 章）】。

接続口の預け入れは、接続口（API・MCP）を使う者が預ける資金です。「AI ステーキング」との関係は [第6章](06-humans-and-ai.md) にあります（Q-M1）。

### 国の中の取り分

【決定済み】数えるのは、「国の戦いで消費されたもの」だけです。

| # | 項目 | 主に報われる人 |
|---|---|---|
| 1 | 砦にいた | 前線で戦う人 |
| 2 | 砦を取った・守った | 前線で戦う人 |
| 3 | 戦いで消費された補給 | 物が最後に戦いへ出た倉の持ち主（組合の倉なら、持ち分の札の割合で、その持ち主） |
| 4 | 国の倉への納め（その中身が 3 と同じ使われ方をした量） | 国を支える一般の村 |
| 5 | 参加の基本分 | 新しく来た村、小さな村 |

**数えないもの**【決定済み】：

- 売った量、送った量
- 仕組みが使われた回数
- 自分で自分の仕組みを使った分
- 国内の襲撃で奪った物
- 国の外への武器商売
- AI の判断や評価

補給網の案（27a、検証する候補）も、この決定を保ちます。

- 第三者による再利用の率は、試作で測る値です。賞金の条件ではありません。
- 使われた回数や売った量を賞金で数えないことは、上のとおり【決定済み】です。利用回数や取引額を賞金に直結させる案を今後考える場合も、自己取引や同じ人の複数アカウントによる水増しを検討しないまま採ることはしません。

### 守るべき線

【決定済み】

| 原則 | 理由 |
|---|---|
| 報酬を新しい発行で払わない | 発行で報酬を払う形は、死の連鎖の前例が多い |
| 札は物と権利だけを表す。賞金の取り分を表す札は作らない | 投資の性質を帯び、規制上の扱いが重くなるおそれ |
| 札は、まずゲームの外で売り買いさせない | 金融商品のように扱われるおそれ。外に出すかは専門家の確認の後 |
| ゲームの中の襲撃や裏切りで、本物のお金を直接奪えない | 現実の詐欺や賭博に見えないように |
| 価値の出どころを示す | 参加費を集めて配り直すだけにしない。手数料は、仕組みが使われた量から生まれる |

### 不正の入口と対策

| 不正 | 例 | 対策 |
|---|---|---|
| なれ合いの往復 | 自分の別の村と物を往復させて、数字を膨らませる | 消費された物だけを数える【決定済み】 |
| わざと消費する | 自分の兵器を、意味のない砦攻めで使い切る | 数えるのを、勝敗の砦に関わる消費に限る【提案：取り分の文書（28 の 5 章）】 |
| 偽の村 | 守りや参加の基本分を使い回す | 村ごとの参加費、守りは村ごとに 1 回【決定済み】。基本分を参加費より明らかに小さくする【提案】 |
| 札の乱発 | 地図を札で埋める | 札を出すのに少しの費用【決定済み】 |
| 小さな送りの大量発生 | 嫌がらせ | 送りの最小量、決まりの数の上限、手数料の前払い【決定済み】 |
| 実行役による順番の操作 | 先着で有利な順に実行する | ターンの始めにまとめて判定し、取り合いは割合で分ける【決定済み】 |
| 仕組みの説明でだます | 中身と違う説明で人を集める | 仕組みの説明書は自動で書き、作者の説明と分ける【決定済み】 |

### 法的な扱い

次のものは、地域によって賭博、懸賞、金融商品として扱われるおそれがあります。

- 賞金を参加費から作る形
- トークン
- 札の外部での売り買い

再設計は、数字とトークンを決める前に、専門家の確認を置いています【決定済み：フェーズ6の進め方】。この文書は法的助言ではありません。
