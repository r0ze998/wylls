# 第5章 UI/UX と地図

この章は、地図と画面の考え方をまとめます。**ここにある画面の案は、すべて検討中です。** hex（六角形のマス）を残すことも、正式には決めていません。この章の内容は、下の「判断の方針」も含めて、すべて【提案】です。決定ログには記録されていません。

## 5.1 判断の方針【提案】

| 方針 | 中身 |
|---|---|
| 面白さを先に置く | 画面の目的は、判断を直感的にし、結果の因果を分からせること（最上位の判断基準の ③）。世界観とビジュアル（④）は、その上に重ねる |
| 差別化だけを理由に地図の構造を作り直さない | 「Eternum も hex だから変える」はしない。地図の構造を変えるのは、遊びや分かりやすさのためにだけ |
| 内部のルールと見せ方を分ける | 位置・移動・距離・戦闘の州は、今の hex のルールのまま考える。変えるのは主に見せ方 |
| 全部を常に見せない | 補給線や情報は、選んだものに応じて見せる。画面が線と数字で埋まる設計を避ける |

**今の事実。** 今のゲームの地図は hex のマスで、州は 61 マスの六角形の地域です。移動は歩（1 マス）で数え、1 回の移動は最大 32 歩・4 州までです【main で確認】【実装あり：S1】。見張り塔の範囲（同じ州の半径 2）や地形の鉱石（半径 2 のマス）も、hex の距離で決まっています【実装あり：S1】。hex をやめると、これらの規則と検証ツールを作り直すことになります。

## 5.2 「生きた文明の地図」【提案】

普段は文明が主役で、マス目は操作するときにだけ前に出る地図です。

| 場面 | 見せ方の案 | 関わる決定・実装 |
|---|---|---|
| 普段 | 地形と街並みを主役にする。マス目は薄くするか消す | ― |
| 軍を選んだとき | 進める範囲、見えている敵、地形の影響（移動の時間、守りやすさ）を出す。マス目をここで強調する | 移動中の軍の行き先は隠れる（封じた進軍）【決定済み】。見えない敵は出さない |
| 施設を選んだとき | 誰が使っているか、どこにつながっているか、何が足りないかを出す | 仕組みの紙【決定済み：段階 4】。生産枠の空きや依存先の表示は補給網の案（27a）の論点 |
| 荷車や補給を選んだとき | 道、危険（塔の範囲、柵）、護衛、届く予定を出す | 荷は全部見える【決定済み】。塔、柵【実装あり：S1】 |
| 時間がたつと | 道路、運ばれた量、街の育ちが、地図の上に積み重なって見える | 道のマスは移動が半分の時間になる規則が今もある【main で確認】。ただし道を作る命令は見つからない。荷車の往来で道が育つなど、活動から道が生まれる形にするかは【未決定】（Q-U2） |
| 何かが失敗したとき | どこで、誰の何が止まったかを、地図の上で指す | 失敗は止まって記録【決定済み】 |

**この案で避けたいこと。**

- 補給網の線を常に全部引き、管理画面のようになること。
- 設定画面が主役になり、地図を見なくなること（27a の撤退の兆しにも同じものがある）。
- 見た目を変えたことで、隠すべき情報（移動中の軍）が漏れること。

## 5.3 画面の一覧との関係

画面ごとの操作の案は [第3章](03-facilities-and-offers.md) の 3.4〜3.6 と [付録C](appendix/c-developer-spec.md) の C.6 にあります。この章の「選んだものに応じて見せる」は、それらの画面への入口を地図に置く考え方です。段階 1 の画面（兵器、倉、荷車、塔の表示）は段階 1f の作業で、まだ作っていません。

## 5.4 確かめ方

- 試作では、画面は判定のための仮のものとする（再設計の README は、具体的な UI と見た目を今回は設計・実装しないとしている）。
- 確かめる問い：参加者が、なぜ届かなかったか、なぜ負けたかを、地図から答えられるか。軍や施設を選んだときに、次の一手を選べるか。
- 世界観とビジュアルの一貫性は、遊びの循環を確かめた後で評価する。

## 5.5 この章の未決定事項

| 番号 | 問い | 推奨 |
|---|---|---|
| Q-U1 | 内部のルールを hex のまま残すか。画面を「生きた文明の地図」にするか | 残す方向で進め、決定ログに記録する。変えるなら、遊びや分かりやすさの理由を書く |
| Q-U2 | 道路や街の育ちを、見た目だけにするか、ルールにするか（今ある「道は移動が半分」の規則と、道の作り方） | 街の育ちはまず見た目だけ。道は、作り方（建てる、往来で育つ）を試作で比べてから決める |
| Q-U3 | 選んだときに出す情報の範囲（他国の補給線、他人の依存先をどこまで見せるか） | 公開の事実と、自分の塔から見えるものだけ。見えない情報の決定に合わせる |
