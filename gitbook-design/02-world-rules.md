# 第2章 世界の基本ルール

プレイヤーがどう組み合わせても、この章のルールは破れません。組み合わせで決められるのは「誰に、何を、どの条件で」までです。資源の量、時間、距離、容量、所有、戦闘の結果は、世界のルールが決めます。

## 2.1 破れない制約

出典は、方針の「境界」（決定）と、基本部品の文書の 2 章（たたき台）です。行ごとに状態を付けます。

| ルール | 中身 | 組み合わせでできないこと（例） | 状態 |
|---|---|---|---|
| 無から増えない | 物は施設で作るか、運ぶか、奪うしかない。札は、裏付けの倉や施設を持つ人しか出せない。裏付けが足りなければ、札は約束どおりに働かない | 「金を払えば鉱石を出す」札を、鉱石のない人が出す | 【決定済み】（境界） |
| 許可なく触れない | 動かせるのは、自分の倉・施設と、自分が持つ札が許す範囲だけ | 他人の工房を、札なしで動かす | 【決定済み】（境界） |
| 任意のコードは渡さない | 運営が、基本の法則と組み合わせの文法を用意する | プレイヤーが自分のプログラムを施設に付ける | 【決定済み】（境界） |
| 運ぶには時間がかかり、襲われうる | 送りは倉どうしの距離に応じて時間がかかり、途中の荷は地図の上を動く | 遠くの倉へ瞬時に送る | 【決定済み】（段階 1 の規則：荷は全部見え、襲撃で奪うか焼く） |
| 失敗は止まるだけ | 条件がそろわない、物が足りないときは、実行されない。失敗は記録に残り、誰でも見られる | 足りない分を後から勝手に埋める | 【決定済み】（段階 3 の規則） |
| 公開 | 地形、建物、持ち主、仕組みの中身は誰でも読める。隠れるのは移動中の軍だけ | 中身を隠した仕組みで人を集める | 【決定済み】（見えない情報） |
| 維持費がかかる | 倉には容量と維持費、施設には 1 日に動かせる回数と維持費がある。建物は燃料が要る | 維持費なしで建物を増やし続ける | 【提案】（燃料が切れた建物が止まることは【決定済み】） |

## 2.3 時間

| 何が | どう進むか | 状態 |
|---|---|---|
| 世界の時計 | 止まらずに動き続ける。決まった時間に集まる形ではない | 【決定済み】 |
| 戦闘と到着 | 10 分ごとのターンでまとめて解決される | 【main で確認】 |
| 生産と工房 | 連続して進む。工房は材料が尽きる時刻を計算で求め、その後は足りない材料の生産で支えられる割合（切り捨て）まで落ちる | 【main で確認：遅延精算】【実装あり：S1：工房の変換】 |
| 決まり（段階 3） | ターンの始まりにまとめて判定する。同じ物を取り合う決まりは割合で分ける。実行役が順番を選べないようにする | 【決定済み】 |
| 戦期 | 2 週間ごとに戦争の勝敗を区切る。世界は続く | 【決定済み】 |

**眠らない AI と人間。** 世界の時計が止まらないので、ずっと動ける AI や長く在席できる人が有利になりやすいことが分かっています。守りの工夫を設計上の条件にしています【決定済み】。具体的には、建物の守りは自動でよく、決まりで物を送れ、代理の AI に任せられます。軍を出して攻めることは自動にしません【決定済み】。

## 2.5 物流：荷車

| 項目 | 中身 | 状態 |
|---|---|---|
| 見せ方 | 荷車が出たこと、出発地、行き先、通る道、着く時刻、荷の中身（種類と量）を、すべて見せる | 【決定済み】 |
| 隠せるもの | 護衛の軍だけ。護衛は、封じた進軍で道の途中のマスへ先に送り、そこで待ち構える（J1） | 【決定済み】 |
| 速さ | 封じた進軍より遅い。S1 の実装では 1.5 倍の時間【仮】。潮の国（B）の特性で 0.8 倍 | 【実装あり：S1】 |

| 混み具合 | 1 つの州に同時にいられる荷車の数に上限がある（S1 の実装では 5） | 【実装あり：S1】 |

## 2.7 所有

| ルール | 中身 | 状態 |
|---|---|---|
| 預けても持ち主は変わらない | 他人の施設に材料を運び込んでも、できた物は使う側の倉に入る | 【決定済み】 |
| 札は国と関係なく残る | 国を移っても札は残る | 【決定済み】 |
| 倉が奪われたら | その倉の持ち分の札と受け取りの札は無効になる。中身は奪った側の物 | 【決定済み】 |
| 札を受け渡すとき | 受け渡しのたびに、それまでの配分を清算する | 【決定済み】 |
| 条件を変えたとき | 変えた条件は新しく出す札にだけ効く。すでに出した札は、期限まで元の条件のまま | 【決定済み】 |
| 持ち主が変わる場合 | 交換（引き換えの預かり）、本人の譲渡、戦闘（荷車の襲撃、倉や建物の奪取）だけ | 【決定済み】から読み取ったまとめ |

## 2.8 戦闘と損失

| 対象 | 何が起きるか | 状態 |
|---|---|---|
| 軍どうし | 今のゲームどおり。ターンごとに州単位でまとめて解決 | 【main で確認】 |
| 荷車の襲撃 | 敵の軍が、荷車と同じターンに同じマスにいると戦いになる。護衛がいれば護衛と戦う。護衛がいないか負けたら、襲う側が選ぶ。**奪う**：荷車ごと持ち主が襲った側に移り、見える荷車として襲った側の村か倉へ進む（決定 J2）。**焼く**：荷を全部なくす。S1 では、選ぶ猶予は 6 ターン。猶予を過ぎると荷車は襲った側へ持ち帰られる（帰れないときは、さらに 144 ターン後に焼かれる。襲った側の村がなくなっていれば、すぐに焼かれる） | 【決定済み】【実装あり：S1】 |
| 奪った荷車 | 見える荷車として進むので、取り返しの戦いが起こりうる | 【決定済み】 |
| 倉 | 兵で攻めれば奪える。S1 の実装では、奪う側の軍が倉のマスにいて、持ち主の軍がいないときに奪える | 【決定済み：奪える】【実装あり：S1】 |
| 建物 | 奪える・壊せる。奪った人が設定を変えられる。燃料が切れると奪いやすくなる | 【提案】（建物の文書の共通の決まり）。燃料が切れた建物が止まることは【決定済み】 |
| 廃墟 | 止まったまま長く放置された建物は廃墟になり、誰でも取り壊して材料の一部を得られる | 【決定済み】 |
| 見張り塔 | 塔の範囲を通った軍は、封が開いたときに兵を削られる。待っている軍は削らない（決定 J4） | 【決定済み】。荷車を道が決まったときに削るのは、実装計画と S1 の実装。S1 では、同じ州の半径 2 を見て、国の構えが「戦い」の相手を削る（構えの投票がまだないので、今は他のすべての国）。敵の塔の範囲を 1 分歩くごとに 1%、最大 30%（仮）。1 人 2 つまで。塔の燃料はまだない。知らせる相手の設定は保存されるが、まだ絞り込まない【実装あり：S1】 |
| 柵 | 国の構えが「止める」相手に対して、そのマスをふさぐ。止められた軍は封を開く時点で、荷車は送る時点で、道を断られる。1 人 4 つまで | 【決定済み：K3】【実装あり：S1】（`ad391ee`） |
| 砦（建物） | 1 人 1 つまで。兵がいなくなった砦だけを奪える。戦いへの参加は段階 1e の後の手順 | 【決定済み：K3】【実装あり：S1：建物と奪取】。戦いへの参加は未実装 |
| 国の構え | 国ごとに、他の国を「戦い」「通す」「味方」のどれとして扱うかを決める（片側だけで決まる）。構えが「戦い」の相手だけを、塔が削り、柵がふさぐ。追放された村は、自分の国の砦と柵に止められる（K2）。S1 の止める規則では、自分の国の塔にも削られる | 【決定済み：K1、K2】。構えの表と止める規則は【実装あり：S1】。構えを決める投票は未実装（今は全部「戦い」） |
| 国内の襲撃 | 同じ国の荷車も襲える。「国内の襲撃」として記録に残る。国は投票でその村を追放できる。追放された村は 3 日戻れず、投票権と取り分を失う | 【決定済み】（K2、K4）。未実装 |

## 2.9 見えない情報

【決定済み】

- 隠すのは、移動中の軍だけ。将来は zk（中身を見せずに、規則を守っていることだけを証明する技術）で本当に隠す。
- 見るのは、公開の建物（塔・砦・村）から。
- 戦いは、見える場所でだけ起きる。
- zk が入るまでは、今の時間ロックの封（指定した時刻まで誰も開けない暗号）を使う。

## 2.10 新しく来た村の守り

【決定済み】（数字はフェーズ6）

| 守り | 中身 |
|---|---|
| 期間つきの守り | 最初の一定期間、自分の村と村の土地を攻められない。国内の襲撃からも守る。村ごとに 1 回だけ。自分から攻めたとき、または村が育ったときに切れる。村の土地の外の荷車と倉は守らない |
| 国の内側に置く | 新しい村は、国の土地の内側に置かれる |
| 詰まない | 普通の兵は兵器なしで訓練でき、平地の村でも鉱石は少し採れる |
| 追いつく道 | 最初の建物は早く建つ。大きいほど維持が重い。取り分は、いた間の行いで数える |
| 国を移った村 | 守らない |

**今の実装。** main と S1 の守りは時間だけです（48 時間。シーズンの 7 日目より後に作った村は延長）。守られている村の軍は、自分から他の村を攻められません。決定の「自分から攻めたら切れる」「育ったら切れる」は、まだ実装されていません【main で確認】【実装あり：S1】。

## 2.11 この文書の補足の提案

決定に書かれていない細部について、遊びが崩れないための案です。

| 論点 | 提案 | 理由 |
|---|---|---|
| 使用権の札を持つ人が、施設の止まっている日に使えなかったとき | 使えなかった回数は、記録に「施設の停止」として残す。払い戻しは札の条件として出す側が選べる（「止まった日は払い戻す」の欄） | 「失敗は止まって記録」の決定に合わせつつ、札の信用を作る手段を持ち主に残す |
| 他人の施設に運び込んだ材料や、加工を終えて引き取り待ちの品が、施設の奪取で残ったとき | 施設の中にある物も、奪った側の物になる（倉と同じ扱い）。【未決定】（Q-F5） | 倉が奪われたら中身は奪った側、の決定と同じ考え方にそろえる |
| 守られた場所にいる荷車 | 守られる場所を「荷車の休み場所」として使えることを、画面で示す | 実装の性質を、プレイヤーが読める戦術にする |
