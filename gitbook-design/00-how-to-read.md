## 主な決定（2026-10-22〜23）

再設計の決定ログから、この文書に関わるものを抜き出します。全文は決定ログにあります。

| 分野 | 決定 |
|---|---|
| 核 | 文明を育てながら、文明の機能そのものも住人が増やしていくゲーム。「受け取る → 実行する → 渡す」を組み立て、完成した仕組みが次の人の部品になる |
| 土台 | 農場・鉱山・工場・軍隊などの文明シミュレーションは残す。今のゲームを土台にする |
| 境界 | 任意のコードは渡さない。資源は無から増えない。許可なく他人の施設に触れない |
| 世界と時間 | 世界は続き、戦争だけを「戦期」で区切る（C 案）。世界ごと消すシーズン制はやめる。戦期は 2 週間で始め、間に休みを置かない |
| 土地と国 | 土地は 3 種（自分の村の土地、国の土地、境の外）。国は命令せず、設定 4 つ（建設、取り分、構え、追放）を持つ。1 村 1 票。いつでも国を移れる。国に属さない村を認める。6 か国で固定 |
| 段階 1 | 兵器は強い兵（長槍兵・弩兵・騎士）の訓練と砦攻めに使う。荷は全部見せ、護衛は道の途中で待ち構える（J1）。襲う側は奪うか焼くかを選び、奪うと荷車の持ち主が移る（J2）。鉱石は丘と山に偏る。国内の襲撃も可（記録に残り、国は追放できる） |
| 段階 2 | 札 3 種（持ち分・受け取り・使用権）と引き換えの預かり。奪われた倉の札は無効。足りなければ割合で減らす |
| 段階 3 | 合図 4 種（時刻・量・到着・公開の事実）とすること 2 つ（送る・動かす）。ターンの始めにまとめて判定。手数料は前払い。失敗は止まって記録 |
| 段階 4 | 仕組みの紙は自動で書く。条件の変更は新しく出す札にだけ効く。前払いが尽きた仕組みは止まる。AI の案は本人が確認してから建てる。写すのは自由 |
| 自動の線引き | 建物が自分の範囲で働く守りは自動でよい。軍を出して攻めるのは自動にしない |
| AI | 役割は 4 つ。同じ規則・費用・速さの上限・情報。代理の権限は「代理の札」としてチェーンの上に置く。世界として「人間と AI が一緒に暮らしている」と告げ、個々には表示しない |
| お金 | 参加費の返らない部分、取引の手数料、接続口の預け入れの利回りを賞金の倉へ。戦期ごとに国へ配り、国の中は国の戦いで消費されたものだけで分ける |
| 守るべき線 | 報酬を新しい発行で払わない。札は物と権利だけを表す。札はまずゲームの外で売らせない。襲撃で本物のお金を奪えない。価値の出どころを示す |
