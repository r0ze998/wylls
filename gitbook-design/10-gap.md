# 第10章 現在の実装と、目指す設計の差

更新日：2026-11-22。照合した `main` は `24b5684`（#140 までマージ済み）。

**1〜20 は、すべて完成したわけではありません。** 多くの担当は `main` に入り、手元の試験世界で遊べるところまで来ています。公開の devnet には、いまの遊べる版はまだ置いていません。一般公開もしていません。

## 10.1 この章でいう「できた」

- **main の土台**：照合した commit にコードがあること。公開ゲームになった意味ではありません。
- **【実装あり：local】**：手元の試験世界（`scripts/play-local.sh` など）で動く。テスト鍵とローカルチェーンです。
- **【実装あり：devnet準備】**：devnet 用のプログラムやページに入っており、オフラインでは確かめたが、実ネットでは未走行。
- **模擬での確認**：fixture や mock を使う試験。本物の AI の判断や、実チェーンでの送信成功を証明しません。
- **全体としての完了**：同じ版で接続・独立検証・実際のプレイを通し、公開に必要な残件を解消した状態。今はここに達していません。

この更新では、公開リポジトリの `main` と、遊びガイド・状態メモを読みました。実デの devnet への設置は行っていません。対象版と制約は [付録F](appendix/f-update-20261122.md) にあります。

## 10.2 いま遊べること、まだ置けないこと

**手元**【実装あり：local】。ワンコマンド `scripts/play-local.sh` で、ブラウザのページが開きます（既定は http://localhost:41920/ ）。

- 国を選んで参加し、最初の村が置かれ、建設・収穫・訓練・編成ができます。
- 封じた進軍を出し、衝突し、砦を奪えます。運営側の AI 住民は、既定で戦争をします（1 人 1 ターンに 1 行動）。
- 霧がかかります（Civilization 型のプレイヤー視点。表示だけ。チェーン上の記録は公開のまま）。
- 保存する世界は止めて再開できます。`--wide` では辺境の村から広い土地へ出られます。`--coexist` では ② の在庫交換と、⑨⑩ の試験カードが使えます。`--external` では外部の AI 住民を入れられます。
- ローカル専用の機能があります（時計を早める、広い土地の中の進軍など）。devnet と同じとは限りません。

**devnet**【実装あり：devnet準備】。シーズンを始める道具、見張り役、ページからの参加・村・収穫・進軍・広い土地、霧のページ、2 つ目・3 つ目の村、領地の隣の州を開く処理などが main にあります。確かめたのは手元とオフラインです。**実デの devnet では、まだ一度も動かしていません。**

置く条件は次です。r0ze さんが手元で遊び、「devnet OK」と言う。その日のプログラムの指紋を確認する。必要な SOL と鍵を用意する（設置と鍵の作成・移動は、チャットでの確認のあと）。最初に置くのは遊べる版の一つのプログラム（版 0x4804）で、賞金プログラムと住民 NFT は含めません。

遊びガイド（2026-11-21 時点の記述）は、devnet 用プリセットについて「中央あり（切り替えは判断待ち）」と書いています。中央塔の廃止（⑭）が決定済みで、ローカルの遊べる世界には中央がありません。この点はコードと文書の食い違いの候補です（[第12章](12-open-questions.md)）。

## 10.4 遊べる版と、権利の試験版を混ぜない

遊べる版のレーン（0x4804）と、②⑨⑩ を載せた共存ビルド（0x7805、`--coexist`）は別です。後者はローカルの試験専用で、devnet の最初のプログラムには入りません。広い土地の中の進軍（WideDepart）も、ローカル専用で、devnet では閉じています。

## 10.5 NFT ログインの完了条件

「1 NFT につき 1 アカウント」は 2026-11-06 の採用方針です。次を一続きで確かめるまでは、入口として完成とはしません。

1. 保有する NFT で最初に入り、対応する住民を一つだけ登録できる。
2. 現在の所有者だけが、その住民を操作できる。
3. 譲渡後に旧所有者・旧 session・旧委任で操作できず、新所有者が操作できる。
4. 中継を通らないゲーム命令でも同じ制限が働く。
5. 記録・検証器・画面が同じ所有者と世代を扱う。
6. 譲渡時の移動中の荷、預かり、未受取分、私的記憶について、採用したルールを守る。

手元の遊べる世界は、この入口を使わずに試験用の鍵で入ります。NFT の試作が動くことだけで、ゲームにログインできるとは説明しません。

## 10.6 完了の判定を混ぜない

- GitHub への保全と、main への統合は別。
- main に入ったことと、公開環境で動いたことは別。
- オフラインで devnet 用の命令を確かめたことと、実デの devnet で通したことは別。
- 担当のテストと、独立検証は別。
- CI の成功と、その担当固有の試験の成功は別。鍵を使う試験は、PR の CI では原則として走りません。
- 模擬の試験と、実モデル・実チェーンの通し試験は別。
