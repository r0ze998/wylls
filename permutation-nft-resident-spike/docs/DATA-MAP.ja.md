# データ対応表：NFT 譲渡で移るもの・残るもの・決めるもの（2026-10-31 改訂）

**決定**：NFT に紐づく住民のゲームデータと操作権は売れる（買い手へ移る）。鍵・API キー・外部アカウント・売り手の財布の資金は移さない。第三者の所有物を自由資産に変えない。義務や未完了取引を消さない。
**別途照合**：預かり物・債務・未受取賞金・私的会話・AI 記憶・封印中情報の**具体的な**扱い。以下は「現在のコード上の挙動」と「推奨案」を分けて書く。試作（`src/world.mjs`）は推奨案の最小部分を模擬。

列の意味：**決定／照合** = 方向が決まっているか、別途照合か。**現コード** = `main` の実装がいまどう振る舞うか。**推奨案** = 本試作の提案（決定ではない）。**試作** = 模擬した範囲。

## 4. 譲渡の境界で起きること（順序の規則）

- **チェーンの実行順が境界**。譲渡 tx より前に実行された操作は成立し、その結果は住民のもの（買い手へ）。後に実行された売り手の操作は prologue で `NotOwner`、世代違いは `StaleGen`。
- relay は送信前に保有者と世代を読み直し（`beforeSend`）、変わっていれば送らない。送った後の最終判定はチェーン。
- 売り手が**署名済みで未送信**の取引は、遅れて届けば拒否（`NotOwner` / `StaleGen`）。blockhash 期限切れは `BlockhashExpired`。**「NFT が移れば署名済み取引も消える」とは仮定しない**。
- **進行中の処理**（輸送中の隊商、加工中の注文、到着待ちの進軍）は住民のもので、止めずに進む。結果は住民へ。
- **費用確認待ち**は売り手の wallet+epoch に束縛され、譲渡で無効。
- **預かり物・債務**は消えない。買い手は「預かり」「債務」として引き継ぐ（具体は照合、U17）。
