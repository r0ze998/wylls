# 普段の地図をもう一段：ひとつの国土、自然な岸、耕された土地、村のレンズ

2026-10-24、2 回目。依頼者が参考に示した Civilization VII の 2 枚（街と地形が連なる普段の地図、都市を選ぶと周りが灰色になる表示）を、見た目の水準の参考とした。外観を写すのではなく、そこから 3 つの考えを取った：地形が切れ目なく続くこと、文明が土地を埋めていること、選んだものの土地だけが色を持つこと。

## 変えたこと

| 何 | どこ | 記録との関係 |
|---|---|---|
| **ひとつの国土**：種類の違う土地が接するところで、互いの色（焼き込みの絵の真ん中の色を一度だけ取る）がタイルの半分まで混ざる。草地と平原、平原と丘が六角形の線で切れずに移る | `map/groundblend.mjs` paintBlend | 地形は記録どおり。色の境目だけを柔らかくした |
| **自然な岸**：水の広がりを丸ごと輪郭にし（州をまたいでも同じ輪郭）、丸めて少し揺らす。輪郭の外に出た水の六角形の角は陸に、内に入った陸の角は水に。水面は一枚の色でそろえ、岸に濡れた砂・浅瀬・白波 | `groundblend.mjs` paintShores、waterBody | どのマスが水かは記録どおり（移動・戦闘の規則は hex のまま）。描く岸の線だけが六角形でない |
| **土地の大きなうねり**：数タイルにわたる長い波で、暖かい光と冷たい影を土地に重ねる（世界の位置で決まるので、州の境で途切れない）。同じ種類の土地が六角形ごとに同じ絵を繰り返して見えるのを和らげる | `groundblend.mjs` paintSwell | 見た目だけ。地形・産出とは無関係 |
| マス目は水の上に引かない | `map/sprites.mjs` gridOf | |
| 焼き込みの「辺ごとの浜と岸」は、岸を描くときは描かない（六角形に沿っていた） | `sprites.mjs` groundOf | 遠景（far）は今のまま |
| **耕された土地**：村の土地のマスに畑。どの村も 1 ＋ 段階 枚（基本の食料の産出は段階で増える：`fland.mjs BASE_PROD`、`TIER_BONUS_PCT`）。自分の村は、建てた農場の数だけ増える。木こり場（伐採場）・石切場・鉱山を建てていれば、木材の山・切り出した段・坑道 | `map/landuse.mjs` | 建物はマスを持たない（規則）。どのマスに絵を置くかは絵の都合で、そのマスについて何も言わない。他の村の建物はページが読んでいないので、段階の分の畑だけ |
| 畑などは州の地面の絵に焼き込む（印の文字列を絵の鍵に入れ、建物が増えたら描き直す） | `sprites.mjs` | 動いている間の 1 枚の時間は変更前と同じ |
| **村のレンズ**：自分の村を選ぶと、その土地の外を灰色にして少し暗くする。村が働かせている土地が一目で分かる | `map/actions.mjs` paintLandLens、`map/fmap.mjs` | ページは着地のあとやガイドの手順で自分の村を自分で選ぶので、灰色は強すぎない程度に |
| **一つの光**：左上から暖かい光、右下へ冷たく落ちる。画面の上に soft-light で重ねる（1 枚ごとの費用なし）。近景で強く、遠景では消える | `uplift.css` .map-light、`index.html` | |

`?country=0` を付けると、地面は変更前の描き方に戻る（比べるため）。

## 描かないもの

- 都市の区画（Civ のような）：Wylls の規則では建物がマスを持たないため。
- 往来で育つ道（Q-U2 は【未決定】）、記録にない道。
- 他の村の建物の絵（ページは他人の Holding を読んでいない）。
- 遠景（全体図）は変えていない。測量した土地だけを描くのは、持ち主のこれまでの決定（UX-DESIGN 3 章）。

## 確かめたこと

- 見本の世界（固定の場面）と、ローカルの本物のチェーン（ボット入りの征服の世界）で、近景・村の選択・スマホを撮って見た。
- 描画の速さ（`uplift-perf.mjs`、1440×900、DPR 2）：静止 25 ms、ドラッグ p50 26 ms（変更前 25）、範囲を照らす full 137 ms（変更前 134〜135）。畑を毎フレーム描いていた途中の版はドラッグ p50 28 ms だったので、地面の絵に焼き込んで戻した。
- 試験：04-VERIFY の数字を更新。

## 残り

- 同じ種類の土地の中で、焼き込みの絵の細かな模様が六角形ごとに繰り返すところは、うねりで和らいだが残る（絵そのものの性質）。
- 岸の輪郭は、まだ測量の外（羊皮紙）に接するところで羊皮紙側に回り込まない。
- 文明が土地を埋める密度は、村の数で決まる。見本の世界は村が 3 つで、本物の世界ほど密にならない。
