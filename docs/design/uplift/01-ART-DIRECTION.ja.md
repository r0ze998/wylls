# 美術方針：3 案の比較と推奨

2026-10-24。比較の画面は `docs/design/uplift/preview/`（静的なページ。起動は 05-HANDOFF）。3 案とも **同じ場面**（`preview/scene.mjs`）を、同じ 3 つの枠（普段／選ぶ・比べる／結果）で描く。数値は比較用の見本で、どの季の記録でもない。

場面：あなたの町ラマール（アステル）、西の丘の集落オルセン（シンダー）、北東の町ヴェルデ（ダンマール）。渡しの倉から東の要塞へ、鉱石 30 の隊商が道を進む。ダンマールの物見櫓が要塞の先を見張り、柵が南の道をふさぐ。ヴェルデから封印した進軍が出発した（行き先は誰にも見えない）。長槍兵 600 を選び、「攻める・要塞に入る・隊商の道で待つ」を比べ、結果で予測と確定を並べる。

## 評価

根拠は、設計書の判断の順（①面白い判断と手応え、②違い、③直感と因果の分かる UI、④世界観とビジュアル、⑤拡張と接続）と、依頼の 4 つの軸。

| 軸 | A | B | C |
|---|---|---|---|
| 世界観（人が暮らし、作り、運ぶ世界に見えるか） | **高い**。家並み、煙、牛の荷車、積み荷が、記録の事実から描ける | 中。地図としての品は高いが、暮らしは記号に縮む | 低い。戦況の模型で、暮らしは見えない |
| 戦略情報の読みやすさ | 中→高。今は格子と絵が競う。格子を普段は息だけにし、選んだときだけ線にすると上がる（比較画面で確認） | **高い**。線と色が少なく、重ねた情報が読みやすい | **高い**。駒と光で、誰がどこかが一目で分かる |
| 操作性（選ぶ・比べる・送る） | パネルの作りで決まり、3 案で差は小さい。A は今のクライアントの操作の部品をそのまま使える | 同左。地図の手触りは最もさっぱり | 同左 |
| 制作コスト | **低い**。地形・山・森・村・兵の絵と描画の仕組みは既にある。足すのは施設の絵と見せ方の順序 | 高い。地形の描画を作り直し、焼き込みの絵を捨てる。持ち主から受け取った絵（兵・人物）とも筆致が合わない | 高い。地形、施設、軍の表現を全部作り直す |
| 動作コスト | 今の描画の仕組み（静止部分のビットマップ化）に乗る。山と村は大きさごとにビットマップで持つ | 軽い（線と塗り）。ただしにじみを毎回描くと重い | 軽い。光（shadowBlur・加算）を多く使うと重い |
| 非公開情報 | 3 案とも、封印中の進軍は出発地と到着のターンだけ。経路も向きも描かない | 同左 | 同左（? の駒） |

計測（参考）：比較ページで 1 枚を描く時間の中央値は、A 約 71 ms、B・C 約 1 ms（1440×900、DPR 2、キャッシュなし）。A は山・木・村を毎回コードで描いているためで、クライアントではこれらを大きさごとにビットマップで持ち、1 枚は主に画像の転写になる。この数字は「A を毎フレーム描き直してはいけない」ことを示すもので、3 案のフレーム時間の比較ではない。クライアントでの計測は 04-VERIFY にある。

## 推奨：A 卓上の箱庭（B と C の良いところを取り入れる）

理由：

1. **世界観と、記録に基づく暮らしの絵が両立するのは A だけ。** 建物の種類ごとの小屋、荷車の積み荷、村の段階、道のマスは、どれも記録にある事実から描ける。B と C では、同じ事実が記号や塊に縮む。
2. **読みやすさの差は、絵ではなく階層で埋められる。** 比較画面の A では、格子を普段は薄い息にし、命令を出せる範囲だけ細い線にした。これで B と C の読みやすさに近づいた。
3. **コスト。** B と C は地形の描画の作り直しで、持ち主から受け取った絵（兵、人物）と筆致が合わない。品質の向上を「作り直し」と取り違えない（依頼の注意）。
4. **3D 化や新しいエンジンは要らない。** A は今の 2D の描画と傾けた卓の上で成り立つ。

取り入れること：

- **B から**：経路はターンの区切りに目盛りを打つ「墨の線」。施設は遠目にも形で分かる（地図記号のように輪郭がはっきりした絵）。地域名は字間を空けた明朝。
- **C から**：戦況のレンズ（遠くの軍を印と数の駒で読む）。選んだときに、範囲の外を一段暗くする。

## A の細かい決め（実装の基準）

- **地形**：焼き込みのタイルと、コードで描く山・森をそのまま使う。格子は普段 `rgba(40,36,20,.09)` 相当の息。命令を出せる範囲に入ったときだけ、象牙色の細い格子と一本の縁。
- **村・街**：今の `paintVillage`。建てた建物の種類ごとの小屋（annex）を、遠くからも読めるように保つ。
- **施設**：倉・物見櫓・柵・要塞を、村と同じ道具（`villageKit`）で描く（`map/structures.mjs`）。自分の物は足元に金の輪。
- **軍**：今のミニチュア。自分の軍は金の輪。
- **荷車**：牛と荷車。積み荷の見た目で中身を言う。位置は記録の州と時刻からの **推定** で、札に「推定」と書く（1f の決まりのまま）。
- **国**：境の内側の色の帯と線。色だけに頼らず、印（円・三角・四角・菱形・十字・六角）を名札と旗に必ず付ける。
- **文字**：名前と見出しは明朝、数字は等幅（tabular-nums）。大きさは 4 段（12・14・17・24）。
- **色**：昼の暖かい光。HUD は真鍮と深緑の金属、文書は羊皮紙。状態の色（予測・確定・待機・失敗・取り消し不可）は 03-COMPONENTS のトークン。
- **光**：左上から一つ。影は右下。
- **動き**：記録が変わったときだけ動く（到着、衝突、完成）。煙・旗・水の揺れは飾りで、状態を表さない。動きを減らす設定では止める。
- **非公開**：封印中の進軍は、出発地の封蝋と到着のターンの札だけ。線、矢印、向きは描かない。
