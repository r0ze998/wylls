# 地図のまわり・文字・演出

2026-10-24、4 回目。地図の外側（上の帯、ターンの文字盤、ガイド、やること、村の札、ドック、手札、引き出し、知らせ）、文字（階層・量・言い回し・数）、演出（出来事への手ごたえ）を、ゲームデザイナーとして見直す。

## 方針：作戦机と、鐘の響く時計

静かな枠、強いターン、文書のように読める結果。

1. **二つの声**：真鍮は事実（確定）、点線とかすれたインクは見込み（予測）。同じ見た目を共有しない。
2. **一つの事実は一か所に**：村の名前、送信中、進み具合を二度三度言わない。
3. **時計が心臓**：ターンの文字盤がターンを運ぶ。帯は短く、その後すぐに「このターンのできごと」。
4. **重さは賭け金に合わせる**：小さな出来事は札、目立つ出来事は輪と音、大きな出来事（村を失う、昇格）は帯と盤面の変化と一呼吸の静止。負けも勝ちと同じだけ扱う。
5. **地図が先**：演出の間は関係のない名札が引く。スマホで層を三重にしない。
6. **ボタンは動詞**：何が起きるか、何が足りないかを言う。

守ること（前の回と同じ）：演出は記録のある出来事だけ。隠れた情報を出さない。予測を結果に見せない。動きを減らす設定でも使える。新しい有料素材なし。

## 進め方

見るための道具：`screens/uplift-fx.mjs`（演出の見本 `?fx=` を、時刻を止めて何枚も撮る）と、画面の行列の写真（`screens/artifacts`）。外部の読み手のレビュー（アートディレクター兼ゲームデザイナーとして）と私の見立てを合わせて、順位を付けた：

| 順 | 何 | なぜ |
|---|---|---|
| 1 | 予測の欄が結果と同じ大きな明朝の数字 | 「570 残る」と覚えて、報告で裏切られたと感じる |
| 2 | 大きな出来事（村を失う、昇格）が小さな札と同じ | 負けたことに気づかない。上がった喜びがない |
| 3 | ターンの文字盤が「9:26」だけで、残りか経過かわからず、動かない | ゲームの心臓が見えない |
| 4 | 「新しいターン — ターン 42」が長く、ターンを二度言い、2.6 秒画面を覆う | 中身（このターンのできごと）が 4 秒後 |
| 5 | 演出の札が地図の名札に重なる（送信中が村の名札の上、戦いの数が留守の札の下） | 何が起きたかが読めない |
| 6 | 断られた送信が、送信中とほぼ同じに見える | 失敗に気づかない |
| 7 | 手札の小さな語が暗号（「○○○ 25:00」「控え 400」「都市へ」） | 押す前にわからない |
| 8 | 報告の判の言葉と文が同じことを三度言う | 結果の一言が弱い |
| 9 | ガイドの札が長く、スマホで切れる | 次にすることが読めない |
| 10 | 資源の帯の「+3」が何かわからない | 収入か、隠れた資源か |

以下、直したものと確かめたことを書き足していく。
