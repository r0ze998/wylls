# Wylls 設計し直し

## 最上位の判断基準（2026-10-23 のユーザー発言）

まず**面白いゲームを作る**。Eternum との違いは、相手にない機能の一覧ではなく、遊んだときの体験全体で評価する。検討する順序は次のとおり。

1. 面白い判断があり、その結果に手応えがあるか。
2. Eternum と異なる戦略、対人相互作用、プレイ展開を生むか。
3. その判断を直感的に行え、結果の因果が分かる UI/UX か。
4. 世界観とビジュアルに一貫性があり、その世界にいたいと思えるか。
5. EVE Frontier の拡張性や Solana の接続性が、上の体験を支えるか。

[補給網の設計案](27a-composable-supply-design-proposal.ja.md)は、この基準で試す**未採用の候補**である。他者への依存が新しい選択を生む場合にだけ採用を検討する。退屈な管理作業、クリック短縮だけ、技術的な合成を見せるための機能は目標にしない。具体的な UI や見た目は今回の文書では設計・実装しない。
