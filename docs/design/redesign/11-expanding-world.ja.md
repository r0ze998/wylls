# 核：人間とAIが「世界でできること」自体を増やしていく

**状態：** たたき台（2026-10-23）。

**あなたの方針（10-23）：**「人間やAIが、世界でできること自体を増やしていく」ゲームにする。開発者も想定していない動きが生まれるようにする。

---

## 0. 先に伝えるべき事実

**同じ方向をすでに進めている大手がいます。CCP の EVE Frontier です。**
- プレイヤーが建てた門・砲台・倉庫に、自分で書いたプログラムを付けて、振る舞いを変えられます（Smart Assemblies）。
  - 例：「味方だけ通れる門」「自動販売の倉庫」
- 2026年3月には Sui と、「A Toolkit for Civilization（文明の道具箱）」という題で賞金8万ドルのハッカソンを開きました。
- 入賞作には、プログラムを書かずに画面で組み立てられる道具（EasyAssemblies、Frontier Flow）があります。
- 出典：[Sui blog](https://blog.sui.io/eve-frontier-migrates-to-sui-hackathon-live/)、[Sui Hackathon 2026](https://blog.sui.io/ccp-games-eve-frontier-hackathon/)、[入賞作](https://unbox.ph/?p=260449)

**ほかの先行例：**
- Lattice の DUST では、箱や力場にプログラムを付けられました。Lattice は2026年4月に解散しています。出典：[DUST template](https://ithub.global.ssl.fastly.net/dustproject/apps-workshop-2)
- Nomic（1982年、Peter Suber）は、「ルールを変えること」自体が手番になるゲームです。オンライン版の Agora は30年以上続いていますが、言葉で書いたルールの解釈をめぐって、人間の裁判官が判決を積み重ねる必要があります。出典：[Nomic](https://en.wikipedia.org/wiki/Nomic)、[Agora](https://agoranomic.org/Herald/theses/html/2020-06-10-G.html)

つまり、「できることを増やせる世界」だけでは他と並びません。**Eternum との違いは出ますが、EVE Frontier とは近くなります。** 差は、次の「どうやって増やすか」で作る必要があります。

## 1. 核［判断］

> **人間とAIが、遊びながら世界のルールを増やしていく国家戦略ゲーム。**
> 誰か（人間でもAIでも）が作った物・約束・決まりは、世界の本物のルールになる。誰にも曲げられず、作った本人も想定していない使われ方をする。それが、プレイヤーとAIが一緒に暮らす世界の中で起きる。

（2026-10-23 あなたの指摘で修正：「言葉で」は核ではなく、作り方の一つ。作る入口は複数あってよい。言葉で書けばAIが積み木に直す／画面で積み木を組む／作り手はコードで書く。どの入口でも、同じ積み木・同じ費用・同じ同意の原則に従う。）

**（2026-10-23 あなたの指摘で、核をさらに修正：検討中）**

> **核は「プレイヤーとAIエージェントの動きによって、ゲームの進行を誰も（開発者も）想定できないこと」。**

- 「コードやルールを書き換えられる」ことは核ではありません。
- 上の「物・約束・決まりを作れる」は、ゲームの基本の規則（土台）を書き換えるものではありません。土台の中で、物や約束を建てることです。進行が読めなくなる原因の一つとして位置づけ直します。

**枯れた技術の水平思考：**

| 枯れた技術 | 昔からの弱点 |
|---|---|
| Nomic（1982）：ルールを変えることが手番 | 言葉のルールは解釈が割れ、人間の裁判官が要る。だから大人数では回らない |
| チェーンの契約（2015〜） | 誰にも曲げられないが、書けるのはプログラマーだけ |
| 言語モデル（2026） | 言葉をプログラムに直せる。ただし間違える |

**3つを組み合わせると、こうなります。**
1. 言葉で書く（Nomic の自由さ）。
2. AIが、決まった積み木だけを使ったルールに直す（言語モデル）。
3. チェーンがそのまま実行する。裁判官は要らない（契約）。

それぞれの弱点を、ほかの2つが埋め合います。

**EVE Frontier との違い：**
- **作れる人：**
  - EVE Frontier では、作るのはプログラムを書く人か、画面で組み立てる人です。
  - Wylls では、**言葉が書ければ誰でも作れ、AIエージェントも作り手になります。** 夜の間もAIが新しい物や約束を作り、人間がそれを使ったり出し抜いたりします。
- **作れるもの：**
  - EVE Frontier で作れるのは主に「物」（門・倉庫）です。
  - Wylls では、**約束（保険・傭兵契約）と国の決まり（税・法）**まで作れます。文明の中身そのものを作れます。

**Eternum との違い（2026-10-23 確認して修正）：**
- **「開発者だけがルールを決める」は言い過ぎでした。**
  - Eternum も2023年の説明で、こう掲げていました。「'open' とは、誰でも Eternum に dojo system（プログラム）を追加して、機能を広げたり、統治のルールを調整したりできることを指す」
  - 出典：2023年11月時点の写し [Generative-Labs/eternum-pvp](https://github.com/Generative-Labs/eternum-pvp)
- **今の説明には、その一文がありません。** 2026年10月の公式 README は「Contracts are the game. The client is just a window.」です。出典：[BibliothecaDAO/eternum](https://github.com/BibliothecaDAO/eternum)
- **［未確認］** 遊ばれているシーズンの中で、プレイヤーが実際にルールを足した例は見つかりませんでした。
- **正確な違い：**
  - Eternum の「誰でも拡張できる」は、開発者がコードを書いて、ゲームの外から足すことです。
  - Wylls では、**ルールを足すこと自体が、遊びの中の手番** です。人間もAIも、世界の中の材料と費用を払って、ゲームの中で作り、使われ、朽ちます。

## 2. 必要な設計（8つ）

### ① 変わらない土台（世界の物理）

- **最小限の物理だけを開発者が作ります。** 土地、少数の資源、兵、移動、戦い、時間、持ち物。これは誰にも変えられません。
- **守られる法則の例：**
  - 資源は何もない所から生まれない。作るか、奪うか、受け取るしかない。
  - 戦争以外の方法では、他人の持ち物を同意なしに動かせない。

**なぜ要るか：** 何でも変えられると、ゲームが壊れるか、一番ずるい人が勝つだけになります。Nomic でさえ「変えにくいルール」を持っています。

### ② 積み木（ルールの材料）

新しいルールは、決まった少数の積み木の組み合わせでしか作れません。

| 種類 | 例 |
|---|---|
| **いつ** | 誰かがここを通ったとき、取引したとき、攻められたとき、毎日 |
| **もし** | 相手がどの国か、何を持っているか、記録に何があるか（公開されていることだけ） |
| **なら** | 自分の持ち物か、預けておいた物を渡す・止める・通す・閉じる |

AIは、この積み木の外のことは作れません。積み木を少なく保つことが、安全で読みやすい世界の条件です。

### ③ 作る道具：言葉 → AI → 確認 → 建てる

1. 言葉で書く。例：「峠に関所を作りたい。北の国の人は無料、それ以外は木材2」
2. AIが積み木に直し、**普通の言葉で読み返す**。例：「この関所では、北の国以外の人が通るたびに木材2をあなたに払います」
3. **試しに動かした結果** を見せる。例：「昨日の通行量なら、1日に木材40」
4. 材料（石50など）を払って建てる。中身は全員に公開される。

人間もAIも、同じ道具と同じ費用で作ります。

### ④ 作れるものは3種類

| 種類 | 例 |
|---|---|
| **物** | 関所のある橋、共同の穀物倉、渡し舟、見張り塔 |
| **約束** | 小麦の保険、傭兵の契約、借りた資源の返済 |
| **決まり** | 国の税、砦の当番、新入りへの支援。国の中の投票で決まる |

### ⑤ 同意の原則（いちばん大事）

**ルールが及ぶのは、次の3つだけです。**
- 作った人自身の物
- それを使うと自分で選んだ人
- その国の決まりを受け入れて国に残っている人。嫌なら国を出られる

**なぜ要るか：** これがないと、他人を一方的に縛る罠のルールが作れてしまいます。この原則があれば、どんなに想定外の使われ方をしても、被害は「自分で選んだ」範囲に収まります。

### ⑥ 使われるものだけが残る（淘汰）

- 作るには材料がかかり、維持には毎日少し費用がかかります。
- 使われると、作った人に使用料が入ります。
- 誰でも、他人の作ったものを写して改良できます（写すにも費用がかかる）。
- 使われないものは朽ちて消えます。

**結果：** 役に立つもの、面白いものだけが広がります。これがネットワーク効果になり、DEX を作れる人が世界の中に市場を作る、といったことも起きます。

### ⑦ 読みやすさ

- 地図のどこでも、「ここでできること」が一覧で出ます。
- 一つ一つが普通の言葉で説明され、誰が作り、何人が使ったかが見えます。

**なぜ要るか：** できることが増え続けるゲームで一番の敵は、新しく来た人が何も分からないことです。

### ⑧ 開発者がしないこと

- **しないこと：** プレイヤーの作ったルールは書き換えません。
- **すること：** ①の土台の調整と、最初の見本（関所・倉・保険の例）を置くことだけです。

これが「開発者も想定していない動き」の条件で、あなたの言う「Rules no one can bend」です。

## 3. 想定外の動きの例

1. **保険の抜け道：**
   - AIの「Rook」が小麦の保険を作る。1日に小麦1を払えば、襲われたとき小麦20が出る。
   - ある人間が、友達に自分の村をわざと襲わせて保険金を集める。
   - Rook は気づいて「同じ国からの襲撃は対象外」という新しい版を出す。古い版の加入者は、新しい版に移るか、古い版に残るかを選ぶ。
2. **関所への対抗：**
   - 峠に高い関所ができる。
   - 別の人が、川に安い渡し舟を作って客を奪う。
   - 関所の主は、渡し舟の岸を攻めるために傭兵の契約を作る。
3. **国が割れる：**
   - 北の国が「収穫の10％を砦の防衛に」という税を投票で決める。
   - 反対した村は国を出て、税の安い新しい集まりを作る。
   - 文明の地図が、プレイヤーの決まりによって変わる。

**どれも開発者が作った筋書きではありません。** 積み木と同意の原則の中で、人間とAIが勝手に起こすことです。

## 4. 危険と、まだ分からないこと

1. **EVE Frontier との競争。** 規模も資金も向こうが上です。差は、言葉で作れること、AIが作り手になること、約束と国の決まりまで作れること。この差が実際に遊んで感じられるかが勝負です。
2. **難しさ。** 多くの人は作らず、使うだけです（作るのは1割程度が普通）。それでも成り立つように、使うだけでも面白い必要があります。
3. **AIの翻訳の間違い。** 言葉と違うルールができる危険があります。読み返しと試し動作で防ぎますが、完全ではありません。
4. **抜け道と悪用。** 同意の原則で被害は狭まりますが、賞金が絡む悪用（自作自演の使用料など）は別に塞ぐ必要があります。自分の作ったものを自分で使っても、賞金の点にはしない、などです。
5. **チェーンの計算量。** 積み木を増やしすぎると、1回の処理が重くなります。
6. **最初の人数。** 作ったものを使う人がいないと、作る意味がありません。最初はAIと見本で世界を埋める必要があります。
7. **お金の規制。** 保険や貸し借りを本物のお金でやると金融になります。ゲーム内の資源に限るのが安全です（法的助言ではありません）。

## 5. 検証の方法（2026-10-23 作り直し）

### なぜ前の方法ではだめだったか

- **何で試すかが決まっていなかった。**「土台のルール1枚」「積み木10枚」と書いただけで、中身がありませんでした。
- **審判が設計者（私）だった。** 判定が甘くなります。
- **数字の基準がなかった。**「想定外の動き」が何を指すのか、決まっていませんでした。
- **2回・数人では、何も起きなくて当然。** 想定外の動きは、足りないもの、賭けるもの、時間、大勢の参加者がそろって初めて起きます。
- **確かめたいことが混ざっていた。** 一つの試しで全部を見ようとしていました。

### 確かめるべき仮説（核が成り立つための条件）

| # | 仮説 | これが外れたら |
|---|---|---|
| H1 | 少ない積み木で、プレイヤーが作りたいものの大半を表せる | 積み木が足りないか、多すぎて読めない |
| H2 | 同意の原則と土台の法則で、他人を縛る罠や壊れたルールを防げる | 世界が悪用で壊れる |
| H3 | 足りないものと賭けがある世界では、作られたルールが他人に使われ、作った本人も想定しない使われ方や、対抗するルールが生まれる | 核の売り（想定外の動き）が起きない |
| H4 | ルールを作れる世界は、作れない世界より、毎回ちがう展開になる | ルールを足せても、ゲームは変わらない |
| H5 | AIが、作りたいもの（言葉）を正しく積み木に直せる | 言葉の入口が使えない |
| H6 | 人間が、作る・使う・出し抜くことを楽しむ。作らない人も楽しめる | 仕組みは動いても、遊びとして面白くない |

**「想定外の動き」の数え方：**
- 作る人は、作るときに「何のために作るか」を一文で登録します。
- 次のどれかが起きたら、1件と数えます。
  - (a) 登録した目的と違う目的で使われた。
  - (b) 別のルールと組み合わされて、どちらの作り手も書いていない結果が出た。
  - (c) それに対抗する新しいルールが作られた。
- 判定は、作り手ではない別の判定役がします。別のAIで判定し、一部をあなたが抜き取って確かめます。

### 段階0：土台と積み木を実際に書く（数日）

これがないと何も試せません。次の3つを、1〜2ページに書き切ります。
- **土台：** 資源3〜4種、土地、兵、移動、戦い、時間。
- **積み木：** 「いつ／もし／なら」で、12個以内。
- **同意の原則**

### 段階1：机の上の試験（1〜2日。H1・H2・H5）

1. **作りたいものを50個集める。**
   - 出どころ：あなた、参考作品（EVE、Foxhole、Travian、Crusader Kings、A Tale in the Desert の法律など）、性格の違う複数のAI。
   - 集めたものを、積み木で表せるか一つずつ試します。
2. **悪用を20個試す。**
   - 「他人の村を同意なしに縛る」「資源を無から作る」「処理を止める」などを、わざと作ろうとします。
3. **言葉から積み木への変換を50個試す。**
   - AIの変換が、作りたかったものと合っているかを、作った本人（またはあなた）が判定します。

**合格の基準：**
- 50個のうち8割以上を、12個以内の積み木で表せる。
- 悪用20個はすべて防げる。
- 変換の正しさは9割以上。

**落ちたら：** 積み木を作り直します。それでも8割に届かなければ、「少ない積み木で何でも作れる」という前提が成り立たないということです。

### 段階2：AIだけの世界で回す（1〜2週間。H3・H4）

- **作るもの：** 画面のない、小さなシミュレーター。土台、積み木の実行、同意の原則だけを入れます。チェーンも画面も要りません。
- **参加者：** 目的と性格の違うAI 30体。
  - 例：稼ぎたい、守りたい、ずるをしたい、国のために動く。
- **条件：** 同じ初期状態で、次の2通りを10回ずつ回します。
  - A：ルールを作れる
  - B：作れない（今あるものだけ）
- **数えること：**
  - 作られたルールの数
  - そのうち他人に使われた割合
  - どれくらい長く使われたか
  - 想定外の動きの件数
  - 対抗ルールの数
  - 1つのルールが使われ方の大半を占めていないか
  - 罠や悪用の件数
  - 10回の結末がどれだけばらけるか（勝った国、資源の分布、国の形）
- **合格の基準：**
  - Aでは、作られたルールの3割以上が他人に使われる。
  - 想定外の動きが、1回あたり平均1件以上起きる。
  - Aの結末のばらつきが、Bより大きい。
  - 1つのルールが使われ方の5割以上を占める回が、半分未満。
- **限界（正直に）：**
  - AIは人間ではないので、ここで分かるのは「仕組みとして想定外が起きる余地があるか」までです。
  - 面白いかどうかは、ここでは分かりません。
- **費用の目安：** 30体×200手番×10回×2通りで約12万回の判断。安いモデルで1〜2万円程度［概算］。
- **注意：** 検証用の使い捨てのコードで、ゲーム本体ではありません。進めるにはあなたの了承が要ります。

### 段階3：人間が入る小さな本番（3〜5日。H5・H6）

- **参加者：**
  - 人間5〜8人：あなた、Superteam Japan の知人、X のフォロワーなど。
  - 段階2のAI 10〜20体
- **場所：** Discord か、簡単なウェブ画面。
  - 言葉で作りたいものを書くと、AIが積み木に直して読み返し、本人が確認すると世界に建ちます。
  - 3〜5日、非同期で遊びます。
- **数えること：**
  - 何か作った人間の割合
  - 人間の行動のうち、他人の作ったものを使った割合
  - 想定外の動きの件数（人間が関わったもの）
  - 1日後・3日後に戻ってきた人の割合
  - 終わった後の「もう一度やりたいか」
- **合格の基準：**
  - 半分以上の人が何かを作る。
  - 半分以上の人が他人の作ったものを使う。
  - 半分以上の人が「もう一度やりたい」と言う。
  - 作り手の確認で、変換の正しさが9割以上。

### 順番と判断

- **段階0 → 1 → 2 → 3 の順に進め、各段階で落ちたら次に進みません。**
- 段階1と2は、人を集めなくても、あなたと私だけで進められます。
- **人を集める前に、核が仕組みとして成り立つかを確かめられる** のが、この順番の利点です。
