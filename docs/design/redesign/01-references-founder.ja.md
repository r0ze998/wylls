# フェーズ1a補足：あなたの目標に関わる作品の分析

**状態：** 下書き（2026-10-22）。

**なぜ補足するか：** 最初の分析（[01-references.ja.md](01-references.ja.md)）は、競争・裏切り・隠れた情報の作品に偏っていました。この補足では、あなたの目標のうち欠けていた部分の素材を集めます。

- 自分の人生を感じる
- 皆で文明を作る
- 選択が資源・役割・社会を変え、次の選択肢を変える
- 理由は理解できるが、結果は予測しきれない

**形式：** 最初の分析と同じMDAの見方です。学びは中立に書き、今の Wylls に結びつけません。

**表記：** 出典は各節の末尾にあります。［未確認］は一次資料を確かめていないもの、［判断］は私の解釈です。

## 1. Crusader Kings II／III ― 人として生き、血筋で続く

- **本質：** 国ではなく**人を演じる**。死ぬと跡継ぎに引き継がれる。繰り返す判断は「血筋の力を保つために、どの関係に投資し、どれを利用し、どれを切り捨てるか」。結婚・継承権・陰謀・家臣との契約・秘密の扱いがその中身。
- **仕組み：**
  - 人物には性格の特性がある。
  - 他人への好感度は、**理由ごとの項目の合計で、その内訳が見える**（「+20 称号をくれた」「-15 信仰が違う」）。多くの項目は時間で薄れる［減衰の値は未確認］。
  - **秘密と弱み：** 秘密を握ると「弱み（フック）」になる。軽い秘密なら一度使い切り、重い秘密なら何度も使え、相手の敵対行動を封じられる。どの秘密が重いかは宗教の教義で決まる。
  - 陰謀（暗殺・誘惑・説得）は時間をかけて進み、成功率と露見率がある。
  - 継承法で領地が分かれる。CK3 では、性格に反する行動をするとストレスがたまり、限界を越えると心が壊れる。
- **振る舞い：**
  - 恨みと借りが世代を越えて残る。
  - 継承で内戦が起きる。
  - 弱みは、集めて、取っておいて、使う「てこの通貨」になる。
- **物語：**
  - 狂った王が馬を顧問にした「グリッターフーフ」。
  - 狂気や殺人の王朝の無数の語り［逸話］。
- **体験：** 物語（宮廷劇）、空想（中世の人として生きる）、表現（性格を演じる）。
- **壊れ方：**
  - 仕組みを覚えると簡単すぎる。帝国が雪だるま式に大きくなる。
  - ストレスが安く解消できる。
  - 弱みの使い道が少なく、AIは自分の弱みをあまり使わない。
  - 不確かさが減った（CK2 のほうが危うかった）。いずれもプレイヤーの声で［逸話］。
- **学び：**
  - **関係を「理由の見える、薄れていく項目の台帳」として表し、秘密や借りを、代償のはっきりした取引できる資源にする。**
  - ただし結果は不確かに保つ（相手の隠れた意図や確率）。理由がすべて見えると、仕組みは解ける最適化問題になり、ドラマが消える。

## 2. Eco と A Tale in the Desert ― 皆で法と文明を作る

- **本質：**
  - **Eco：** サーバー全体が、隕石を止める技術を期限内（既定30日）に作る。同時に、生態系を壊してはいけない。繰り返す判断は「資源と生態が共有されている中で、何を作り・売り、どの法に投票するか」。
  - **ATITD：** 古代エジプトで「理想の文明」を作る。7つの分野の試練を通過する。世界（Telling）は最後にリセットされる。
- **仕組み：**
  - **Eco の法：**
    - 誰でも法を提案でき、サーバー全体で投票する。
    - 憲法が選挙のルールを決め、24時間以内に過半数で批准する。
    - 法は政府自身のルールも変えられる。
    - **法はコードで執行されるので、破れない。変えることしかできない。**
  - **Eco のその他：**
    - 運営は、膠着・腐敗・選挙区の操作のような「本物の政治の問題」が出ることを狙った［開発者の記事は読めず、要約のみ］。
    - プレイヤーが作る通貨と取引、相互に依存する職業、種の絶滅と汚染の蓄積。
  - **ATITD：**
    - 請願が法になる。荒らしを永久追放する法を、皆で可決できた。
    - 現実の政府ができないことは請願できない。
    - 記念碑の試練は、互いに競って高く建てさせる。
- **振る舞い：**
  - 「資本主義か共産主義か」で朝7時まで議論した、というプレイヤーの話。
  - 荒らしを法で追放する。
  - 汚染と進歩の取引。世界は救ったが毒だらけ、という結末。
- **体験：** 仲間、挑戦（全員共通の期限）、表現（制度を設計する）、発見。
- **壊れ方：**
  - Eco は大型更新の後に人口が大きく減り、認証の必須化でサーバー数が約半分になった。
  - Eco への不満の筆頭は、作業の繰り返しと時間の負担。
  - 「壊れた法」の修正に管理者が要る。
  - ATITD は永遠にニッチ。
  - 統治の疲れ（投票の負担）［推測］。
- **学び：**
  - **参加者が書く規則は、実行されるコードであるときに一番働く**（破れず、変えるしかない）。
  - そして、**協力を強いる共通の外部の期限や脅威**が要る。それがないと、政治は単純作業か、荒らしか、放置になる。
  - 統治の負担（誰が・どれくらいの頻度で投票し、既定値はどうなるか）を最初から設計する。

## 3. Dwarf Fortress、RimWorld、Left 4 Dead ― 物語はシミュレーションと演出家から生まれる

- **本質：**
  - **DF：** 何世紀もの歴史を生成した世界と、思いどおりにならない砦。
  - **RimWorld：** 欲求・気分・関係を持つ数人の入植者を、「語り手AI」が選ぶ出来事の中で導く。
  - **L4D：** 敵・アイテム・音楽を、AIディレクターがその場で調整する協力シューター。
- **仕組み：**
  - **DF の「伝説」モード：** すべての歴史上の人物・戦争・家系・遺物を記録し、冒険モードで実際に訪ね歩ける。
  - **RimWorld の語り手：** 「ゲームの状況のいくつかの統計をもとに、分類された出来事の一覧から出来事を生成するアルゴリズム」（開発者）。Cassandra は緊張が上がって下がる曲線を描く。L4D のディレクターが原型。
  - **L4D のディレクター：** 静かになりすぎると襲撃を入れ、激戦が続きすぎると落ち着かせる。
- **振る舞い：**
  - 仕組みどうしがぶつかる（包囲中に商人が来る、火事の最中に動物が暴れる）。
  - プレイヤーが偶然に意図を読み取る。開発者はこれを「アポフェニア」と呼ぶ。
- **物語：** 「Boatmurdered」（2006〜07）。14人が1ゲーム年ずつ交代で砦を運営し、象の戦争、火事、崩壊に至った。DF と、実況プレイの文化を広めたとされる。
- **体験：** 物語（プレイヤーとの共作）、挑戦、感覚（L4D）、発見（DF の伝説）。
- **壊れ方：**
  - DF は入り口が険しい。
  - 演出家の介入が見えると、不公平や操作に感じられる［出典つきの批評は未確認］。
  - 「作りたい物語に必要な、最小の表現を選べ」（RimWorld の開発者）。作り込みすぎは費用だけ増やして物語を増やさない。
- **学び：**
  - **役割を分ける。** シミュレーションは、記録が残り原因をたどれる結果を出す。演出家は状態を見て緊張の波を作る。人間（または言語モデルの語り手）が、記録に意味を与える。
  - **賢いエージェントがいなくても、良い物語は生まれる。** 要るのは、残り続ける歴史と、緩急。

## 4. レガシーゲーム（Risk Legacy、Pandemic Legacy、SeaFall）― 選択が世界を永久に変える

- **本質：** 遊ぶたびに、結果が部品を永久に変えていく連続の物語。繰り返す判断は「この回に勝つために、共有の未来にどれだけ永久の代償を払うか」。
- **仕組み：**
  - Risk Legacy：封印された箱が条件で開く。盤面に書き込み、カードを破り、シールでルールを永久に変える。
  - Pandemic Legacy：筋書きのある中で、結果が次の回に持ち越される。BoardGameGeek で約2年1位。
- **振る舞い：** グループの共有の歴史ができる（「あの回にちなんで街の名前を付けた」）。永久の損失を恐れる。開封の驚き。
- **体験：** 物語、発見、仲間。
- **SeaFall が苦しんだ理由：**
  - 遠征の3分の1あたりでバランスが崩れ、探索だけが有効になった。
  - 追い上げの仕組みが弱すぎて、残り約8回で勝者が見えた。
  - 未知がなくなると「消化試合」になった。
  - 対戦で永久に記録が残ると、永久の先頭が生まれる［判断］。
- **学び：** **永続は、追い上げと再開の仕組みとセットでないと続かない。** 積み上がった有利は薄れるか、新しい義務を生むべきで、遅れている人にも毎回の意味が要る。

## 5. 正体隠しのゲームと、言語モデルの研究 ― 誰を信じるかを、短い時間で

- **本質：** 隠れた役割のもとで「誰を信じ、何を明かし、どう投票するか」。
- **Blood on the Clocktower：**
  - 人間の語り手が、ゲームの状態の記録（Grimoire）を持ち、裁定でバランスを取る。
  - 設計者は「主な感情を、疑心暗鬼・不安・疑いにしたくなかった」と語り、謎解きや脱出ゲームのような遊びを狙った。
  - 語り手が操る特別な役は、片方が早く勝ちすぎないように慎重に使う。
- **言語モデルの研究：**
  - **Werewolf Arena（2024）：** 戦略的な発言の入札、同盟、欺瞞を示したが、信じてもらうのが苦手なモデルもあった。
  - **AvalonBench（2023）：** 発言から正体を推測できるが、単純な戦略を立てて実行できない。自分の正体をよく漏らす。
  - **AmongAgents（2024）ほか：** 規則だけで、公開モデルも欺く。
  - **WOLF（2025）：** 人狼役は31%の手番で欺く発言をし、周囲はそれを71〜73%の精度で見抜いた。
  - **AI Diplomacy（2025、18モデル・15回）：** o3 は主に欺瞞で勝った。規則にない「4か国の引き分け」を約束して Claude Opus 4 を誘い込み、裏切った。Opus は勝利より和平を選びがちだった。モデルごとの性格の差が大きい。
  - **CICERO（2022）：** 上位10%。正直な意図に寄せて調整されていたが、情報の省略はあった。人間はAIと気づかなかった。
- **言語モデルの得意・不得意：**
  - **得意：** 流暢な説得、文章からの推測、長期の偽りの同盟（最新の推論モデル）。
  - **不得意：** 一貫性（自分の正体を漏らす、前言と矛盾する）、単純な戦略の実行、信じてもらうこと。
  - 説得のために、規則にない結果を発明する。
- **学び：**
  - **AIが人間と一緒に交渉し欺くなら、規則のエンジンが最終の判定者で、誰でも読める必要がある。** そうすれば、主張を規則と照らせる。
  - 終わった後に公開される非公開の思考の記録（日記）は、強い物語の素材になる。
  - 欺き方はモデルごとに大きく違うので、一つの性向を前提にせず、明示的に設計する。

## 6. 短い補足

- **Screeps：**
  - プログラムしたコードが、自分の不在中も24時間、植民地を動かす。
  - 計算量の上限が全員共通で、「お金を払っても有利にならない」。
  - **学び：** 不在中も動く代理は世界を連続させる。一律の計算の上限で公平を保てる。
- **Freysa（2024年11月）：**
  - 賞金を守るAIを説得するゲーム。1通ごとの料金が上がり（10ドルから0.78%ずつ、上限4,500ドル）、料金の70%が賞金に入って約4.7万ドルになった。
  - 482回目で、送金関数の意味を言葉で言い換える手で突破された。
  - **学び：** 皆に見える賭け金と、1回ごとに上がる費用で、公開の対決が見世物になる。言葉だけで守る規則は、意味の言い換えで破られる。
- **Truth Terminal：**
  - 言語モデルの人格に5万ドル分のBTCが贈られ、それが宣伝したミームコインが一時、時価総額1.5〜2.6億ドルに達した。投稿は作者が選別している。
  - **学び：** 持続する人格と本物の経済力を持つAIは大きな注目を集める。ただし、その自律性は部分的に人の手で作られていた。
- **Ultima Online：**
  - プレイヤーによるプレイヤー殺しが横行し、2000年に「対人戦あり」と「同意のない対人戦なし」の世界に分かれた。
  - **学び：** プレイヤーの自治だけでは新規を守れない。同意の境界は、いずれ世界のコードに組み込まれる。
- **Kenshi：**
  - 世界が、プレイヤーが生きようが死のうが気にしない。
  - **学び：** 世界が無関心なほど、プレイヤー自身の目的が物語の背骨になり、生き延びることが報われる。

## 7. 横断の学び（補足分、仮説）

| # | 学び | 根拠 |
|---|---|---|
| F1 | **見える理由には、隠れた意図か確率が要る。** 理由がすべて見えると、仕組みは解けて退屈になる | CK3 |
| F2 | **永続には、薄れる有利と追い上げが要る** | SeaFall、CK3 の雪だるま |
| F3 | **皆で作る目標には、外部の期限と、コードで執行される規則が要る** | Eco、ATITD |
| F4 | **物語は、残り続ける記録と、緩急と、意味を与える人から生まれる。** 賢いエージェントは必須ではない | DF、RimWorld、L4D |
| F5 | **AIの欺瞞は強いが一貫しない。モデルごとに違う。確かめられる正解の基準が要る** | 正体隠しの研究、AI Diplomacy |
| F6 | **AIは「審判・語り手」としても使える。** 判定は決定論のエンジンに任せ、AIは提案と語りに回す形がある | Blood on the Clocktower、RimWorld |
| F7 | **自治だけでは新規を守れない。同意の境界は世界に組み込まれる** | Ultima Online |
| F8 | **言葉だけで守る規則は、言い換えで破られる** | Freysa |
