# 段階1e の作り方（2026-10-23）

1e で作るものは、次の4つです（[30](30-stage1-build-plan.ja.md) の2章）。

- 砦と柵の「誰を通す・止める」の設定（国の構えに従う）
- 包囲の宣言で兵器を使い切る
- 国内の襲撃の記録
- 追放の投票

作り始める前にコードを確かめたところ、計画の前提と違う点が4つ見つかりました。判断してほしい項目を、5章にまとめています。

## 1. コードで分かったこと［事実］

1. **国の状態が、チェーンの上にまだない。**
   - 国ごとの口座も、構え（戦争／通行可／同盟）も、投票の仕組みもない。
   - 戦いの処理は「自分の国以外はすべて敵」で固定されている。
2. **砦と柵という建物が、まだない。**
   - 今あるのは、村の壁と、州の中心の砦（キープ）だけ。
   - 「誰を通すか」を持たせる建物を、新しく作る必要がある。
3. **同じ国の荷車は、今は襲えない。**
   - 荷車の襲撃（1c）は、戦いの中で「荷車の国と違う国の軍勢がマスを取った」ときに起きる。
   - 同じ国の軍勢は味方として扱われるので、決定済みの「同じ国の荷車も襲える」が、まだ成り立っていない。
   - 同じ国どうしで起きるのは、倉と塔の奪取だけ。その記録には、すでに「国内」の印がある。
4. **包囲の宣言は、すでに金を預けている。**
   - 兵器も同じ支払いに足せばよい。新しい仕組みは要らない。

## 2. 包囲の兵器（判断不要）

- 包囲を宣言すると、元の村から兵器を **使い切る**（燃やす）。成功しても失敗しても戻らない。
- 量はシーズンの設定に置く。たたき台は20［フェーズ6］。
- 宣言の記録に兵器の量を残し、検証ツールが確かめる。

## 3. 国内の襲撃（提案）

- **起こし方：** 新しい命令「国内の襲撃」を作る。
  - 荷車が立っていたマス、そのターンに、自分の軍勢が名簿に載って立っていたことを示せば、その荷車に襲撃が開く。
  - そのとき、荷車の持ち主の軍勢がそのマスにいれば、襲えない。
  - 倉の奪取と同じ「そこに立っていた」の判定。
- **開いた後：** 今の「奪う／焼く」の決着（1c の襲撃と同じ命令）に流す。
- **記録：** 荷車の襲撃の記録に「国内」の印を足す。中継サーバーは、国内の襲撃を国ごとの一覧として公開する。

## 4. 砦・柵・構え・追放（提案）

- **国の口座：** 6か国に1つずつ。構えと追放の状態を持つ。
- **投票：**
  - 1村1票。国に入って2日たった村だけが投票できる［フェーズ6］。
  - 提案から1日で締め切る。
  - 有効な票の過半数で可決。最低の投票数も置く。
  - 決めるのは「他の国への構え」と「追放」の2つだけ。建設と取り分は段階2。
- **柵：** マスに建てる新しい建物。
  - 止める相手（構えが「戦争」の国、追放された村）は、そのマスを通れない。
  - 進軍の封が開くとき（Reveal）と、荷車の道で判定する。塔の判定と同じ場所。
- **砦：** マスに建てる新しい建物。兵を置ける。
  - そのマスの戦いで、守り手として加わる。止める相手とだけ戦い、通す相手とは戦わない。
  - 自分の荷車や軍勢は、砦のマスでは守られる。
- **追放：**
  - 追放された村は「追放」の状態になる。国の印は残る。
  - その国の砦と柵に止められる側になる。投票権と、国の賞金の取り分を失う。
  - 一定期間（3日）戻れない［フェーズ6］。
  - 「どこにも属さない村」と「国を移る」は、今の戦いの仕組みを「6か国＋無所属」に作り替える大きな作業になる。戦期の作業でまとめて作る。
