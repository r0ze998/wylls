# 段階1（倉・送り・工房1種）：遊びとしてどうなるか

**状態：** たたき台（2026-10-23）。
- 数字は、すべて説明のための例です。本当の数字はフェーズ6で決めます。
- 段階の位置づけは [17](17-summary-uniqueness-integration.ja.md) の3-3 にあります。

## 1. 段階1で何が変わるか（一言で）

**今：**
- どの村も、自分の村の中で全部をまかなう。
- 物は村から一歩も動かない。
- 戦争は「兵を集めて、砦へ送る」だけ。

**段階1の後：**
- 強い軍を作るには、**他の場所の物が要る**。
- 物は地図の上を **運ばれ**、運ぶ道が **狙われる**。
- 戦争は「兵」だけでなく、**補給の道の取り合い** になる。

## 2. 足すものは3つ

| 足すもの | 遊びの上での役割 |
|---|---|
| **工房** | 鉱石と木材から **兵器** を作る建物。兵器は、強い兵（例：重装兵、攻城兵）の訓練と、砦攻めに要る |
| **倉** | 物を置いておく建物。自分の村の外（国の土地や境の外）にも建てられる。前線の近くに兵器をためる、交易の受け渡し場所にする、といった使い方 |
| **送り（荷車）** | 村や倉から、別の村や倉へ物を運ぶ。地図の上を動き、着くまで時間がかかる。途中で敵の軍に出くわすと、荷を奪われる |

**依存を生むための前提：**
- 鉱石は、山や丘の近くの村でしか多く採れないようにします。今の土地の違い（土地ごとの資源）を、生産量に効かせます。
- 平地の村は、鉱石を他から手に入れないと、兵器を作れません。

（あなたの 10-19 の言葉「土地はきっかけ。森林なら木材を得やすい」にあたる部分です。）

## 3. プレイヤーが新しく迷うこと

| 判断 | 迷う理由 |
|---|---|
| **兵器を自分で作るか、買うか** | 自分で作るには、工房を建て、鉱石を集める必要がある。買えば早いが、売り手に頼ることになる |
| **倉をどこに置くか** | 前線の近くなら、兵器がすぐ届く。そのかわり、見つかって襲われやすい。村の近くなら安全だが、届くのが遅い |
| **どの道で運ぶか** | 近道は早いが、峠や境の外を通る。遠回りは遅いが安全 |
| **護衛を付けるか** | 軍を一緒に動かせば荷は守れるが、その軍はその間、他のことができない |
| **ためるか、売るか** | 兵器をためれば、いざという時に強い。売れば、今のうちに資源が入る |

## 4. 場面で見る

### 場面A：平地の村が兵器を手に入れる

1. あなたは平地の村。木材と食料は多いが、鉱石がほとんど採れない。
2. 国が「来週、東の砦を攻める」と話している。砦攻めには兵器が要る。
3. 選べる道は3つ。
   - **買う：** 丘の村の Mara（人間かAIかは分からない）に、木材と引き換えに鉱石を送ってもらう。段階1には、取引を守らせる仕組み（引き換えの預かり）がない。だから、どちらが先に送るかで揉める。あなたが先に木材を送ると、Mara が鉱石を送ってこない危険がある。
   - **自分で採る：** 境の外にある鉱石の多い丘に、倉を建てる。鉱石をそこで採り、荷車で村に運ぶ。ただし、その道は他国の軍も通る。
   - **作ってもらう：** すでに工房を持つ南の村から、兵器を直接買う。高いが早い。

### 場面B：補給の道をめぐる戦い

1. あなたの国は、東の砦の近くに倉を建て、兵器をためている。
2. 荷車は、出発地と行き先が地図に見える。敵の国は、それを見ている。
3. 敵の軍は、行き先を隠したまま動ける。荷車の通る峠で待ち伏せするかもしれないし、しないかもしれない。
4. 選択：
   - 荷車に護衛を付ける（攻める軍が減る）。
   - 遠回りの道で送る（砦攻めが遅れる）。
   - 危険を承知で近道を使う。
5. 待ち伏せされれば、兵器の一部が奪われる。奪った敵は、その兵器で強い兵を訓練する。

### 場面C：兵器の商売

1. 丘の村の B は、鉱石が多いので工房を建てる。
2. 自分の兵器を作るだけでなく、周りの村に兵器を売り始める。
3. 戦争が近づくと、兵器の値段は上がる。B は、どちらの国にも売るか、自分の国にだけ売るかを迫られる。
4. B の工房は、敵国から見ると、真っ先に狙いたい場所になる。

## 6. 段階1が「成り立った」と言えるのは

（あなたの方針の「確かめるべきこと」を、段階1の範囲に当てはめたもの）

- **指定しなかった使い方：** 例えば、こちらが用意していない「前線の倉を囮にする」「荷車を空で送って敵の軍を引きつける」が出てくるか。
- **他人がそれを使いたくなる：** 他人の工房から兵器を買う、他人の倉に物を預ける動きが出るか。

## 7. 兵器の使い道［決定 2026-10-23］

**「強い兵の訓練」と「砦攻め」の両方に使う。**
- 訓練：重装兵・攻城兵などを訓練するたびに、兵器を使う。
- 砦攻め：攻める側が兵器を使う。

このため、兵器を運ぶ荷車は、戦争の前に最も狙われる荷になります。

## 8. 荷の中身を見せるか［決定 2026-10-23：この章の案を採用］

**注（2026-10-23 追記）：** コードを読んだ結果、今の「封じた進軍」は点から点で、道の途中の戦いには加わらないことが分かりました。そのため、この章の「護衛が荷車と同じ道を進む」形と、9章の「奪った荷を持ち帰る軍が見える標的になる」形は、そのままでは作れません。作り直しの案は [30](30-stage1-build-plan.ja.md) の0章と4章（J1・J2）にあります。

**2026-10-23 に、作り直しの案を次のとおり採用しました。**
- **護衛：** 封じた進軍で、道の途中のマスへ先に送って待ち構える。
- **奪った荷：** 襲われた荷車の持ち主が移り、見える荷車として襲った側の村か倉へ運ぶ。

### 結論：荷車は全部見せる。分からないのは「護衛がいるかどうか」

| 情報 | 見せるか |
|---|---|
| 荷車が出たこと、出発地、行き先、通る道、着く時刻 | 見せる |
| **荷の中身（種類と量）** | **見せる** |
| **護衛の軍** | **隠せる**。護衛は、今の「行き先を封じた進軍」で荷車と同じ道を進む。敵には、その軍が荷車の護衛なのか、別の所へ向かっているのか分からない |

### 理由

1. **中身だけを隠すことは、今の仕組みではできない。**
   - 村の在庫はチェーンの上で公開されている。荷車を出すと、村の在庫の何が何個減ったかが誰にでも分かる。
   - 中身を隠すには、在庫そのものを zk で隠す必要があります。これは [13](13-hidden-information.ja.md) の範囲（移動中の軍だけ）を大きく超えます。
   - 画面だけで隠すのは、チェーンを読む人やAIが得をするので採らない（あなたの方針）。
2. **読み合いは、中身ではなく護衛で作れる。**
   - 襲う側は「あの兵器の荷車に、護衛は付いているか」を読むことになる。
   - 守る側は「護衛を付けるか、付けたふりをするか（別の軍を同じ方向に出すだけ）」を選ぶ。
   - 今ある封じた進軍がそのまま使えるので、新しい暗号の仕組みは要りません。
3. **将来の選択肢：** zk で在庫と荷を隠せるようになったら、中身を隠す案を見直します（段階1〜4の後）。

## 9. 奪われる量［決定 2026-10-23：この章の案を採用］

### 襲撃の起き方

- 荷車は、地図の上の **見える物** です（「戦いは見える場所でだけ起きる」に沿う）。
- 敵の軍が、荷車と同じターンに同じマスに着くと、そこで戦いになります。
- 護衛がいれば、今の戦いの規則で、護衛と襲う側が戦う。
- 護衛がいない、または護衛が負けたら、襲う側が次のどちらかを選ぶ。

| 選択 | 中身 |
|---|---|
| **奪う** | 襲った軍が **運べる量まで** 持ち去る。運べる量は兵の数で決まる（Travian の「運べる量」と同じ考え方）。残りの荷は、そのまま行き先へ進む |
| **焼く** | 荷を **全部** なくす。何も得られないが、敵の砦攻めや訓練を確実に止められる |

- 護衛が勝てば、荷は無事で、襲う側に損害が出ます。

### 奪った物のその後

- 奪った荷は、襲った軍が持って帰ります。軍が自分の村か倉に着くまでは、その軍も荷を持った「見える標的」です。
- 取り返しの戦い（反撃）が起こりえます。

### この形にする理由

- **全部奪えると、強すぎる。** 一度の待ち伏せで戦争が決まってしまう。
- **少しも奪えないと、襲う意味がない。**
- 「運べる量まで」にすると、たくさん奪うには大きな軍が要り、大きな軍は目立ちます。
- 「焼く」があると、襲う側に「得をとるか、敵の足を止めるか」の判断が生まれます。

### 場面

1. 東の国が、砦攻めのための兵器200を、前線の倉へ送る。荷は誰にでも見える。
2. 西の国は、峠に兵300を出す（行き先は封じてある）。東の国から見ると、それが待ち伏せか、別の目的かは分からない。
3. 東の国は、護衛に兵400を付けた。ただし、それが護衛だとは西の国にも分からない。
4. 峠で戦いになる。
   - 護衛が勝てば、兵器は無事に届く。
   - 西が勝てば、西は選ぶ。
     - 兵300で運べる分（例：120）を奪う。
     - あるいは、200全部を焼いて、東の砦攻めを止める。

## 10. 依存の作り方：鉱石の偏り［決定 2026-10-23：この章の案を採用］

### 目的

- 誰かに頼らないと強い軍を作れない。だから物が動き、道が狙われる。
- かといって、鉱石のない村が何もできなくなるのは避ける（あなたの 10-19 の言葉「序盤の失敗で長時間何もできなくなる設計は避けたい」）。

### 案

| 決まり | 中身 |
|---|---|
| **鉱石は丘と山から** | 村の周りにある丘・山のマスが多いほど、鉱石が多く採れる。平地の村は少しだけ採れる（ゼロにはしない） |
| **国の中にも偏りを作る** | どの国の土地にも、丘の村の場所と平地の村の場所の両方がある。地図は6か国で同じ形なので、どの国も条件は同じ。**同じ国の中で、丘の村と平地の村が頼り合う** |
| **境の外に豊かな鉱脈** | 境の外に、丘の村よりずっと多く採れる鉱脈を置く。そこに倉を建てて掘るのは、得だが危ない。**国と国が争う理由** になる |
| **頼り合いは両方向** | 兵器には木材も要り、兵の訓練には食料が要る。平地の村は、食料と木材で丘の村に頼られる |
| **兵器なしでも戦える** | 普通の兵は、兵器なしで訓練できる。兵器が要るのは、強い兵と砦攻めだけ。鉱石がなくても、守ることはできる |

### 遊びとしてどうなるか

- **平地の村：** 序盤は普通の兵で守りながら、食料と木材を育てる。丘の村や工房の持ち主との関係が、強い軍を持てるかを決める。
- **丘の村：** 鉱石と兵器で頼られる。そのぶん、敵からも味方からも狙われ、交渉の材料も多い。
- **境の外の鉱脈：** 戦争の火種になる。持てば強いが、補給の道が長く、襲われやすい。

## 11. 同じ国の荷を襲えるか［決定 2026-10-23：この章の案を採用］

### 案：襲える。ただし、国が追い出せる

- **同じ国の荷車も襲える。** 規則で禁止はしない（運営は介入しない）。
- **国内の襲撃は、記録に「国内の襲撃」として残り、誰でも見られる。**
- **国の設定に「追放」を足す。** 国の仲間の投票で、ある村を追い出せる。追い出された村は、国を移るときと同じく、すぐに無防備になる（[14](14-land-and-nation.ja.md)）。

### 理由

- **禁止すると、国の中の対立が戦いにならない。** 国の中で利害が違う、というあなたの考えが、実際の行動につながりません。
- **何も対抗手段がないと、国の中で弱い者いじめになる。** 追放の投票があれば、国の仲間がそれを止められます。

### 危険

- 古参が新参を襲う、というのが一番心配な形です。
- 新しく来た村を一定期間守る仕組み（国内の襲撃を受けない期間など）が要るかもしれません。新規との公平さとまとめて考えます。
