# 続いていく世界と、区切り（戦期）（たたき台）

**状態：** C案（世界は続き、戦争だけを戦期で区切る）を採用（2026-10-23、あなたの判断）。2章の細部と数字は、引き続き提案です。

## なぜ今これを決めるか

これまでの言葉と決定が、3つの方向に分かれたままです（[17](17-summary-uniqueness-integration.ja.md) の1-2）。

| 出どころ | 中身 |
|---|---|
| 方針（[15](15-direction-2026-10-23.ja.md)） | 「一つの続いていく世界」「永続世界」 |
| 10-22 の検討 | 「シーズン制の廃止を検討している」「国に途中から加わる」 |
| 10-19 の大枠 | 「国・村・資源・軍事・砦・シーズン・賞金」 |

段階1〜4で決めた倉・札・仕組みは、**積み上がること自体が遊びの価値** です（方針「積み上がるのは『世界でできること』そのもの」）。シーズンごとに世界を消すと、それも消えてしまいます。

一方で、賞金と国の勝敗には、どこかで「区切り」が要ります。

## 1. 選択肢

| 案 | 中身 | 良い点 | 悪い点 |
|---|---|---|---|
| **A. シーズンで世界を消す** | 今の形。2週間ごとに、地図も村も仕組みもリセット | 毎回同じ条件から始まる。古参の有利が消える | 仕組みが積み上がらない。方針の核と正面から食い違う |
| **B. 区切りなし** | 世界も勝敗も、ずっと続く | 方針に一番近い | 賞金をいつ、何で配るかが決まらない。先に強くなった国が勝ち続ける |
| **C. 世界は続き、戦争だけを区切る（推奨）** | 村・建物・倉・札・仕組み・記録は続く。**「戦期」**（例：2週間）ごとに、国の勝敗を決めて賞金を配り、戦争の状態だけを元に戻す | 仕組みは積み上がる。賞金の区切りもある。途中から入っても、次の戦期からは対等に競える | 戦争の勝ち負けの差は、経済の差として残る。古参の有利をどう薄めるかが課題 |

先例は Foxhole です。戦争ごとに勝敗が決まって区切られますが、プレイヤーの歩みと連隊は続きます。ただし Foxhole は地図もリセットするので、C はそれより続く部分が多い形です。

## 2. 推奨：C「世界は続き、戦争だけを区切る」

### 戦期の終わりに、続くもの・戻るもの［提案］

| 続くもの | 戻るもの |
|---|---|
| 村・建物・施設 | **勝敗を決める砦**：どの国のものでもない状態に戻り、守備の兵は家に帰る |
| 倉・中身・札・決まり・公開された仕組み | **国どうしの戦争の状態**：いったん「戦争なし」に戻る（次の戦期で改めて決める） |
| 国の所属・国の設定 | **勝ち点**：0に戻る |
| 歴史・実績の記録 | |

### 賞金［提案、数字と方式はフェーズ6］

- **配る単位：** 賞金は戦期ごとに配る。
- **国の勝敗：** その戦期の中で、勝敗の砦をどれだけ長く持ったか。
- **国の中の取り分：**
  - その戦期の中の行いを、確かめられる結果で数える。
  - 自分の仕組みが、同じ国の他人に使われた量も数えるか、は未決。数えるなら、自分で自分の仕組みを使った分は除く。
- **元手：** 方向として、参加費・取引の手数料・AIのステーキング（10-22 のあなたの答え）。
  - 注（2026-10-23）：「AIのステーキング」は、[25](25-money-structure.ja.md) で「接続口の預け入れ（接続口を使う者が預ける）」に置き換わりました（決定）。

### 古参の有利を薄める［提案］

- **勝敗の砦が毎回中立に戻る：** 前の戦期の勝者も、砦の取り合いはゼロから。
- **大きいほど重い（決定済みの考え方）：** 維持費・燃料・長い補給の道。
- **新しく来た村の守り（決定済み）：** [19](19-newcomers.ja.md)
- **取り分は、その戦期の中の行いだけで数える：** 前の戦期までの稼ぎは、今の戦期の取り分に入らない。

## 3. 遊びとしてどうなるか

1. **戦期の初め：**
   - 勝敗の砦は全部中立。
   - どの国も、前の戦期で築いた補給の仕組みと倉を持っている。
   - だから、**砦の取り合いは「どの国の補給網が強いか」の勝負になる**。
2. **戦期の途中：**
   - 補給の道を断ち、仕組みを奪い、札を買い集める。
   - 途中から入った人も、次の砦攻めの補給に加われる。
3. **戦期の終わり：**
   - 賞金が配られ、砦と戦争の状態が戻る。
   - 経済と仕組みは残るので、**次の戦期の準備は、終わった瞬間から始まる**。
   - 負けた国は、仕組みを作り直したり、仲間を集めたり、別の国に移ったりする（国を移るのは決定済み）。

## 4. 今のゲームとの関係

- **今の形：** 14日のシーズンで、終わると精算して終わる（`frontier/season-complete`）。
- **C にするには、次が要る。**
  - 世界を次の戦期へ持ち越すこと。
  - 砦と戦争の状態だけを戻す処理。
  - 戦期ごとの賞金の精算。
- **［未確認］** 今のゲームの「シーズン」の作りのどこまでが使い回せるかは、実装の段階で確かめる。

## 5. まだ決めていないこと

1. 戦期の長さ（例：2週間）。
2. 国の中の取り分に「他人に使われた仕組み」を入れるか。
3. 戦期と戦期の間に、休みの期間を置くか。
4. 長く続くと、使われない古い仕組みや廃墟が地図にたまる。片付ける仕組みが要るか。
