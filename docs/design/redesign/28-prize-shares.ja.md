- 重みや割合は、フェーズ6で模擬実験をしてから決めます。

## 前提（あなたの言葉と決定）

- **配り方：** 賞金は事前に分かる規則と、確かめられる結果で配る。AIの主観で配らない（10-19）。
- **支援役：** 軍事以外の支援役にも意味を持たせたい。ただし、物資の受け渡しを単純に点数にすると、仲間内の往復取引や複数アカウントで水増しできる（10-19）。
- **お金の流れ（決定）：** 賞金は戦期ごとに国へ配り、国の中では、その戦期の中の確かめられる行いで分ける。運営のAIの取り分は提案中。

## 1. 考え方：「使われて、国の戦いで消費されたもの」だけを数える

**単純に数えると、水増しされます。**
- 「送った量」「売った量」「仕組みが使われた回数」をそのまま数えると、仲間内や自分の別の村との往復で、いくらでも増やせます。

**そこで、数えるのは「国の戦いの中で実際に消費されたもの」に限ります。**
- 兵器が、国の砦攻めや、勝敗の砦を守る兵の訓練で **使い切られた**。
- 食料が、国の砦の燃料として **燃やされた**。
- 兵が、勝敗の砦に **いた**。

水増しのために往復させた物は、消費されないので数えられません。数を増やすには、本当に国の戦いに物を使う必要があり、それは国の得になります。

**これで、未決だった「他人に使われた仕組み」の答えが出ます。** 数えるのは、仕組みが国の戦いでの消費につながったときだけです。「使われた回数」そのものは数えません。

## 2. 数える項目［提案］

| # | 項目 | 数え方 | 主に報われる人 |
|---|---|---|---|
| 1 | **砦にいた** | 勝敗の砦に、自分の兵がいたターン数×兵の規模 | 前線で戦う人 |
| 2 | **砦を取った・守った** | 国が勝敗の砦を取った、または守り切った戦いに、兵を出していた | 前線で戦う人 |
| 3 | **戦いで消費された補給** | 自分の倉（または自分が持ち分を持つ倉）から出た兵器・食料が、国の砦攻め、勝敗の砦の兵の訓練、国の砦の燃料として消費された量 | 補給・生産・組合を作った人 |
| 4 | **国の倉への納め** | 国の取り分として国の倉に納め、その中身が 3 と同じ使われ方をした量 | 国を支える一般の村 |
| 5 | **参加の基本分** | その戦期に、一定日数以上動いていた村に、同じ額を少しずつ | 新しく来た村、小さな村 |

**3 の「誰に数えるか」：**
- 物が倉を出た時点の、その倉の持ち主に数えます。
- 倉が組合（持ち分の札）なら、札の割合で分けます。
- 仕組みを何段もつないでいても、最後に戦いへ物を出した倉で数えます。つなぎの途中の人は、その倉の持ち分の札を持っていれば、割合で報われます。

**5 の理由：**
- 新しく来た人や小さな村にも、確実な最低限があるようにします（[19](19-newcomers.ja.md) の「追いつく道」）。
- 以前の版でも、貢献とは別に、動いていた人へ同じ額を配る部分がありました。
- 偽の村で稼げないように、少額にし、村ごとの参加費より明らかに小さくします（フェーズ6）。

## 3. 数えないもの［提案］

| 数えないもの | 理由 |
|---|---|
| 売った量・送った量・仕組みが使われた回数 | 往復取引で水増しできる |
| 自分で自分の仕組みを使った分 | 同上 |
| 国内の襲撃で奪った物 | 国の中で奪い合っても、国の得にはならない |
| 国の外への武器商売 | ゲームの中の稼ぎにはなるが、国の勝利への貢献ではない。国に属さない村は、もともと取り分を持たない |
| AIの判断や評価 | 主観で配らない（あなたの原則） |

## 4. 遊びとしてどうなるか

- **補給役が報われる：** 前線に出なくても、組合や工房、定期配送を作った人は、その兵器が砦攻めで使われた分だけ取り分を得る。
- **「国の戦いに役立つ仕組み」を作る理由になる：** 国の中の仕組みは、国の勝利につながるほど作り手の取り分が増える。
- **国の外への商売は別の得になる：** 敵国にも兵器を売る商人は、ゲームの中では稼げるが、国の賞金の取り分は増えない。国に忠実でいるか、商売を取るかという判断が生まれる。
- **新しく来た村にも最低限がある：** 参加の基本分で、何もできずに終わることがない。

## 5. 危険と、まだ分からないこと

1. **消費の記録を追う手間：** 物がどの倉から出たかを、消費されるまで追う必要があります。今のゲームの遅延計算と、検証ツールの再計算に、追う仕組みを足すことになります（組み込みのときに確かめる）。
2. **わざと消費する水増し：** 自分の兵器を、意味のない砦攻めで使い切る手が考えられます。ただし、砦攻めは実際の兵と時間を使い、勝敗の砦に限れば、国の得にもなります。数えるのを勝敗の砦に関わる消費に限ることで、狭めます。
3. **重みの釣り合い：** 1〜5の重みしだいで、前線と補給のどちらが得かが変わります。フェーズ6の模擬実験で決めます。
4. **国の外への商売の扱い：** 数えないことで、商人が国から離れやすくなります。それ自体が、国の中の政治と移籍の理由になります。
