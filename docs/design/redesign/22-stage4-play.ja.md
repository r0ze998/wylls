## 1. 段階4で何が変わるか（一言で）

**段階3：**
- 倉・札・決まりを組めば仕組みは動くが、それは作った本人の手元にあるだけ。
- 他人からは、どこにどんな仕組みがあるか分かりにくい。

**段階4の後：**
- 仕組みに名前を付けて **地図に公開** できる。
- 誰でも「欲しいもの」から仕組みを **探し**、ひと手間で **つなげる**。
- 作るときは、**テンプレート** か **AIの手伝い** を使い、コードは書かない。
- 公開された仕組みは、**写して作り変えられる**。
- 仕組みの持ち主の権利も **札** になり、売り買いできる。

## 2. 足すもの

| 足すもの | 中身 |
|---|---|
| **まとめる** | 倉・札・決まりの組み合わせに名前を付けて、一つの「仕組み」にする |
| **仕組みの紙** | 仕組みごとに、次のことが **普通の言葉で自動で書かれる**。作者が自分で書く説明とは分けて表示する<br>・何を受け取り、何をし、誰に渡すか<br>・出している札とその条件<br>・これまでの実績（送った回数・失敗した回数・襲われた回数） |
| **地図と検索** | 地図の上に、仕組みが倉と倉を結ぶ線として見える。「兵器が欲しい」「鉄を売りたい」から、条件に合う仕組みの一覧が出る（値段・距離・実績つき） |
| **つなぐ** | 一つの操作で済む。札を買う（引き換えの預かり）、または自分の倉を送り先・合図の元に指定する |
| **テンプレート** | 運営が、同じ部品で作った見本を用意する。数字を入れれば使える。プレイヤーも、自分の仕組みをテンプレートとして公開できる<br>・組合<br>・定期配送<br>・補充<br>・先渡し<br>・工房の貸し出し<br>・新参への投資 |
| **写して作り変える** | 公開された仕組みを写し、道や倉の場所、条件を変えて、自分の仕組みとして出せる。写すにも費用がかかる |
| **AIの手伝い** | 「鉄を毎日砦に届けたい」と伝えると、AIが部品で組み立て案を作る。仕組みの紙と、今の状況での動きの予想を見せる。本人が確認してから建てる |
| **持ち主の札** | 仕組みの持ち主の権利（決まりを変える、札を出す、手数料を受け取る）も札になる。売れるし、倉に預けて共同で持てる |

**AIエージェントも、人間と同じ道具・同じ費用で仕組みを作り、公開し、使います。**

## 3. 場面

### 場面A：コードを書かない新参が兵器を手に入れる

1. 新参のあなたは、地図で「兵器が欲しい」と検索する。
2. 3つの仕組みが出る。

   | 仕組み | 安さ | 実績 | 道 |
   |---|---|---|---|
   | 北の軍需組合 | 安い | 先週2回襲われた | 峠を通る |
   | 南の工房の貸し出し | 材料は自分で出す | 失敗なし | 川沿い |
   | 兵器の先渡し | 高い | 来週から届く | — |

3. あなたは北の軍需組合の持ち分の札を、少しだけ買う。2回の操作で、自分の村が流れの先に加わる。

### 場面B：写して競う

1. 南の村の G は、北の軍需組合の仕組みの紙を見て、こう考える。「峠を通るから襲われる。川沿いの倉を使えば安全だ」
2. G は仕組みを写し、道と倉の場所だけ変えて「南の軍需組合」として公開する。
3. 北の組合の札を持っていた人の一部が、南へ移る。
4. 北の組合は、護衛を付けるか、値を下げるかを迫られる。

### 場面C：AIが仕組みを作る

1. AIエージェントの Rook は、前線の砦で兵器が足りないことと、B の工房が夜に空いていることに気づく。
2. Rook は、鉱山の受け取りの札と、B の工房の使用権の札（夜の分）を買う。それをまとめて「夜間の前線補給」として公開する。
3. 砦の持ち主たち（人間もAIも）がつながり、Rook は手数料を得る。
4. その仕組みの持ち主の札を、ある国が国の倉で買い取り、国営の補給にする。

### 場面D：誰も想定していない組み合わせ

1. ある人が「北の組合の持ち分の札」と「南の組合の持ち分の札」を自分の倉に集める。
2. 「どちらかが襲われても兵器が届く」保険のような仕組みとして公開する。
3. それを別の人がさらに部品にして、「前線の三つの砦に均等に配る」仕組みを作る。

方針の「確かめるべきこと」の3つ（指定しなかった使い方、他人が使いたくなる、さらに組み合わさる）が、この段階で一番はっきり見えます。

## 4. 決める必要のある規則［決定 2026-10-23：この章の案を採用］

| 問題 | 案 | 理由 |
|---|---|---|
| **仕組みの説明でだます** | 仕組みの紙は、決まりと札から **自動で** 書く。作者の説明は「作者の説明」として別に表示する | 中身と違う説明で人を集める手を防ぐ |
| **持ち主が条件を変える** | 変えた条件は、**新しく出す札にだけ** 効く。すでに出した札は、期限まで元の条件のまま | 札を買った人が、後から不利な条件を押し付けられないように |
| **放置された仕組み** | 手数料の前払いがなくなった仕組みは止まり、地図の一覧から自動で外れる（記録は残る） | 地図と検索が、使われない仕組みで埋まらないように |
| **AIの組み立て間違い** | AIが作った案は、必ず仕組みの紙と動きの予想を本人が確認してから建てる。AIが自分のために作るときも、同じ費用と規則 | 言葉と中身のずれを、建てる前に見つけるため |
| **写すことの扱い** | 写すのは自由。ただし費用がかかる。元の作者には何も払わない | フォークしやすさを優先する。元の作者を守りたい場合は、持ち主の札や実績で差をつける |

## 5. まだ決めていないこと

1. **地図の見せ方。** 仕組みの線が増えすぎたとき、どう整理して見せるか。画面の設計で決める。
2. **元の作者への見返り。** 写された元の作者に、何か見返りを与えるか（今の案では与えない）。
3. **AIの手伝いの費用。** 誰が払うか（言語モデルの費用）。
4. **国が持つ仕組み。** 持ち主の札を国の倉で持つとき、国の投票で決まりを変えるのか。
