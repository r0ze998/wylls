# アイデア：Loot 型の自律世界を Wylls にどう応用するか

**状態：** アイデアのたたき台（2026-10-22）。まだ決定ではありません。

**前提（あなたの決定）：**
- 中心の部品は「行いと約束の記録」
- 公式ゲームは作らず、使い方の見本として小さな遊びを一つ置く
- 外部の画面には手数料を分ける

---

## 1. 一言でいうと

> **Wylls は「誰が、誰に、何を約束し、実際に何をしたか」が消えずに残る世界。**
> 私たちはその記録の部品と、小さな見本の遊びだけを作る。記録をどう使うかは、ゲームを作る人、AIを作る人、ゲーム以外のサービスを作る人に任せる。

Loot と比べるとこうなります。
- Loot は「アイテムの一覧」だけを置き、意味づけを他人に任せました。
- Wylls は「約束と行いの記録」だけを置き、意味づけを他人に任せます。

---

## 2. 置く部品（できるだけ少なく）

| 部品 | 中身 | 今の Wylls にある素材 |
|---|---|---|
| **名前** | 人もAIも同じ形で持つID。AIかどうかの表示は本人が選ぶ | 村・プレイヤーのアカウント |
| **誓い** | 「誰に、何を、いつまでに」を記録する。<br>・中身は自由な文章。<br>・機械で確かめられる条件（「ターン300までに木材100を渡す」など）を付けてもよい | AI市民の評議会の動議 |
| **封をした誓い** | 中身を決まった時刻まで誰にも読めなくする。<br>・密約を後で公開する。<br>・同盟の中身を戦いの後まで隠す。 | **時間ロックの封をした進軍（drand）をそのまま流用** |
| **行い** | 世界で実際に起きた行動（資源を渡した、兵を送った、着いた、攻めた）を自動で記録する | チェーン上のすべての行動 |
| **照合** | 期限が来たら、誓いと行いを機械で突き合わせ、「守った／破った／確かめられない」を記録する。人の口コミは使わない | 外部の検証ツール |

**作らないもの：** 評判の点数。点数の付け方は、読む側（アプリやAI）がそれぞれ決めます。Loot が数値の能力値を付けなかったのと同じ考え方です。

## 3. 見本の遊び（小さく一つだけ）

**目的：** 記録が貯まる場所を作ることと、部品の使い方を見せること。公式の大作ゲームにはしません。

**形の案：**
- 小さな地図で、世界の時計が常に動く局地戦。
- 村は資源を作り、渡し、兵を送る。
- 今の Wylls から、核だけを抜き出して小さくします。8種類の資源や段階の多い建物は削ります。
- 勝つには他人の助けが要ります。だから約束が生まれ、守られたり破られたりします。

**場面の例：**
> 夜、AIの「Mira」から北の砦を一緒に攻めようと誘われる。Mira の記録は「誓い40、守った37、破った3」。破った3回は、どれも大国が相手のときだった。
> あなたは信じて、封をした進軍で兵を送る。Mira も「ターン420に到着する」と封をした誓いを立てる。
> ターン420、Mira の兵は来なかった。照合が「破った」と記録する。
> 翌日、ゲーム外の取引所で、Mira に貸すときの担保の条件が上がっている。あなたの国の年代記には「北の砦の裏切り」と一行が増える。

**あなたの思想との対応：**
- 誰を信じるか（最優先）
- 行動で物語が変わる
- 理由は読めるが、結果は読めない（Mira にも事情がある）

## 4. 外部の人が作れるもの（例）

| 作る人 | 作るもの | 記録の使い方 |
|---|---|---|
| DEXを作れる人 | **村の作物の取引所・先渡し市場** | 約束を破ったことのある相手には、担保を多く求める |
| AIエージェントを作る人 | **傭兵・交渉代理のAI** | 自分の約束の履行率を売りにして、依頼を受ける |
| 保険を作る人 | **裏切り保険** | 「同盟相手が破ったら払う」。相手の記録で保険料が決まる（※規制の確認が必要） |
| 物語好き・AIの作り手 | **年代記・新聞** | AIが記録から歴史を書く（Dwarf Fortress 型の物語） |
| 別のゲームを作る人 | **酒場・闘技場・別の地方** | Wylls で裏切った者は、別のゲームの酒場で歓迎されない |
| 道具を作る人 | **評判の検索・警報** | 「この人と組む前に」の調べ物、約束の期限の通知 |
| 遊ぶ人どうし | **懸賞金・復讐の依頼** | 破った相手に懸賞を掛ける |

**手数料の分け方（案）：**
- 見本の遊びの参加費や取引手数料の一部を、そのプレイヤーが使った画面（クライアント）を作った人に分ける（Loot Survivor 型）。
- 誓いの登録手数料の一部を、その誓いを仲介したアプリに分ける。

## 5. 「口コミの評判」の失敗を避ける理由

調査では、タダで書ける評判（ERC-8004 など）は偽アカウントに汚されていました（[02b-primitives.ja.md](02b-primitives.ja.md)）。Wylls の記録は、次の点で違います。

- **書かれるのは行いだけ。** 「この人は良い人」という評価は書けません。
- **行いには世界の中のコストがかかる。** 兵、資源、時間を使います。偽アカウントで記録を作るには、実際に資源を動かす必要があります。
- **新しいIDは記録が空。** 信頼は最初からはなく、積み上げるしかありません。
- **照合は機械が行う。** 誰かの主観ではありません。

［未確認］偽アカウントどうしで約束と履行を繰り返し、「守った」記録を水増しする手は残ります。そのため、読む側が「相手が誰か」「どれだけの量を賭けたか」で重みを付けられるよう、記録にその情報を残します。

## 7. まだ分からないこと・危険

- **約束を破る自由を残すか。** 記録は残すが罰しない、が基本です。罰が重いと、駆け引きが詰まらなくなります（Diplomacy の学び）。
- **自由な文章の約束は機械で照合できない。** 「確かめられない」がどれだけ増えるかは、試して確かめる必要があります。
- **記録が消えないことと、プライバシー。** 一度の裏切りが永遠に残るのは重すぎないか。見本の遊びで、古い記録をどう扱うか（薄れる、本人が説明を書き足せる、など）を試す必要があります。
- **外部の作り手が本当に来るか。** 最初は私たち自身が、見本の外部アプリ（年代記AI、取引所の簡易版）を一つ作る必要があるかもしれません。
- **保険・担保・先渡しは金融に近い。** 規制の確認が必要です（法的助言ではありません）。
- **運営費。** Pirate Nation は月15万ドルで倒れました。部品は「運営なしで続く」形にします。
