# 新しく来た村を守る仕組み（たたき台）

**状態：** 2章の4つの守りを採用（2026-10-23、あなたの判断）。数字はすべて例で、本当の値はフェーズ6で決めます。

## 前提

- **世界の形：** 一つの続いていく世界で、いつでも途中から入れる（[15](15-direction-2026-10-23.ja.md)、10-22 の検討）。
- **国内の襲撃：** 認める。ただし記録に残り、国は投票で追放できる（[18](18-stage1-play.ja.md) の11章、決定）。
- **あなたの言葉（10-19）：** 「序盤の失敗で長時間何もできなくなったり、交易相手がいないと立て直せなくなったりする設計は避けたい」。

---

## 1. 何から守るか

| 危険 | 中身 |
|---|---|
| **潰される** | 育つ前に、古参（他国や同じ国）に村を襲われて終わる |
| **詰む** | 鉱石もなく、交易相手もなく、何もできない |
| **追いつけない** | 古参との差が大きすぎて、何をしても意味がないと感じる |

## 2. 案：4つの守り

### ① 新参の守り（期間つき）

- 新しい村は、**最初の一定期間（例：3日）**、自分の村と村の土地を攻められない。
  - 国内の襲撃も含みます。
  - 先例は Travian の初心者保護。
- **守りが早く終わる条件**（守りを悪用させないため）：
  - 自分から他人の村・倉・荷車を攻めたり襲ったりしたとき。
  - 村が一定の段階（例：町）まで育ったとき。
- **守られないもの：** 自分の村の土地の外に出た荷車と倉。
  - 古参が新参の村を「襲われない運び屋」として使う手を防ぐためです。
  - 新参の荷車も、外に出れば普通に襲われます。

### ② 最初の場所は国の内側

- 新しい村は、国の土地の **内側**（国境や境の外から遠い所）に置かれる。
- 国の仲間の村や砦に囲まれているので、期間が終わった後も、いきなり最前線には立たされない。
- 先例は EVE の安全な宙域。

### ③ 詰まない

- **普通の兵は、兵器なしで訓練できる**（決定済み）。鉱石がなくても守れる。
- **平地の村でも鉱石は少し採れる**（決定済み）。ゆっくりでも、自分だけで兵器に届く。
- **新参の売り物には、必ず買い手がいる。**
  - 古参の工房や軍は、食料と木材を大量に使います。新参が作る物には、最初から需要があります。
  - これは依存の設計（[18](18-stage1-play.ja.md) の10章）から自然に生まれる形で、特別な仕組みは足しません。

### ④ 追いつく道

- **最初の建物は早く建つ。** 建物の費用と時間は、同じ建物を増やすほど重くなる（今のゲームにもある規則）。だから、序盤の数手は速く進む。
- **大きいほど重い。**
  - 古参ほど、維持費・燃料・長い補給の道を抱える（勝ち逃げさせない）。
  - 新参は身軽な分、小回りが利く。
- **取り分は、いた間の行いで数える**（国を移るときの提案と同じ考え方）。
  - 途中から入っても、入った後の行いがそのまま数えられる。
  - 古参との差は、取り分の計算では引きずらない。

## 3. 古参が新参を育てる理由（段階2以降）

あなたが以前出した案「古参に育ててもらう」は、段階2の **札** で自然に作れます。
- 古参が新参の村に資源を送り、見返りに「その村の木材の一部を受け取る札」をもらう。
- 新参は早く育ち、古参は将来の取り分を得る。

段階1では、新参への送りは、ただの贈り物か口約束になります。

## 4. 悪用への備え

| 悪用 | 備え |
|---|---|
| 新しい村を次々に作って、守りの期間を使い回す | 村を持つには、村ごとに参加費（預け入れ）が要る（[14](14-land-and-nation.ja.md) の提案）。守りは村ごとに1回だけ |
| 守られた新参の村を、古参の倉代わりにする | 新参の村に送られた物は、新参の物になる。古参は取り出せない |
| 守りの期間中に力をためて、期間の終わりに奇襲する | 自分から攻めた時点で守りが切れる |
| AIの村を大量に作って守りを使う | 人間もAIも同じ。村ごとの参加費と、1回だけの守り |

## 5. 遊びとしてどうなるか（新参の最初の3日）

1. **1日目：** 国の内側に村ができる。誰にも攻められない。
   - 畑と伐採場を建てる。
   - 地図を見ると、丘の村と工房の持ち主が、食料と木材を欲しがっている。
2. **2日目：** 国の掲示や会話で、工房の持ち主に「木材を売るから、兵器を少し分けてほしい」と持ちかける。
   - 引き換えを守らせる仕組みがない（段階1）ので、少量から試す。
3. **3日目：** 村が町に上がり、守りが切れる。
   - その頃には、普通の兵と少しの兵器がある。
   - 誰に頼り、誰に頼られているかも分かっている。
   - 自分の荷車を外に出すかどうか、初めて「襲われる危険」と向き合う。

## 6. まだ決めていないこと

1. 守りの期間と、守りが切れる段階（フェーズ6）。
2. 国の内側に空きがなくなったときの置き場所。今のゲームには、混んできたら地図の外側の輪が開く仕組みがある。ただし、外側は境の外に近い。
3. 国を移った村にも、守りを与えるか。
   - 移った村は、移行の期間はすでに無防備になる提案。
   - 与えると、移籍が安全になりすぎる。
