# フェーズ3用の付録：フェーズ1から取り分けた仮説

**状態：** 保管用（2026-10-22）。

**なぜ分けたか：** フェーズ1は、中立な素材にとどめるべきです。ところが最初の下書きでは、学びを「今の Wylls の資産」（封をした進軍、AI市民、信頼）に結びつける書き方をしていて、後の発想を前の核へ引き戻していました（反対の立場からの見直しで指摘）。

そこで、Wylls に結びついた部分をここに移しました。**フェーズ3（統合の発想）で、他の素材と同じ重さの一候補として使います。** 特別扱いはしません。

## 1. 参考作品の学びと、Wylls への含意（仮説）

| # | Wylls への含意（仮説） |
|---|---|
| L1 | 「誰を信じるか」を核にするなら、言葉と行動の照合は要る。罰（担保の没収）が要るかは別に検討する |
| L2 | 人間どうし・人間とAIの委任は、同じ「権限」の形で扱える |
| L3 | 隠す仕組み（Wylls の封をした進軍）は、情報の売り買いと組んで初めて生きる |
| L4 | 暗号で隠せば、明かす行為が交渉の通貨になる |
| L5 | 出発してから届くまでの時間は、もう Wylls にある |
| L6 | AIがプレイヤーとして眠らずに動くなら、時間の床などで抑えないと「人間とAIが同じ世界」が成り立たない（AIを審判や語り手にするなら、この問題は形が変わる） |
| L7 | 以前の「国内の負担の押し付け合い」と一致する |

## 2. 三つの素材の緊張関係（見取り図）

| 緊張 | 中身 | 関係する学び |
|---|---|---|
| **隠す ⇔ 公開が基本** | チェーンは全部見える。だからこそ隠す仕組みを持つと、「明かす」ことが戦略の通貨になる | L3・L4（Dark Forest、Subterfuge） |
| **言葉 ⇔ 拘束** | AIの言葉は軽く（Civ の失敗）、チェーンの記録は重い。言葉を記録と結べば、言葉に重みが出る。ただし、守らせるとせっつき合いになる（Diplomacy） | L1・L9、F5 |
| **眠らないAI ⇔ 人間の生活** | AIがプレイヤーなら24時間動ける。時間の床・予約命令・守る側が選ぶ時間帯がないと、人間は負ける | L6 |
| **無料の身元 ⇔ 信頼** | 別アカウントは無料で、AIでさらに増える。担保と評判が、信頼のコストを作る | L2・L8、トークン入門の8 |
| **共有の資産 ⇔ ただ乗り** | 共同所有（Eternum）とチーム報酬（Foxhole）。見えない貢献を見えるようにするのは、チェーンの記録が得意なところ | L7 |
| **世界が残る ⇔ 一度リセットする快感** | 運営なしで続く世界と、ラウンドの区切り。永続には、追い上げと薄れる有利が要る（SeaFall） | L10、F2 |
| **価値を配り直す ⇔ 発行して配る** | 発行で報酬を払う形は、死の連鎖の前例が多い（Axie、StepN） | トークン入門の1〜5 |
| **見える理由 ⇔ 予測できない結果** | 理由が全部見えると解けてしまう（CK3）。理由が見えないと不公平に感じる（Civ） | F1、Civ の批判 |
| **再計算できる検証 ⇔ AIの判断** | 言語モデルの出力は再計算できない。全行動の検証という資産と衝突する | AIの役割の1章 |

- 外部ツールによる、全行動の後からの検証。
