**状態：** 下書き（2026-10-22）。あなたの確認待ち。

**このフェーズの目的：** 設計し直しの出発点として、今の Wylls が「何を持ち、何を借り、どこで失敗し、何を学んだか」を正直に書き出します。ここで合意してから、フェーズ1（素材の理解）に進みます。

## 1. 今の Wylls は何か（一段落で）

［事実］六つの国がくさび形の地図を分け合います。プレイヤーは村を持ち、資源を生産し、段階を上げ、兵を訓練します。行き先を隠した進軍で、環4の砦を奪い合います。シーズンは14日で、終了時に砦を最も多く持つ国が勝ちます。参加費が賞金になり、勝った国の中で占領などの点に応じて分けます。

AI市民（運営が動かすローカルのモデル）が各国に1人いて、評議会で発言・投票します。チェーンは Solana（ローカルのテスト用チェーン）で、すべての行動がチェーンに記録され、外部のツールで再計算して検証できます。

（出典：`frontier/season-complete` @ `adb4ac98`。これまでの調査とリハーサル）

## 2. 四つの分類

### A. 独自の資産（Wylls にしかない、または珍しいもの）

| 資産 | 中身 | 確度 |
|---|---|---|
| **時間ロックで封をした進軍** | 行き先を公開のビーコン（drand）の未来のラウンドに向けて暗号化し、チェーン上で検証する。到着するまで誰にも読めない。出発地・規模・到着時刻は公開 | ［事実］実装済み。［未確認］今回の検索の範囲（ウェブ検索数回。GitHub やハッカソンの作品一覧は未調査）では、同じ方式の稼働中のゲームは見つからなかった |
| **すべての行動を後から検証できる** | 外部の検証ツールが、チェーンの全取引を再計算して照合する | ［事実］実装済み。ただし前哨の状態に関して、検証ツール側の不具合が見つかっている |
| **AI市民の社会の層** | 記憶、信頼値、遺恨、評議会の動議・投票、封をした攻撃命令。人間が1人でも投票しないと攻撃命令は決まらない規則 | ［事実］実装済み（試験段階、長い走行の完走はまだない） |
| **持ち主が任せるAIの財布** | 権限と予算を持ち主が決め、任せられない命令の一覧がある | ［事実］未統合のブランチ（`feature/agent-wallet`） |
| **六か国の対称な地図** | どの国も同じ環に同じ土地を持つ | ［事実］ |
| **砦の保持時間の計数** | 国ごとに、砦を持っていた時間をターン単位で数える | ［事実］今は同点の決着にだけ使用 |

### C. 失敗とその理由

| # | 失敗 | 理由 | 確度 |
|---|---|---|---|
| C1 | **経済が浅い** | どの村も同じ基本生産で、土地の差は生産に効かない。資源の受け渡しもない。足りなくなるもの（木材・石材・金）と余るもの（食料）が全員同じで、交換する理由が生まれない | ［事実］コードと計算で確認 |
| C2 | **ブロックチェーンが「置き場」にとどまっている** | 封をした進軍以外は、チェーンでなくても同じ遊びになる（3章の荷重テスト） | ［判断］ |
| C3 | **AIが飾りにとどまっている** | AI市民は運営が動かすNPCで、賞金の対象外。戦略への影響は小さい。約束の仕組みを外したので（決定X2）、記憶が駆け引きに効く場面がない | ［事実］X2・賞金対象外は事実。［判断］影響の小ささ |
| C4 | **トークン・賞金が価値を生まない** | 参加費を集めて配り直すだけで、ゲームの中に価値を生む仕組みがない。勝った国の総取りで、国の中の配分はチェーン外の暫定の点 | ［事実］ |
| C5 | **核の思想と実装がつながっていない** | あなたの思想は「関係・記憶・選択で文明が変わる」。実装は「砦の数を競う戦争」。思想を運ぶ仕組みがない | ［判断］ |
| C6 | **重要な部分が実際には遊ばれていない** | 14日走行では、ボットは昇格も包囲もせず、前哨も0。作戦の出兵も0だった（検証用ブランチで修正済み）。人間のプレイテストは一度も行っていない | ［事実］ |
| C7 | **決定が積み上がらず、核が揺れた** | 多くの論点（取り分、賞金、交易、前哨、シーズン、トークン）を並行して扱い、上位の問い（何を遊ぶゲームか）が固まる前に下位を詰めた | ［判断］今回の設計し直しのプロセスで正す |

### D. 学んだこと

| 学び | 根拠 |
|---|---|
| **分業は、交換の仕組みだけでは生まれない。** 交換を前提に双方が育て方を選び直したときに初めて生まれる | 2村の交換の計算（`design-sims/two-village-trade`） |
| **今のルールでは、前哨はほぼ常に建てたほうが得。** 早く建てると本拠が市に上がるのが10〜45ゲーム時間遅れる。奪われる危険はまだ測れていない | ボットの7日走行（`sim/outpost-bots`）と、包囲の修正（`sim/outpost-horn-resident`） |
| **（仮説）記憶が戦略上の価値を持つ場面の一つは、確かめられない情報と、守らせる仕組みのない約束があるとき。** ほかに、関係・愛着・弱みとしての記憶（Crusader Kings）や、世界の歴史としての記憶（Dwarf Fortress）もある（フェーズ1の批評を受けて修正） | 壁打ちの議論。Diplomacy・Neptune's Pride・Subterfuge・Crusader Kings・Dwarf Fortress の前例 |
| **チームのゲームでは、ただ乗り、単独勝利をねらう裏切り、裏方が報われない問題が必ず起きる** | Foxhole（補給担当のストライキ）、Call of War（単独勝利の条件が楽）、Rise of Kingdoms（個人の貢献が報酬の条件）の調査 |
| **人間とAIは、チェーンからは確実に見分けられない。** AIだけに課すルールは強制できない | 壁打ちの議論（ステーキングの検討） |
| **参加者の支払いを成績で配り直す形は、規制上の確認が必要。** 後から入る人の支払いで回す形は避けるべき | 壁打ちの議論（専門家への確認が必要） |
| **Realms/Eternum が持っていないもの** | 国単位で常に続く集団戦、行き先を隠した進軍、国の中の政治（競合調査） |

## 3. 荷重テスト

「この要素を外したら、ゲームは同じか？」に答えます。**「同じ」なら、その要素は飾りで、まだ統合（ジンテーゼ）になっていません。**

| 要素 | 外した場合 | 判定 |
|---|---|---|
| チェーン上の状態 | 中央のサーバーでも、同じ遊びになる | **飾り** ［判断］ |
| 封をした進軍（時間ロック） | サーバーが行き先を隠せば遊びは同じ。ただし「運営も行き先を知らない」という信頼の性質は失われる | **半分は荷重** ［判断］ |
| すべての行動を検証できること | プレイヤーの体験はほとんど変わらない | **飾り寄り** ［判断］ |
| 参加費と賞金のチェーン上の預かり | 中央のサーバーでも可能。運営を信頼する必要が生まれる | **弱い荷重** ［判断］ |
| AI市民（6人） | 戦略の判断はほとんど変わらない | **飾り** ［判断］ |
| AIの記憶と信頼値 | それが判断に効く場面がない | **飾り** ［判断］ |
| トークン | 今は存在しない（テスト用USDCの参加費のみ） | **なし** ［事実］ |

**結論［判断］：** 今の Wylls は「普通の戦略ゲーム＋チェーンに置いた状態＋AIのNPC」です。ブロックチェーン・AI・トークンのどれも、まだ遊びの面白さを支える柱になっていません。設計し直しの目標は、**外すと遊びが成り立たなくなる形で、これらが面白さを生む構造**を見つけることです。

## 4. 守るべき思想（これまでのあなたの言葉から）

フェーズ2（ビジョン）の素材です。ここではまとめるだけで、まだ磨きません。

- **AIが駆動する世界。** キャラクターには記憶があり、会話が意味を持ち、自分の行動によって物語が実際に変わる。
- **AIが物語を文章で説明するだけでは足りない。** 記憶や会話が、提案・取引条件・協力・行動・戦況に効く。
- **「記憶しているから必ず恩返しする」ではない。** 相手には相手の目的と事情がある。判断の理由は理解できるが、結果は完全には予測できない。
- **自分の人生や選択を感じられることと、人間やAIと文明を作っていくことの両方。**
- **自分や他者の選択が積み重なって、資源の流れ・関係・役割・社会が変わり、その変化によって次の選択肢や戦略も変わる。**
- **シンプルな駆け引きによる戦略性。**
- **（2026-10-22）一番楽しんでほしいもの：** 読み合い、国の一員としての役目、誰を信じるか。そのうち最優先は「誰を信じるか」。

**疑ってよいもの［あなたの指示］：** 国・村・砦・シーズン・Solana・人間とAIの共存を含め、すべて。今のコードは素材として扱います。
