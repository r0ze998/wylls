# 段階3（条件と繰り返しの送り）：遊びとしてどうなるか

**状態：** 2章（合図4種・すること2つ・動かし方の決まり）を採用（2026-10-23、あなたの判断）。数字はすべて例。

**前提（決定済み）：**
- **段階1（[18](18-stage1-play.ja.md)）：** 倉、送り、工房。荷は見え、護衛は隠せる。奪うか焼くか。
- **段階2（[20](20-stage2-play.ja.md)）：** 持ち分・受け取り・使用権の札と、引き換えの預かり。奪われた倉の札は無効。足りなければ割合で減らす。

---

## 1. 段階3で何が変わるか（一言で）

**段階2：** 組合も配送も、毎回だれかが手で送りを出す。眠っている間は止まる。

**段階3の後：**
- 「いつ・どうなったら・何を送る／動かす」を決めておけば、仕組みが自分で動く。
- 一つの仕組みの結果が、次の仕組みの合図になる。仕組みどうしが、つながったまま動く。

**ただし：** 自動の流れは決まった時刻・決まった道を通るので、**敵にとって読みやすい**。便利さと、読まれる危うさの取り引きになる。

## 2. 足すもの：決まり（ルール）

一つの決まりは「**合図** → **すること**」の形です。

### 合図（少数に絞る）［決定］

| 合図 | 例 |
|---|---|
| **時刻** | 毎日6時、6時間ごと |
| **量** | 送り元に100以上たまったら、送り先が20を下回ったら |
| **到着** | この倉に鉄が届いたら、代金が届いたら |
| **公開の事実** | 自分の国が東の砦を持っている間、○○国と戦争中なら |

- **使えない合図：** 隠れた情報（移動中の軍の位置）。
- **例外：** 見張り塔の持ち主は、自分の塔が見たことを、自分の決まりの合図に使える。「塔が敵を見たら、倉の兵器を砦へ送る」のように。

### すること（2つだけ）

| すること | 中身 |
|---|---|
| **送る** | 倉から倉へ、物か札を送る（荷車は地図の上を運ばれ、襲われうる） |
| **動かす** | 工房などの施設を動かす（使用権の札の範囲で） |

### 動かし方の決まり［決定］

- **実行の順番：**
  - 決まりは、ターンの始まりにまとめて判定する。
  - 同じ物を取り合う決まりは、段階2の規則どおり割合で分ける。
  - 実行役（キーパー）が順番を選べないようにする。
- **手数料：** 決まりを作る人が、実行の手数料を前払いする。払い分がなくなると止まる。
- **最小量：** 送りには最小量がある。ごく小さな送りを大量に出す嫌がらせを防ぐため。
- **上限：** 一つの倉に付けられる決まりの数に上限がある（乱立と連鎖の暴走を防ぐ）。
- **失敗：** 物が足りないなどで実行できなかった決まりは、止まるだけで、記録に残る。

## 3. 場面

### 場面A：眠っている間に動く軍需組合

1. 組合は、決まりを3つ置く。
   - 「毎日6時、組合の倉から鉄9を B の工房へ送る」
   - 「工房に鉄が届いたら、使用権の札で3回動かす」
   - 「組合の倉に兵器が届いたら、持ち分の札の割合で配る」
2. 誰も起きていなくても、毎朝、兵器が作られて配られる。
3. D の砦には、毎日兵器が届く。

### 場面B：読まれる自動の流れ

1. 敵の国は、組合の荷車が **毎日6時に** 峠を通ることに気づく。自動の流れは、規則正しいので読みやすい。
2. 6時半、峠で待ち伏せ。荷を焼かれる。
3. D の砦には決まりがある。「兵器が20を下回ったら、南の倉から補充する」。それが動き、別の荷車が川沿いの道を出る。
4. 敵がそれも読んでいれば、二度目の待ち伏せになる。
5. 組合は、次のどれかを選ぶ。
   - 時刻を毎日変える（手間）。
   - 護衛を付ける（兵が要る）。
   - 自動をやめて手で送る（眠れない）。

### 場面C：燃料を断つ

1. 前線の砦は、「毎日、国の倉から食料を燃料として送る」決まりで動いている（建物の燃料、[12](12-structures.ja.md)）。
2. 敵は、砦を直接攻めずに、燃料の荷車を何日か続けて焼く。
3. 燃料が切れた砦は止まり、少ない兵でも奪えるようになる。

### 場面D：仕組みどうしの連鎖

1. 鉱山の倉に「100たまったら組合へ送る」決まりがある。組合には「鉄が届いたら工房を動かす」決まりがある。
2. 鉱山の倉が奪われると、組合への鉄が止まる。工房が止まり、砦への兵器が止まる。
3. 砦の「下回ったら補充」の決まりが、遠くの倉から兵器を引き出し始める。
4. 一か所の出来事が、何人もの仕組みを通って広がる。誰もこの順番を計画していない（「小さな出来事の連鎖」）。

## 4. 遊びとして新しく迷うこと

| 判断 | 迷う理由 |
|---|---|
| **自動にするか、手で送るか** | 自動は眠っていても動くが、時刻と道を読まれる。手で送れば読まれにくいが、手間がかかり、眠ると止まる |
| **決まりをどこまでつなぐか** | つなぐほど便利だが、一か所が止まると全部止まる |
| **「下回ったら補充」の線をどこに引くか** | 高くすると安心だが、荷車が頻繁に出て狙われる。低くすると、尽きてから気づく |

## 5. 段階3でわざと入れないもの

- 隠れた情報を合図に使うこと（塔の持ち主の例外を除く）。
- 「すること」に、攻撃や進軍を入れること。軍の自動化はしない。攻める判断は、人間かAIのプレイヤーが毎回する。
- 仕組みの公開とテンプレート（段階4）。

## 6. まだ決めていないこと

1. 合図の4種類で足りるか。特に「公開の事実」の中身（どの事実を使えるか）。
2. 自動の荷車の道を、決まりの中で固定するか、毎回その時の最短路にするか。
3. 手数料と最小量と決まりの数の上限（フェーズ6）。
4. 留守番のAI（眠っている間の代理）との関係。決まりで足りる部分と、AIが判断すべき部分の分け方。
