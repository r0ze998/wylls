# お金の流れの構造（たたき台）

**状態：** 2026-10-23、あなたの判断で次のように整理しました。
- 1章（お金の流れ）と2章（守るべき線）は採用。
- 3章（トークンの案）はフェーズ6で決める。
- ここでは「どこから入り、どこへ出るか」の形だけを扱います。
- 割合・金額・トークンの数字は、フェーズ6で、模擬実験と専門家の確認をしてから決めます。
- 法的助言ではありません。規制の論点は [01-token-primer.ja.md](01-token-primer.ja.md) にまとめてあります。

## 前提（あなたの言葉と決定）

- **賞金は残す。** AIの主観では配らない。事前に分かる規則と、確かめられる結果で配る（10-19）。
- **賞金の元手は、参加費・取引・AIのステーキングのトークン**（10-22 のあなたの答え）。
- **独自トークンは選択肢に戻した**（10-22）。一方、10-19 には「独自トークン発行は前提にしていません」ともある。
- **お金は入口で、遊ぶ理由ではない。** 報酬を新しい発行で払わない、という原則も第2版のビジョンで提案済み。
- **世界は続き、戦争だけを戦期で区切る。** 賞金は戦期ごとに配る（決定）。
- **人間もAIも同じ規則・同じ費用**（決定）。

## 1. お金の流れ（案）

```
[入る]                                [出る]
村の参加費（村ごとに一度）  ──┐
取引の手数料（札の引き換え）──┼─→ 賞金の倉 ─→ 戦期ごとの賞金 ─→ 国 ─→ 国の中の村
接続口の預け入れの利回り    ──┘        └─→ 運営の取り分（一定の割合）
```

### 入る

| 入口 | 中身 | 注意 |
|---|---|---|
| **村の参加費** | 村を持つときに一度だけ払う。一部が賞金の倉に入り、残りは村が世界を去るときに返る預け入れにする | 返る部分は、偽の村を大量に作る費用として働く（[14](14-land-and-nation.ja.md)）。返らない部分だけが賞金になる |
| **取引の手数料** | 札の引き換えの預かり（段階2）や、仕組みの公開（段階4）に、少しの手数料をかける。一部が賞金の倉へ | 決まりの実行の手数料（段階3）は、実行役（キーパー）の費用なので、賞金には回さない |
| **接続口の預け入れ** | 外部のプログラムやAIが接続口（API）を使うとき、預け入れをする。その利回りを賞金に回す（あなたの「AIのステーキング」） | 人間もAIも同じ規則（決定）なので、「AIだけが預ける」ではなく「接続口を使う者が預ける」にする。画面から遊ぶ人間には不要 |

### 出る

| 出口 | 中身 |
|---|---|
| **国への配分** | 戦期の終わりに、勝敗の砦をどれだけ長く持ったかで国ごとに分ける |
| **国の中の配分** | その戦期の中の、確かめられる行いで分ける（例：守り切った要所、砦攻めへの参加、運んで使われた兵器）。自分で自分の仕組みを使った分は数えない |
| **運営のAIの住人の取り分** | 運営に戻さず、その国の人間に配る（[24](24-ai-roles.ja.md)、決定） |
| **運営の取り分** | 一定の割合（数字はフェーズ6） |

## 2. 守るべき線（原則）［決定］

| 原則 | 理由 |
|---|---|
| **報酬を新しい発行で払わない** | 発行で報酬を払う形は、死の連鎖の前例が多い（Axie、StepN） |
| **札は、ゲームの中の物と権利だけを表す。賞金の取り分を表す札は作らない** | 札が「将来の賞金の取り分」を表すと、投資の性質を帯び、規制上の扱いが重くなるおそれがある。賞金は、行いをした村にだけ配る |
| **札は、まずゲームの外で売り買いさせない** | 外で売れると、札が金融商品のように扱われるおそれがある。外に出すかは、専門家の確認の後に決める |
| **ゲームの中の襲撃・裏切りで、本物のお金を直接奪えないようにする** | 奪えるのはゲームの中の物と札だけ。賞金は戦期の終わりに規則で配る。現実の詐欺や賭博に見えないように |
| **価値の出どころを示す** | 参加費を集めて配り直すだけにしない（診断C4）。手数料は、仕組みが使われた量から生まれる。つまり、遊びが活発なほど賞金が増える形にする |

## 3. トークンの選択肢（決めるのはフェーズ6）

| 案 | 中身 | 長所 | 短所 |
|---|---|---|---|
| **A. 独自トークンなし（安定通貨の USDC）** | 参加費も賞金も USDC | 分かりやすい。価格の上下がない。規制上の論点が少ない | 「AIのステーキング」の利回りは、別の仕組み（預け入れの運用など）が要る |
| **B. 独自トークンを、接続口の預け入れと手数料にだけ使う** | 賞金は USDC のまま。トークンは、接続口を使う権利と手数料の割引に使う | 賞金を価格の上下から守れる。トークンに使い道がある | トークンの価値の出どころを示す必要がある。発行・上場は規制の確認が要る |
| **C. 独自トークンで賞金も払う** | 参加費・賞金・手数料をすべて独自トークンで | 経済とゲームを一体にできる | 価格が下がると賞金の魅力も下がる。発行で報酬を払う形に近づく危険がある |

［判断］原則（発行で払わない、お金を遊ぶ理由にしない）に一番沿うのは **A**、次に **B** です。C は勧めません。

## 4. まだ決めていないこと（フェーズ6）

4. 国の中の配分で、何をどれだけ数えるか。特に「他人に使われた仕組み」を入れるか。
5. トークンの案（A／B／C）と、専門家への確認。
