# 段階2（札と引き換えの預かり）：遊びとしてどうなるか

**状態：** 5章の規則を採用しました（2026-10-23）。それ以外の中身は提案のままです。数字はすべて例です。

**前提（段階1で決めたこと。[18](18-stage1-play.ja.md)）：**
- 倉、送り、工房（兵器）がある。
- 荷は全部見えて、護衛だけが隠せる。
- 襲う側は「奪う」か「焼く」を選ぶ。
- 国の中の襲撃も認めるが、国は投票でその村を追放できる。

---

## 1. 段階2で何が変わるか（一言で）

**段階1：**
- 物を一人で運び、一人で作る。
- 取引は口約束だけで、先に送った側が損をする危険がある。

**段階2の後：**
- 何人かで倉を共有し、持ち分を売り買いできる。
- 他人の工房を借りられる。
- 取引は「両方そろったら交換」にできる。
- **作った仕組み（の持ち分）が、次の人の部品になる。** レゴのつなぎ目が、ここで初めてできる。

## 2. 足すもの

| 足すもの | 中身 | 例 |
|---|---|---|
| **持ち分の札** | 倉に物を預けると、預けた割合の札がもらえる。札を返すと、その割合の物を引き出せる。倉から誰かに配るときも、札の割合で配る | 「組合の倉」の10％の札 |
| **受け取りの札** | 倉の持ち主が出す札。「この倉から、○を、一定期間ごとに△まで受け取れる」 | 「北の鉱山の倉から、鉄を週20まで」 |
| **使用権の札** | 施設の持ち主が出す札。「この施設を、1日○回まで動かせる」。材料は使う側が出し、できた物は使う側の倉に入る | 「B の工房を1日3回」 |
| **引き換えの預かり** | 両方が品を預け、両方そろったら同時に交換する。期限までにそろわなければ、両方に返る | 「鉄100と、使用権の札1枚を交換」 |

**変わらないこと：**
- 物は、相変わらず地図の上を荷車で運ばれ、襲われる。
- 札は「受け取ってよい」「動かしてよい」という権利であって、物を瞬間移動させるものではない。

## 3. 場面：軍需組合ができるまで

1. **倉と持ち分：** 丘の村の X と平地の村の Y・Z が、国の土地に「組合の倉」を建てる。
   - X は鉄を、Y と Z は木材と食料を預ける。
   - 預けた量に応じて、持ち分の札を受け取る。
2. **工房を借りる：** 工房を持つ B から、「1日3回動かせる」使用権の札を、引き換えの預かりで買う。代金は、組合の倉の鉄の一部。
3. **作って配る：**
   - 組合は毎日、倉の鉄と木材を B の工房へ荷車で送り、兵器を作り、倉へ戻す。段階2では、送りは毎回手で出す。自動になるのは段階3。
   - できた兵器は、持ち分の札の割合で配る。
4. **砦の持ち主が加わる：**
   - D は鉱山も工房も持たない。
   - 引き換えの預かりで、Z から持ち分の札を買う。
   - D の分の兵器は、D の砦へ送られるようになる。
5. **運ぶ道が狙われる：**
   - 組合の倉から B の工房へ、工房から D の砦へと、荷車が毎日通る。
   - その道は、敵にも、国の中の不満な村にも見えている。

## 4. 想定していない使い方が生まれる余地

段階2の部品だけで、運営が用意していない次の仕組みが作れます。

| 生まれうる仕組み | 部品の組み方 |
|---|---|
| **兵器の先渡し** | 組合が「来週から兵器を週5まで受け取れる」受け取りの札を出し、今売って材料費にする。買った人は、それをさらに転売できる |
| **投資の倉** | E が自分の倉を作り、いくつもの組合の持ち分の札を預けて集める。その倉の持ち分の札を売る。持ち主は、複数の組合の兵器を少しずつ受け取れる |
| **工房の又貸し** | B から使用権の札を買った F が、それを高値で別の国に売る |
| **新参への投資** | 古参が新参の村に資源を送り、見返りに「その村の木材を週10まで」受け取りの札をもらう。新参の村が出す札なので、新参にしか作れない（[19](19-newcomers.ja.md) の3章） |
| **敵国への武器商人** | 中立の村が、両方の国の組合の札を持ち、両方に兵器を流す |

方針の「確かめるべきこと」（指定しなかった使い方・他人が使いたくなる・さらに組み合わさる）は、これらが実際に出てくるかで見ます。

## 5. 決める必要のある規則［決定 2026-10-23：この章の案を採用］

| 問題 | 案 | 理由 |
|---|---|---|
| **倉が奪われたら、札はどうなるか** | その倉の持ち分の札と受け取りの札は、**無効になる**。中身は奪った側のもの | 倉を守ることが、札を持つ全員の共通の利害になる。奪う側の得も大きい。敵の倉への権利が残る、というややこしさもなくせる |
| **物が足りず、受け取りの札を全部守れないとき** | その期間の受け取りを、**札の割合で均等に減らす** | 先着にすると、実行する人（キーパー）が順番を操作できてしまう |
| **持ち分の配り方** | 札が売り買いされるたびに、それまでの配分を清算する | 清算の順番で取り分が変わらないように |
| **札を出しすぎる** | 受け取りの札は、倉の持ち主が出す。出しすぎて守れなければ、5章の均等割りで減るだけ。守れなかったことは記録に残る | 出しすぎた持ち主は信用を失う。運営は止めない |
| **札の乱発で地図が埋まる** | 札を新しく出すのに、少しの費用をかける | 乱立を防ぐ（数字はフェーズ6） |
| **国を移った人の札** | 札は国とは関係なく残る | 札はその倉の持ち主と持ち手の間の約束。ただし、国どうしが戦争中なら、その荷車は敵地を通ることになり、襲われやすい |

## 6. まだ決めていないこと

1. 札の種類は、この3つで足りるか（段階4の前に見直す）。
2. 使用権の札で施設を動かすとき、材料をどこから出すか。使う側の倉から施設まで、荷車で運ぶ前提でよいか。
3. 引き換えの預かりに、物と札以外（例：期限つきの約束）を入れるか。
4. 札を、ゲームの外の市場で売り買いできるようにするか（賞金・規制と合わせてフェーズ6）。
