# フェーズ1c補足：トークン経済と法規制の入門

**状態：** 下書き（2026-10-22）。

**これは法的な助言ではありません。** 法律に関わる部分は、すべて**専門家への確認が必要**です。

**目的：** 独自トークンを選択肢に戻したので、トークンを「ゲームの素材」として評価できるだけの知識をそろえます。ここでは結論を出しません。フェーズ6で、遊びの面白さが確かめられた後に決めます。

**表記：** ［事実］出典あり、［未確認］、［判断］。

## 1. 三つの基本の選択肢（比較の基準）

| | お金なし | 安定通貨（USDC）の賞金 | 独自トークン |
|---|---|---|---|
| 得られるもの | 設計の自由。裏切りがゲームの中だけで済む。金融の法律に触れない | 価値の安定した本物の賞金。発行者として証券の問題を負わない。分かりやすい | 自分で制御できる単位（発行・焼却・ロック）。統治の重み。将来の価値で初期の貢献者に報いる。資金調達。立ち上げ時の勢い |
| 失うもの | 本物の賭け金や賞金の引力 | 賭博・景品・送金の法律は残る。賞金は本物の収入か参加費から出す必要がある | 安定通貨の欄のすべてに加えて、発行者の規制、価格の変動。ゲームの経済が、評価される「市場」になる |

**独自トークンにしかできないこと［事実と判断］：**
- 現金ではなく「将来の価値への権利」を配れる（発行の主な理由）。
- 政策のてこ（発行量・焼却・ロック）として使える。
- その世界の中でしか価値のない担保になる。
- 資金を調達できる。

**安定通貨にしかできないこと：**
- 賞金の価値が、プロジェクトの成否に左右されない。
- 「価格下落→報酬減→人が減る→さらに下落」の連鎖を避けられる。Axie の SLP はピークから約99.9%下落し、1日の稼ぎは約35ドルから約1ドルになった［事実］。https://afkgaming.com/amp/story/blockchaingames/news/axie-infinitys-utility-currency-slp-is-down-an-astonishing-999-from-its-peak

**設計上の読み［判断］：** 独自トークンがゲームの中でできること（消費先・担保・見た目・入場）は、たいてい譲渡できないポイントでもできる。独自トークンが本当に足すのは、**資金調達と、譲渡できる将来の利益**で、そこがまさに金融の法律に触れる部分。

## 2. 「持つ理由」と「使う理由」

- **使うだけのトークンは、すぐ手放される［未確認］。** 行動の支払いにしか使わないなら、買ってすぐ使う。価値は使われる量ではなく、量÷回転の速さで決まる。
- **持たせる仕組みと、その代償：**
  - 手数料の分配・収益の分配：証券とみなされやすい。
  - 買い戻して焼却：分配の間接版。
  - 発行で払う預け入れの利回り：預けていない人の持ち分を薄めるだけ。
- **買い戻しは、ロック解除に負けやすい［事実］。**
  - Jupiter は2025年に、手数料収入の約半分にあたる7,000万ドル超を買い戻しに使った。それでも毎月の大量のロック解除で、価格はピークから約89%下落した。チームは買い戻しをやめて、SOLやUSDCで報いるべきかを公に問うた。https://finance.yahoo.com/news/jupiter-helium-expose-token-buyback-123954276.html
  - Helium も、市場の反応が乏しいとして、収益による買い戻しを止めたと報じられている［二次資料］。
- **［判断］** 金融の理由より、ゲームの中の持つ理由のほうが強い。例：
  - 入場の担保で、裏切ると失う
  - 席を確保する預け金
  - 遊ぶ人にだけ意味のある統治

## 3. 投機が止まった後、誰が買うのか

| 買い手の候補 | 必要とするもの | 注意 |
|---|---|---|
| 新しく入るプレイヤー | 参加費の単位 | 買ってすぐ使う。需要は新規の数に比例し、続かない |
| 見た目を買う人 | トークン建ての見た目の品 | いちばん続く非投機の需要［未確認］。ただし USDC やカードでも払える |
| 出資者・スポンサー | 賞金、命名権 | 安定通貨や法定通貨を好む［未確認］ |
| 1回ごとに払うAIエージェント | 少額の支払い | 実際の決済の仕組み（x402、Coinbase のエージェント用の財布）は、主に USDC で決済される［事実］ |
| ギルドの資本 | 投じた資産の利回り | Axie で利回りが崩れると消えた |

**［判断］** 投機でない買い手の多くは、通貨の種類を気にしないか、安定通貨を好む。独自トークンには、**そのトークンでしか満たせない消費先**が要る。そうでないと、買い手がいなくなる。

## 4. 一つのトークンか、二つか

- **Axie（統治用の AXS と、発行される報酬の SLP）：** 発行が速く焼却が遅く、超インフレになった。2022年の発行量の削減は一時的に効いたが、長期の収益は約99.7%減った［事実］。
  - **学び：** トークンを二つにすると価格の変動は分けられるが、発行と消費の不均衡は分けられない。
- **EVE Online（PLEX／ISK）：**
  - PLEX は、現実のお金を ISK に変えるための公認の橋。
  - ISK や PLEX を現金に戻すのは規約で禁止され、大規模な追放で取り締まっている［事実］。https://www.eveonline.com/news/view/overlays-isk-buyer-amnesty-and-account-security
  - **お金が一方向にしか流れない。これが、EVE の公認の裏切りを、法的に「ゲームの中」にとどめている。**
- **懸賞型カジノ（買える Gold Coins と、換金できる Sweeps Coins）：**
  - 米国で法律によって封じられつつある。
  - カリフォルニア州 AB 831（2026年1月1日施行）は、二通貨の懸賞型を犯罪にした。責任は決済業者や紹介者にも及ぶ［事実］。https://casinobeats.com/2025/10/13/california-sweepstakes-casino-ban-ab-831/
  - **学び：「二通貨だから賭博ではない」という設計は、米国では危険の印になった。**
- **LORDS（Realms）：**
  - 一つのトークンで、参加費・賞金・輸送の燃料を兼ねる。設計は筋が通っているが、規模は小さい（時価総額の一時点の値は約360万ドル）［事実］。
  - 参加費から賞金を出す形は、賭博の分析にそのまま入る。

## 5. 供給と金庫

- **発行とロック解除：** プレイヤーへの発行は、実質的に市場への売り。投資家とチームのロック解除は、買い戻しを上回る（Jupiter の例）。
- **固定の供給か、増える供給か［未確認］：**
  - 固定なら、運営の費用は手数料か消費先で賄う必要がある。
  - 増えるなら、消費先が発行より速く増える必要がある。
- **Treasure DAO の教訓［事実］：**
  - 金庫の半分以上を自分のトークン（MAGIC）で持っていた。MAGIC は約0.70ドルから約0.07ドルに下落した。
  - 四半期の収入約4万ドルに対し、費用は約1,130万ドル。
  - 自前のチェーンとゲームの出版をやめた。https://www.blockworks.com/news/treasure-dao-gaming-closes-cuts-layoffs
  - **原則：** 運営資金は安定通貨で持ち、自分のトークンは「条件付きの持ち分」とみなす。現金とはみなさない。
- **市場の構造［未確認］：**
  - 流動性の作り方は二つある。一つは金庫が資金を入れる自動取引の場で、損失や狙い撃ちの対象になる。もう一つはマーケットメーカーで、多くはトークンの貸し出しとオプションの形を取り、見えない希薄化になる。
  - 流動性が薄く、取引の場が公開されていると、ゲーム内の価格を操作でき、操作するのはプレイヤー自身かもしれない。

## 6. 楽しい消費先と、税

- **楽しい消費先：** プレイヤーが望むことの副作用として、通貨が消えるもの［未確認］。
  - EVE で壊れた船は永久に消え、作る人の需要になる。
  - 命名権、像、記念碑。
  - 法を提案する費用（荒らし対策も兼ねる）。
  - 世界を変える焼却（不思議の建造、季節の出来事の発動）。
- **税：** 送金の手数料や維持費は、取り立てに感じられ、避けられる。
- **試し方［判断］：** お金のない版でも、プレイヤーはそれに払うか。払うなら楽しい消費先。

## 7. プレイヤーは「持ち主」か「客」か

- **持ち主の側の主張：** Chris Dixon『Read Write Own』（2024）。持ち分がユーザーをネットワークと同じ方向に向ける［事実］。
- **批判［未確認］：**
  - 持ち分は遊びを労働に変え、プレイヤーを初期保有者の「出口の流動性」にする。
  - 投資目的の保有者と、遊びたい人は、望む更新が違う。
  - 投機が設計を取り出しの方向に引っ張る（Dan Olson「Line Goes Up」、Raph Koster の論考）。
- **データ：** Delphi は、資金を得た2,489のweb3ゲームのうち514が止まったと数えている［事実］。https://members.delphidigital.io/reports/gaming-year-ahead-2025

## 8. 担保としてのトークンか、譲渡できない評判か

| | 譲渡できる担保（没収できる保証金） | 譲渡できない評判（ソウルバウンド） |
|---|---|---|
| 別アカウント対策 | 資本に比例して効く | 買えないので、人とのつながりの来歴で効く |
| 弱み | 金持ちが強い。貸し借りされる。本物の価値の担保を「裏切り」で没収すると、実質的に金銭の罰になり、消費者法や賭博の問題が出る | ウォレットを量産される、鍵をなくす、プライバシー［未確認］ |
| 出典 | ― | Weyl・Ohlhaver・Buterin「Decentralized Society: Finding Web3's Soul」（2022）https://papers.ssrn.com/abstract=4105763 |

**混合の形［未確認］：** 譲渡できない評判で入場を限り、1試合ごとの荒らしには少額の安定通貨かポイントの保証金を使う。

## 9. 本物のお金と「公認の裏切り」

- **EVE：**
  - ゲーム内の詐欺は原則として訴えられない。
  - 一方、現実のお金を使わせる詐欺（偽のチャリティなど）は永久追放。ISK の現金での売買も禁止［事実］。https://wiki.eveuniversity.org/Scams_in_EVE_Online
  - **裏切りが許されるのは、価値がゲームの外に出られないから。**
- **換金できると変わること［未確認、要確認］：**
  - ゲーム内の「詐欺」が、現実の詐欺や窃盗になりうる。
  - 結託や複数アカウントが、賞金の詐取になる。示し合わせた勝ち負けは、腕前の大会の地位を崩す。
  - 公正の義務、依存症への配慮義務。
  - 宣伝のしかたに、景品表示法や米国の消費者保護法が及ぶ。
  - アプリストアや決済業者の規約。
- **設計の選択肢［判断］：**
  - 裏切りの報酬は、換金できない単位にとどめる。
  - 賞金は、規則で確かめた最終の順位だけで払う。
  - 結託と複数アカウントは失格にする。
  - 賞金の受取人は本人確認する。

## 11. この入門から出てくる仮説（結論ではない）

1. **いちばん安全な形［判断、要確認］：** 換金なし。または、協賛・主催者の資金で出す USDC の賞金で、参加費を賞金の原資にしない。
   - 日本では、参加費から賞金を出さないことが鍵で、購入に付く景品は景品表示法の上限がある。
   - 米国では、腕前の大会は「主たる要素」の州に地域を限って可能で、偶然の要素があれば無料の参加の道が要る。
   - 二通貨の懸賞型は避ける。
2. **独自トークンが足すもの：** 発行者の開示義務（日本の改正金融商品取引法は2027年ごろから、EU の MiCA の白書）と、インサイダー規制。賭博・景品の法律の上に積み重なる。そのゲーム上の利点（消費先・担保・統治）の多くは、譲渡できないポイントや評判でも実現できる。
3. **それでも発行するなら：** 手数料の分配や買い戻しを約束しない。運営資金は安定通貨で持つ。消費先は楽しいものにする。公認の裏切りの報酬は換金できない単位にとどめる（EVE の一方向の PLEX のように）。

> 注：以前の議論で保留にした「参加費を賞金の元手にする」案は、日本では上の1に正面から触れます。フェーズ6で、専門家への確認を前提に見直します。

## 確かめていないこと

- 米国 CLARITY 法の行方。NY の懸賞型の禁止に署名がされたか。
- 日本の改正金融商品取引法の、暗号資産の規定の施行日。
- NFT のガチャと二次流通についての、2025〜26年の日本の公式見解。
