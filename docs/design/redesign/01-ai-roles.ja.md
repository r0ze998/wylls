# フェーズ1b補足：AIの役割

**状態：** 下書き（2026-10-22）。

**目的：** AIは「プレイヤー」か「NPC」だけではありません。役割ごとに、何ができ、いくらかかり、後から確かめられるかが大きく違います。フェーズ3で役割を選べるように、その違いを並べます。

**表記：**
- 価格と待ち時間は見積もりです。URL付きのものだけが出典ありです。
- ［未確認］は一次資料を確かめていないもの、［判断］は私の解釈です。

## 1. すべての役割に共通する前提

### 結果を再計算できない

- 温度0でも、言語モデルの出力は既定では再現しない。処理のまとめ方で浮動小数点の計算順が変わるためで、同じ入力を1,000回送ると80通りの出力が出た例がある。専用の処理にすれば1,000回とも同じになった（遅くはなる）。https://simonwillison.net/2025/Sep/11/defeating-nondeterminism
- GPUの機種と専用の処理を固定すれば、ビット単位で同じ結果を出せる例もある（EigenAI、遅延は約1.8%増）。https://arxiv.org/abs/2602.00182
- **ホスト型の非公開モデルは、検証者が再計算できない。** たとえば Claude の API は、2026-10-21 以降、温度などの指定を受け付けない（Anthropic の API リファレンス）。
- 現実的な形は「**記録して約束する**」。入力と出力のハッシュをチェーンに記録し、他人が監査する。再計算はできない。
- **［判断］** これは「すべての行動を後から検証できる」という Wylls の資産と衝突する。AIの判断を状態の変化に直結させるなら、この衝突の扱いを決める必要がある。

### 証明（アテステーション）の選択肢（2025〜26年の成熟度）

| 方式 | 中身 | 成熟度・費用 |
|---|---|---|
| TEE（安全な実行環境） | 改ざんされていない環境で動いたことを証明する | 今いちばん実用的。H100 で多くの問い合わせの負担は5%未満〜8%。ただしGPUのメモリは暗号化されない https://arxiv.org/html/2409.03992v2 |
| opML | 結果を先に出し、異議があれば二分探索で検証する | 7Bのモデルまで。経済的な安全性に依存する https://arxiv.org/abs/2401.17555 |
| zkML | 計算の正しさをゼロ知識で証明する | 2025年に言語モデルで可能になったが遅い（小さいモデルで毎分86〜174トークン）。たまの裁定ならよいが、毎手番の会話は無理 https://lagrange.dev/blog/deepprove-1 |

### 1回の判断の費用（見積もり）

前提は、1回の判断で入力約3,000トークン・出力約300トークン、大きいモデルではさらに思考に約1,500トークン。Anthropic の価格は API リファレンスによります。

| モデル | 価格（入力／出力、100万トークンあたり） | 1回の判断 |
|---|---|---|
| Claude Haiku 5.5 | $0.10／$0.50 | 約$0.0005〜0.001 |
| Claude Sonnet 5.5 | $2／$10 | 約$0.01〜0.02 |
| Claude Opus 5.5 | $4／$20 | 約$0.02〜0.05 |
| 公開モデルの例（第三者の掲載、未確認） | ― | 約$0.0003〜0.0005 |

- **規模：** 1,000体が1日24回判断すると、Haiku 級で1日約12〜24ドル、Sonnet 級で約240〜480ドル。
- **待ち時間：** 小さいモデルで1〜3秒、推論ありで5〜60秒。非同期の手番には合うが、実時間には合わない。
- まとめて処理する API を使えば半額。手番制のゲームに向く。
- 今の Wylls のAI市民は、ローカルの公開モデル（Gemma）なので、API の費用はかからない［事実］。

### モデルが途中で変わる

- 「同じ」ホスト型モデルでも、数か月で性能が変わった例がある（GPT-4 の素数判定の正答率が、2023年3月から6月で84%から51%へ）。https://arxiv.org/abs/2307.09009
- **［判断］** 対策：
  - シーズン中はモデルのIDか、公開モデルのファイルとそのハッシュを固定する。
  - 変更はシーズンの境目に告知して行う。
  - 人格はデータ（指示文・記憶・確認用の質問集）として版を管理し、モデルを替える前に一貫性の試験を通す。

### 公開モデルかホスト型か

| | 公開モデル | ホスト型 |
|---|---|---|
| 費用 | 1トークンあたり安い | 高い |
| 固定・再現・証明 | できる | できない |
| 品質 | 劣ることがある | 最高 |
| 運用 | 自分で負う | 任せられる |
| 変化 | 自分で管理できる | 黙って変わりうる |

- 日本語の品質は、Nejumi リーダーボード（https://nejumi.ai）で選ぶ前に確かめる［順位は未確認］。

### 人間との公平さ

- **前例：** AlphaStar は、5秒あたり22回の行動に制限され、画面も人間と同じカメラで見るよう制約された。制約はプロ選手の承認を得ている。https://deepmind.google/discover/blog/alphastar-grandmaster-level-in-starcraft-ii-using-multi-agent-reinforcement-learning/
- **手番制での相当物：** 1手番あたりのメッセージ数、トークン数、計算予算、人間が持たない情報へのアクセスの禁止。

### AIが面白いかを測る

- **PersonaGym：** 期待される行動、行動の理由づけ、口調、人格の一貫性、有害さの抑制を採点する。大きいモデルが人格づくりで勝つとは限らない。https://arxiv.org/abs/2407.18416
- **Generative Agents：** 人間の評価者が順位を付けた。比較の基準は「エージェントを演じた人間の作業者」で、完全な構成がそれより上に来た。https://hai.stanford.edu/news/computational-agents-exhibit-believable-humanlike-behavior
- **RPGBench：** 言語モデルの審査で「面白さ」を測ったが、ばらつきが大きい。https://arxiv.org/abs/2502.00595
- **見る指標［判断］：** 断る率、役から外れる率、記憶との矛盾、人間による二択の好み。台本どおりに攻撃してくるプレイヤーと、記録したシーズンの再生での試験。

### 安全と節度

- **AI Dungeon（2021）：** 単語のブロックで誤検知が起き、「私の8歳のノートPC」まで止まった。運営が非公開の物語を読むことにも反発が出た。https://www.techdirt.com/tag/sexual-content/
- **Character.AI：** 2025-11-25 から18歳未満の自由な会話を終了した。訴訟とFTCの調査を受けての対応。https://techcrunch.com/2025/10/29/character-ai-is-killing-the-chatbot-experience-for-minors/
- **プロンプト注入：** 言語モデルのリスクの筆頭（OWASP LLM01）。Freysa は、新しい管理者のふりをした文章で破られた。
- **［判断］原則：** 言語モデルに、価値の移動を直接決める権限を持たせない。言語モデルとゲームの状態の間に、決定論の規則のエンジンを置く。

## 2. 六つの役割

| 役割 | できること | 費用 | 後から確かめる必要 | 主な危険 | 前例 |
|---|---|---|---|---|---|
| **(a) 人間と同じルールのプレイヤー** | 卓を埋める。いつでも相手がいる | 低い（判断の回数が少ない） | 要らない。手は人間の手と同じく判定される | 持ち主との結託。人間の言葉による操作 | CICERO（正体を隠して上位10%。開示の倫理が問題になった） |
| **(b) 持ち主の代わりに動くAI** | 不在中も遊べる | 手番の頻度に比例 | 要らない。上限を「推論」ではなく「行動の予算」にかける | 大口が計算やより良いモデルを買う。上限とモデルの固定で揃える | Screeps（共通のCPU上限）、Parallel Colony（持ち主は提案だけ、AIは断れる。提供は未確認） |
| **(c) NPC・市民** | 世界に人がいる | 量が一番多い。小さいモデルとキャッシュが要る | 状態を変えるときだけ要る。雰囲気だけの発言は確かめなくてよい | 自由な会話の節度。情報を漏らすよう説得される | Generative Agents |
| **(d) 審判・語り手・ゲームマスター** | 緩急、裁定、語り | 中程度 | **最も要る。** 裁定がそのまま状態になるため、決定論か証明が必要 | 公開の台帳では、裁量が争いの種になる | RimWorld の語り手（言語モデルではなく、数値で決まる演出家）、Blood on the Clocktower、AI Dungeon |
| **(e) 世界のシミュレーター** | 世界の反応を作る | 大きい | 再計算できない | 権威のある状態に使えない | ― |
| **(f) 内容・法・規則を書く** | 新しい法や出来事を書く | 事前に書くなら待ち時間は関係ない | 事前に書いて、審査してハッシュを記録できる | Project Sid は「新しい制度をゼロから発明できない」。制度は事前に用意されていた | Project Sid（憲法の改正と税の遵守率） |

**［判断］(d)〜(f) の安全な形：** AIは提案し、語り、決まった枠（憲法の形式など）の中の値を埋める。判定は決定論のエンジンがする。

- **持ち主が任せるAIの財布（未統合）：** (b)の土台。
- **(d)(e)(f)：** 今の Wylls にはない。
