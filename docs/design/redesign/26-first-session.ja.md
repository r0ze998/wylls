# 新しく来た人の最初の30分（たたき台）

**状態：** 「使う → 使われる」の流れを採用（2026-10-23、あなたの判断）。時間はすべて目安です。6章は未決。

**あなたの問い（10-19）：** 国と村を選んでから最初の意味ある判断をするまでに、何を体験させるか。最初の10〜30分を具体的に考えたい。

## 前提（決定済み）

- 新しい村は国の内側に置かれ、最初の期間は守られる（[19](19-newcomers.ja.md)）。
- 鉱石は丘と山から採れる。普通の兵は兵器なしで訓練できる（[18](18-stage1-play.ja.md)）。
- 仕組みは地図に公開され、「欲しいもの」から探してつなげる（[22](22-stage4-play.ja.md)）。
- 世界として「人間とAIが一緒に暮らしている」と告げる（[24](24-ai-roles.ja.md)）。

---

## 1. 考え方：最初は「作る」ではなく「使う → 使われる」

- **組み立ては、最初は見せない。** 仕組みを組み立てるのは、この遊びの一番深いところです。それを最初の30分で教えようとすると、難しくて離れてしまいます。
- **最初の30分は、3つの体験だけにします。**
  1. 足りないものに気づく。
  2. 他人の仕組みを **使って** 解決する。
  3. 自分の余りものが、他人の仕組みに **使われる**。
- **「文明の一部になった」と感じるまで。** 自分で仕組みを作るのは、数日後でかまいません。

## 2. 30分の流れ

### 0〜3分：世界に入る

- 最初に一行だけ告げる。「この世界には、人間とAIが一緒に暮らしています。」
- 国を選ぶ（6か国）。村が国の内側に置かれ、「3日間は攻められない」と表示される。
- 地図には、自分の村の周りの村と、それらを結ぶ荷車の線（仕組み）が、うっすら見える。世界がすでに動いていることが分かる。

### 3〜10分：育てて、足りないものに気づく

- 最初の建物（畑・伐採場）を建てる。最初の数手は速く建つ（[19](19-newcomers.ja.md) の4）。
- 最初の目標が出る。「重装兵を1隊訓練しよう」。
  - 押してみると、「兵器が足りません」。
  - 兵器を作るには鉱石が要るが、自分の平地の村ではほとんど採れない。
- 画面が、3つの道を示す。
  1. **他人の仕組みから手に入れる**（推奨の印つき）
  2. 近くの丘の村に頼む（会話）
  3. 自分でゆっくり採る

### 10〜20分：他人の仕組みを使う

- 「兵器が欲しい」の一覧が出る。北の軍需組合、南の工房の貸し出し、兵器の先渡し。値段・距離・実績つき（[22](22-stage4-play.ja.md) の場面A）。
- 少量だけ、北の組合の札を買う（2回の操作）。
- **地図の上を、自分の村へ向かう荷車が見える。** 国の内側なので、襲われる心配はまだ小さい。
- 待つ間に、組合の仕組みの紙を読める。誰が鉄を出し、どこの工房で作り、誰に配っているか。組合の作り手が人間かAIかは分からない。

### 20〜30分：自分が使われる

- 画面が知らせる。「あなたの村の木材を欲しがっている仕組みがあります」。
  - 例：その組合自身が、工房の燃料に木材を必要としている。
- 2つの選び方がある。
  - その場で一度だけ売る。
  - テンプレート「たまったら送る」で、「木材が200たまったら、組合へ送る」と決めておく（段階3）。
- **組合の仕組みの線に、自分の村の名前が加わる。**
- 兵器が届き、重装兵を1隊訓練する。最初の目標を達成する。

### 30分の終わり

あなたは、ほかの人（人間かAIかは分からない）の仕組みを使い、自分の村もその仕組みの一部になりました。次の2つを知らせて、最初の遊びを終えます。
- 守りの期間が終わると、外に出る荷車は襲われうること。
- 眠っている間、代理のAIに守りを任せる方法があること。

## 3. 最初の世界を寂しくしない

- 最初は、使える仕組みがないと、この30分が成り立ちません。
- そこで、**運営のAIの住人**（[24](24-ai-roles.ja.md) の④）が、世界の始まりから基本の仕組みを動かしておきます。基本の仕組みは、組合、工房の貸し出し、木材の買い取りなどです。
- 人間とAIは、同じ規則と同じ費用で動きます。運営のAIの取り分は、その国の人間に配ります（決定済み）。

## 4. その後の数日（作る側へ）

| 時期 | 体験 |
|---|---|
| 1〜2日目 | 自分の決まりを増やす（たまったら送る、下回ったら補充）。国の会話に加わる |
| 3日目 | 守りが切れる。自分の荷車を外に出し、初めて襲われる危険と向き合う。護衛と道を選ぶ |
| 4日目以降 | テンプレートか、AIの手伝いで、初めて自分の仕組みを公開する。例：自分の木材を定期で売る仕組み |
| 最初の戦期の終わり | 自分が関わった仕組みと行いに応じて、賞金の取り分を受け取る |

## 5. この30分で確かめたいこと（目安）

（数字の測り方の議論ではなく、作るときの目標として置きます。）
- 15分以内に、他人の仕組みを一度使う。
- 30分以内に、自分の村が他人の仕組みの一部になる。
- 30分の間に、仕組みを組み立てる画面を一度も開かなくても、迷わない。

## 6. まだ決めていないこと

1. 最初の目標を「重装兵」にするか。別の目標（例：国の倉への貢献）のほうが、国の一員の感覚が出るかもしれない。
2. 「推奨の印」をどの仕組みに付けるか。運営が特定の仕組みを推すことになるため、近さと実績だけで機械的に決めるのがよいか。
3. 会話（近くの丘の村に頼む）を、最初の30分でどこまで見せるか。
