# コアプレイテスト 運用手順（進行役用）

## 目的

確かめたいのは、核の一文「国の一員として、見えない敵の動きを仲間と読み合い、誰を信じて、自分の役目をどこで果たすかを決める」です。これを今のルールのまま遊び、次のことを判断します。

- 約束を記録する仕組みが要るかどうか（決定X2の見直し）
- この核が成り立っているかどうか

計画の全体は `~/.claude/plans/pasted-content-id-4785-wylls-velvety-cocoa.md` にあります。

- **ブランチ：** `docs/core-playtest`（`frontier/season-complete` @ `adb4ac98` から分岐）
- **変えたもの：** 設定ファイル1つ（`permutation-gateway/citizens/stack/ai-cq-core-playtest.toml`）と、この文書だけです。ルール・数値・プログラムは変えていません。

## 構成

## 前日までの準備

1. **ホストのMac**
   - 「システム設定 → 一般 → 共有 → リモートログイン」をオンにし、参加者用の一般ユーザーを作る。
   - スリープしないよう、電源アダプターにつないで「スリープしない」に設定する。
2. **バイナリとプログラム**
   - このワークツリーにはビルドがありません。`FRONTIER_BIN` に `season-complete` のビルドを指定します。
   - プログラム（`.so`）は `season-complete` からコピー済みで、sha256 は14日走行と同一（`9ffef02f…`）です。
3. **参加者の割り当て**：国0と国1に、人数が均等になるように振り分けておく。

## 当日の起動（毎晩の最初）

### 1夜目だけ：新しい世界を起動する

1. 言語モデルを起動する（約1分）：

   `{"status":"ok"}` が返れば準備完了です。

2. 世界とAIを起動する（世界ができるまで約1分。その後、開幕まで開幕前の待ち時間が約8分）：

   ```bash
   FRONTIER_RELAY_TXS_PER_DAY=400 \
   FRONTIER_BIN=$PWD/../season-complete/frontier-node/target/release \
   AI_RUNS_MD=$HOME/wylls-core-playtest-RUNS.md \

   ```

   - **起動のたびに run id を変えること**（同じ id の征服ルールの世界は、もう一度は立ち上げられません）。
   - 事前確認だけをしたいときは、末尾に `--check` を付ける。

## 参加者のノートPCでの準備（各人、約5分）

1. ポート転送をつないだままにする：

   ```bash
   ssh -N -L 41902:127.0.0.1:41902 -L 41940:127.0.0.1:41940 <ユーザー名>@<ホストのLANのIP>
   ```

2. **Chrome** で `http://127.0.0.1:41902/frontier/frontier/` を開く。
   - **開幕前（画面上部に「開始まで」が出ている間）は参加できません。** 「シーズンが参加できる状態ではありません」と出ます。開幕を待ってください。
3. 割り当てられた国を選び、「〇〇で始める」を押す。最初の村はすぐにでき、すぐに確定します。
4. **評議会に自分の鍵を入れる**（下の「分かったこと」の2を参照）：
   - ゲーム画面のタブで、開発者ツールのコンソール（⌥⌘J）を開き、次の1行を貼り付けて実行します。シーズン番号を聞かれたら `51`（その晩の世界の番号）を入れます。

     ```js
     (()=>{const s=prompt('season id','51');const k=Object.keys(localStorage).find(k=>k.startsWith('ps-fsession:')&&k.split(':')[3]===s);if(!k)return 'no key';const p=k.split(':');copy(`Wylls key\nSeason: ${p[3]}\nWallet: ${p[4]}\n${localStorage.getItem(k)}\n`);return 'copied'})()
     ```

   - `council.html` を開き、「鍵ファイルを貼り付け」に貼り付けて「この鍵を使う」を押す。
   - 「鍵を読み込みました：このシーズンの市民」と出れば成功です。
   - この鍵はテスト用の世界のゲーム内の鍵で、価値はありません。ただし、他人に渡すとその人があなたとして書き込めます。

## 代替案：このMac1台で交代に遊ぶ（SSHなし）

ノートPCをつなげないときや、まず核のアイデアだけを確かめたいときの形です。

- **プレイヤーごとに、別のアドレスでゲームを開く。** Chromeは `*.localhost` をこのMac自身として扱うので、次のようなアドレスがそのまま使えます。アドレスが違えばブラウザは別のサイトとして扱うため、ウォレットと村も人ごとに分かれます。
  - プレイヤー1：`http://p1.localhost:41902/frontier/frontier/`（評議会は `http://p1.localhost:41902/council.html`）
  - プレイヤー2：`http://p2.localhost:41902/frontier/frontier/`（以下同様）
- 各プレイヤーのタブ（またはウィンドウ）を一列に並べ、交代でMacの前に座る。**画面を見ていいのは本人だけ**にして、封をした進軍の行き先などは他の人に見せない。
- 一人の持ち時間は、目安で2〜3ターン（現実で2〜3分）。その間に、状況を見て、評議会に書き込み、部隊を動かす。
- 同じ国の相談は部屋で口頭で行う。他国との交渉は評議会の文字だけで行う。
- 確認済み（2026-10-22、core-playtest-2）：`p1.localhost` と `p2.localhost` で別々のDev Walletが作られ、Aster と Borealis にそれぞれ参加できた。
- 制約：一度に操作できるのは一人だけなので、同時に動く読み合いは弱まる。そのぶん、交代の順番が回ってくる間に考える時間ができる。

## 片付け

- 2夜目が終わったら、`ai-citizens-run.sh` のターミナルで Ctrl-C を押す。子プロセスが止まり、ロックが外れます。
- 言語モデルのサーバーも止める。
- 世界のデータは `.local/frontier/core-playtest-N/` と `.local/frontier/ai/core-playtest-N/` に残ります。
