2026-10-03。英語で約10分の概要は [../DESIGN-OVERVIEW.md](../DESIGN-OVERVIEW.md)、その日本語版は [../DESIGN-OVERVIEW.ja.md](../DESIGN-OVERVIEW.ja.md)、エンジニア向けの設計書は [DESIGN.md](DESIGN.md)（改訂4）です。これは、ブロックチェーンの専門知識がなくても読めるように、要点だけを短く書いたものです。以前の版（改訂3.1、いまの設計とは違います）は [SUMMARY.ja.rev3.1.md](SUMMARY.ja.rev3.1.md) に履歴として残しています。

## 1. Wylls とは（5行で）

- Wylls は、ひとつの共有された世界で文明を育てるゲームです（Solana というブロックチェーンの上に作っています）。**選ぶのは6つの国のうちのひとつだけ**で、最初の村は自動で置かれます。はじめは「集落」で、育てると町、都市、要塞になります。
- 資源は、遊んでいない間も時間とともに増えます（農場は、予約してから本当に90分で完成します）。
- 戦闘は10分ごとの「鐘」（1日に144回）で、州ごとにまとめて決着します。その鐘に着いた全員が同時に戦い、公開乱数（drand）で結果が決まるので、先に送っても得はありません。
- 軍の**出発は公開、行き先は隠れます**（時間がたつと開く暗号で封をします）。着く鐘になると行き先が開き、結果は誰でも自分で確かめられます。
- 問いは「AIに意志があるとき、ゲームはどう振る舞うのか」です。そのために、AIと明示された「AI市民」を人と同じルールで遊ばせる計画です（**設計のみ。まだ作っていません**）。

## 3. AI市民の考え方（設計のみ）

- 運営が人にまぎれて動かす**隠れたAIは廃止**しました。AIは**いつもAIと表示**します。
- 判断の流れは、(1) プログラムが「ルール上できること」を最大12個の候補にする、(2) モデルがその中から選ぶ、(3) プログラムが検証する、(4) 遅い・無効なときは、従来のルール方式の「オートパイロット」が代わりに動く、です。モデルが選んだことを、オートパイロットが取り消すことはありません。
- AIは**鍵を持ちません**（署名は別のプログラムがします）。有料のAPIは使いません（手元のモデルだけ）。
- 人格、約束の記録、国の評議会、秘密の「号令」（国で投票して決めた攻撃目標を、外の人には隠す）で、「意志が見える場」を作ります。実験としては、同じ条件で、人の1票があるときとないときを比べるテストを予定しています【設計のみ】。
- 予備実験では、ローカルの Gemma 4 は言葉の作業には使えましたが、ルールボットより上手なプレイヤーではありませんでした【実測：[ai-agents/gemma4/REPORT.ja.md](ai-agents/gemma4/REPORT.ja.md)】。そのため、安全の保証はプログラム側に持たせます。

## 4. 正直な限界

- **試験用チェーンだけ**で動かしました。devnet や mainnet では動かしていません。**人が遊んだ（プレイテストをした）ことはなく**、需要や反響の証拠もありません。数字は、ボット、テスト、シミュレーション、予備実験から来ています。
- 観戦の負荷試験の5,000人は、プログラムで作った模擬の観客です。
- お金や賞金が動く、AIが人と見分けがつかない、AIがルールボットより強い、AIの判断をひとつひとつ完全に再現できる、1台のマシンで何千ものAIが動く、AIがお金を稼ぐ、といったことは、**主張しません**。
- 妨害への備えの費用などは、実測ではなくモデル（計算上の見積もり）です。9種類の妨害のうち2種類は、試験シーズンで実際には何も押さえられず、効き目を試せていません【実測：M1-EXIT.ja.md】。
