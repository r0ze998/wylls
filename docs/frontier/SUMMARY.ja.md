## 1. Wylls とは（5行で）

- Wylls は、ひとつの共有された世界で文明を育てるゲームです（Solana というブロックチェーンの上に作っています）。**選ぶのは6つの国のうちのひとつだけ**で、最初の村は自動で置かれます。はじめは「集落」で、育てると町、都市、要塞になります。
- 資源は、遊んでいない間も時間とともに増えます（農場は、予約してから本当に90分で完成します）。
- 戦闘は10分ごとの「鐘」（1日に144回）で、州ごとにまとめて決着します。その鐘に着いた全員が同時に戦い、公開乱数（drand）で結果が決まるので、先に送っても得はありません。
- 軍の**出発は公開、行き先は隠れます**（時間がたつと開く暗号で封をします）。着く鐘になると行き先が開き、結果は誰でも自分で確かめられます。
- 問いは「AIに意志があるとき、ゲームはどう振る舞うのか」です。そのために、AIと明示された「AI市民」を、人と同じ鍵・回数制限・霧で遊ばせる計画です（**設計のみ。まだ作っていません**）。

## 3. AI市民の考え方（設計のみ）

- 運営が人にまぎれて動かす**隠れたAIは廃止**しました。AIは**いつもAIと表示**します。人数は、どの国も同じです（A/Bテストと録画で12人、本番の実行で18人、最初の試運転で6人）。
- 判断の流れは、(1) プログラムが「ルール上できること」を最大12個の候補にする、(2) モデルがその中から選ぶ、(3) プログラムが検証する、(4) 遅い・無効なときは、従来のルール方式の「オートパイロット」が代わりに動く、です。オートパイロットは、経済と日課だけを受け持ち、**自分から軍を出すことはありません**。だから、AIの自発的な進軍は、モデルが選んだものか、国の攻撃命令かのどちらかです。モデルが選んだことを、オートパイロットが取り消すことはありません。
- 人と同じなのは、鍵、1時間30回の操作枠、霧です。AIにだけ、安全のための制限が付きます（選べるのは最大12個の候補だけ、1回と1日に動かせる兵は自宅の60%まで、AIが選べる進軍は1日4回まで）。「人と完全に同じルール」とは言いません。
- AIは**鍵を持ちません**（署名は別のプログラムがします）。有料のAPIは使いません（手元のモデルだけ）。
- **記憶が核です**（あなたの言葉、2026-10-04）。AIは、公開された記録から、コードが作る「出来事の記録」（たとえば「鐘205で、国3があなたより先に野営地を倒した」）を持ち、判断のたびに、そのうちのいくつかを思い出します。モデルは、使ったものを引用でき、画面には、その文が、モデル自身の言葉（確認されていない）の横に出ます。引用は「その行を見せられて挙げた」ことしか示さず、「記憶のせいで決めた」とは言いません。
- デモの主役は、**AIが自分で選んだ進軍**です。軍が出発し（行き先は隠れる）、到着の鐘が終わると、理由と引用した記憶と行き先が開き、本物の戦いの結果が出ます。2番目の場面が、国の評議会です。AIが案を出し、人（試験では運営の席）が投票し、採用された目標、**攻撃命令**（コードの中の名前は「Call」）は、攻撃の時まで外の人には隠れます。評議会はゲームの外にあり、チェーンが強制するものではありません。
- 「意志」は、システムが作り、目に見えるように出すものです。続く目標、記憶を引用した理由、人間関係（信頼と恨み）、断ること、評議会での発言と投票の5つです。モデルが何かを「望んでいる」とは言いません。
- 実験としては、同じ条件で、席の投票があるときとないときを比べるテストを予定しています。試験では、席の投票は運営が台本で入れます【設計のみ】。
- **AI同士の協定と裏切りは、入れません**（あなたの言葉、2026-10-04）。設計は、契約書の附録に、動かない状態で残します。
- 予備実験では、ローカルの Gemma 4 は言葉の作業には使えましたが、ルールボットより上手なプレイヤーではありませんでした【実測：[ai-agents/gemma4/REPORT.ja.md](ai-agents/gemma4/REPORT.ja.md)】。そのため、安全の保証はプログラム側に持たせます。

## 4. 正直な限界

- **試験用チェーンだけ**で動かしました。devnet や mainnet では動かしていません。**人が遊んだ（プレイテストをした）ことはなく**、需要や反響の証拠もありません。数字は、ボット、テスト、シミュレーション、予備実験から来ています。
- 観戦の負荷試験の5,000人は、プログラムで作った模擬の観客です。
- お金や賞金が動く、AIが人と見分けがつかない、AIがルールボットより強い、AIの判断をひとつひとつ完全に再現できる、1台のマシンで何千ものAIが動く、AIがお金を稼ぐ、AI同士の協定や裏切りがある、AIが人のように「覚えている」「望んでいる」、記憶があると上手に遊ぶ、といったことは、**主張しません**。
- 妨害への備えの費用などは、実測ではなくモデル（計算上の見積もり）です。9種類の妨害のうち2種類は、試験シーズンで実際には何も押さえられず、効き目を試せていません【実測：M1-EXIT.ja.md】。
