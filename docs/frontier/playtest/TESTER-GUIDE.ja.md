# Wylls 友だちテスト: 参加者向けガイド

(English version: [`TESTER-GUIDE.md`](TESTER-GUIDE.md)。送る前に、運営者が `{CONTACT}`(連絡先)と `{SURVEY_LINK}`(アンケートのリンク)の2か所を書き換えてください。)

## Wylls とは

Wylls は、たくさんの人が同じ世界で、リアルタイムに遊ぶ文明の戦略ゲームです。国を一つ選ぶと自分の村ができ、村を育て、兵を訓練し、封をした進軍(行き先は到着するまで本人にしか見えません)で送り出します。あなたがいない間も世界は動き続けるので、少し遊んで離れ、また戻ってくる遊び方です。

## このテストについて

- **小さな招待制のテストです。** 10〜30人ほどの友だちに、一人に一つずつ招待リンクを送っています。
- **本物ではなく、テスト用の世界です。** ゲームは運営者のパソコンの中の、ローカルなテスト用チェーンで動いています。**お金も、暗号資産のウォレットも、賞品も、取引もありません。** ここでの結果にテスト以外の価値はありません。
- **基本のゲームだけです。** 建設、訓練、探索、進軍、衝突の報告まで。予定はあるがまだ作っていない機能は入っていません。
- **世界にはボットがいます。** ほかの国の村の多くは、単純なルールで動くコンピューターのプレイヤー(ボット)で、世界が空にならないようにしています。**AI の住民はこのテストには入っていません。**
- **時間は実時間です。** 「鐘」一つが10分、ゲーム内の1日が現実の24時間で、早送りはしません。期間は約3日間、2026年10月6日の夜から10月9日の夜まで(日本時間)の予定です。日程が動くときは運営者から連絡します。
- **未完成です。** 壊れたり、わかりにくかったり、しばらく止まったりするかもしれません(運営者のパソコンがスリープや再起動をすることがあります)。それを見つけるのがこのテストの目的です。

## 参加のしかた

1. 送られてきたリンクを、そのまま開きます。`https://….trycloudflare.com/frontier/frontier/playtest/#i=…` のような形で、`#` から後ろがあなた専用の招待です。一人一回しか使えないので、転送しないでください。
2. 普通のブラウザで開いてください: **Chrome・Edge・Firefox、または iOS 17 以降の Safari**。iPhone ではどのブラウザも同じ仕組みなので、古い iPhone では遊べません(パソコンを使うか、始める前に運営者に伝えてください)。**LINE・Instagram などのアプリの中**でリンクを開くと、ページが気づいて「リンクをコピー」を出します。コピーして Safari か Chrome に貼り付けて開いてください(アプリのメニューの「ブラウザで開く」でも構いません)。アプリの中では鍵の保存がうまく動かないことが多いためです。**プライベートブラウズ(シークレットウィンドウ)は使わないでください。**
3. ページが招待を確認して「招待を確認しました」と出たら、**まずゲスト鍵を保存します**(「はじめる」の上にある「1. あなたのゲスト鍵を保存」): 「鍵をファイルに保存」を押すか、「鍵をコピー」してメモや LINE Keep に貼ります。ウォレットやログインの代わりに、ゲーム用の「ゲスト鍵」がブラウザの中に作られます。価値のあるものは入っていませんが、**それがあなたの村そのもの**です。ブラウザのデータを消したとき、別のブラウザや端末で開くとき、運営者のアドレスが変わったときは、保存した鍵を開始ページの「鍵を持っています」に入れると戻れます。鍵は誰にも見せないでください。開始ページはあとからいつでも開き直して保存できます。「鍵を保存しました」にチェックを入れます。
4. **「はじめる」**を押します(ページの「2. はじめる」)。
5. 次からも、同じ端末の同じブラウザで開いてください。

## 最初の10分

1. 六つの国から一つ選び、**「ゲーム内の鍵を作って参加する」**を押します。(画面には「ゲーム内の鍵」を作ること、ウォレットが2回たずねることが書いてありますが、ゲスト鍵なら自動で静かに済みます。ウォレットの画面は出ず、保存も要りません。保存するのは開始ページのゲスト鍵だけです。)
2. **最初の村は、参加の約11〜21分後にできます。** この待ち時間はゲームの仕組みで、故障ではありません。リハーサルでは約18分でした。**20分のタイマーをかけるか、夕食のあとにまた来てください。** そのあいだ、することはありません。
3. 待つあいだに、**ガイドカード**を開いてみてください(手順: ようこそ、参加、最初の建設、最初の斥候、練習の衝突、最初の封をした進軍、最初の報告)。覚える言葉は五つだけです。**村**(あなたの土地)、**軍勢**(動かす兵)、**鐘**(10分ごとの区切り)、**進軍**(封をした移動)、**探索**(斥候で周りを調べる)。地図を眺めてみてください。待っている画面の**「待つあいだに練習で戦ってみる」**ボタン(上の**「練習」**タブでも同じ)で練習の衝突が始まります。世界には何も送られないので安心です。
4. **最初の村は「仮」の状態かもしれません。** 確定まで最長で約4時間かかります(同じ10分間に土地を希望した人たちの結果がそろうまで)。それまでは収穫・建設・訓練はできますが、**軍勢の編成・探索・進軍は確定を待ちます。** 「村はまだ確定していません」と断られるボタンがあっても、それで正しい動きです。あとでまた来てください。(実際にどれくらいかかるかは、リハーサルでは測っていません。)
5. 村が確定したら、「村」のタブで農場と伐採場を建て、斥候を訓練して軍勢に編成し、隣の2マスを探索します。
6. そのあと、届く範囲の蛮族の野営地への封をした進軍を組み、**「封をして出発する」**を押します。
7. ページはいつ閉じても構いません。ゲームはあなたがいなくても進みます。

**2回目の訪問**(たとえば翌日)では、報告とお知らせを読み、収穫を押し、何かを建てるか訓練し、軍勢がいれば進軍を出してみてください。

一度に全部やる必要はありません。

## 何が起きるか

- **待つのが普通です。** 村: 参加の約11〜21分後。そのあと確定まで最長で約4時間(上を見てください)かかり、確定してから進軍できます。探索の結果: 村の待ち時間と同じくらい。**最初の衝突の報告: 最初の進軍を出してから約30〜45分後**(リハーサルでは33〜42分)。参加から数えると、最初の報告は数分ではなく数時間後になるので、画面の前で待たなくて大丈夫です。
- **1日あたりの操作の上限があります。** 1村につき**1ゲーム日に約40回**です(ゲーム日は現実の24時間で、シーズンの開始から数えるため、午前0時には切り替わりません。使わなかった分は60回まで持ち越されます)。収穫・建設・訓練・編成・出発・探索を押すたびに1回減り、参加直後の自動の手順も数えられます。使い切ると「次のゲーム日まで待ってください」と出ます。故障ではありません。開始ページに、上限が戻る時刻が出ます。収穫を何度も押すより、よく考えた数回の操作をおすすめします。
- **世界は実時間で動くので、明日また来てください。** 予約した建設や訓練は離れている間に終わり、資源は村にたまり(上限まで。上限に達するとそれ以上たまりません)、ほかの国の進軍があなたに届くこともあります。1日に数回、数分ずつ見に来る遊び方を想定しています。
- **出てくるはずのメッセージがあります。** 「資源か残高が足りません」(足りないのに訓練や建設を押した場合。ここでの「残高」は村の資源のことで、このテストにお金はありません。費用はまだわかりやすく表示されません)、編成のときの「この州の枠がいっぱいです」、「村はまだ確定していません」(上を見てください)、「この州はまだ前の鐘の決着が済んでいません」(数秒待ってもう一度押してください)。これらで迷ったら教えてください。役に立つ情報です。
- **ページが開かない**、または Cloudflare のエラー画面が出るときは、運営者のパソコンがスリープか再起動中か、アドレスが変わっています。数分待ってもう一度リンクを開き、運営者から新しいアドレスの連絡が来ていないか見てください。アドレスが変わっても村はそのままです。新しいアドレスを開き、「鍵を持っています」に保存したゲスト鍵を貼り付けると戻れます。そのあと、ゲーム内の鍵をもう一度作るようゲームが1回たずねるので、ボタンを押してください。

## 保存するデータと、参加は任意であること

参加は**任意**です。理由を言わずにいつでもやめられます(リンクを開かなくなるだけで構いません)。集計に自分の記録を入れてほしくないときは、{CONTACT} に伝えてください。あなたの招待コードを集計から外します。

運営者のパソコンの中に、次のものを保存します。

- **招待コードごと**の記録: そのコードで参加したかどうかと、その後のそのゲーム内住民の操作(建設・訓練・進軍など)と時刻。住民は、ブラウザが作ったランダムな参加者番号(ゲスト鍵の公開側)で、名前ではありません。
- テスト用チェーンのゲーム記録(ゲームそのものに必要な、同じ操作の記録)。
- プログラムの技術的なログ(エラーや再起動)。

**集めないもの**: 名前、メールアドレス、電話番号、アカウント。IP アドレスは、こちらのどのファイルにも書き込みません。(運営者のプログラムは、悪用を防ぐためのアクセス回数をアドレスごとにメモリの中だけで数え、再起動で消えます。正直に書く例外が一つあります。チェーン上の住民と結び付かないアクセスは、ネットワークアドレスを元に戻せない形にしたコードで数えられ、そのコードがプログラムのレート制限用の状態ファイルに書かれます。このコードは、再起動のたびに変わる、メモリの中だけの鍵による HMAC で、アドレスには戻せず、再起動後は意味を持ちません。リンクは Cloudflare のトンネルを通るため、一般のウェブサービスと同じく Cloudflare 側には接続元が見えますが、こちらは受け取りも保存もしません。)ゲームのページは、ホスト以外にはつながらないセキュリティ設定で配信され、分析・広告のサービスも使っていません。ゲーム用の鍵と設定は、あなたの端末のブラウザの中に保存されます。

正直に言っておくと、招待コードはあなた個人に渡したものなので、**リンクを送った人が、そのコードの操作記録を調べようと思えば調べられます。** 報告するのは人数などの集計(たとえば、何人が参加し、何人が12時間以上あけてまたゲームの操作をしたか)だけで、特定の人が何をしたかは報告しません。

アンケート({SURVEY_LINK})は外部のフォームで、個人情報は聞かず、招待コードとも結び付きません。

テストが終わったら、ログは報告のために運営者のパソコンに保管し、そのあと削除するか、ゲスト鍵を含めない形でアーカイブします。

## 問題の報告のしかた

{CONTACT} に次のことを送ってください。

- **何を押して、何が起きると思ったか**と、**出たメッセージの文面そのまま**(コピーしてください)。
- **いつ**起きたか(日付と時刻、日本時間)。
- **端末とブラウザ**(例: iPhone の Safari)。
- 役に立つなら、スクリーンショット。**ゲスト鍵は絶対に送らず、スクリーンショットに写っていたら隠してください。**

壊れてはいないが、わかりにくかっただけ、ということも教えてください。最後のアンケートにも書く欄があります。
