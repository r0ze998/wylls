# Wylls 友だちテスト: 参加者向けガイド

(English version: [`TESTER-GUIDE.md`](TESTER-GUIDE.md)。送る前に、運営者が `{CONTACT}`(連絡先)と `{SURVEY_LINK}`(アンケートのリンク)の2か所を書き換えてください。)

## Wylls とは

Wylls は、たくさんの人が同じ世界で、リアルタイムに遊ぶ文明の戦略ゲームです。国を一つ選ぶと自分の村ができ、村を育て、兵を訓練し、封をした進軍(行き先は到着するまで本人にしか見えません)で送り出します。あなたがいない間も世界は動き続けるので、少し遊んで離れ、また戻ってくる遊び方です。

## このテストについて

- **小さな招待制のテストです。** 10〜30人ほどの友だちに、一人に一つずつ招待リンクを送っています。
- **本物ではなく、テスト用の世界です。** ゲームは運営者のパソコンの中の、ローカルなテスト用チェーンで動いています。**お金も、暗号資産のウォレットも、賞品も、取引もありません。** ここでの結果にテスト以外の価値はありません。
- **基本のゲームだけです。** 建設、訓練、探索、進軍、衝突の報告まで。予定はあるがまだ作っていない機能は入っていません。
- **世界にはボットがいます。** ほかの国の村の多くは、単純なルールで動くコンピューターのプレイヤー(ボット)で、世界が空にならないようにしています。**AI の住民はこのテストには入っていません。**
- **時間は実時間です。** 「鐘」一つが10分、ゲーム内の1日が現実の24時間で、早送りはしません。期間は約3日間、2026年10月6日の夜から10月9日の夜まで(日本時間)の予定です。日程が動くときは運営者から連絡します。
- **未完成です。** 壊れたり、わかりにくかったり、しばらく止まったりするかもしれません(運営者のパソコンがスリープや再起動をすることがあります)。それを見つけるのがこのテストの目的です。

## 参加のしかた

1. 送られてきたリンクを、そのまま開きます。`https://….trycloudflare.com/frontier/frontier/playtest/#i=…` のような形で、`#` から後ろがあなた専用の招待です。一人一回しか使えないので、転送しないでください。
2. **Chrome・Edge・Firefox・Safari(17 以降)**で開いてください。LINE・Instagram・メールアプリの中のブラウザは、閉じたときにデータが消えることがあるので避けます。**プライベートブラウズ(シークレットウィンドウ)は使わないでください。**
3. ページが招待を確認して「招待を確認しました」と出たら、**「はじめる」**を押します。
4. **ゲスト鍵を保存してください**(開始ページの「鍵をファイルに保存」か「鍵をコピー」)。ウォレットやログインの代わりに、ゲーム用の「ゲスト鍵」がブラウザの中に作られます。価値のあるものは入っていませんが、**それがあなたの村そのもの**です。ブラウザのデータを消したとき、別のブラウザや端末で開くとき、運営者のリンクが変わったときは、保存した鍵を開始ページの「鍵を持っています」に入れると戻れます。鍵は誰にも見せないでください。
5. 次からも、同じ端末の同じブラウザで開いてください。

## 最初の10分

1. 六つの国から一つ選び、**「参加」**を押します。(村の準備がまだのときはその旨が出ます。次の鐘まで待ちます。)
2. **最初の村は、参加の約11〜21分後にできます。** この待ち時間はゲームの仕組みで、故障ではありません。リハーサルでは約18分でした。
3. 待つあいだに、**ガイドカード**を開いてみてください(手順: ようこそ、参加、最初の建設、最初の斥候、練習の衝突、最初の封をした進軍、最初の報告)。覚える言葉は五つだけです。**村**(あなたの土地)、**軍勢**(動かす兵)、**鐘**(10分ごとの区切り)、**進軍**(封をした移動)、**探索**(斥候で周りを調べる)。地図を眺めたり、世界には何も送られない**練習の衝突**を試したりできます。
4. 村ができたら、「村」のタブで農場と木材所を建て、斥候を訓練して軍勢に編成し、隣の2マスを探索します。
5. そのあと、届く範囲の蛮族の野営地への封をした進軍を組み、**「出発」**を押します。
6. ページはいつ閉じても構いません。ゲームはあなたがいなくても進みます。

一度に全部やる必要はありません。

## 何が起きるか

- **待つのが普通です。** 村: 参加の約11〜21分後。探索の結果: 同じくらい。**最初の衝突の報告: 最初の進軍を出してから約30〜45分後**(リハーサルでは33〜42分)。村と最初の軍勢にも時間がかかるので、現実的には**参加から1時間半ほど**で最初の報告が届きます。画面の前で待たなくて大丈夫です。
- **世界は実時間で動くので、明日また来てください。** 予約した建設や訓練は離れている間に終わり、資源は村にたまり(上限まで。上限に達するとそれ以上たまりません)、ほかの国の進軍があなたに届くこともあります。1日に数回、数分ずつ見に来る遊び方を想定しています。
- **出てくるはずのメッセージがあります。** 「資源か残高が足りません」(足りないのに訓練や建設を押した場合。費用がまだわかりやすく表示されません)、編成のときの「この州の枠がいっぱいです」、「この州はまだ前の鐘の決着が済んでいません」(数秒待ってもう一度押してください)。これらで迷ったら教えてください。役に立つ情報です。
- **ページが開かないとき**は、運営者のパソコンがスリープか再起動中のことが多いです。数分待って、もう一度リンクを開いてください。アドレス自体が変わったときは、運営者から新しいものが届きます。

## 保存するデータと、参加は任意であること

参加は**任意**です。理由を言わずにいつでもやめられます(リンクを開かなくなるだけで構いません)。集計に自分の記録を入れてほしくないときは、{CONTACT} に伝えてください。あなたの招待コードを集計から外します。

運営者のパソコンの中に、次のものを保存します。

- **招待コードごと**の記録: そのコードで参加したかどうかと、その後のそのゲーム内住民の操作(建設・訓練・進軍など)と時刻。住民は、ブラウザが作ったランダムな参加者番号(ゲスト鍵の公開側)で、名前ではありません。
- テスト用チェーンのゲーム記録(ゲームそのものに必要な、同じ操作の記録)。
- プログラムの技術的なログ(エラーや再起動)。

**集めないもの**: 名前、メールアドレス、電話番号、アカウント。IP アドレスは、こちらのどのファイルにも書き込みません。(運営者のプログラムは、悪用を防ぐためのアクセス回数をアドレスごとにメモリの中だけで数えます。どこにも書かれず、再起動で消えます。リンクは Cloudflare のトンネルを通るため、一般のウェブサービスと同じく Cloudflare 側には接続元が見えますが、こちらは受け取りも保存もしません。)ゲームのページは、ホスト以外にはつながらないセキュリティ設定で配信され、分析・広告のサービスも使っていません。ゲーム用の鍵と設定は、あなたの端末のブラウザの中に保存されます。

正直に言っておくと、招待コードはあなた個人に渡したものなので、**リンクを送った人が、そのコードの操作記録を調べようと思えば調べられます。** 報告するのは人数などの集計(たとえば、何人が参加し、何人が別の日にまた来たか)だけで、特定の人が何をしたかは報告しません。

アンケート({SURVEY_LINK})は外部のフォームで、個人情報は聞かず、招待コードとも結び付きません。

テストが終わったら、ログは報告のために運営者のパソコンに保管し、そのあと削除するか、ゲスト鍵を含めない形でアーカイブします。
