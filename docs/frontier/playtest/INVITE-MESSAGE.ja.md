# Wylls 友だちテスト: 招待メッセージ(日本語)

友だち一人ひとりの専用リンクに添えて送る短いメッセージのひな形です。`{LINK}` は招待 CSV のその人の行(`playtest-invite.sh` は `invite_code,url` を書き出します。送るのは `url`)、`{CONTACT}` は連絡先、`{SURVEY_LINK}` はアンケートのリンクです。`{NAME}` も含めて手で書き換えてください。参加者向けガイド([`TESTER-GUIDE.ja.md`](TESTER-GUIDE.ja.md))も一緒に(またはそのリンクを)送ります。**リンクは一人に一つ。グループには送らないでください。**コードを送る前に、その人がスマホかパソコンか何を使うかを聞いてください。iPhone は iOS 17 以降が必要で(それより古いとブラウザを替えても動きません)、古い iPhone の人にコードを無駄にしないでください。**シーズンが開いてから約10分たつまでは、最初のリンクを送らないでください([`OPERATOR-RUNBOOK.md`](OPERATOR-RUNBOOK.md) 第3節)。
