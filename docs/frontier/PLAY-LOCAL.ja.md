# ローカルで遊んで確かめる（TEST 専用・ワンコマンド）

devnet に出す前に、手元の Mac で遊べる版（遠征・広い土地・砦の奪取）を自分で確かめるための手順です。
広い土地（リング 129 から外）を見るのは `--wide` の世界だけです（§6）。ほかの世界の地図はリング 16 までです。
使うのは手元のローカルチェーンとテスト鍵だけです。本物の鍵・SOL・devnet・有料 API は一切使いません。
英語版: [PLAY-LOCAL.md](PLAY-LOCAL.md)

## 1. 最初に一度だけ入れるもの

スクリプトは何もインストールしません。足りないものがあれば、名前と入れ方を表示して止まります。

| もの | 版 | 入れ方の例 |
|---|---|---|
| Rust（rustup） | 1.89.0 と 1.95.0 | `rustup toolchain install 1.89.0 1.95.0 --profile minimal` |
| cargo-build-sbf と platform-tools | 3.1.9 / v1.52 | `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.9/install)"` |
| Node.js | 20 以上 | `brew install node`（`node -v` が v20 以上ならそのままで構いません） |
| git・python3 | macOS 標準 | 入っていなければ `xcode-select --install` |
| 空きディスク | 初回 20 GiB 以上 | |

初回のビルドは crate を取りにネットワークを使います。遊んでいるあいだも、keeper が公開の drand 乱数を HTTPS で読みます。

## 2. ワンコマンド

リポジトリの一番上で次を実行します。

```bash
scripts/play-local.sh
```

- 道具の確認、ビルド（前回から変更がなければ省きます）、世界の起動まで進み、ブラウザで `http://localhost:41920/` を開きます。
- 初回はビルドに約 3 分かかりました（2026-11-18、crate がキャッシュ済みの Mac）。2 回目以降は数秒です。
- 世界は 3 種類あります。
  - **保存する世界（既定）**: 通常の速さ（1 ターン 10 分）で、ルール上は終わりません。止めても、あとで
    `--resume` で同じ村から続けられます。チェーンは `.local/play-local/kept/` に、ページのテスト鍵はこのブラウザに保存されます。
  - **15 分の攻略デモ（`--demo`）**: ×60 の時計（1 ターン 10 秒）で、砦の奪取まで 15 分ほどで試せます。
    保存はされません。止めるとその世界は終わります。
  - **広い版（`--wide`）**: 準備のあいだに地図をリング 128 まで広げ、その外の広い土地（リング 129〜131）を開いた世界です。
    保存はされません。§6 を見てください。
- よく使う指定:
  - `--resume`: 前回の保存する世界を続けます
  - `--fresh`: 保存する世界を新しく始めます（`--resume` を付けないときと同じです）
  - `--random-map`: 新しい世界に、その世界だけの地図を作ります。付けないと**ローカルの世界は毎回同じ地図**です
    （ローカルのチェーンはいつも同じ時刻から始まるので、どの世界も同じ創世シードを引き、地形・村の候補地・自由都市が
    同じになります）。付けると、ランダムに選んだ過去の時刻から始まり、プログラムが変更なしのルールで別のシードを
    導きます。ルール上変わらないもの: 地形の六回対称と、（中心なしルールの PR #69 までは）各国の本拠が自分のくさびに
    あること。`--resume` とは一緒に使えません（保存した世界は作ったときの地図のままです）。
  - `--demo`: 15 分の攻略デモにします（`--speed 30` で ×30 にもできます）
  - `--wide`: 広い版の世界にします（§6）
  - `--ai 0`: AI 住民なし（既定は 2 人）。AI 住民は**既定で戦争をします**（fix-loop4）: 建設・訓練に加えて軍勢を編成し、
    届く他国の砦へ進軍して包囲・奪取します（1 ターンに 1 回の行動。保存する世界・`--random-map`・`--wide`・`--demo` のどれでも）
  - `--ai-peaceful`: AI 住民は戦争をしません（建設・収穫・訓練・編成だけ）
  - `--two`: 二人で一つの世界にします（§3.1。保存する世界でも `--demo` でも使えます）
  - `--port 41930`: ポートを変えます
  - `--lang en`: スクリプトの表示を英語にします
  - `--check-only`: 確認だけして終わります
  - `--help`: すべての指定を表示します
- ページの言語はブラウザに合わせて決まります。右上のボタンで 日本語 ⇄ English を切り替えられます。

## 3. 試すこと

保存する世界では 1〜5（参加・村・建設・訓練・編成）を試し、§4 の手順で止めて続きから再開します。
編成した軍勢が動けるのは、ターンが決着してから（通常の速さで約 17 分後）です。
6〜8（砦・衝突・奪取）は `--demo` で 15 分ほどで試せます。

**保存する世界（1×）では、最初の村から届く他国の砦はありません**（不具合ではなく、ルールと時計のためです）。
- 世界の始まりに州があるのは第2〜3輪だけで、そこはすべて、どこかの国の本国（heartland）です。本国の砦は奪い合いの
  対象になりません（`fkeepreach.mjs` の `contestableKeeps`、ルールの `heartland_safe`）。なので「この軍勢がいま届く
  他国の砦はありません」と出ます。
- 奪い合える砦があるのは、次の第4輪が開いてからです。第4輪は、くさびの村を置ける場所の 65% に村が置かれると開きます
  （OpenRing の混み具合のルール）。AI 住民 2 人と人間 1〜2 人では、まず届きません。
- 第4輪が開いても、1× では砦までの進軍に数ターン（1 ターン 10 分なので 1 時間以上）かかります。15 分の確認には収まりません。
- `--demo` は、テスト用の参加者で第4輪を開き、時計を ×60 にするので、15 分ほどで砦まで試せます。
- これは TEST 用の preset の調整では直せません（砦の本国保護は devnet と同じルールです）。保存する世界では 1〜5 と §4 を、
  砦は `--demo` で確かめてください。

**中央（第0〜1輪）について**: 地図の中央の 7 州（第0〜1輪）には、この世界では州がありません。いまのシーズンのルールは、
まだ中央を普通の土地にしていないためです（⑭ R2 の切り替え `CENTRE_PLAYABLE` は、ページの地形・道のりのモジュールが
対応するまで off です）。調べると「第1輪（中央・州なし）」と出て、村も置けず、進軍の行き先や通り道にもできません
（2026-11-19 に修正・fix-b14-b16。前は「生まれるところです」と出て、そこへの進軍が送れてしまい、軍勢が戻りませんでした）。
もしそういう進軍がチェーンに届いても、到着ターンの窓が閉じたあと、軍勢は「敗走」として村に戻ります（兵は半分になります）。

1. **参加**: 「世界を開始（保存された世界は続きから）」（`--demo` では「新しい世界を開始」）→「国を選ぶ」→ 旗を一つ選ぶと、下のボタンが「（国の名前）で始める」に変わるので、それを押します。最初の村は自動で置かれます。
   AI 住民はボレアリスとエンバーに入ります。それ以外の国を選ぶと、AI と同じ国の村置きでぶつかりません。
2. **村**: 「ここが、あなたの村です。」が出たら成功です。地図の上の「鉱石 +2」の表示を見てください。
   「地形の鉱石なし」の村は、兵を 600 人ほどまでしか増やせません。
3. **建設**: 「最初の建設を選ぶ」→ 農場の「建てる」。約 1 分（ゲーム内）で完成します。
4. **訓練**: 下のバーの「訓練」→「最大 500」→「槍兵 500 を訓練する」。訓練はすぐ終わります。
5. **編成**: 村の画面の「兵」→「全部（500）」→「編成する」。
   「この州はまだ前のターンの決着が済んでいません」と出ているあいだは押せません。数秒待って、消えたら押してください。
   「立っている 1」になれば動かせます。
6. **砦へ進軍**: 右上のガイドが「届く砦を見る」になったら押します。
   ずっと「軍勢の準備を確かめる」のままなら、下のバーの「国と領土」を一度開くと切り替わります。
   砦の行を選んで「確認した命令で出発」を押します。
   赤い「まだ決着が済んでいません」が出ていないときに押してください。「最初の出陣」が出れば出発しています。
7. **衝突の確認**: 着いたターンに「戦闘 … 衝突が決着しました」が出ます。「報告」→「このブラウザで確かめる」を押し、
   「一致：このブラウザで計算し直した結果はチェーンの記録と同じです」が出れば確認できています。
   お知らせが消えたあとも、下のバーの「その他」の一覧に「報告」ボタンが残っています。
8. **奪取**: 砦のマスを 72 ターン保つと奪取です（×60 で約 12 分以上）。地図の砦の上の「砦を保持中」と丸い数字、
   または衝突の報告の「奪取まで N/72 ターン」で進み具合を見られます。

### 3.1 二人で一つの世界（`--two`）

ふつうは、ブラウザごとに別の世界になります（ランチャーは「ブラウザ（アドレス）ごとに一つの世界・同時に2つまで」です）。
二人で同じ世界に入るには `--two` を付けます。

```bash
scripts/play-local.sh --two            # 保存する世界を二人で
scripts/play-local.sh --demo --two     # 15 分の攻略デモを二人で
```

1. 1 人目は、いつもどおり `http://localhost:41920/` を開いて「世界を開始」を押します。「もう一人のプレイヤーを待っています」
   と出て、待ちます（約 4 分。過ぎたらもう一度押します）。
2. 2 人目は、**別のブラウザ**（または別のプロファイル）で同じアドレスを開くか、同じブラウザなら
   **`http://127.0.0.1:41920/`** を開いて、同じボタンを押します。保存する世界のテスト鍵はブラウザとアドレスごとに一つなので、
   同じブラウザの別のタブでは同じプレイヤーになってしまいます。
3. 二人がそろうと、一つの世界が始まり、それぞれが自分の国を選んで村を置きます。進軍や戦いは同じ世界の中で起きます。
- `--resume` すると、同じ二人の世界に戻ります（`--two` を付けなくても構いません）。どちらが先に押しても、待たずに二人分の世界が
  開きます。それぞれ前回と同じブラウザ・同じアドレスで開いてください。
- 一人用で始めた保存する世界は、あとから二人用にはできません（`--fresh --two` で新しく始めます）。
- どちらかが「世界を終了」すると、二人とも止まります（保存する世界なら `--resume` で続けられます）。3 人目は入れません。


## 4. 止める・あした続ける

1. 止めるときは、スクリプトを動かしている端末で **Ctrl-C** を押します。世界を閉じてから終わり、
   ログの場所と「この世界は保存されています。続きは同じブラウザで: scripts/play-local.sh --resume」を表示します。
2. ブラウザのタブは閉じても構いません。保存する世界では、ページのテスト鍵はこのブラウザに残ります。
3. 次の日に、同じ Mac・同じブラウザで次を実行します。

   ```bash
   scripts/play-local.sh --resume
   ```

   同じアドレス（`http://localhost:41920/`）が開きます。「世界を開始（保存された世界は続きから）」を押すと、前回の村に戻ります。
   止めていたあいだ、世界の時計は止まっています。
- `--resume` は、前回と同じポートと AI 住民の数で開きます（違う `--port` や `--ai` を付けると断ります）。
  ブラウザはテスト鍵をアドレスごとに覚えているためです。
- `git pull` などでプログラムが変わると、前の世界は続けられません。スクリプトがそう表示して止まるので、
  `--fresh` で新しい世界を始めてください。
- `--resume` が開くのは、いちばん最後に始めた保存する世界だけです。`--fresh` で新しい世界を始めると、前の世界のフォルダは
  残りますが、`--resume` では新しいほうが開きます。前の世界に戻すには、`.local/play-local/last-kept` の中身を
  そのフォルダの場所（`…/.local/play-local/kept/<日時>`）に書き換えます。
- 世界は既定で 90 分たつとプロセスが止まります（`--minutes` で変えられます）。保存する世界なら、そのあとも `--resume` で続けられます。
- テスト鍵を消したいときは、ページのパネルの「このブラウザに保存した試験用の鍵を消す」を押します。
  世界のフォルダ（`.local/play-local/kept/<日時>/`）は自分で消すまで残ります。
- `--demo` の世界は保存されません。止めたら、そのブラウザのタブを閉じてください（メモリ上のテスト鍵が消えます）。

## 5. 困ったとき・知らせ先

- ログの場所:
  - 保存する世界: `.local/play-local/kept/<日時>/`（`launcher-<日時>.log`、`persist/<アドレス>/starts/<回>/` に runner・herald・relay・operators のログ）
  - `--demo` と `--wide`: `.local/play-local/worlds/<日時>/`（`launcher-<日時>.log` と、世界ごとのフォルダ。`--wide` では
    世界のフォルダの `wide-land.json` に、広げたリングと開いた州が書かれます）
- 知らせ先は GitHub の Issue（r0ze998/wylls）です。画面のスクリーンショットと、上のフォルダの場所を添えてください。
- 知られている問題（2026-11-18 時点）:
  - （2026-11-19 に修正・fix-b14-b16）第1輪のマスへの進軍が送れてしまい、軍勢が「封を開ける鍵を待っています」のまま戻らなかった件。
    ページは中央（第0〜1輪）を行き先にも通り道にもしなくなり、ランナーはそういう進軍を敗走として村に戻します。
  - （2026-11-19 に修正・fix-march-held）チェーンのノードが受け付けなかった進軍（ターンの変わり目に送ったときなど）は、
    「進軍は送られていません」と理由が出て、命令のカードがそのまま残ります。軍勢は動かせるので、確かめてもう一度押してください。
    送信済みで結果がまだわからない進軍は、ページが約 2 分のあいだ自動で確かめ、期限切れなら軍勢を解放します。
  - タイトル画面の「10 分ごとにターンが変わり」と、開始画面の「既定は開始から2時間」は、この試験世界には当てはまりません
    （×60 では 1 ターン 10 秒、世界は 90 分）。
  - （2026-11-19 に修正・fix-march-held）×60 で広い土地の試し機能の FoldLand が計算量の上限で断られていた件は、
    計算量に収まる分だけ畳むようにして直りました（runner.out の `fold_fit` は、一度に畳むターン数を減らしたしるしです）。

## 6. 広い版（`--wide`、TEST 専用）

```bash
scripts/play-local.sh --wide
```

- シーズンは devnet の遊べる版と同じ設定 `S1_DEVNET_WIDE_7D`（PR #70。中心なしの国の配置、地図の上限リング 128、
  θ 1 bp、州の基金 36 SOL）で作ります。
- 世界の準備のあいだ（ページで「国を選ぶ」より前）に、プログラム自身の命令で地図を **1 ターンに 1 リングずつ**
  リング 128 まで広げます。そのあいだだけ、ローカルのチェーンの時計をターン単位で進めます（準備は約 11 秒、
  2026-11-19 の Mac）。準備のあと、時計は `--speed` 倍（既定 ×60、1 ターン 10 秒）で、ゲームはターン 130 ごろから始まります。
  - 各国に 1 人ずつテスト用の住民が中心近くに村を置きます（地図が広がる条件「どこかのくさびに住民がいる」のため）。
    中心の州は 1 つだけ先に開き、残りは広げたあとに開くので、どの州もゲームの始まりのターンまで決着済みです。
  - リング 129〜131 の広い土地を開き（WideRequestRingSeed / WideConsumeRingSeed / WideSetRules / WideOpenProvince）、
    各くさびの真ん中あたりに 6 州ずつ、計 108 州を置きます。そのすぐ内側のリング 128 の州（42 州）も開きます。
  - リング 5〜127 の州は開きません（devnet の keeper の `lazy_provinces` と同じです）。地図には地形だけが描かれます。
- 広い土地を見る:
  - 普通の地図と「全体図」: リング 129〜131 の記録された州が、その地形と城砦を持つ国の色で、ハートランドの外側に描かれます
    （「広い土地／第129–131輪・記録」の札が六つの方向に出ます）。遠くからは国の色のモザイク、近づくと地形の上に国の色、
    いちばん近くでは 61 マスの地形と拠点です。記録にない場所は雲のままです（読み取り専用。村を置けるようにはなりません）。
  - （霧の世界（§7）では、広い土地も見たところまでしか描かれず、下の「記録」の画面は出ません。）
  - 地図の右下の「記録」→「記録された世界（読み取り専用・実験中）」。右の一覧で「第129輪」の州を選び、
    「ここを原点にする」を押してから拡大すると、リング 128（金色）とリング 129〜131（六つの国の色）が並んで見えます。
  - 「全体図」では、地図の真ん中に自分の村、六つの角の外側に広い土地が見えます。
  - 広い土地の村（自分のも AI 住民のも）は、その国の印で描かれます。近づくとその村の場所に、遠くからと「全体図」では
    州に一つの印です（伝令が記録したあと）。
- 広い土地で遊ぶ（2026-11-19 の TEST 専用ルール。devnet の設定・プログラムは変わりません）:
  - **この世界だけのシーズンのバイト**: 中心なし（⑭ R2、`centre` = 1。リング 0〜1 は普通の土地、リング 1 の 6 州を開く。
    (0,0) はページの地形カーネルがまだ中心を描くので開きません）と、`outpost_tier_min` = 0（「集落」の最初の村でも
    広い土地を申し込める。`S1_LOCAL_7D` は 1 =「町」。2026-11-20 のオーナー決定 Q-W1 から devnet の広い版
    `S1_DEVNET_WIDE_7D` も 0）。この世界はプリセットを変えません。
  - 準備で、各国 2 つずつのリング 128 の州（広い土地のとなり、くさびを分けて）に、テスト住民が本物の申し込み
    （FileTicket → ビーコンのアンカーと種 → SettleTicket）で村を置きます。
  - 「国を選ぶ」のあと、ページは最初の村の候補として **辺境（リング 128）の州を先に** 出します。辺境の村は 1 区画の
    申し込み（FileTicket）で、ターンの終わりにランナーが決めます（PlaceHome はシーズンの元の r_max 16 より外の州を
    指せないため）。
  - 村の画面の「広い土地に村を出す（テスト）」で、射程 3 以内の広い土地の州に 2 つめ・3 つめの村を申し込みます
    （0xD9 WideClaimSite。費用は村の蔵から: 木材 1,200 など。決着はランナーが WideSettleTicket / WideFinalize で）。
  - 時計は `--speed`（既定 60、10〜60）倍。集落の生産では費用がたまるのに 30 ゲーム時間ほどかかるので、×60 で約 30 分。
  - AI 住民（`--ai N`）も辺境に村を申し込み、蔵をためて広い土地を申し込み、軍勢を広い土地へ遠征させます。
    既定では戦争もします（届く他国の砦へ進軍）。1 ターンに 1 行動です。
  - 始まってしばらくは、辺境の州の決着が数十ターン遅れています（世界の準備のあと、進行役が追いつくまで）。そのあいだ
    編成や出発は「送信待ち」になり、ページは「この州の決着が N ターン遅れています。このマシンの負荷が高く…」と
    言って、追いつき次第 1 回だけ送ります（押し直す必要はありません）。

## 7. 霧（戦場の霧、ローカルの試験世界すべて）

ローカルの試験世界では、Civ のようなプレイヤー視点で地図を描きます。表示だけの霧です。ローカルチェーンの記録はすべて公開のまま
で何も変わらず、devnet にも何も変わりません。ローカルの試験世界でないページ（devnet、観戦ページ、練習）は今までどおりです。

- **いま見えるもの:** 自分の村と軍勢のまわり、自分の国の村と自分の国が持つ州のまわり。同盟国とは視界を分けません。
- **前に見たもの:** 最後に見たときのようす（薄く）のまま地図に残ります。村、砦とその持ち主はそのときのままです。
  世界とプレイヤーごとに、このブラウザに残します（`localStorage` のキー `ps-ffog:v1:…`）。
- **まだ見ていない土地:** 地図でも「全体図」でも白紙です。地形も村も砦も国の色も出ません。
- **ほかの国の軍勢・進軍・衝突・争奪:** いま見えている場所でだけ出ます（残像は残しません）。自分の村へ向かう敵の進軍は、
  見えている場所から出発したとき、または到着の 3 ターン前から知らせます。
- 砦の一覧、調べる画面、年代記、知らせ、ミニマップも同じ決まりです。「記録」の画面（記録されたすべての州）と、地図の見かたの
  観戦ページへのリンクは、霧の世界では出ません。
- スイッチは一つ: `permutation-server/web/frontier/map/fog.mjs` の `LOCAL_FOG`（`false` で今までどおり）。半径などの
  決めごとは同じファイルの `FOG_RULES` にあります。
