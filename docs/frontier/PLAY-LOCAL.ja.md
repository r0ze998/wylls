# ローカルで遊んで確かめる（TEST 専用・ワンコマンド）

devnet に出す前に、手元の Mac で遊べる版（遠征・広い土地・砦の奪取）を自分で確かめるための手順です。
使うのは手元のローカルチェーンとテスト鍵だけです。本物の鍵・SOL・devnet・有料 API は一切使いません。
2026-11-23 時点の main（#172 まで）に合わせています（#157〜#172: 広い土地の村の軍勢の作り直しと遠征の占拠の表示 §4、`--wide` での外部の AI 住民 §11、開けるアドレスの決まりとページのファイルを書き換えたとき §9、① の板の英語 §13。残っている問題は §8）。英語版: [PLAY-LOCAL.md](PLAY-LOCAL.md)

## 1. 最初に一度だけ入れるもの

スクリプトは何もインストールしません。足りないものがあれば、名前と入れ方を表示して止まります。

| もの | 版 | 入れ方の例 |
|---|---|---|
| Rust（rustup） | 1.89.0 と 1.95.0 | `rustup toolchain install 1.89.0 1.95.0 --profile minimal` |
| cargo-build-sbf と platform-tools | 3.1.9 / v1.52 | `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.9/install)"` |
| Node.js | 20 以上 | `brew install node`（`node -v` が v20 以上ならそのままで構いません） |
| git・python3 | macOS 標準 | 入っていなければ `xcode-select --install` |
| 空きディスク | 初回 20 GiB 以上 | |

初回のビルドは crate を取りにネットワークを使います。遊んでいるあいだも、keeper が公開の drand 乱数を HTTPS で読みます。

## 2. ワンコマンド

リポジトリの一番上で実行します。道具の確認 → ビルド（変更がなければ省きます）→ 世界の起動 → ブラウザで
`http://localhost:41920/` を開く、まで進みます。初回のビルドは約 3 分、2 回目以降は数秒です。

```bash
scripts/play-local.sh                 # 保存する世界（1 ターン 10 分。止めても --resume で続き）
scripts/play-local.sh --demo          # 15 分の攻略デモ（×60、1 ターン 10 秒。保存なし）
scripts/play-local.sh --wide          # 広い版（辺境と広い土地。×60。保存なし）→ §4
scripts/play-local.sh --coexist --demo --two   # ② 権利（在庫の交換）を二人で一周（×60。保存なし）→ §10（⑨⑩ は §12、① の依頼は §13）
scripts/play-local.sh --demo --external <アドレス>   # 外部の AI 住民を入れる（×60。保存なし）→ §11
```

広い版は `--wide` だけで起動します（`--demo` `--resume` `--fresh` `--two` と一緒に付けると、どれを付けたかを言って止まります。`--coexist` とも一緒には使えません。`--external` は使えます。
`--ai` `--ai-peaceful` `--random-map` `--speed` `--minutes` `--port` `--no-coop-board` は一緒に使えます）。

世界は 3 種類です。どれも霧（§5）がかかり、AI 住民は既定で戦争をします。`--coexist` は 4 つめの世界ではなく、
保存する世界か `--demo` を ②+⑨+⑩ つきのプログラムで動かす指定です（② 権利 §10、⑨ 工房貸し・⑩ 預かり・奪取 §12、① の依頼の配達 §13）。
`--external` も世界の種類ではなく、保存する世界・`--demo`・`--wide` に外部の AI 住民を受け入れる指定です（§11）。

| 世界 | 時計 | 保存 | 向いている確認 |
|---|---|---|---|
| 保存する世界（既定） | 通常（1 ターン 10 分） | あり（`.local/play-local/kept/`、テスト鍵はブラウザ） | 参加・村・建設・訓練・編成、止めて続ける |
| `--demo` | ×60（`--speed` で 10〜60） | なし | 砦へ進軍・衝突・奪取を 15 分で |
| `--wide` | ×60（`--speed` で 10〜60） | なし | 辺境の村 → 広い土地の村 → 遠征 → 広い土地の中の進軍 |

指定:

| 指定 | 意味 | 一緒に使えないもの |
|---|---|---|
| `--resume` | 最後に始めた保存する世界を続けます（同じブラウザ・同じポート・同じ AI の数） | `--fresh` `--demo` `--wide` `--random-map`、違う `--port` / `--ai` |
| `--fresh` | 保存する世界を新しく始めます（何も付けないときと同じ） | `--resume` `--wide` |
| `--demo` | 15 分の攻略デモ | `--resume` `--wide` |
| `--wide` | 広い版（§4） | `--demo` `--resume` `--fresh` `--two` `--coexist` |
| `--random-map` | 新しい世界に、その世界だけの地図。付けないと**ローカルの世界は毎回同じ地図**です | `--resume` |
| `--ai N` | AI 住民の数 0〜4（既定 2）。**既定で戦争をします**: 届く他国の砦へ進軍・包囲（1 人 1 ターンに 1 行動） | |
| `--ai-peaceful` | AI は砦へ進軍しません（建設・収穫・訓練・編成。`--wide` では辺境と広い土地の村・遠征もします） | |
| `--two` | 二人で一つの世界（§3.1） | `--wide` `--external` |
| `--coexist` | ②+⑨+⑩ つきの世界（§10・§12。① の依頼の隊商もこの世界だけ、§13）。保存する世界か `--demo`。`--ai` `--two` `--random-map` `--resume` `--external` と使えます | `--wide` |
| `--external ADDR[,ADDR]` | 外部の AI 住民を 2 人まで、**公開アドレス**で受け入れます（§11。鍵は渡しません）。読み取り専用の MCP サーバーも 127.0.0.1 で起動します。保存する世界・`--demo`・`--wide`。`--ai` `--random-map` `--coexist` `--resume` と使えます | `--two` |
| `--no-mcp` | `--external` のとき、MCP サーバーを起動しません | `--external` なしでは使えません |
| `--no-coop-board` | ① 協力の板と ⑮ の「称号と記録」のカードを付けません（付けるのが既定、§13） | |
| `--speed N` | `--demo` / `--wide` の時計 10〜60（既定 60） | 保存する世界 |
| `--minutes N` | 世界のプロセスが止まるまでの分 15〜240（既定 90）。`--wide` でもこの時間で止まります（local-perf の修正前は、長く動いた広い版の世界がこれを過ぎても止まらないことがありました） | |
| `--port BASE` | ページのポート（既定 41920）。BASE から 22 個（`--ai 0` なら 14 個）を使います。`--external` はさらに 8 個と、MCP サーバーの 1 個（既定なら MCP は 41950、`--ai 0` なら 41942。`--no-mcp` なら使いません）。41000〜41999 の中で、41904〜41907 と 41970 を含まないこと | |
| `--lang ja\|en` | スクリプトの表示の言語（ページは右上のボタンで切り替え） | |
| `--no-open` `--no-build` `--rebuild` `--check-only` `--print-plan` | 開かない / ビルドしない / 必ずビルド / 確認だけ / 設定と起動コマンドを表示して終わる | |
| `--cluster NAME` | `localnet` だけ受け付けます（ほかの名前は断って終わります。devnet・mainnet にはつなぎません） | |
| `--coexist-node` | ページのない ②⑨⑩ のノードだけ（開発用。遊ぶ用ではありません） | `--port` 以外のすべて |

- AI 住民が入る国は決まっています: 1 人目ボレアリス、2 人目エンバー、3 人目シンダー、4 人目フィヨルダル。
  **AI のいない国**（`--ai 4` ならアステルかダンマール）を選ぶと、村の場所の取り合いになりません。
- `--random-map` は、ランダムに選んだ過去の時刻から世界を始め、プログラムが変更なしのルールで別の創世シードを導きます。
- ページを開けるアドレスは `http://localhost:<ポート>/` と `http://127.0.0.1:<ポート>/` の 2 つだけです（ほかの名前や別のマシンからは開けません。§9）。
- 止めるのは端末の **Ctrl-C** です（§6）。

## 3. 15 分のチェック

`--demo` で 1〜8 を通せます。保存する世界では 1〜5 をして、§6 の手順で止めて続きから再開します
（1× では、編成した軍勢が動けるのはターンが決着してから＝約 17 分後です）。

1. **参加**: 「世界を開始（保存された世界は続きから）」（`--demo` では「新しい世界を開始」）→「国を選ぶ」→ 旗を一つ選び、
   「（国の名前）で始める」を押します。最初の村は自動で置かれます。鍵のカードやウォレットの確認は出ません。
2. **村**: 「ここが、あなたの村です。」が出たら成功です。地図の上の「鉱石 +2」を見てください。
   「地形の鉱石なし」の村は、兵を 600 人ほどまでしか増やせません。
3. **建設**: 「最初の建設を選ぶ」→ 農場の「建てる」。約 1 分（ゲーム内）で完成します。
4. **訓練**: 下のバーの「訓練」→「最大 500」→「槍兵 500 を訓練する」。すぐ終わります。
5. **編成**: 下のバーの「編成」（右上のガイドが「軍勢を編成する」なら、それを押しても同じ）→「全部」（送るときの控え全部です。カードを開いたあとに入った訓練の兵も含みます。fix-loop9 LP9-5）→
   「槍兵 N をここに集める」。「この州はまだ前のターンの決着が済んでいません」と出ていても**押して構いません**。
   送信待ちになり、整い次第 1 回だけ送ります（押し直しは不要。兵種・兵数が変わると取り消します）。
   ×60 の `--demo` でも、この待ちはまれになりました（#146: 自分の州が編成できる状態にある時間は約 8 割。前は約 3 割。
   verify-pr146 では文が出ずにすぐ送られました。§8.2）。
   村の画面の「兵」の「編成する」は、決着待ちのあいだ押せません（送信待ちになるのは下のバーの「編成」だけです）。
   軍勢が整列するまでのあいだ、右上のガイドは「ガイド 3/7 軍勢の整列を待つ」と出ます（その間にできることがあれば
   「待つ間に：建設をひらく」のように添えます）。「軍勢の準備を確かめる」か「届く砦を見る」になれば編成できています。
6. **砦へ進軍**: 右上のガイドが「届く砦を見る」になったら押します（「軍勢の準備を確かめる」のままなら、下のバーの
   「国と領土」を一度開きます）。砦の行を選んで「確認した命令で出発」。決着待ちのときは、同じ命令のまま整い次第 1 回だけ
   送ります。「最初の出陣」が出れば出発しています。
   - 一覧が「届く砦 0」（「見えている他国の砦で、この軍勢がいま届くものはありません。」）のときは、村のまわりから他国の
     砦が見えていません（`--random-map` ではよくあります）。右上のガイドと一覧のカードに「進軍で地図から選ぶ」が出ます（#130）。
     それを押すか下のバーの「進軍」を押し、地図で第1輪の州の砦のマス（霧で白紙でも押せます）を行き先に選んで「確認した命令で出発」で
     攻められます（行き先は「見えていない土地」と表示されます）。進軍は体力を 10＋2×マス数
     使い（9 マスなら 28、32 マスなら 74。上限 120）、体力は 1 ターンに 1 戻ります。遠い白紙のマスへ先に偵察に出すと、
     体力が戻るまで砦へ出発できないことがあります（loop-play6 では約 30 ターン待ちました）。
7. **衝突の確認**: 着いたターンに「戦闘 … 衝突が決着しました」が出ます。「報告」→「このブラウザで確かめる」で
   「一致：このブラウザで計算し直した結果はチェーンの記録と同じです」が出れば確認できています。
   お知らせが消えたあとも、下のバーの「その他」の一覧に「報告」ボタンが残っています。
8. **奪取**: 砦のマスを 72 ターン保つと奪取です（×60 で約 12 分以上、1× では約 12 時間）。地図の砦の上の「砦を保持中」と
   丸い数字、または衝突の報告の「奪取まで N/72 ターン」で進み具合を見られます。保持のターンは、州が決着しても
   飛ばされても 1 ターンに 1 つ数えます（#120 の確認: ×60 の `--wide --ai 4` で AI が 11 回奪取、どれも保持 72 ターン）。

知っておくこと:

- **中央はありません（ローカルの世界だけのルール、#88）。** 第1輪の 6 州は普通の土地で、それぞれどこかの国が砦を持って
  始まります（いつもの地図では 6 つの国が 1 州ずつ）。本国（第2〜3輪）の砦は守られていて奪えませんが、**第1輪の砦は奪い合えます**。保存する世界でも AI 住民は
  ここへ進軍し（#98 の確認では開始から 8 ターンめに出発、12〜13 ターンめに衝突）、自分の国の砦が攻められると知らせ
  「州 P,Q の砦を （国）が攻めはじめた／あなたの国が守っている」が出ます。「国と領土」の「他国が占拠を進めている、あなたの国の砦
  … 守りに向かう」には、あなたの軍勢が届かない砦も出ます（「いまのあなたの軍勢では届きません。」と付きます。#130）。真ん中の 1 州 (0,0) だけは「第0輪（中央・州なし）」で、
  行き先にも通り道にもなりません。最初の村は第2輪より外にだけ置けます。
- **霧のため、砦の一覧に出るのは見えている他国の砦だけです**（§5）。「見えている他国の砦で、この軍勢がいま届くものは
  ありません。」は不具合ではありません。
- 1× の保存する世界では、包囲は見られますが、奪取（72 ターン＝12 時間）まではまず見られません。奪取は `--demo` か
  `--wide` で確かめてください。

### 3.1 二人で一つの世界（`--two`）

ふつうは、ブラウザ（アドレス）ごとに別の世界になります（同時に 2 つまで）。二人で同じ世界に入るには `--two` を付けます。

```bash
scripts/play-local.sh --two            # 保存する世界を二人で
scripts/play-local.sh --demo --two     # 15 分の攻略デモを二人で
```

1. 1 人目は `http://localhost:41920/` で「世界を開始」を押します。「もう一人のプレイヤーを待っています」と出て、待ちます
   （約 4 分。過ぎたらもう一度押します）。
2. 2 人目は、**別のブラウザ**（または別のプロファイル）で同じアドレスを開くか、同じブラウザなら
   **`http://127.0.0.1:41920/`** を開いて、同じボタンを押します（テスト鍵はブラウザとアドレスごとに一つです）。
3. 二人がそろうと一つの世界が始まり、それぞれが国を選んで村を置きます。
- `--resume` で同じ二人の世界に戻ります（`--two` は付けなくて構いません）。前回と同じブラウザ・同じアドレスで開いてください。
- 一人用で始めた保存する世界は、あとから二人用にはできません（`--fresh --two` で新しく始めます）。
- どちらかが「世界を終了」すると二人とも止まります。3 人目は入れません。`--wide` は一人用です。

## 4. 広い土地を確かめる（`--wide`、約 60〜90 分）

```bash
scripts/play-local.sh --wide --ai 4 --minutes 180
```

広い版は `--wide` だけで起動します（`--fresh` `--resume` `--demo` `--two` は付けません。§2 の表）。

世界の準備（約 20 秒）のあいだに、プログラム自身の命令で地図をリング 128（辺境）まで広げ、その外の広い土地
（リング 129〜131、108 州）を開きます。ゲームはターン 140 ごろから、×60（1 ターン 10 秒）で始まります。
既定の 90 分では下の 4 まで届かないことがあるので、`--minutes 180` を付けてください。

1. **辺境の村**: 「国を選ぶ」で AI のいない国（`--ai 4` ならアステルかダンマール）を選び、「（国の名前）で始める」。
   場所は選びません。ページが**辺境（リング 128）の州**に村を申し込み（「辺境の村を申し込んでいます…」→
   「辺境の村の申し込みを送りました（ターン N、M ターン前）。世界の進行役がターンの終わりに決めます。…このページは待ち続けます。
   押し直す必要はありません。」）、数ターン（verify-pr130 では 3〜5 ターン。負荷が高いと約 60 ターン・約 10 分）で「（名前）の集落ができました」と出ます。
   村の名前に「仮」が付いているあいだは、村の画面の「収穫する」を一度押すと確定します（「…が確定しました」）。
   辺境の村には「初めての建設」（1 分）はなく、農場も 1 時間 30 分（×60 で約 1 分半）かかります。
   - 「（国の名前）で始める」は 1 回押せば通ります（#130。verify-pr130 では 8 回の参加がどれも 1 回）。村の場所を読んでいる
     あいだはボタンが「村を準備しています…」になって押せません。
   - 最初に「留守のあいだ：この端末では、このシーズンとウォレットで確認した記録がありません…」のカードが出たら、
     「確認した」を押して閉じます（世界がターン 140 ごろから始まるためで、不具合ではありません）。
2. **広い土地の村（×60 で約 30 分）**: 村の画面の「広い土地に村を出す（テスト）」に費用（木材 1,200 など）と候補の州が
   出ます。蔵がたまったら「ここに村を出す」。申し込みはターンの終わりに決まり、地図にその国の印で描かれます。
   いちばん簡単な開きかたは、左下の村の札の下に出る「W2」を押すことです（「遠方の村 第129輪（枠 2）」が開きます）。
   地図でその州を調べて「あなたの村（広い土地）」→「この村を開く」でも開けます。
   - 訓練（§3 の 4）は蔵の食料と金を使います。先に広い土地の村を出してから訓練すると、待ち時間が短くなります。
3. **遠征（辺境 → 広い土地）**: 辺境の村で訓練・編成し（§3 の 4〜5）、下のバーの軍勢（「槍兵 500」など）を選んで
   「境界への道を準備」を押します。
   1. 方角のボタン（東・北東・北西・西・南西・南東）か地図の破線のマスで一歩ずつ道を引き、「道から決まる終点」が
      広い土地の州（リング 129 以上）になるまで伸ばします。開いている広い土地は、リング 129〜131 のうち地図に描かれる
      州だけです。開いていない州が終点になると、カードにすぐ「終点の州 P,Q は、この世界ではまだ開いていません…
      いちばん近い開いた州は …（N 州先）です。」と出ます。
   2. 「地形・時間を確認」。「山や水のマスには進めません (N)」と出たら N 歩めが通れません。「一歩戻す」か「道を消す」で
      別の道にします（道は地形を見ずに引けてしまいます）。通れる道なら「到着候補：ターン A〜B」と、到着ターンを入れる
      ボタン（次の 3）が出ます。結果はカードの中で見える位置まで自動で送られます。読み取りの途中で世界の時計が進むと、
      ページが 2 回まで自動で読み直します（「…読み直しています（1 / 2 回目）…」）。それでも間に合わないと
      「読み取りの途中で世界の時計が進んだため… もう一度押してください。」と出るので、押し直します。
      読み取った結果は「この道を読み取った結果です。道を変えるまで出ています。」と添えて、道を変えるまで残ります（#137。
      loop-play8: 通れない道の「山や水のマスには進めません N 歩め（西）のマスで止まります。…」が 15 秒たっても出ていました）。
   3. 「間に合う候補（ターン N）を使う」を押します（×60。1× では「最も早い候補（ターン A）を使う」）。×60 では最も早い
      ターン A に、確認して送るあいだに時計が進む分（3 ターン）と、州の決着の遅れの分を足した候補が出ます。最も早いターン
      そのものは、次の「出発条件を確認」が終わるころにはもう過ぎていて、毎回断られていました（loop-play6 LP6-1、#130 で修正。
      verify-pr130 では 5 回の出発で、到着ターンを断られたのは 0 回）。押すと到着ターンの欄に入り、ページが道を読み直します。
      到着ターンを自分で入れる欄は、カードの下の「詳細」の中です（ふつうは要りません）。
   4. 「出発条件を確認」→「この読取時点では、軍勢と村の出発条件を満たしています。」が出たら「出発する（ローカルプレイ）」。
      - ×60 では「…満たしていません。 (NotResident)」がよく出ます（州の決着がターンの一部の時間しか整っていないため）。
        **ここだけは押し直しが要ります**: 1〜2 秒おいて「出発条件を確認」をもう一度押します。この確認は読み取りだけで、
        何も送りません（中継の送信の上限にも数えません）。verify-pr130 では 5 回の出発のうち 3 回が 1 回めに断られ、
        2〜3 回めで通りました（#130 の前: loop-play6 で 17 回・18 秒、fix-loop5 で 16 回・27 秒。#109 の前は約 60 回・約 10 分）。
      - ×60 では、確認の結果は世界の時計を読むたびに画面から消えます（0.3〜2 秒。verify-pr117 V117-1）。消えた直後でも、
        道と到着ターンを変えていなければ「出発する」は効きます: ページが出発条件を読み直し、整っていれば出発します（#130）。
        ボタンが見えなくなったら「出発条件を確認」から押し直します。
      - うまくいかないとき:
        「到着ターンの候補が、記録から計算した範囲に入りません。」＝ 到着ターンが早すぎます（3 のボタンを押し直すか、
        「詳細」の欄にもう少し先のターンを入れます）。「到着ターンはまだ入っていません。「地形・時間を確認」を押すと…」＝
        到着ターンの欄が空です（2 から）。
   5. 「出発が確定しました（ターン N に到着予定・移動枠 0）」が出れば出発しています。
   - **封は世界の進行役が開けます。** 到着のあと、地図の札は「ターン N に到着」→「到着 · 開封を待っています」→
     「到着 · 封は開きました · 結果の確定を待っています」と変わり、行き先の州が追いつくと進軍の画面に
     「結果を受け取りました　留まる：軍勢は広い土地の州に立っています（兵 500）」と出ます。待つだけで構いません
     （fix-loop5・verify-pr117・loop-play6 の 3 回とも、進行役が期間内に開けました）。
   - **広い土地の砦のマスに着いた遠征は、その砦を占拠します**（72 ターンで奪います）。進軍のカードが占拠を追います
     （fix-loop9 LP9-2。その州だけを約 1 ターンごとに読みます）:「遠征の軍勢が州 P,Q の砦を占拠中です：n / 72 ターン。…」→
     「砦を奪いました：軍勢は砦の守備兵になりました」と「結果：遠征の軍勢が州 P,Q の砦を奪いました。…」（知らせも 1 回出ます）、
     または「結果：州 P,Q の砦は奪えませんでした。…」。軍勢はそのマスから見えるので、州は地図に描かれます（広い土地には砦の印や
     軍勢の姿はまだ描かれません。verify-pr162）。「国と領土」では「あなたの軍勢が着いている他国の砦」に出ます（loop-play9 ではチェーン上で奪っても、ページは何も言いませんでした）。
   - 予備として、到着のターンにはこのページでも封を開けられます（境界のカードの中の「封を開けるか確認する」→
     「封を開く（ローカルプレイ）」）。#105 より前の、負荷の高いマシンの ×60 では進行役が約 10 秒の期間を逃したことが
     あります（§8）。「封を開ける期間が終わっています。(RevealWindowClosed)」と出たら、その遠征はもう決着しません。
   - 次の軍勢を出す前に、カードの「送信しました。確定はまだ確認できていません」の下の「結果を照合する」を一度押します
     （押さないと「出発する」が出ません）。
   - バーのボタンには「送信しません」と書いてありますが、ローカルではこのカードの最後のボタンで実際に出発します。
4. **広い土地の中の進軍（広い土地 → 広い土地）**: 2 の村を開くと「広い土地の軍勢（テスト）」のカードがあります。
   「次の一手（広い土地）」を押すと、槍兵を訓練 → 軍勢を編成 → 隣の州の砦へ進軍、と一手ずつ進みます。
   **1 手につき 1 回押して、あとは待ちます**（訓練・編成・進軍で合わせて 3 回）。
   - 村の見出しには「この村の記録の表示は読み取り専用です。命令は、下の「広い土地の軍勢（テスト）」だけが送ります
     （訓練・編成・進軍）。収穫・建設・隊商・追いつかせる は、この村には送れません。」と出ます（#130）。
   - 次の一手の理由は、カードにページの言葉で出ます（#130。英語の画面では英語）: 「広い土地の村で槍兵 N を訓練します。」→
     「広い土地の村で槍兵 N の軍勢を編成します。」→「軍勢（兵 N）が州 P,Q の砦へ進軍します（（国）が保持）。到着はターン N です。」。
     進軍に出たあとは「軍勢は進軍に出ています。」で、打つ手はありません。
   - 新しい村の州は、最初はチェーンより大きく遅れます（loop-play4 では村ができてから 77 ターン、loop-play5 では
     最大約 180 ターン遅れました）。**州が遅れているあいだは、押し続けないでください。** カードが「この村の州の決着が
     N ターン遅れています。…このページが約 1 ターンごとに自動で確かめ、送れるようになったら一手を送ります。」と出して
     自分で待ちます（ボタンは「待っています…（押す必要はありません）」になって押せなくなり、「待つのをやめる」で
     止められます）。待つ理由はほかに「軍勢が整列中か休んでいます。」などがあります。
     送るあいだにターンが変わって断られたとき（NotResident）や、進軍の送信が 1 回失敗したときも、次のターンに自動で
     もう一度送ります（verify-pr117: 「次の一手」を 2 秒おきに 10 分押し続けても、ページが送ったのは 4 回だけで、
     訓練 → 編成 → 進軍まで進みました。loop-play6: 187 ターンの遅れのあいだカードが自分で待ち、約 3 分で送りました）。
   - 進軍の封は世界の進行役が開け、行き先の州が遅れていてもまとめて追いつかせます（verify-pr106 では到着から数分で
     開封・衝突・決着）。下のバーの「進軍」の一覧には、広い土地の中の進軍は出ません。砦の上に 72 ターンとどまると
     砦を奪います。進軍のようすは同じカードに出ます（#130。約 1 ターンごとに読み直します）:
     「軍勢は州 P,Q の砦へ進軍中です。到着はターン N です（いまはターン M）。」→「到着ターン N を過ぎました。到着先での決着を
     待っています（州の決着が遅れると数ターンかかります）。」→「結果：軍勢（兵 N）は州 P,Q に立っています。」と、砦のようす
     （「砦は（国）が保持しています（あなたの国は占拠できていません）。」「あなたの国が砦を占拠中です：n / 72 ターン。」
     「砦はあなたの国のものです。」）。負けたときは「結果：軍勢は州 P,Q に残れませんでした（戦いに敗れました）。」です。
     負けた軍勢が兵 100 未満で村に戻ったとき（兵 100 未満の軍勢は進軍できず、ローカルのページは解散もできません）は、続けて
     「生き残った兵 N が村に戻っています。…新しい軍勢を作ります。 次の一手：槍兵 100 を訓練します（兵 100 そろうと編成できます）。」と
     「次の一手を送れます（新しい軍勢づくり）。自動では送りません。…」が出ます。押すと訓練、もう一度押すと編成し、新しい軍勢が
     最初の軍勢と同じように進軍します（fix-loop9 LP9-1。それまではカードが「軍勢が整列中か休んでいます。」のまま止まっていました）。
     テスト世界では、1 つの村から広い土地の中への進軍は 2 回までです。2 回目のあとは、最後の結果と「…テスト世界では 2 回までです。…」が出ます。
     （verify-pr130 で「…進軍します」→「…過ぎました…」→「結果：軍勢（兵 76）は州 -63,-66 に立っています」を確認）
- **見えかた**: 広い土地は、普通の地図と「全体図」の六つの角の外側に、**自分が見たところまで**描かれます（霧）。
  「支配する州」と国の順位は、辺境と広い土地の砦も数えます（#102）。
- **AI 住民**も辺境に村を申し込み、蔵をためて広い土地に村を出し、戦争をします（loop-play6: 広い土地の村 4、砦への
  出発 70）。ただし戦場は相手の国の辺境なので、霧の中でほとんど見えません。自分の国の砦が攻められたときだけ
  知らせが出ます。AI の辺境 → 広い土地の遠征も届きます（#130。verify-pr130 で 10 回中 10 回。その前の loop-play6 では
  454 回中 0 回でした）。AI の広い土地の中の進軍も届きます。
- **AI の奪取を見たいとき**は `--wide --speed 15`（1 ターン 40 秒）が安定です（#102 の確認: 順位が遅れず、開始から
  約 90 ターンで奪取が順位に反映）。ただし広い土地の村の費用がたまるのは約 2 時間後になります。runner-throughput の
  変更からは ×60 でも順位は遅れません（数ターン遅れ）が、戦いはすぐに過ぎていきます。
- 時計が速いほど、このマシンの負荷で世界の進行が遅れます（§8）。ほかの重い作業を止めて試してください。

## 5. 霧（ローカルの試験世界すべて、#93）

Civ のようなプレイヤー視点です。表示だけの霧で、ローカルチェーンの記録は公開のままです。devnet のページにも同じ霧が
かかります（fog-devnet、ランブック §7 P5）。

| | 見えるもの |
|---|---|
| いま見える | 自分の村と軍勢のまわり、自分の国の村と、自分の国が持つ州のまわり。同盟国とは視界を分けません |
| 前に見た | 最後に見たときのようすが薄く残ります（村、砦とその持ち主）。このブラウザに保存 |
| まだ見ていない | 地図でも「全体図」でも白紙。地形も村も砦も国の色も出ません |
| 他国の軍勢・進軍・衝突・争奪 | いま見えている場所でだけ。残像は残しません |
| 自分の村へ向かう敵 | 見えている場所から出発したとき、または到着の 3 ターン前から「来襲」として知らせます |

- 砦の一覧、調べる画面、年代記、知らせ、ミニマップも同じ決まりです。
- **他国どうしの衝突の報告と「戦いを再生」**は、その州の砦のマス（砦がなければ州全体）がいま見えているときだけ
  出ます。州の端の数マスが見えているだけでは出ません。自分の村の州と、自分の進軍が着いた衝突はいつでも見られます。
  見えていない衝突の報告を開こうとすると「この場所はいま見えていません。…」と出て、何も読みません。
  地図の衝突の印（赤い輪・ミニマップの点・「このターンに衝突あり」）、年代記の「…で衝突が決着した」と「最近の衝突」、
  他国どうしの砦の争奪・奪取の知らせも同じ決まりです（自分の国が関わる砦の知らせはいつでも出ます）。
  地図の上の他国の出来事（「…の新しい村」、出発、到着、野営地の消滅）は、そのマスがいま見えているときだけ出ます。
  進軍の「近くの行き先」の野営地は、測量したことのあるマスのものだけです。
- 霧の世界では、地図右下の「記録」（記録された世界の全州）と、観戦ページへのリンク（凡例と設定の「観戦ページ」）は、
  最初の画面から**出ません**（fog-devnet：以前は最初の村を置くまで凡例と設定にリンクが出ていました）。
- スイッチはモードごとに一つ: `permutation-server/web/frontier/map/fog.mjs` の `LOCAL_FOG`（ローカルの試験世界）と
  `DEVNET_FOG`（fog-devnet：クラスタが `devnet` のシーズンのプレイ画面）。`false` でそのモードは霧なし。半径などは
  同じファイルの `FOG_RULES`。観戦ページと練習のページには霧はありません。

## 6. 止める・あした続ける

1. 止めるときは、スクリプトを動かしている端末で **Ctrl-C** を押します。世界を閉じてから終わり、ログの場所を表示します。
   世界を閉じるのは最大 20 秒待ちます。それでも閉じない世界があれば、残った世界をログに書き、自分が起動したプロセスを止めて終わります。
   待ちたくないときは、もう一度 **Ctrl-C** を押すとすぐに終わります（世界の時間切れのあとでも同じです。loop-play6 LP6-3、fix-loop6）。
2. 保存する世界は、次の日に同じ Mac・同じブラウザで続けられます。止めていたあいだ、世界の時計は止まっています。

   ```bash
   scripts/play-local.sh --resume
   ```

   同じアドレスが開くので、「世界を開始（保存された世界は続きから）」を押すと前回の村に戻ります。
- `--demo` と `--wide` の世界は保存されません。止めたらブラウザのタブを閉じてください。遊んでいる途中で**ページを
  再読み込みしないでください**（テスト鍵はメモリにだけあり、その世界に戻れなくなります）。
- `git pull` などでプログラムが変わると、前の世界は続けられません。スクリプトがそう表示するので `--fresh` で始め直します。
- `--resume` が開くのは最後に始めた保存する世界だけです。前の世界に戻すには、`.local/play-local/last-kept` の中身を
  そのフォルダ（`…/.local/play-local/kept/<日時>`）に書き換えます。
- 世界は既定で 90 分たつとプロセスが止まります（`--minutes`）。保存する世界なら、そのあとも `--resume` で続けられます。
  `--resume` は `--minutes` を覚えていないので、長く遊ぶときは `--resume --minutes 240` のように付け直します。
- テスト鍵を消すには、ページのパネルの「このブラウザに保存した試験用の鍵を消す」。世界のフォルダは自分で消すまで残ります。

### 8.2 ×60 のふるまい（#102・#105・#109・#117・#120 のあと）

- **争っている州は、負荷が高いとチェーンより遅れます。** ×60 では、ふだんはどの州もターン表示より 2〜4 ターン遅れです
  （runner-throughput の確認、`--wide --random-map --ai 4`）。その変更の前や、負荷のとても高い Mac では 10〜24 ターン
  遅れることがあります（#102 の確認）。そのあいだ編成や出発は「送信待ち」になり、ページは「この州の決着が N ターン
  遅れています。このマシンの負荷が高く…」と言って、追いつき次第 1 回だけ送ります。押し直す必要はありません。
- **ふつうの進軍が封を開ける時間（×60 で約 10 秒）を逃しても、州は止まりません**（#105）。キーパーは各パスの最初と
  各村のパスの前に、期限の来た進軍の封をすべて先に開けます。それでも逃した進軍（重い負荷での 3 ターンの進軍で見られました）は、
  プログラムが開かれなかった進軍を決着させるとおりに決着します：行き先の州のターンはその進軍なしで決着し、そのあと
  SettleTransit（結果はプログラムが決めます：敗走して村に戻る、または押し戻し）。ランナーの stderr に `reveal-missed` と
  出ます。拒否で止まった村の進軍ドライバーは、6 ステップ（倍々で最大 96。パスではなくドライバーのステップの数です。保存される世界では 1 パスに 1 ステップ、
  `--demo` と `--wide` ではパスの 1 巡ごとに最大 4 ステップ）待って
  からチェーンを読み直して続け、そのあいだその村の軍勢が立つ州は世界の巡回が決着させます。到着ターンを 2 ターンより
  多く過ぎた軍勢の地図の札は「軍勢の到着ターン N から M ターン · 結果の確定を待っています」です。広い土地への遠征が
  逃した場合の決着はプログラムに無く、r0ze の判断待ちです（§−2.4f (d)）。
- **×60 では自分の州は 1〜2 ターンの遅れです**（runner-throughput の確認: ページでの中央値 2、最大 3〜4。変更の前は中央値 4、
  最大 8）。キーパーは AI の村の番の前に毎回あなたの州を決着させ直すので、編成や進軍はたいてい 1 回押せば数秒で
  送られます（確認: 編成 1.8〜5 秒、進軍 2〜14 秒。作者の回では取り消し 0 回、verify-pr109 の回では進軍 12 回中 2 回が
  自分の州が 3 ターン遅れていたときに取り消され、どちらも次に押して送られました。ターンの最後の 1 秒に押した編成が
  1 回断られ、3 秒後に押し直して送られました）。それでも取り消されたとき
  （「送信待ちを取り消しました…」）は、もう一度押してください。
- **`--demo`（と `--external`）の ×60 では、自分の州が編成できる状態にある時間は約 8 割で、外部の住民の州もほぼ同じです**
  （runner-throughput-2、BREAK-143-1）。「編成できる状態」とは、住民の命令（編成・駐屯・解散・探索）についてのプログラムの決まり
  で、州が 2 ターン前まで決着していることです。この変更の前は自分の州で約 3 割、外部の住民の州で 0〜6% でした。デモのキーパーは
  何も送らなかった回のあと 10 秒（×60 の 1 ターン）待ち、デモの 60 州を 1 件ずつ決着させ、外部の住民の村はまったく受け持って
  いなかったからです。いまは縮めた時計（`--demo`、`--wide`）では、すべての住民の州（あなた、AI の住民、外部の住民）を 1 つの
  ブロックでまとめて、最初に、そして順番が来るたびに決着させ、次のターンの区切りで起きます。測った値（デモ ×60、AI 1、外部 1）:
  あなた 79%、外部の住民 86%（前は 30% と 6%。verify-pr146 の測り直しでは 82% と 88%）。×15 では 93% と 96%（前は 79% と 60%）。100% にはなりません。ターンは次の
  ターンが始まってからでないと決着できないからです。どの州も同じバッチで同時に決着させます。残る差は州そのものの状態です。
  村のマスに軍勢を編成した（または到着がある）ターンは静かなターンではないので、同じブロックの早送りではなく、次の公開 drand の回
  の本当のシードが要ります（×60 で約 2 秒）。この測定では、あなたは訓練と編成を 23〜27 回しましたが、外部の住民は 1 ターン 1 命令
  なのでほとんど収穫でした。79% と 86% の差はこれです。国を入れ替えても、差は役割や場所ではなく軍勢についてきました（verify-pr146）。整っていないあいだは、これまでどおりページの「編成」が待って 1 回だけ送ります。
- **広い土地への遠征は、封を開ける期間を逃すと二度と決着しません**（プログラムに決着の道がなく、r0ze の判断待ち）。
  進軍の画面は「到着しました。封が開けられるのを待っています」のままで、その辺境の村からは次の遠征も出せません
  （「出発できませんでした（DepartRolesUnavailable）」）。#105 より前の確認（verify-pr106、負荷の高い Mac の ×60）で
  1 回起きました（`runner.out` に `never revealed: transit 0: the reveal window of bell 262 closed unrevealed`）。
  そのあとの fix-loop5・verify-pr117・loop-play6 では、進行役が毎回期間内に開けています（`reveal-missed` 0 件）。
  心配なときは、到着のターンに §4 の 3 のとおり自分で「封を開く」を押せます。
- **包囲されている州もチェーンについて行きます**（runner-throughput の確認: ×60 でどの州も 1 分に 5.9〜6 ターン。
  チェーンは 6。変更の前は 1〜2）。キーパーはほかの州と包囲の州のターンを、同じブロックにまとめて送って決着させます。
  順位の「第 N ターンまでの確定した得点」は、いちばん遅い州のターンです。ターン表示より数ターン遅れです（変更の前は
  数百ターン。例: ターン 495 で第 251 ターン）。
- **辺境の村が「仮の村」のまま**のときは、自分の操作（「収穫する」など）を一度すると確定します。画面の「遅くとも…」の
  時刻どおりには確定しません。
- **AI 住民は多くのターンを断られた送信に使います**（蔵が足りない訓練など）。動きが遅く見えますが、ルールどおりです。
  AI は 256 回送っても止まりません（#117。loop-play6 では約 3,000 回送って、中継に断られたのは 0 回）。
- **押しすぎで世界が送れなくなることは、もうありません（#117）。** ランチャーの中継は、**まだ決着していない**命令を
  1 つの世界で 256 件まで覚え、送った命令は取引の有効期限（ローカルのチェーンで約 1 分。負荷が高いともう少し）が
  過ぎると数えなくなります。上限に届くと「送ったばかりの命令がまだ多く決着していません。送っていません。1 分ほど
  待ってから、もう一度押してください。」と出て、1 分ほどで戻ります。進軍の中継（上限 64）も同じです。
  #117 より前は送った命令をすべて数えたので、256 回送るとその世界では二度と送れず、「今日送れる操作の回数を
  使い切りました…」という誤った文が出ました（loop-play5）。それでも**待つと書いてある場面では押し直さないでください**:
  編成・進軍の「送信待ち」と「次の一手（広い土地）」は、ページが自分で待って 1 回だけ送ります。押し直しが要るのは、
  境界のカードの「出発条件を確認」（読み取りだけ）と、「送信待ちを取り消しました…」と出たときだけです。
- **砦の奪取は保持 72 ターンちょうどです**（#120 の確認: ×60 の `--wide --random-map --ai 4` で AI の奪取 11 回が
  すべて保持 72 ターン。州は 1 分に 5.99 ターン）。
- **遠征の結果待ち**: 封が開いたあとは、地図の札が「到着 · 封は開きました · 結果の確定を待っています」に変わります。
  結果（「留まる：…」など）は行き先の州が追いつくまで出ません。
- 広い土地の村を出す場所は、空いている場所だけが候補に出ます。3 つめの村の費用（2,400）は「集落」の蔵（上限 2,000）
  では足りません。
- 遠征のカードは地形を見ずに道を引けます（「地形・時間を確認」で「山や水のマスには進めません (N)」と出ます）。
- 「記録」の画面は霧の世界では出ません（`LOCAL_FOG` を `false` にすると出ます）。

## 9. 困ったとき・知らせ先

- ログの場所:
  - 保存する世界: `.local/play-local/kept/<日時>/`（`launcher-<日時>.log`、`persist/<アドレス>/starts/<回>/` に
    runner・herald・relay・operators のログ）
  - `--demo` と `--wide`: `.local/play-local/worlds/<日時>/`（`launcher-<日時>.log` と世界ごとのフォルダ。
    `--wide` では `wide-land.json` に広げたリングと開いた州、`runner.out` の 1 行めの `local_rules` に
    プリセットから変えたバイトが書かれます）
  - 起動コマンドは同じフォルダの `command.txt` です。
- **開けるアドレスは 2 つだけです**: `http://localhost:<ポート>/` と `http://127.0.0.1:<ポート>/`（`--two` の 2 人目が使うのは後者です）。
  ランチャーも世界も 127.0.0.1 でだけ待ち受け、Host がこの 2 つ以外の要求を断ります。`http://[::1]:41920/`、`http://<Mac の名前>.local:41920/`、
  LAN の IP アドレス、別のマシンやスマートフォンからは開けません（ページの代わりに `{"error":"HostDenied"}` と出ます。世界の読み取りは
  `WorldOriginDenied`）。#164 からは世界の中継（relay）も同じ決まりです: Host が `127.0.0.1:<その中継のポート>` か `localhost:<同じ>` で、
  **Origin ヘッダーのない**要求だけを受け、ほかは 403 `LocalPlayHostNotAllowed` です。ページ・AI 住民・付属の外部の住民（Node）はこの形なので、
  ふつうに遊ぶぶんには何も変わりません（verify-pr164: `--two` の二人とも 403 は 0 回）。当たるのは、中継のポートをブラウザのページから直接呼ぶ
  自作の道具（ブラウザは Origin を付けます）と、`curl -H 'Origin: …'` や別の Host 名を付けた手書きの要求だけです。
- **ページのファイル（`permutation-server/web/`）を書き換えたとき**は、スクリプトの再起動は要りません。ランチャーは要求のたびにディスクから
  読み、コードとページはブラウザに保存させません（`no-store`。絵とフォントは毎回確かめます）。ブラウザを再読み込みすれば新しいファイルです。
  ただし `--demo` と `--wide` は再読み込みでテスト鍵を失うので（§6）、再読み込みのあと「新しい世界を開始」で世界を作り直します
  （保存する世界は再読み込みしても続きます）。#170 の herald の配信キャッシュはローカルの世界では使いません（ページを配るのはランチャーで、
  世界の herald は `--web` なしで動きます）。herald にページを配らせる構成（devnet 用）でも、書き換えたファイルは大きさか時刻が変われば次の要求で
  読み直すので、再起動は要りません。再起動が要るのは、ランチャーや中継のコード（`permutation-gateway/src/`）と Rust のコードを変えたときです
  （Ctrl-C して `scripts/play-local.sh` をもう一度。変わったものだけビルドし直します）。
- 「ポートがふさがっています」と出たら、別の `--port`（例 `--port 41450`）にするか、前の世界を止めてください。
- 知らせ先は GitHub の Issue（r0ze998/wylls）です。画面のスクリーンショットと、上のフォルダの場所を添えてください。

## 10. ② 権利（在庫の交換）を遊ぶ（`--coexist`、試験専用）

オーナー決定 ② A の形です: 工房の村の持ち主が、同じ州にある相手の貯蔵庫に「在庫を交換する権利」を出します。相手は
自分の鉱石と木材を、工房が作った兵器に替え、その兵器を**隊商でだけ**運び出します。権利を出すのはウォレットだけです。

```bash
scripts/play-local.sh --coexist --demo --two --ai 2     # ×60。一周は約 10 分。保存なし
scripts/play-local.sh --coexist --two                   # 保存する世界（通常の速さ。貯蔵庫の費用にほぼ一日）
```

- **二人要ります。** 権利の相手は別のプレイヤーでなければなりません。一人で確かめるときは、ブラウザの窓を 2 つ使います:
  A は `http://localhost:41920/`、B は `http://127.0.0.1:41920/`（§3.1）。以下、**A ＝ 工房の村の持ち主**、**B ＝ 相手**。
- `--coexist` は、保存する世界か `--demo` を ②+⑨+⑩ の**共存の線**（プログラム版 0x7805、`RULESET_HASH_V4`）で動かします。
  `--ai`・`--two`・`--random-map`・`--resume` と使えます。`--wide` とは使えません。⑨⑩ は試験用のカードがあります（§12）。
- 最初の `--coexist` はビルドに 1〜2 分かかります。そのあと普通の世界を始めると、スクリプトが自分のバイナリを数秒で
  作り直します（#128。作る場所が同じ `frontier-node/target/debug` のため。#128 より前は作り直さず、普通の世界が
  「—」のまま始まりませんでした）。

手順（「」はページのボタンと表示そのままです）:

1. **同じ州に入る**: A も B も「世界を開始」（`--demo` では「新しい世界を開始」）→「国を選ぶ」で**同じ国**（AI のいない国。`--ai 2` ならボレアリスと
   エンバー以外）を選びます。`--two` の二人が同じ国を選ぶと、村は同じ州の別の場所に置かれます（#130。verify-pr130 で 3 回中 3 回、
   verify-pr133 で 1 回中 1 回。その前は 5 回中 4 回が中央をはさんだ反対側の州で、世界を始め直す必要がありました）。
   州は、村の画面のいちばん下の「村の詳細」を開くと出ます（例「州 -2,0」）。違う国を選ぶと州が離れ、隊商が届きません
   （道は 32 マス・4 州まで）。
2. **A: 工房を建てる**: 村の建設の一覧で「ほかの建物（6）」を開き、「工房」の「建てる」（費用は食料 60・木材 120・石材 80・鉱石 40）。
   工房が出るのは `--coexist` の世界だけです。ふつうの世界の一覧には代わりに「工房はこの試験世界では建てられません（…--coexist でだけ建てられます）。」と出ます（fix-loop9 LP9-3。以前は出ていて、押すと断られました）。
   「工房の建設を始めました」と出ます。
   工事は約 1 時間半（9 ターン。×60 で約 1 分半）です。建ち上がると、その村が「工房の村」になり、兵器を 1 時間に 4 作りはじめます
   （工房を建てられるのは `--coexist` の世界だけです）。
3. **B: 貯蔵庫を建てる**: 地図で、A の村と同じ州の空いたマスを選び、「ここに建てる」→「貯蔵庫を建てる」
   （費用は木材 200・石材 200・金 50。選んでいる村の蔵から）。「貯蔵庫を建てました」と出ます。
   山や水のマスでは「この建物はこのマスに建てられません（通れない土地、…）」と出て押せません。平地のマスを選び直します。
4. **B: 鉱石と木材を貯蔵庫へ運ぶ**: 貯蔵庫のマスを選んで「ここへ隊商を送る」（または村の画面の「交易と防備」→
   「隊商を送る」）。「出発地」が自分の村、「行き先」が貯蔵庫になっているのを確かめ、木材と鉱石の数を入れて
   「隊商を送る」。兵器 1 につき鉱石 2・木材 1 が要ります（例: 木材 20・鉱石 40 で兵器 20 まで）。
5. **B: 着いた隊商を届ける**: ローカルの試験世界には隊商を届ける係がいません。村の画面の「権利（在庫の交換）」に
   「着いた隊商（あなたが届けます）」が出ます。はじめは「通った州（P, Q）の決着が到着のターン N を過ぎるのを待っています。
   過ぎると届けられます（数ターン）。」と出ていて、ボタンはありません（#130）。1〜2 ターンで「隊商を届ける」が出るので押します
   （「隊商が届きました」。手数料は戻ります。verify-pr133 では 2 回とも 1 回めの押下で届きました）。
6. **A: 権利を出す**: 村の画面の「権利（在庫の交換）」→「権利を出す」を開き、「工房の村と相手の貯蔵庫」で B の貯蔵庫を
   選び、「交換の回数」（初期値 3）・「兵器の上限」（30）・「有効な日数」（1）を入れて「権利を出す」
   （費用：工房の村から金 25）。A の欄に「あなたが出した権利 有効 … 交換 0 / 3 回 · 兵器 0 / 30」と出ます。
   - 「工房のある村の州に、ほかの人の貯蔵庫が見えていません。…」と出るときは、B の貯蔵庫がまだ無いか、別の州です。
     「権利を出すには、工房のある村が要ります。」は 2 がまだか、工房がまだ工事中です（verify-pr133: ターン 11 では出て、ターン 18 には出せました）。
7. **B: 交換する**: B の欄で「権利の一覧を読み直す」→「あなたが受けた権利 有効」。数を入れて「交換を予約する」
   （「予約中 N」。貯蔵庫から鉱石と木材が、工房の村から兵器が出ます）→「交換を実行する」（「交換しました。兵器は
   あなたの貯蔵庫に入りました」）。予約をやめるときは「予約を戻す」。
8. **B: 兵器を隊商で村へ運ぶ**: 貯蔵庫のマス →「ここから隊商を送る」。フォームは「出発地」が貯蔵庫、「行き先」が自分の村で
   開き、数の欄の上限は貯蔵庫にある分です（#130。verify-pr133: 木材 18・鉱石 36・兵器 2）。兵器の数を入れて「隊商を送る」。
   着いたら 5 と同じく「隊商を届ける」。村の蔵に兵器が入ります。
9. **A: 取り消して閉じる**: 「権利を取り消す」→「取り消し済み」（B の開いている予約は戻ります）→「権利を閉じる」→
   「閉じた」（賃料が戻ります）。取り消したあとは、B はもう予約できません。

知っておくこと:
- 霧の決まり：欄に出るのは自分が出したか受けた権利だけです。ほかの人どうしの権利や、ほかの人の貯蔵庫の中身は出しません。
  A から見た B の貯蔵庫は「（国）の貯蔵庫（マス N）」とだけ出ます。
- 相手の欄に反映されないときは「権利の一覧を読み直す」を押します。
- 権利を出す・取り消すは、ウォレット（このブラウザの試験用の鍵）だけができます。AI 住民や代理には任せられません。
  （プログラムは取り消しだけセッションの鍵でも受けます。ローカルでは中継が断ります。devnet に出す前に直す項目です）
- 隊商は道の上で略奪されることがあります。届けたあとの知らせ「…到着しましたが、入った量は確認できません…」は
  長い文ですが、失敗ではありません（蔵の上限を超えた分は切り捨てられる、という意味です）。村あての隊商では
  「…決着しました。入った量はまだ確かめられていません…」と出ることもあります。これも失敗ではありません（村の蔵に入っています）。
- 普通の世界（`--coexist` なし）では、工房は建てられず、隊商を届けるボタンもありません（着いた隊商は届けられないままです）。
- ページのない旧ノードは `--coexist-node` です（開発用）。

## 11. 外部の AI 住民を入れる（`--external`、試験専用）

外部の住民は、あなた（または別の人）が自分のプロセスで、自分のテスト鍵を使って動かすプログラムです（⑬ 独立した住民／⑤ 案 B）。人と同じ規則で、新しく来た住民としてあなたのローカルの世界に入ります。運営側は特権を与えず、鍵も見ません。ページには普通の住民として出ます（AI の印はありません）。

1. 住民のテスト鍵を一度だけ作り、ファイルを持っておきます（`0600`。外に出るのは表示される公開アドレスだけです）。

   ```sh
   cd workstreams/03-composability/mcp && npm ci --ignore-scripts
   node -e "import('./examples/external-resident/key.mjs').then(m => console.log(m.createKeyFile('/path/to/resident.json').address))"
   ```

2. そのアドレスを付けて世界を起動します（2 つまで、カンマ区切り）。MCP サーバーは gateway のクライアントを読み込むので、一度 `(cd permutation-gateway && npm ci --ignore-scripts)` を実行します。まだ入れていなければ、確認の段階で「足りないもの」に出ます。

   ```sh
   scripts/play-local.sh --demo --external <アドレス>
   ```

   `--external` を付けると、③ の**読み取り専用**の MCP サーバーもこの世界のために起動します。待受は 127.0.0.1 だけで、ポートは世界のポートの次です（既定の `--port` と `--ai` なら 41950、`--ai 0` なら 41942。「読み取り専用の MCP (③): http://127.0.0.1:<port>/mcp」と表示されます。`--lang en` では `Read-only MCP (③): …`）。読むのは最初の世界だけです。使えるのは読むツールだけで、つなぐのは住民自身です（住民の財布がつなぐ文に署名します）。`--no-mcp` を付けると起動しません。スクリプトが動いているあいだ動き続け（世界の時間が切れたら次の世界を待ちます）、Ctrl-C ですべてと一緒に止まります。

3. いつもどおりページで開始を押してから、住民を起動します（早すぎたときは、あなたの世界ができるまで待ちます）。

   ```sh
   node workstreams/03-composability/mcp/examples/external-resident/agent.mjs --launcher http://localhost:41920 \
     --key /path/to/resident.json --mcp http://127.0.0.1:<port>/mcp
   ```

   住民は一歩ごとに JSON を 1 行出します（`discover`、`mcp`、`act` … `landed`／`refused`）。命令はページと同じ 6 つ（Join・PlaceHome・Harvest・Build・Train・Muster）です。どれも自分の鍵で署名し、自分の relay から送ります。運営側の AI 住民と同じく、行動は 1 ターンに 1 回です（Join は数えません。同じターンの 2 回目は `ResidentAlreadyActed`）。あなたのページにはこの上限はありません。自分の AI をつなぐには、`examples/external-resident/rule.mjs` の `decide()` を差し替えます（そのフォルダの README を見てください）。

   **⑬ の住民**も同じように動かせます。参照の規則の代わりに ⑬ の目標・上限・記憶で決めます（モデルも有料 API も使いません。`workstreams/13-citizens/resident/local/README.ja.md`）。

   ```sh
   node workstreams/13-citizens/resident/local/client.mjs --launcher http://localhost:41920 \
     --key /path/to/resident.json --dir /絶対パス/resident-state [--goal village-first|surplus-use] [--nation 0-5] \
     [--mcp http://127.0.0.1:<port>/mcp]
   ```

   判断は `<dir>/decisions.jsonl`（一歩ごとに JSON 1 行）に、記憶は `<dir>/state.json` に残ります。再起動した住民は前の命令を署名でたどり、同じターンに 2 回行動しません。`touch <dir>/HALT` で一時停止します。
   `--key` のファイルがまだ無ければ、`--new-key` を付けるとその場所に作ります（手順 1 の代わり。アドレスは最初の行 `start` の `wallet` に出ますが、世界はそのアドレスを `--external` で受け入れてから起動するので、ふつうは手順 1 で先に作ります）。

4. **数ターンの計画（`--plan`、④ の実行、#148）**: ⑬ の住民に `--plan --runexec <runexec の絶対パス>` を付けると、村ができたあと、住民は自分の村の次の命令を 12 手の計画にし（建物 → 収穫 → 訓練 → … → 部隊の編成）、④ の計画の記録（SQLite、既定は `<dir>/plans.sqlite`）が 1 ターンに多くて 1 手ずつ実行します（次の手の費用が村に足りない間は、その手は待ちます。`decisions.jsonl` の `"what":"wait"` の行に、足りない資源と待つターンの目安が出ます。verify-pr156 では 6 手めの建設が木材を十数ターン待ちました）。`--plan` は `play-local.sh` の指定ではなく、この住民（`client.mjs`）の指定です。

   ```sh
   (cd workstreams/04-execution && cargo build --release --locked --bin runexec)   # 一度だけ
   (cd workstreams/03-composability/mcp && npm ci)
   node workstreams/13-citizens/resident/local/client.mjs --launcher http://localhost:41920 \
     --key /path/to/resident.json --dir /絶対パス/resident-state \
     --plan --runexec "$PWD/workstreams/04-execution/target/release/runexec" [--plan-db /絶対パス/plans.sqlite] [--plan-steps 12]
   ```

   - `--runexec` は絶対パスで、`--plan` と一緒にだけ使えます（`--plan-db` も絶対パス。`--plan-steps` は 4〜64、既定 12）。
   - 見るところ: `<dir>/decisions.jsonl` の計画の行（`planStep`）。意図は署名の前に、署名は送る前に ④ に書かれるので、途中で止めて（Ctrl-C でも強制終了でも）同じ指定で起動し直すと、署名をチェーンで読んで続きから進み、同じ命令を二度送りません（verify-pr148: 12 手が部隊の編成まで着地、二重の行動 0）。
   - 同じ `--dir` で 2 つめのプロセスは動けません。起動し直したプロセスは、前のプロセスの持ち時間（20 秒）が切れるまで待ちます。
   - チェーンに断られたり世界が変わったりすると、計画を止めて今の村から作り直します（1 つの世界で 24 個まで）。
     資源が足りないとチェーンに断られた建物は、その建物にかかる資源がどれも断られたときより増えるまで送り直さず、新しい計画の最初の手にもしません。自分の建物が着地したのに herald の記録にまだ出ていないときは、作り直さずに記録を待ちます（fix-loop9、LP9-4）。S1 の世界では、鉱山を村の地形の鉱石より上の分で数えます（プログラムと同じ。LP9-4：前は 4 つめの鉱山を 2 つめの値段で見積もり、8 回断られました）。
   - 計画に入るのは 6 つの命令だけです。隊商・進軍は入りません（隊商は r0ze の判断待ち、Q4）。

- `--demo` の ×N の時計は、**あなた**の最初の村が置かれてから動きます。それまでは 1 ターン 10 分なので、住民の 2 つ目の命令はあなたを待ちます。
- `--two` とは一緒に使えません。保存する世界・`--demo`・`--wide`・`--ai`・`--random-map`・`--coexist`・`--resume` では使えます（続きから遊ぶときも `--external` をもう一度付けます）。
- **`--wide` の世界では**（external-wide）ランチャーが住民にも「広い版」だと伝えます（開始の答えの `wideLand`。あなたのページに伝えるのと同じです）。⑬ の住民は最初の村を、ページと同じ選び方で選びます。外側から先に、自国の、入植済みの辺境の州の空いた地を、遠い環から探します。中心地より外では一か所の申し込み（`FileTicket`。ページの「辺境の村を申し込みました」と同じ）で頼み、世界がターンの終わりに決めるのを待ちます（最大 72 ターン。そのあいだ 2 つ目は出しません）。申し込みがそのターンの行動です。そのあとは辺境の村を同じ 6 つの命令で遊びます。広い土地そのものの命令（広い土地の取得、広い村の訓練・編成・進軍、遠征）は外部の住民の命令にはありません。広い土地に村は作りません。住民の中継（relay）もそれを断ります（verify-pr163、`--no-wide-orders`：取得と広い村の命令は `LocalActWideOrderRefused` で送らず、遠征の道は開いていません）。参照の住民（`agent.mjs`）は今も中心地（環 2〜3、PlaceHome）しか読みません。
  例: `scripts/play-local.sh --wide --random-map --ai 2 --external <アドレス> --speed 60`。
- 外部の住民の村の州も、世界の進行役があなたの州と同じ組で決着させます（#146。保存する世界でも同じ）。×60 の `--demo` で住民の州が編成できる状態にある時間は 8〜9 割です（前は 0〜6%。§8.2）。
- 付属の 2 つの住民が送るのは 6 つの命令（と、`--wide` の最初の村の申し込み）だけです。隊商・進軍は送りません。① の板も使いません。住民の中継そのものは、ふつうの進軍の道も開けています（自作の住民なら送れます。`--wide` の世界では広い土地の命令と遠征だけを断ります。ふつうの世界と `--demo` では遠征の道も開いています。verify-pr163 D-2。外部の住民に進軍を許すかは r0ze の判断待ちです）。住民の中継は Host が自分のアドレスで Origin のない要求だけを受けます（#164。Node の住民はそのままで通ります。§9）。世界の時計を止める・速さを変える操作は、ランチャーの合言葉が要るので住民にはできません（#137）。
- ローカルだけです。devnet には外部の住民の受け入れも MCP サーバーもありません（公開の MCP の方針 MCP-1..11 は未決です）。

## 12. 試験：⑨ 工房を貸す・⑩ ほかの人の貯蔵庫に鉱石を預ける（`--coexist`、試験専用）

2026-11-21 の決定どおりです。⑨ は ② A の貯蔵庫と隊商の上に作る試験版で、占領されたら中身は占領者がすべて取ります。⑩ は ②
A の貯蔵庫に合わせ、運んでいる途中の荷は運び手のもので、運び手が負けると失われます。預けた人の兵は守りません。奪われたこと・
失ったことは画面に出します。預けられるのは鉱石だけです。devnet には何も出ていません（coexist の世界のプログラムの命令を
ページが送り、プログラムが確かめます）。

`--coexist` の世界の村の画面には、② のカードの下に 「預かりと工房貸し（試験）」 があります。準備は §10 の 1〜5 と同じです。

⑨ 工房を貸す（A が工房の村の持ち主、B はその州に貯蔵庫あり）:
1. A: 「工房を貸す」 を開き、数を入れて 「工房を貸し出す」。「工房を貸し出しました」。
2. A: 「使わせる相手（この州に貯蔵庫がある人）」 で B を選び（#149 から、選択肢は「ダンマール の村 ○○（貯蔵庫 マス N · 4RLP…cWEN）」のように村の名前・マス・持ち主の短い住所で見分けます）、工房の数・「兵器の上限」・「有効な日数」 を入れて 「工房を使わせる」（ウォレットで署名）。
3. B: 「使える工房」 の 「使う工房の数」 と 「作る兵器の数」 を入れて 「予約して材料を入れる」。予約と、兵器 1 につき鉱石 2・木材 1 の投入が一度に行われます。
4. B: 「あなたの作業」 の 「兵器 N / M」 が増えます（工房 1 で毎時 4。×60 なら 10 個で約 2.5 分）。「貯蔵庫へ受け取る」 →
   「兵器と残りの材料が貯蔵庫に入りました」。家へは §10 の 8 と同じく隊商で運びます。
5. A: 「取り消す」 で権利を終え（予約済みの作業は続きます）、「空いた工房を戻す」 で村に戻します。

⑩ 鉱石を預ける（B が貯蔵庫の持ち主、A が預ける人）:
1. B: 「鉱石を預かる」 を開き、A の村（#149 から村の名前・マス・持ち主の短い住所が出ます。選べる人が複数いると、一覧は「（預ける人を選んでください）」か、前に選んだ人から始まります。fix-loop9 LP9-7）と 「鉱石の枠」 を選んで 「預かりの枠を開く」（ウォレット）。
2. A: 「預けた鉱石」 に貯蔵庫が出ます。量を入れて 「鉱石を預ける」。着いて、通った州の決着が済んだら 「鉱石を届ける」 →
   「預ける鉱石が届きました」（② のカードはこの隊商を出しません）。
3. A: 「引き取る」 で家へ。届いたら ② のカードの 「隊商を届ける」。空になったら 「枠を閉じる」。
4. B には 「あなたの貯蔵庫の預かり」 だけが見えます（国と量）。

失ったとき（一度だけ警告を出し、カードにも残します。ただし道中で奪われた隊商の行「隊商 N：道中で奪われた」は、「帳簿を確かめる」を
押すとカードから消え、残るのは地図の知らせの履歴だけです）: 貯蔵庫を奪われた、預けに向かう隊商が奪われた、工房の村が奪われた。
#145（fix-9-10-followups）から、上の 2 つ（貯蔵庫・道中の隊商）は `--coexist --two` の世界で実際の命令として起こせます（プログラムが
もともと持つ SeizeVault・RaidDomestic・RaidCaravan。チェーン側は何も変えていません）。村の占領はまだ起こせません（テストのみ）。
ふつうの世界（`--coexist` なし）では、これらのボタンは出ません。軍勢は 100 人以上で編成します（それより少ない編成はプログラムが断ります）。
×60 では止めてから決めるまでが約 20 秒しかないので、`scripts/play-local.sh --coexist --demo --two --speed 15`（1 ターン 40 秒）が楽です。
- **道中の隊商を止める**（B が A の預ける鉱石を奪う）：二人は同じ国で、衝突は自国の隊商を襲わないので、B が自分で止めます。
  隊商がマスに「立つ」のはターンの始まりだけ（平地でおよそ 1 ターン 5 マス）なので、1 ターンの中で出発して着く隊商は止め
  られません。検証では州 (-1, 2) の A の村がマス 28、B の貯蔵庫がマス 22 で、ターンの残りがゲーム時間で約 5 分半（×15 で約 22
  秒）のときに 「鉱石を預ける」 を押すと、隊商はマス 20 に立ちました。手順：B は先にそのマスに軍勢を置きます（村の画面の
  「編成」、盤面でマスを選ぶ）。隊商が立ったターンの決着がついたら、B はそのマスを押し、軍勢カードの ⓘ（マスの欄）で
  「隊商を止める（ターン N まで）」→「隊商を止めました。…」、同じ欄で 「奪って運ぶ」 か 「焼き払う」（立ったターンから 6 ターン
  以内）。A には 「預けに向かった鉱石 N は道中で奪われました。」（または 「…焼き払われました。」）と出て、「帳簿を確かめる」
  （ReconcileLot）で枠が空きます。奪われた隊商は B の村へ向かい、B が ② のカードの 「奪った隊商」→「隊商を届ける」 で届けます
  （鉱石は B の村へ）。まだ道中のあいだは ② のカードの「奪った隊商（あなたの村へ向かっています）」に「ターン N に着きます。…」と出て、地図の札も着くターンを示します（奪った場所から村まで近いと、すぐ着いて「着いた隊商」にだけ出ます。verify-pr162 では奪ったターンの次のターンに「着いた隊商」に出て、地図の札は「略奪された隊商 ターン 108 着」でした）（fix-loop9 LP9-6。以前は「ターン 0 着」で、約 65 ターン何も出ませんでした）。焼かれた隊商は空のまま進み、A が 「鉱石を届ける」 で届けます。
- **貯蔵庫を奪う**：もう一人が貯蔵庫のマスに軍勢を置き（持ち主の軍勢がいると奪えません）、マスを押して ⓘ →
  「貯蔵庫を奪う」（持ち主の軍勢がいてもボタンは押せますが、プログラムが断ります）。預かる側には 「あなたの貯蔵庫が奪われ、預かっていた鉱石も奪われました。」 と出ます。二人だけなので奪う
  のは預けた本人で、そのカードは 「あなたが奪った貯蔵庫」 と出て損失は出ません。「帳簿を確かめる」 で預けた分は、いま自分の
  ものになった貯蔵庫に入ります（奪った側がすべて取る）。第三者による奪取と、預けた人の兵が守らないことの確認は 3 人目の席が要り
  ます（未実装）。
- 届けた預かりの隊商は、記録係（herald）が地図から消します（#145。その前は「隊商 ターン N 着・位置は推定」のまま残っていました）。
- 焼かれて空になった預かりの隊商を届けても、知らせは「預ける鉱石が届きました」のままです（中身は 0。verify-pr145）。


## 13. ① 国をまたぐ依頼の板と ⑮ 称号「依頼に応えた」（試験専用、#149・#152）

`play-local.sh` は、どの世界にも workstream 01 の協力の板（ランチャーの `--coop-board ws01-board-v1`）を付けます。
付けたくなければ `--no-coop-board` を付けます。板があると、村の「交易と防備」に「国をまたぐ依頼を開く」が出て、
下のバーの「その他」に ⑮ の「称号と記録」のカード（「国をまたぐ協力の達成。勝敗・得点・賞金には関わらない」）が出ます。
板はゲームのページと同じ言語で出ます（#171。ゲームのページの右上のボタンで英語にすると、開いている板の窓も英語に変わります。
板の窓にも切り替えのボタンがあります。日本語の表示は前と同じです。以下の「」は日本語の表示です）。

依頼から配達まで（隊商を送れるのは `--coexist` の世界だけです。ふつうの世界の村は隊商を送りません）:

```bash
scripts/play-local.sh --coexist --two --demo --ai 0      # ×60。二人で一つの世界（§10 と同じ。`--ai 0` は AI なし）
```

**称号まで確かめるなら、A と B は違う国を選びます**（同じ国の依頼は配達はできますが、称号は付きません）。verify-pr152 では
いつもの地図（`--random-map` なし）で A ＝ アステル、B ＝ ボレアリスにして届きました（隊商の道は 32 マス・4 州まで）。

1. **A（依頼する人）**: 村 → 交易と防備 → 「国をまたぐ依頼を開く」。別の窓に板が開きます。「このウォレットで署名する」
   （このページのテスト用ウォレットが、板の記録だけに署名します）→ 木材・石材の量を入れて「依頼を出す（署名）」。
   届け先は A の村です（例「木材 20・石材 20 → …（アステル・申告。判定には使わない）の村 (-1,2) 村5 受付中」）。板の「自分の国」は
   ゲームと同じ国の名前で、ウォレットを接続するとチェーンで確かめた国に合わせます（申告であることは変わりません。
   fix-loop9 LP9-8。以前は「国1…国6」で、初めは「国1」でした）。
2. **B（届ける人）**: 同じように板を開き、「このウォレットで署名する」→ その依頼の「応じる（送るつもり。義務はない）」。
3. **B**: ゲームの村 → 交易と防備 → 隊商を送る。15 秒ほどで行き先に「① 依頼の届け先：村（-1, 2 · マス 28）」が出ます
   （後ろに「 · アステル」のように国の名前が付きます）。この行き先が出るのは**その依頼に「応じる」と答えた人だけ**です。
   依頼した人が板に公開した場所だけで、まわりの土地は見えないままです（霧はそのまま）。量を入れて「隊商を送る」→
   「ほかの人の村か貯蔵庫へ送る隊商は、ウォレットで署名します…」→「隊商が出発しました」。
   （#149 の前は「ローカルプレイでは、まだ命令を送れません（読み取りのみ）」で断られていました。LP8-3）
4. **B**: 板を読み直して「隊商 #0（木材 20・石材 20）をこの依頼に結び付ける」→「結び付けた。数えるのは確定した到着だけ」。
5. 着くと、B の「権利（在庫の交換）」のカードの「着いた隊商（あなたが届けます）」に「隊商を届ける」が出ます
   （通った州の決着が到着のターンを過ぎるまで待ちます。×60 で数十秒）。押すと「隊商が届きました」。
6. 板の依頼の「隊商と到着」に「到着（確定）・届いた 木材 20 以上・石材 20 以上（規則から）・Fulfilled」と出て、
   「依頼の充足：依頼量に届いた（数えた量の下限で証明）」になります。一部だけ届けたときは「依頼量に届かなかった
   （すべて終わり、上限で証明）」と出ますが、依頼は「受付中」のままで、残りを届けて結び付ければ「依頼量に届いた」に変わります。
7. **⑮ の称号「依頼に応えた」（#152、オーナー決定 Q1-⑮）**: 依頼が依頼量に届くと、届けた B のページの「その他」→「称号と記録」に
   「ターン N あなたが称号「依頼に応えた」を得た」と出ます（英語の画面では “Answered a request”。N は依頼量に届いた到着のターン。
   板を読むのに少し時間がかかります）。依頼した A の札には出ません（「まだ称号はありません」のまま。称号は本人にだけ見せます）。

称号が付く条件（⑮ の規則 B 版 4。`workstreams/15-coop-outcomes/src/rulesets.mjs`）:
- **他国の人**の依頼に、**自分の隊商で届け**、その依頼が**依頼量に届いた**こと（板の、数えた量の下限での証明）。
- 付かないもの: 「応じる」と答えただけ、一部だけ届けて依頼量に届かなかった依頼、同じ国の人の依頼、自分の依頼（板がそもそも受け付けません）。
- 称号と記録だけです。勝敗・得点・賞金・シーズンの終わりには何も加えません（オーナー決定 ⑮ B）。
- ほかにいま取れる称号は P-raider（「他の国の隊商から奪った（国内の襲撃は数えない）」）で、依頼とは関係ありません。
- カードの「まだ判定できない達成 N」は、すべての住民の未判定の数の合計です（自分のものとは限りません）。
