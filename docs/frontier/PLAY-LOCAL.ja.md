# ローカルで遊んで確かめる（TEST 専用・ワンコマンド）

devnet に出す前に、手元の Mac で遊べる版（遠征・広い土地・砦の奪取）を自分で確かめるための手順です。
使うのは手元のローカルチェーンとテスト鍵だけです。本物の鍵・SOL・devnet・有料 API は一切使いません。
2026-11-20 時点の main（#102 まで）に合わせています。英語版: [PLAY-LOCAL.md](PLAY-LOCAL.md)

## 1. 最初に一度だけ入れるもの

スクリプトは何もインストールしません。足りないものがあれば、名前と入れ方を表示して止まります。

| もの | 版 | 入れ方の例 |
|---|---|---|
| Rust（rustup） | 1.89.0 と 1.95.0 | `rustup toolchain install 1.89.0 1.95.0 --profile minimal` |
| cargo-build-sbf と platform-tools | 3.1.9 / v1.52 | `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.9/install)"` |
| Node.js | 20 以上 | `brew install node`（`node -v` が v20 以上ならそのままで構いません） |
| git・python3 | macOS 標準 | 入っていなければ `xcode-select --install` |
| 空きディスク | 初回 20 GiB 以上 | |

初回のビルドは crate を取りにネットワークを使います。遊んでいるあいだも、keeper が公開の drand 乱数を HTTPS で読みます。

## 2. ワンコマンド

リポジトリの一番上で実行します。道具の確認 → ビルド（変更がなければ省きます）→ 世界の起動 → ブラウザで
`http://localhost:41920/` を開く、まで進みます。初回のビルドは約 3 分、2 回目以降は数秒です。

```bash
scripts/play-local.sh                 # 保存する世界（1 ターン 10 分。止めても --resume で続き）
scripts/play-local.sh --demo          # 15 分の攻略デモ（×60、1 ターン 10 秒。保存なし）
scripts/play-local.sh --wide          # 広い版（辺境と広い土地。×60。保存なし）→ §4
```

世界は 3 種類です。どれも霧（§5）がかかり、AI 住民は既定で戦争をします。

| 世界 | 時計 | 保存 | 向いている確認 |
|---|---|---|---|
| 保存する世界（既定） | 通常（1 ターン 10 分） | あり（`.local/play-local/kept/`、テスト鍵はブラウザ） | 参加・村・建設・訓練・編成、止めて続ける |
| `--demo` | ×60（`--speed` で 10〜60） | なし | 砦へ進軍・衝突・奪取を 15 分で |
| `--wide` | ×60（`--speed` で 10〜60） | なし | 辺境の村 → 広い土地の村 → 遠征 → 広い土地の中の進軍 |

指定:

| 指定 | 意味 | 一緒に使えないもの |
|---|---|---|
| `--resume` | 最後に始めた保存する世界を続けます（同じブラウザ・同じポート・同じ AI の数） | `--fresh` `--demo` `--wide` `--random-map`、違う `--port` / `--ai` |
| `--fresh` | 保存する世界を新しく始めます（何も付けないときと同じ） | `--resume` `--wide` |
| `--demo` | 15 分の攻略デモ | `--resume` `--wide` |
| `--wide` | 広い版（§4） | `--demo` `--resume` `--fresh` `--two` |
| `--random-map` | 新しい世界に、その世界だけの地図。付けないと**ローカルの世界は毎回同じ地図**です | `--resume` |
| `--ai N` | AI 住民の数 0〜4（既定 2）。**既定で戦争をします**: 届く他国の砦へ進軍・包囲（1 人 1 ターンに 1 行動） | |
| `--ai-peaceful` | AI は砦へ進軍しません（建設・収穫・訓練・編成。`--wide` では辺境と広い土地の村・遠征もします） | |
| `--two` | 二人で一つの世界（§3.1） | `--wide` |
| `--speed N` | `--demo` / `--wide` の時計 10〜60（既定 60） | 保存する世界 |
| `--minutes N` | 世界のプロセスが止まるまでの分 15〜240（既定 90） | |
| `--port BASE` | ページのポート（既定 41920）。BASE から 22 個（`--ai 0` なら 14 個）を使います。41000〜41999 の中で、41904〜41907 と 41970 を含まないこと | |
| `--lang ja\|en` | スクリプトの表示の言語（ページは右上のボタンで切り替え） | |
| `--no-open` `--no-build` `--rebuild` `--check-only` `--print-plan` | 開かない / ビルドしない / 必ずビルド / 確認だけ / 設定と起動コマンドを表示して終わる | |

- AI 住民が入る国は決まっています: 1 人目ボレアリス、2 人目エンバー、3 人目シンダー、4 人目フィヨルダル。
  **AI のいない国**（`--ai 4` ならアステルかダンマール）を選ぶと、村の場所の取り合いになりません。
- `--random-map` は、ランダムに選んだ過去の時刻から世界を始め、プログラムが変更なしのルールで別の創世シードを導きます。
- 止めるのは端末の **Ctrl-C** です（§6）。

## 3. 15 分のチェック

`--demo` で 1〜8 を通せます。保存する世界では 1〜5 をして、§6 の手順で止めて続きから再開します
（1× では、編成した軍勢が動けるのはターンが決着してから＝約 17 分後です）。

1. **参加**: 「世界を開始（保存された世界は続きから）」（`--demo` では「新しい世界を開始」）→「国を選ぶ」→ 旗を一つ選び、
   「（国の名前）で始める」を押します。最初の村は自動で置かれます。鍵のカードやウォレットの確認は出ません。
2. **村**: 「ここが、あなたの村です。」が出たら成功です。地図の上の「鉱石 +2」を見てください。
   「地形の鉱石なし」の村は、兵を 600 人ほどまでしか増やせません。
3. **建設**: 「最初の建設を選ぶ」→ 農場の「建てる」。約 1 分（ゲーム内）で完成します。
4. **訓練**: 下のバーの「訓練」→「最大 500」→「槍兵 500 を訓練する」。すぐ終わります。
5. **編成**: 村の画面の「兵」→「全部（500）」→「編成する」。「この州はまだ前のターンの決着が済んでいません」と出ていても
   **押して構いません**。送信待ちになり、整い次第 1 回だけ送ります（押し直しは不要。兵種・兵数が変わると取り消します）。
   「立っている 1」になれば動かせます。
6. **砦へ進軍**: 右上のガイドが「届く砦を見る」になったら押します（「軍勢の準備を確かめる」のままなら、下のバーの
   「国と領土」を一度開きます）。砦の行を選んで「確認した命令で出発」。決着待ちのときは、同じ命令のまま整い次第 1 回だけ
   送ります。「最初の出陣」が出れば出発しています。
7. **衝突の確認**: 着いたターンに「戦闘 … 衝突が決着しました」が出ます。「報告」→「このブラウザで確かめる」で
   「一致：このブラウザで計算し直した結果はチェーンの記録と同じです」が出れば確認できています。
   お知らせが消えたあとも、下のバーの「その他」の一覧に「報告」ボタンが残っています。
8. **奪取**: 砦のマスを 72 ターン保つと奪取です（×60 で約 12 分以上、1× では約 12 時間）。地図の砦の上の「砦を保持中」と
   丸い数字、または衝突の報告の「奪取まで N/72 ターン」で進み具合を見られます。

知っておくこと:

- **中央はありません（ローカルの世界だけのルール、#88）。** 第1輪の 6 州は普通の土地で、それぞれどこかの国が砦を持って
  始まります（いつもの地図では 6 つの国が 1 州ずつ）。本国（第2〜3輪）の砦は守られていて奪えませんが、**第1輪の砦は奪い合えます**。保存する世界でも AI 住民は
  ここへ進軍し（#98 の確認では開始から 8 ターンめに出発、12〜13 ターンめに衝突）、自分の国の砦が攻められると「国と領土」に
  「他国が占拠を進めている、あなたの国の砦 … 守りに向かう」と出ます。真ん中の 1 州 (0,0) だけは「第0輪（中央・州なし）」で、
  行き先にも通り道にもなりません。最初の村は第2輪より外にだけ置けます。
- **霧のため、砦の一覧に出るのは見えている他国の砦だけです**（§5）。「見えている他国の砦で、この軍勢がいま届くものは
  ありません。」は不具合ではありません。
- 1× の保存する世界では、包囲は見られますが、奪取（72 ターン＝12 時間）まではまず見られません。奪取は `--demo` か
  `--wide` で確かめてください。

### 3.1 二人で一つの世界（`--two`）

ふつうは、ブラウザ（アドレス）ごとに別の世界になります（同時に 2 つまで）。二人で同じ世界に入るには `--two` を付けます。

```bash
scripts/play-local.sh --two            # 保存する世界を二人で
scripts/play-local.sh --demo --two     # 15 分の攻略デモを二人で
```

1. 1 人目は `http://localhost:41920/` で「世界を開始」を押します。「もう一人のプレイヤーを待っています」と出て、待ちます
   （約 4 分。過ぎたらもう一度押します）。
2. 2 人目は、**別のブラウザ**（または別のプロファイル）で同じアドレスを開くか、同じブラウザなら
   **`http://127.0.0.1:41920/`** を開いて、同じボタンを押します（テスト鍵はブラウザとアドレスごとに一つです）。
3. 二人がそろうと一つの世界が始まり、それぞれが国を選んで村を置きます。
- `--resume` で同じ二人の世界に戻ります（`--two` は付けなくて構いません）。前回と同じブラウザ・同じアドレスで開いてください。
- 一人用で始めた保存する世界は、あとから二人用にはできません（`--fresh --two` で新しく始めます）。
- どちらかが「世界を終了」すると二人とも止まります。3 人目は入れません。`--wide` は一人用です。

## 4. 広い土地を確かめる（`--wide`、約 60〜90 分）

```bash
scripts/play-local.sh --wide --ai 4 --minutes 180
```

世界の準備（約 20 秒）のあいだに、プログラム自身の命令で地図をリング 128（辺境）まで広げ、その外の広い土地
（リング 129〜131、108 州）を開きます。ゲームはターン 140 ごろから、×60（1 ターン 10 秒）で始まります。
既定の 90 分では下の 4 まで届かないことがあるので、`--minutes 180` を付けてください。

1. **辺境の村**: 「国を選ぶ」で AI のいない国を選ぶと、最初の村の候補に**辺境（リング 128）の州が先に**出ます。
   そのまま始めます。村が「仮の村」のままなら、「収穫する」など自分の操作を一度すると確定します。
2. **広い土地の村（×60 で約 30 分）**: 村の画面の「広い土地に村を出す（テスト）」に費用（木材 1,200 など）と候補の州が
   出ます。蔵がたまったら「ここに村を出す」。申し込みはターンの終わりに決まり、地図にその国の印で描かれます。
   地図でその州を調べると「あなたの村（広い土地）」と「この村を開く」が出ます。
3. **遠征（辺境 → 広い土地）**: 辺境の村で訓練・編成し（§3 の 4〜5）、軍勢を選んで「境界への道を準備」を押します。
   地図の破線のマスを押して、道をリング 128 の外まで伸ばす →「到着ターンの候補」を入れる →「地形・時間を確認」→
   「出発条件を確認」→「出発する（ローカルプレイ）」。到着のターンが終わると、世界の進行役が封を開けて決着します。
   - 到着ターンは「地形・時間を確認」の**前**に入れます（あとで変えるとやり直しです）。
   - 道は地形を見ずに引けてしまいます。山で断られたら、別の道で引き直してください。
   - バーのボタンには「送信しません」と書いてありますが、ローカルではこのカードの最後のボタンで実際に出発します。
4. **広い土地の中の進軍（広い土地 → 広い土地）**: 2 の村を開くと「広い土地の軍勢（テスト）」のカードがあります。
   「次の一手（広い土地）」を 1 ターンに 1 回押すと、槍兵を訓練 → 軍勢を編成 → 隣の州の砦へ進軍、と一手ずつ進みます
   （理由がカードに出ます）。新しい村の蔵は空から始まり、その州の決着が追いつくまで数分は編成が断られます。
   砦の上に 72 ターンとどまると砦を奪います。
- **見えかた**: 広い土地は、普通の地図と「全体図」の六つの角の外側に、**自分が見たところまで**描かれます（霧）。
  「支配する州」と国の順位は、辺境と広い土地の砦も数えます（#102）。
- **AI 住民**も辺境に村を申し込み、蔵をためて広い土地に村を出し、遠征と戦争をします。ただし戦場は相手の国の辺境なので、
  霧の中でほとんど見えません。自分の国の砦が攻められたときだけ「国と領土」に出ます。
- **AI の奪取を見たいとき**は `--wide --speed 15`（1 ターン 40 秒）が安定です（#102 の確認: 順位が遅れず、開始から
  約 90 ターンで奪取が順位に反映）。ただし広い土地の村の費用がたまるのは約 2 時間後になります。
- 時計が速いほど、このマシンの負荷で世界の進行が遅れます（§8）。ほかの重い作業を止めて試してください。

## 5. 霧（ローカルの試験世界すべて、#93）

Civ のようなプレイヤー視点です。表示だけの霧で、ローカルチェーンの記録は公開のまま、devnet には何も変わりません。

| | 見えるもの |
|---|---|
| いま見える | 自分の村と軍勢のまわり、自分の国の村と、自分の国が持つ州のまわり。同盟国とは視界を分けません |
| 前に見た | 最後に見たときのようすが薄く残ります（村、砦とその持ち主）。このブラウザに保存 |
| まだ見ていない | 地図でも「全体図」でも白紙。地形も村も砦も国の色も出ません |
| 他国の軍勢・進軍・衝突・争奪 | いま見えている場所でだけ。残像は残しません |
| 自分の村へ向かう敵 | 見えている場所から出発したとき、または到着の 3 ターン前から「来襲」として知らせます |

- 砦の一覧、調べる画面、年代記、知らせ、ミニマップも同じ決まりです。
- 霧の世界では、地図右下の「記録」（記録された世界の全州）と、観戦ページへのリンクは**出ません**。
- スイッチは一つ: `permutation-server/web/frontier/map/fog.mjs` の `LOCAL_FOG`（`false` で霧なし）。半径などは同じ
  ファイルの `FOG_RULES`。devnet・観戦ページ・練習のページには霧はありません。

## 6. 止める・あした続ける

1. 止めるときは、スクリプトを動かしている端末で **Ctrl-C** を押します。世界を閉じてから終わり、ログの場所を表示します。
2. 保存する世界は、次の日に同じ Mac・同じブラウザで続けられます。止めていたあいだ、世界の時計は止まっています。

   ```bash
   scripts/play-local.sh --resume
   ```

   同じアドレスが開くので、「世界を開始（保存された世界は続きから）」を押すと前回の村に戻ります。
- `--demo` と `--wide` の世界は保存されません。止めたらブラウザのタブを閉じてください。遊んでいる途中で**ページを
  再読み込みしないでください**（テスト鍵はメモリにだけあり、その世界に戻れなくなります）。
- `git pull` などでプログラムが変わると、前の世界は続けられません。スクリプトがそう表示するので `--fresh` で始め直します。
- `--resume` が開くのは最後に始めた保存する世界だけです。前の世界に戻すには、`.local/play-local/last-kept` の中身を
  そのフォルダ（`…/.local/play-local/kept/<日時>`）に書き換えます。
- 世界は既定で 90 分たつとプロセスが止まります（`--minutes`）。保存する世界なら、そのあとも `--resume` で続けられます。
- テスト鍵を消すには、ページのパネルの「このブラウザに保存した試験用の鍵を消す」。世界のフォルダは自分で消すまで残ります。

## 7. ローカルだけのもの・devnet と同じもの

| | ローカル（このスクリプト） | devnet の遊べる版（まだ出していません） |
|---|---|---|
| プログラム | ローカル専用の `.so`（プログラム ID `[0x45; 32]`、デプロイ不可） | devnet 用の `.so`（別のビルド。ローカルの機能は入りません） |
| 中央 | **なし**（世界ごとのシーズンのバイト `centre` = 1） | プリセットは中央あり（`CENTRE_PLAYABLE` の切り替えは r0ze の判断） |
| 広い土地を申し込める村 | 「集落」から（`--wide` だけ `outpost_tier_min` = 0） | 「町」から（プリセットは 1） |
| 辺境の最初の村 | 準備でテスト住民が先に入植、進行役が申し込みを決着 | #104（ドラフト）で対応中 |
| 辺境 → 広い土地の遠征 | できます（0x4804 の遠征、#92） | 同じ命令が入っています |
| 広い土地 → 広い土地の進軍・広い土地の砦の奪取 | できます（ローカル専用の機能 `localnet-wide-depart`、#94） | **閉じています**（WideDepart） |
| 時計 | ×10〜×60 に早められる（テスト用の時計） | 通常の速さだけ |
| AI 住民の戦争・進行役が封を開けること | ランチャーのテスト用の仕組み | このランチャーの仕組みはありません |
| 霧 | あり（表示だけ） | なし |

砦の本国保護、72 ターンの奪取、衝突の計算、村・建設・訓練の費用は devnet と同じルールです。

## 8. 知られている問題（2026-11-20、main）

- **争っている州は、負荷が高いとチェーンより遅れます。** ×60 では参加のあと数分で、どの州も 10〜24 ターン遅れることが
  あります（#102 の確認、負荷の高い Mac）。そのあいだ編成や出発は「送信待ち」になり、ページは「この州の決着が N ターン
  遅れています。このマシンの負荷が高く…」と言って、追いつき次第 1 回だけ送ります。押し直す必要はありません。
- **×60 で封を開ける時間（約 10 秒）を逃した進軍は、その州を止めます。** 包囲の数字が進まず、そこへ向かった自分の軍勢は
  「位置を読み込んでいます」のまま、「支配する州」と順位もそのターンで止まります（#102 の確認で ×60 は 1 つの世界で 3 回、
  ×15 は 0 回）。ふつうの進軍の分は #105（ドラフト）で直しているところです。広い土地への遠征が逃した場合の決着は
  プログラムに無く、r0ze の判断待ちです（§−2.4f (d)）。
- **包囲されている州は 1 分に 1 ターンほどしか進みません**（×60 ではチェーンの 6 分の 1。#105 の確認）。奪取のあとは
  すぐ追いつきます。順位の「第 N ターンまでの確定した得点」は、いちばん遅い州のターンです。
- **辺境の村が「仮の村」のまま**のときは、自分の操作（「収穫する」など）を一度すると確定します。画面の「遅くとも…」の
  時刻どおりには確定しません。
- **AI 住民は多くのターンを断られた送信に使います**（蔵が足りない訓練など）。動きが遅く見えますが、ルールどおりです。
  ×60 の `--wide --ai 4` では、AI は 1 人 256 回の送信で止まります（約 45〜60 分後）。
- 広い土地の村を出す場所は、空いている場所だけが候補に出ます。3 つめの村の費用（2,400）は「集落」の蔵（上限 2,000）
  では足りません。
- 遠征のカードは地形を見ません（山を通る道は出発で断られます）。
- 「記録」の画面は霧の世界では出ません（`LOCAL_FOG` を `false` にすると出ます）。

## 9. 困ったとき・知らせ先

- ログの場所:
  - 保存する世界: `.local/play-local/kept/<日時>/`（`launcher-<日時>.log`、`persist/<アドレス>/starts/<回>/` に
    runner・herald・relay・operators のログ）
  - `--demo` と `--wide`: `.local/play-local/worlds/<日時>/`（`launcher-<日時>.log` と世界ごとのフォルダ。
    `--wide` では `wide-land.json` に広げたリングと開いた州、`runner.out` の 1 行めの `local_rules` に
    プリセットから変えたバイトが書かれます）
  - 起動コマンドは同じフォルダの `command.txt` です。
- 「ポートがふさがっています」と出たら、別の `--port`（例 `--port 41450`）にするか、前の世界を止めてください。
- 知らせ先は GitHub の Issue（r0ze998/wylls）です。画面のスクリーンショットと、上のフォルダの場所を添えてください。
