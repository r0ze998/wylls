# ローカルで遊んで確かめる（TEST 専用・ワンコマンド）

devnet に出す前に、手元の Mac で遊べる版（遠征・広い土地・砦の奪取）を自分で確かめるための手順です。
使うのは手元のローカルチェーンとテスト鍵だけです。本物の鍵・SOL・devnet・有料 API は一切使いません。
2026-11-21 時点の main（#131 と #129 まで）に合わせています（loop-play6 までの確認を反映。fix-loop6 の #130 はまだ下書きで、入っていません → §8）。英語版: [PLAY-LOCAL.md](PLAY-LOCAL.md)

## 1. 最初に一度だけ入れるもの

スクリプトは何もインストールしません。足りないものがあれば、名前と入れ方を表示して止まります。

| もの | 版 | 入れ方の例 |
|---|---|---|
| Rust（rustup） | 1.89.0 と 1.95.0 | `rustup toolchain install 1.89.0 1.95.0 --profile minimal` |
| cargo-build-sbf と platform-tools | 3.1.9 / v1.52 | `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.9/install)"` |
| Node.js | 20 以上 | `brew install node`（`node -v` が v20 以上ならそのままで構いません） |
| git・python3 | macOS 標準 | 入っていなければ `xcode-select --install` |
| 空きディスク | 初回 20 GiB 以上 | |

初回のビルドは crate を取りにネットワークを使います。遊んでいるあいだも、keeper が公開の drand 乱数を HTTPS で読みます。

## 2. ワンコマンド

リポジトリの一番上で実行します。道具の確認 → ビルド（変更がなければ省きます）→ 世界の起動 → ブラウザで
`http://localhost:41920/` を開く、まで進みます。初回のビルドは約 3 分、2 回目以降は数秒です。

```bash
scripts/play-local.sh                 # 保存する世界（1 ターン 10 分。止めても --resume で続き）
scripts/play-local.sh --demo          # 15 分の攻略デモ（×60、1 ターン 10 秒。保存なし）
scripts/play-local.sh --wide          # 広い版（辺境と広い土地。×60。保存なし）→ §4
scripts/play-local.sh --coexist --demo --two   # ② 権利（在庫の交換）を二人で一周（×60。保存なし）→ §10
```

世界は 3 種類です。どれも霧（§5）がかかり、AI 住民は既定で戦争をします。`--coexist` は 4 つめの世界ではなく、
保存する世界か `--demo` を ② 権利つきのプログラムで動かす指定です（§10）。

| 世界 | 時計 | 保存 | 向いている確認 |
|---|---|---|---|
| 保存する世界（既定） | 通常（1 ターン 10 分） | あり（`.local/play-local/kept/`、テスト鍵はブラウザ） | 参加・村・建設・訓練・編成、止めて続ける |
| `--demo` | ×60（`--speed` で 10〜60） | なし | 砦へ進軍・衝突・奪取を 15 分で |
| `--wide` | ×60（`--speed` で 10〜60） | なし | 辺境の村 → 広い土地の村 → 遠征 → 広い土地の中の進軍 |

指定:

| 指定 | 意味 | 一緒に使えないもの |
|---|---|---|
| `--resume` | 最後に始めた保存する世界を続けます（同じブラウザ・同じポート・同じ AI の数） | `--fresh` `--demo` `--wide` `--random-map`、違う `--port` / `--ai` |
| `--fresh` | 保存する世界を新しく始めます（何も付けないときと同じ） | `--resume` `--wide` |
| `--demo` | 15 分の攻略デモ | `--resume` `--wide` |
| `--wide` | 広い版（§4） | `--demo` `--resume` `--fresh` `--two` `--coexist` |
| `--random-map` | 新しい世界に、その世界だけの地図。付けないと**ローカルの世界は毎回同じ地図**です | `--resume` |
| `--ai N` | AI 住民の数 0〜4（既定 2）。**既定で戦争をします**: 届く他国の砦へ進軍・包囲（1 人 1 ターンに 1 行動） | |
| `--ai-peaceful` | AI は砦へ進軍しません（建設・収穫・訓練・編成。`--wide` では辺境と広い土地の村・遠征もします） | |
| `--two` | 二人で一つの世界（§3.1） | `--wide` |
| `--coexist` | ② 権利つきの世界（§10）。保存する世界か `--demo`。`--ai` `--two` `--random-map` `--resume` と使えます | `--wide` |
| `--speed N` | `--demo` / `--wide` の時計 10〜60（既定 60） | 保存する世界 |
| `--minutes N` | 世界のプロセスが止まるまでの分 15〜240（既定 90） | |
| `--port BASE` | ページのポート（既定 41920）。BASE から 22 個（`--ai 0` なら 14 個）を使います。41000〜41999 の中で、41904〜41907 と 41970 を含まないこと | |
| `--lang ja\|en` | スクリプトの表示の言語（ページは右上のボタンで切り替え） | |
| `--no-open` `--no-build` `--rebuild` `--check-only` `--print-plan` | 開かない / ビルドしない / 必ずビルド / 確認だけ / 設定と起動コマンドを表示して終わる | |
| `--coexist-node` | ページのない ②⑨⑩ のノードだけ（開発用。遊ぶ用ではありません） | `--port` 以外のすべて |

- AI 住民が入る国は決まっています: 1 人目ボレアリス、2 人目エンバー、3 人目シンダー、4 人目フィヨルダル。
  **AI のいない国**（`--ai 4` ならアステルかダンマール）を選ぶと、村の場所の取り合いになりません。
- `--random-map` は、ランダムに選んだ過去の時刻から世界を始め、プログラムが変更なしのルールで別の創世シードを導きます。
- 止めるのは端末の **Ctrl-C** です（§6）。

## 3. 15 分のチェック

`--demo` で 1〜8 を通せます。保存する世界では 1〜5 をして、§6 の手順で止めて続きから再開します
（1× では、編成した軍勢が動けるのはターンが決着してから＝約 17 分後です）。

1. **参加**: 「世界を開始（保存された世界は続きから）」（`--demo` では「新しい世界を開始」）→「国を選ぶ」→ 旗を一つ選び、
   「（国の名前）で始める」を押します。最初の村は自動で置かれます。鍵のカードやウォレットの確認は出ません。
2. **村**: 「ここが、あなたの村です。」が出たら成功です。地図の上の「鉱石 +2」を見てください。
   「地形の鉱石なし」の村は、兵を 600 人ほどまでしか増やせません。
3. **建設**: 「最初の建設を選ぶ」→ 農場の「建てる」。約 1 分（ゲーム内）で完成します。
4. **訓練**: 下のバーの「訓練」→「最大 500」→「槍兵 500 を訓練する」。すぐ終わります。
5. **編成**: 下のバーの「編成」（右上のガイドが「軍勢を編成する」なら、それを押しても同じ）→「全部」→
   「槍兵 N をここに集める」。「この州はまだ前のターンの決着が済んでいません」と出ていても**押して構いません**。
   送信待ちになり、整い次第 1 回だけ送ります（押し直しは不要。兵種・兵数が変わると取り消します）。
   村の画面の「兵」の「編成する」は、決着待ちのあいだ押せません（送信待ちになるのは下のバーの「編成」だけです）。
   軍勢が整列するまでのあいだ、右上のガイドは「ガイド 3/7 軍勢の整列を待つ」と出ます（その間にできることがあれば
   「待つ間に：建設をひらく」のように添えます）。「軍勢の準備を確かめる」か「届く砦を見る」になれば編成できています。
6. **砦へ進軍**: 右上のガイドが「届く砦を見る」になったら押します（「軍勢の準備を確かめる」のままなら、下のバーの
   「国と領土」を一度開きます）。砦の行を選んで「確認した命令で出発」。決着待ちのときは、同じ命令のまま整い次第 1 回だけ
   送ります。「最初の出陣」が出れば出発しています。
   - 一覧が「届く砦 0」（「見えている他国の砦で、この軍勢がいま届くものはありません。」）のときは、村のまわりから他国の
     砦が見えていません（`--random-map` ではよくあります。ガイドは見えていない砦も数えて「届く砦を見る」と出します）。
     下のバーの「進軍」を押し、地図で第1輪の州の砦のマス（霧で白紙でも押せます）を行き先に選んで「確認した命令で出発」で
     攻められます（行き先は「見えていない土地」と表示されます）。進軍は体力を 10＋2×マス数
     使い（9 マスなら 28、32 マスなら 74。上限 120）、体力は 1 ターンに 1 戻ります。遠い白紙のマスへ先に偵察に出すと、
     体力が戻るまで砦へ出発できないことがあります（loop-play6 では約 30 ターン待ちました）。
7. **衝突の確認**: 着いたターンに「戦闘 … 衝突が決着しました」が出ます。「報告」→「このブラウザで確かめる」で
   「一致：このブラウザで計算し直した結果はチェーンの記録と同じです」が出れば確認できています。
   お知らせが消えたあとも、下のバーの「その他」の一覧に「報告」ボタンが残っています。
8. **奪取**: 砦のマスを 72 ターン保つと奪取です（×60 で約 12 分以上、1× では約 12 時間）。地図の砦の上の「砦を保持中」と
   丸い数字、または衝突の報告の「奪取まで N/72 ターン」で進み具合を見られます。保持のターンは、州が決着しても
   飛ばされても 1 ターンに 1 つ数えます（#120 の確認: ×60 の `--wide --ai 4` で AI が 11 回奪取、どれも保持 72 ターン）。

知っておくこと:

- **中央はありません（ローカルの世界だけのルール、#88）。** 第1輪の 6 州は普通の土地で、それぞれどこかの国が砦を持って
  始まります（いつもの地図では 6 つの国が 1 州ずつ）。本国（第2〜3輪）の砦は守られていて奪えませんが、**第1輪の砦は奪い合えます**。保存する世界でも AI 住民は
  ここへ進軍し（#98 の確認では開始から 8 ターンめに出発、12〜13 ターンめに衝突）、自分の国の砦が攻められると知らせ
  「州 P,Q の砦を （国）が攻めはじめた／あなたの国が守っている」が出ます。「国と領土」の「他国が占拠を進めている、あなたの国の砦
  … 守りに向かう」は、その砦があなたの軍勢の届く範囲にあるときだけ出ます（loop-play6）。真ん中の 1 州 (0,0) だけは「第0輪（中央・州なし）」で、
  行き先にも通り道にもなりません。最初の村は第2輪より外にだけ置けます。
- **霧のため、砦の一覧に出るのは見えている他国の砦だけです**（§5）。「見えている他国の砦で、この軍勢がいま届くものは
  ありません。」は不具合ではありません。
- 1× の保存する世界では、包囲は見られますが、奪取（72 ターン＝12 時間）まではまず見られません。奪取は `--demo` か
  `--wide` で確かめてください。

### 3.1 二人で一つの世界（`--two`）

ふつうは、ブラウザ（アドレス）ごとに別の世界になります（同時に 2 つまで）。二人で同じ世界に入るには `--two` を付けます。

```bash
scripts/play-local.sh --two            # 保存する世界を二人で
scripts/play-local.sh --demo --two     # 15 分の攻略デモを二人で
```

1. 1 人目は `http://localhost:41920/` で「世界を開始」を押します。「もう一人のプレイヤーを待っています」と出て、待ちます
   （約 4 分。過ぎたらもう一度押します）。
2. 2 人目は、**別のブラウザ**（または別のプロファイル）で同じアドレスを開くか、同じブラウザなら
   **`http://127.0.0.1:41920/`** を開いて、同じボタンを押します（テスト鍵はブラウザとアドレスごとに一つです）。
3. 二人がそろうと一つの世界が始まり、それぞれが国を選んで村を置きます。
- `--resume` で同じ二人の世界に戻ります（`--two` は付けなくて構いません）。前回と同じブラウザ・同じアドレスで開いてください。
- 一人用で始めた保存する世界は、あとから二人用にはできません（`--fresh --two` で新しく始めます）。
- どちらかが「世界を終了」すると二人とも止まります。3 人目は入れません。`--wide` は一人用です。

## 4. 広い土地を確かめる（`--wide`、約 60〜90 分）

```bash
scripts/play-local.sh --wide --ai 4 --minutes 180
```

世界の準備（約 20 秒）のあいだに、プログラム自身の命令で地図をリング 128（辺境）まで広げ、その外の広い土地
（リング 129〜131、108 州）を開きます。ゲームはターン 140 ごろから、×60（1 ターン 10 秒）で始まります。
既定の 90 分では下の 4 まで届かないことがあるので、`--minutes 180` を付けてください。

1. **辺境の村**: 「国を選ぶ」で AI のいない国（`--ai 4` ならアステルかダンマール）を選び、「（国の名前）で始める」。
   場所は選びません。ページが**辺境（リング 128）の州**に村を申し込み（「辺境の村を申し込んでいます…」→
   「辺境の村を申し込みました。ターンの終わりに決まります。」）、数ターン（負荷が高いと約 60 ターン・約 10 分。そのあいだ「村の受け取りを確認しています…」。**押し直す必要はありません**）で「（名前）の集落ができました」と出ます。
   村の名前に「仮」が付いているあいだは、村の画面の「収穫する」を一度押すと確定します（「…が確定しました」）。
   辺境の村には「初めての建設」（1 分）はなく、農場も 1 時間 30 分（×60 で約 1 分半）かかります。
   - 「（国の名前）で始める」は、`--wide` では 1 回で通らないことがあります（loop-play6 では 3〜4 回）。**連打しないでください**:
     前の押下が村の場所を読んでいる途中で次を押すと、前の読み取りが打ち切られます（fix-loop6 の調べ）。押して 5〜10 秒
     待ち、画面が変わらなければもう一度押します。
   - 最初に「留守のあいだ：この端末では、このシーズンとウォレットで確認した記録がありません…」のカードが出たら、
     「確認した」を押して閉じます（世界がターン 140 ごろから始まるためで、不具合ではありません）。
2. **広い土地の村（×60 で約 30 分）**: 村の画面の「広い土地に村を出す（テスト）」に費用（木材 1,200 など）と候補の州が
   出ます。蔵がたまったら「ここに村を出す」。申し込みはターンの終わりに決まり、地図にその国の印で描かれます。
   いちばん簡単な開きかたは、左下の村の札の下に出る「W2」を押すことです（「遠方の村 第129輪（枠 2）」が開きます）。
   地図でその州を調べて「あなたの村（広い土地）」→「この村を開く」でも開けます。
   - 訓練（§3 の 4）は蔵の食料と金を使います。先に広い土地の村を出してから訓練すると、待ち時間が短くなります。
3. **遠征（辺境 → 広い土地）**: 辺境の村で訓練・編成し（§3 の 4〜5）、下のバーの軍勢（「槍兵 500」など）を選んで
   「境界への道を準備」を押します。
   1. 方角のボタン（東・北東・北西・西・南西・南東）か地図の破線のマスで一歩ずつ道を引き、「道から決まる終点」が
      広い土地の州（リング 129 以上）になるまで伸ばします。開いている広い土地は、リング 129〜131 のうち地図に描かれる
      州だけです。開いていない州が終点になると、カードにすぐ「終点の州 P,Q は、この世界ではまだ開いていません…
      いちばん近い開いた州は …（N 州先）です。」と出ます。
   2. **×60（既定）では、先に到着ターンを自分で入れます。** カードの下の「詳細」を開き、「到着ターンの候補」の欄に
      **いまのターン＋5** ほどを入れます（例: いまターン 251 なら 256）。main では、カードが出す
      「最も早い候補（ターン A）を使う」が ×60 だと次の確認で断られやすいためです（loop-play6 では 24 回とも
      断られました。fix-loop5 と verify-pr117 では通りました。ページの時計がチェーンの時計より遅れているほど
      断られます）。欄を空のまま 3 に進み、出てきた「最も早い候補（ターン A）を使う」を押す道も残っています。
      `--speed 10`〜`15` のゆっくりした時計なら、そちらで構いません。
   3. 「地形・時間を確認」。「山や水のマスには進めません (N)」と出たら N 歩めが通れません。「一歩戻す」か「道を消す」で
      別の道にします（道は地形を見ずに引けてしまいます）。通れる道なら「到着候補：ターン A〜B」が出ます。
      結果はカードの中で見える位置まで自動で送られます。
   4. すぐ続けて「出発条件を確認」→「この読取時点では、軍勢と村の出発条件を満たしています。」が出たら、すぐ
      「出発する（ローカルプレイ）」。
      - ×60 では「…満たしていません。 (NotResident)」がよく出ます（州の決着がターンの一部の時間しか整っていないため）。
        **ここだけは押し直しが要ります**: 1〜2 秒おいて「出発条件を確認」をもう一度押します。この確認は読み取りだけで、
        何も送りません（中継の送信の上限にも数えません）。loop-play6 では 17 回・18 秒、fix-loop5 では 16 回・27 秒、
        verify-pr117 では 2 回・約 45 秒で出発できました（#109 の前は約 60 回・約 10 分）。
      - ×60 では、確認の結果は**画面に 0.3〜2 秒しか残りません**（世界の時計を読むたびに結果が捨てられるため。
        verify-pr117 V117-1）。結果が出たら迷わず次のボタンを押します。消えたら、消えた段（「地形・時間を確認」か
        「出発条件を確認」）から押し直します。ターンが変わったときも同じです。
      - うまくいかないとき:
        「到着ターンの候補が、記録から計算した範囲に入りません。」＝ 到着ターンが早すぎます（2 の欄にもう少し先の
        ターンを入れ直して 3 から）。「地形・時間を確認」を押しても何も出ない ＝ 到着ターンの欄が空です（案内は
        たたまれた「詳細」の中にしか出ません）。「読み取りの途中で世界の時計が進んだため… もう一度押してください。」＝
        読み取りの途中で時計が進み、ページが 2 回読み直しても間に合いませんでした。押し直します。
   5. 「出発が確定しました（ターン N に到着予定・移動枠 0）」が出れば出発しています。
   - **封は世界の進行役が開けます。** 到着のあと、地図の札は「ターン N に到着」→「到着 · 開封を待っています」→
     「到着 · 封は開きました · 結果の確定を待っています」と変わり、行き先の州が追いつくと進軍の画面に
     「結果を受け取りました　留まる：軍勢は広い土地の州に立っています（兵 500）」と出ます。待つだけで構いません
     （fix-loop5・verify-pr117・loop-play6 の 3 回とも、進行役が期間内に開けました）。
   - 予備として、到着のターンにはこのページでも封を開けられます（境界のカードの中の「封を開けるか確認する」→
     「封を開く（ローカルプレイ）」）。#105 より前の、負荷の高いマシンの ×60 では進行役が約 10 秒の期間を逃したことが
     あります（§8）。「封を開ける期間が終わっています。(RevealWindowClosed)」と出たら、その遠征はもう決着しません。
   - 次の軍勢を出す前に、カードの「送信しました。確定はまだ確認できていません」の下の「結果を照合する」を一度押します
     （押さないと「出発する」が出ません）。
   - バーのボタンには「送信しません」と書いてありますが、ローカルではこのカードの最後のボタンで実際に出発します。
4. **広い土地の中の進軍（広い土地 → 広い土地）**: 2 の村を開くと「広い土地の軍勢（テスト）」のカードがあります。
   「次の一手（広い土地）」を押すと、槍兵を訓練 → 軍勢を編成 → 隣の州の砦へ進軍、と一手ずつ進みます。
   **1 手につき 1 回押して、あとは待ちます**（訓練・編成・進軍で合わせて 3 回）。
   - 村の見出しには「読み取り専用：この村には命令を送れません（収穫・建設・訓練・編成・進軍・隊商・追いつかせる の
     どれも）」と出ますが、このカードだけは実際に訓練・編成・進軍を送ります（見出しの文が古いままです。loop-play6 LP6-6）。
   - 次の一手の理由は、日本語の画面でもカードに英語で出ます。`train 100 Spearmen …` = 訓練、
     `a host of 100 Spearmen at the wide village …` = 編成、
     `the host (100 troops) marches wide -> wide … arriving turn N` = 進軍、
     `its host is away (a march is open)` = 軍勢は進軍に出ていて、いまは打つ手がありません。
     英語の画面にしても、カードの見出しと説明は日本語のままです（LP6-15）。
   - 新しい村の州は、最初はチェーンより大きく遅れます（loop-play4 では村ができてから 77 ターン、loop-play5 では
     最大約 180 ターン遅れました）。**州が遅れているあいだは、押し続けないでください。** カードが「この村の州の決着が
     N ターン遅れています。…このページが約 1 ターンごとに自動で確かめ、送れるようになったら一手を送ります。」と出して
     自分で待ちます（ボタンは「待っています…（押す必要はありません）」になって押せなくなり、「待つのをやめる」で
     止められます）。待つ理由はほかに「軍勢が整列中か休んでいます。進軍できるようになるまで待ちます。」などがあります。
     送るあいだにターンが変わって断られたとき（NotResident）や、進軍の送信が 1 回失敗したときも、次のターンに自動で
     もう一度送ります（verify-pr117: 「次の一手」を 2 秒おきに 10 分押し続けても、ページが送ったのは 4 回だけで、
     訓練 → 編成 → 進軍まで進みました。loop-play6: 187 ターンの遅れのあいだカードが自分で待ち、約 3 分で送りました）。
   - 進軍の封は世界の進行役が開け、行き先の州が遅れていてもまとめて追いつかせます（verify-pr106 では到着から数分で
     開封・衝突・決着）。下のバーの「進軍」の一覧には、広い土地の中の進軍は出ません。砦の上に 72 ターンとどまると
     砦を奪います。**このページには、その進軍の結果（衝突・占拠の進み）がまだ出ません**: 出発のあと、カードは英語の
     `its host is away (a march is open)` のままです（loop-play6: 開封はターン 365、行き先の州はターン 433 まで決着済み）。
     行き先の州も霧で白紙のままです。
- **見えかた**: 広い土地は、普通の地図と「全体図」の六つの角の外側に、**自分が見たところまで**描かれます（霧）。
  「支配する州」と国の順位は、辺境と広い土地の砦も数えます（#102）。
- **AI 住民**も辺境に村を申し込み、蔵をためて広い土地に村を出し、戦争をします（loop-play6: 広い土地の村 4、砦への
  出発 70）。ただし戦場は相手の国の辺境なので、霧の中でほとんど見えません。自分の国の砦が攻められたときだけ
  知らせが出ます。**AI の辺境 → 広い土地の遠征は、main ではほぼ届きません**（loop-play6: 454 回試みて 0 回。
  ターンが変わった直後に 1 回だけ確認して断られるため。#130 で直る予定）。AI の広い土地の中の進軍は届きます。
- **AI の奪取を見たいとき**は `--wide --speed 15`（1 ターン 40 秒）が安定です（#102 の確認: 順位が遅れず、開始から
  約 90 ターンで奪取が順位に反映）。ただし広い土地の村の費用がたまるのは約 2 時間後になります。runner-throughput の
  変更からは ×60 でも順位は遅れません（数ターン遅れ）が、戦いはすぐに過ぎていきます。
- 時計が速いほど、このマシンの負荷で世界の進行が遅れます（§8）。ほかの重い作業を止めて試してください。

## 5. 霧（ローカルの試験世界すべて、#93）

Civ のようなプレイヤー視点です。表示だけの霧で、ローカルチェーンの記録は公開のままです。devnet のページにも同じ霧が
かかります（fog-devnet、ランブック §7 P5）。

| | 見えるもの |
|---|---|
| いま見える | 自分の村と軍勢のまわり、自分の国の村と、自分の国が持つ州のまわり。同盟国とは視界を分けません |
| 前に見た | 最後に見たときのようすが薄く残ります（村、砦とその持ち主）。このブラウザに保存 |
| まだ見ていない | 地図でも「全体図」でも白紙。地形も村も砦も国の色も出ません |
| 他国の軍勢・進軍・衝突・争奪 | いま見えている場所でだけ。残像は残しません |
| 自分の村へ向かう敵 | 見えている場所から出発したとき、または到着の 3 ターン前から「来襲」として知らせます |

- 砦の一覧、調べる画面、年代記、知らせ、ミニマップも同じ決まりです。
- **他国どうしの衝突の報告と「戦いを再生」**は、その州の砦のマス（砦がなければ州全体）がいま見えているときだけ
  出ます。州の端の数マスが見えているだけでは出ません。自分の村の州と、自分の進軍が着いた衝突はいつでも見られます。
  見えていない衝突の報告を開こうとすると「この場所はいま見えていません。…」と出て、何も読みません。
  地図の衝突の印（赤い輪・ミニマップの点・「このターンに衝突あり」）、年代記の「…で衝突が決着した」と「最近の衝突」、
  他国どうしの砦の争奪・奪取の知らせも同じ決まりです（自分の国が関わる砦の知らせはいつでも出ます）。
  地図の上の他国の出来事（「…の新しい村」、出発、到着、野営地の消滅）は、そのマスがいま見えているときだけ出ます。
  進軍の「近くの行き先」の野営地は、測量したことのあるマスのものだけです。
- 霧の世界では、地図右下の「記録」（記録された世界の全州）と、観戦ページへのリンク（凡例と設定の「観戦ページ」）は、
  最初の画面から**出ません**（fog-devnet：以前は最初の村を置くまで凡例と設定にリンクが出ていました）。
- スイッチはモードごとに一つ: `permutation-server/web/frontier/map/fog.mjs` の `LOCAL_FOG`（ローカルの試験世界）と
  `DEVNET_FOG`（fog-devnet：クラスタが `devnet` のシーズンのプレイ画面）。`false` でそのモードは霧なし。半径などは
  同じファイルの `FOG_RULES`。観戦ページと練習のページには霧はありません。

## 6. 止める・あした続ける

1. 止めるときは、スクリプトを動かしている端末で **Ctrl-C** を押します。世界を閉じてから終わり、ログの場所を表示します。
   - 世界が時間切れ（`--minutes`）で止まってから何時間もたったあとの Ctrl-C で、スクリプトが終わらなかったことが 1 回
     あります（loop-play6: `--wide --ai 4` を時間切れのあと約 7 時間放置。15 分の `--demo` では再現せず、原因は不明）。
     main ではもう一度 Ctrl-C を押しても変わりません。そのときは別の端末で `pgrep -fl local-play-launcher` を実行し、
     自分のポート（`--port 41920` など）が入っている行の先頭の番号だけを `kill -KILL <番号>` で止めます
     （ほかの行は、ほかの世界のランチャーです。止めないでください）。
2. 保存する世界は、次の日に同じ Mac・同じブラウザで続けられます。止めていたあいだ、世界の時計は止まっています。

   ```bash
   scripts/play-local.sh --resume
   ```

   同じアドレスが開くので、「世界を開始（保存された世界は続きから）」を押すと前回の村に戻ります。
- `--demo` と `--wide` の世界は保存されません。止めたらブラウザのタブを閉じてください。遊んでいる途中で**ページを
  再読み込みしないでください**（テスト鍵はメモリにだけあり、その世界に戻れなくなります）。
- `git pull` などでプログラムが変わると、前の世界は続けられません。スクリプトがそう表示するので `--fresh` で始め直します。
- `--resume` が開くのは最後に始めた保存する世界だけです。前の世界に戻すには、`.local/play-local/last-kept` の中身を
  そのフォルダ（`…/.local/play-local/kept/<日時>`）に書き換えます。
- 世界は既定で 90 分たつとプロセスが止まります（`--minutes`）。保存する世界なら、そのあとも `--resume` で続けられます。
  `--resume` は `--minutes` を覚えていないので、長く遊ぶときは `--resume --minutes 240` のように付け直します。
- テスト鍵を消すには、ページのパネルの「このブラウザに保存した試験用の鍵を消す」。世界のフォルダは自分で消すまで残ります。

### 8.2 ×60 のふるまい（#102・#105・#109・#117・#120 のあと）

- **争っている州は、負荷が高いとチェーンより遅れます。** ×60 では、ふだんはどの州もターン表示より 2〜4 ターン遅れです
  （runner-throughput の確認、`--wide --random-map --ai 4`）。その変更の前や、負荷のとても高い Mac では 10〜24 ターン
  遅れることがあります（#102 の確認）。そのあいだ編成や出発は「送信待ち」になり、ページは「この州の決着が N ターン
  遅れています。このマシンの負荷が高く…」と言って、追いつき次第 1 回だけ送ります。押し直す必要はありません。
- **ふつうの進軍が封を開ける時間（×60 で約 10 秒）を逃しても、州は止まりません**（#105）。キーパーは各パスの最初と
  各村のパスの前に、期限の来た進軍の封をすべて先に開けます。それでも逃した進軍（重い負荷での 3 ターンの進軍で見られました）は、
  プログラムが開かれなかった進軍を決着させるとおりに決着します：行き先の州のターンはその進軍なしで決着し、そのあと
  SettleTransit（結果はプログラムが決めます：敗走して村に戻る、または押し戻し）。ランナーの stderr に `reveal-missed` と
  出ます。拒否で止まった村の進軍ドライバーは、6 ステップ（倍々で最大 96。パスではなくドライバーのステップの数です。保存される世界では 1 パスに 1 ステップ、
  `--demo` と `--wide` ではパスの 1 巡ごとに最大 4 ステップ）待って
  からチェーンを読み直して続け、そのあいだその村の軍勢が立つ州は世界の巡回が決着させます。到着ターンを 2 ターンより
  多く過ぎた軍勢の地図の札は「軍勢の到着ターン N から M ターン · 結果の確定を待っています」です。広い土地への遠征が
  逃した場合の決着はプログラムに無く、r0ze の判断待ちです（§−2.4f (d)）。
- **×60 では自分の州は 1〜2 ターンの遅れです**（runner-throughput の確認: ページでの中央値 2、最大 3〜4。変更の前は中央値 4、
  最大 8）。キーパーは AI の村の番の前に毎回あなたの州を決着させ直すので、編成や進軍はたいてい 1 回押せば数秒で
  送られます（確認: 編成 1.8〜5 秒、進軍 2〜14 秒。作者の回では取り消し 0 回、verify-pr109 の回では進軍 12 回中 2 回が
  自分の州が 3 ターン遅れていたときに取り消され、どちらも次に押して送られました。ターンの最後の 1 秒に押した編成が
  1 回断られ、3 秒後に押し直して送られました）。それでも取り消されたとき
  （「送信待ちを取り消しました…」）は、もう一度押してください。
- **広い土地への遠征は、封を開ける期間を逃すと二度と決着しません**（プログラムに決着の道がなく、r0ze の判断待ち）。
  進軍の画面は「到着しました。封が開けられるのを待っています」のままで、その辺境の村からは次の遠征も出せません
  （「出発できませんでした（DepartRolesUnavailable）」）。#105 より前の確認（verify-pr106、負荷の高い Mac の ×60）で
  1 回起きました（`runner.out` に `never revealed: transit 0: the reveal window of bell 262 closed unrevealed`）。
  そのあとの fix-loop5・verify-pr117・loop-play6 では、進行役が毎回期間内に開けています（`reveal-missed` 0 件）。
  心配なときは、到着のターンに §4 の 3 のとおり自分で「封を開く」を押せます。
- **包囲されている州もチェーンについて行きます**（runner-throughput の確認: ×60 でどの州も 1 分に 5.9〜6 ターン。
  チェーンは 6。変更の前は 1〜2）。キーパーはほかの州と包囲の州のターンを、同じブロックにまとめて送って決着させます。
  順位の「第 N ターンまでの確定した得点」は、いちばん遅い州のターンです。ターン表示より数ターン遅れです（変更の前は
  数百ターン。例: ターン 495 で第 251 ターン）。
- **辺境の村が「仮の村」のまま**のときは、自分の操作（「収穫する」など）を一度すると確定します。画面の「遅くとも…」の
  時刻どおりには確定しません。
- **AI 住民は多くのターンを断られた送信に使います**（蔵が足りない訓練など）。動きが遅く見えますが、ルールどおりです。
  AI は 256 回送っても止まりません（#117。loop-play6 では約 3,000 回送って、中継に断られたのは 0 回）。
- **押しすぎで世界が送れなくなることは、もうありません（#117）。** ランチャーの中継は、**まだ決着していない**命令を
  1 つの世界で 256 件まで覚え、送った命令は取引の有効期限（ローカルのチェーンで約 1 分。負荷が高いともう少し）が
  過ぎると数えなくなります。上限に届くと「送ったばかりの命令がまだ多く決着していません。送っていません。1 分ほど
  待ってから、もう一度押してください。」と出て、1 分ほどで戻ります。進軍の中継（上限 64）も同じです。
  #117 より前は送った命令をすべて数えたので、256 回送るとその世界では二度と送れず、「今日送れる操作の回数を
  使い切りました…」という誤った文が出ました（loop-play5）。それでも**待つと書いてある場面では押し直さないでください**:
  編成・進軍の「送信待ち」と「次の一手（広い土地）」は、ページが自分で待って 1 回だけ送ります。押し直しが要るのは、
  境界のカードの「出発条件を確認」（読み取りだけ）と、「送信待ちを取り消しました…」と出たときだけです。
- **砦の奪取は保持 72 ターンちょうどです**（#120 の確認: ×60 の `--wide --random-map --ai 4` で AI の奪取 11 回が
  すべて保持 72 ターン。州は 1 分に 5.99 ターン）。
- **遠征の結果待ち**: 封が開いたあとは、地図の札が「到着 · 封は開きました · 結果の確定を待っています」に変わります。
  結果（「留まる：…」など）は行き先の州が追いつくまで出ません。
- 広い土地の村を出す場所は、空いている場所だけが候補に出ます。3 つめの村の費用（2,400）は「集落」の蔵（上限 2,000）
  では足りません。
- 遠征のカードは地形を見ずに道を引けます（「地形・時間を確認」で「山や水のマスには進めません (N)」と出ます）。
- 「記録」の画面は霧の世界では出ません（`LOCAL_FOG` を `false` にすると出ます）。

## 10. ② 権利（在庫の交換）を遊ぶ（`--coexist`、試験専用）

オーナー決定 ② A の形です: 工房の村の持ち主が、同じ州にある相手の貯蔵庫に「在庫を交換する権利」を出します。相手は
自分の鉱石と木材を、工房が作った兵器に替え、その兵器を**隊商でだけ**運び出します。権利を出すのはウォレットだけです。

```bash
scripts/play-local.sh --coexist --demo --two --ai 2     # ×60。一周は約 10 分。保存なし
scripts/play-local.sh --coexist --two                   # 保存する世界（通常の速さ。貯蔵庫の費用にほぼ一日）
```

- **二人要ります。** 権利の相手は別のプレイヤーでなければなりません。一人で確かめるときは、ブラウザの窓を 2 つ使います:
  A は `http://localhost:41920/`、B は `http://127.0.0.1:41920/`（§3.1）。以下、**A ＝ 工房の村の持ち主**、**B ＝ 相手**。
- `--coexist` は、保存する世界か `--demo` を ②+⑨+⑩ の**共存の線**（プログラム版 0x7805、`RULESET_HASH_V4`）で動かします。
  `--ai`・`--two`・`--random-map`・`--resume` と使えます。`--wide` とは使えません。⑨⑩ のページはまだありません。
- 最初の `--coexist` はビルドに 1〜2 分かかります。そのあと普通の世界を始めると、スクリプトが自分のバイナリを数秒で
  作り直します（#128。作る場所が同じ `frontier-node/target/debug` のため。#128 より前は作り直さず、普通の世界が
  「—」のまま始まりませんでした）。

手順（「」はページのボタンと表示そのままです）:

1. **同じ州に入る**: A も B も「世界を開始」（`--demo` では「新しい世界を開始」）→「国を選ぶ」で**同じ国**（AI のいない国。`--ai 2` ならボレアリスと
   エンバー以外）を選びます。村の画面のいちばん下の「村の詳細」を開くと州が出ます（例「州 -2,0」）。二人が同じか確かめます。違う州（中央をはさんだ
   反対側）に置かれたら、隊商が届きません（道は 32 マス・4 州まで）。Ctrl-C で止めて、同じ州になるまで世界を
   始め直します（loop-play6 では 3 回中 2 回、verify-pr133 では 5 回中 4 回が反対側でした。始め直しは 1 回 30 秒ほどです）。
2. **A: 工房を建てる**: 村の建設の一覧で「ほかの建物（6）」を開き、「工房」の「建てる」（費用は食料 60・木材 120・石材 80・鉱石 40）。
   知らせは名前が空のまま「の建設を始めました」と出ます（§8.1）。
   工房のある村が「工房の村」になり、兵器を 1 時間に 4 作りはじめます（工房を建てられるのは `--coexist` の世界だけです）。
3. **B: 貯蔵庫を建てる**: 地図で、A の村と同じ州の空いたマスを選び、「ここに建てる」→「貯蔵庫を建てる」
   （費用は木材 200・石材 200・金 50。選んでいる村の蔵から）。「貯蔵庫を建てました」と出ます。
   山や水のマスでは「この建物はこのマスに建てられません（通れない土地、…）」と出て押せません。平地のマスを選び直します。
4. **B: 鉱石と木材を貯蔵庫へ運ぶ**: 貯蔵庫のマスを選んで「ここへ隊商を送る」（または村の画面の「交易と防備」→
   「隊商を送る」）。「出発地」が自分の村、「行き先」が貯蔵庫になっているのを確かめ、木材と鉱石の数を入れて
   「隊商を送る」。兵器 1 につき鉱石 2・木材 1 が要ります（例: 木材 20・鉱石 40 で兵器 20 まで）。
5. **B: 着いた隊商を届ける**: ローカルの試験世界には隊商を届ける係がいません。村の画面の「権利（在庫の交換）」に
   「着いた隊商（あなたが届けます）」が出たら「隊商を届ける」を押します（手数料は戻ります）。
   「できませんでした：隊商はまだ到着していないか、通った州の決着がまだです」と出たら、1〜2 ターン待ってもう一度
   押します（ボタンが州の決着より先に出るためです）。
6. **A: 権利を出す**: 村の画面の「権利（在庫の交換）」→「権利を出す」を開き、「工房の村と相手の貯蔵庫」で B の貯蔵庫を
   選び、「交換の回数」（初期値 3）・「兵器の上限」（30）・「有効な日数」（1）を入れて「権利を出す」
   （費用：工房の村から金 25）。A の欄に「あなたが出した権利 有効 … 交換 0 / 3 回 · 兵器 0 / 30」と出ます。
   - 「工房のある村の州に、ほかの人の貯蔵庫が見えていません。…」と出るときは、B の貯蔵庫がまだ無いか、別の州です。
     「権利を出すには、工房のある村が要ります。」は 2 がまだです。
7. **B: 交換する**: B の欄で「権利の一覧を読み直す」→「あなたが受けた権利 有効」。数を入れて「交換を予約する」
   （「予約中 N」。貯蔵庫から鉱石と木材が、工房の村から兵器が出ます）→「交換を実行する」（「交換しました。兵器は
   あなたの貯蔵庫に入りました」）。予約をやめるときは「予約を戻す」。
8. **B: 兵器を隊商で村へ運ぶ**: 貯蔵庫のマス →「ここから隊商を送る」。**開いたフォームの「行き先」が同じ貯蔵庫に
   なっているので、自分の村に選び直します**。兵器の数を入れて「隊商を送る」（数の欄の上限は村の蔵の数字で出ますが、
   運べるのは貯蔵庫にある分までです）。着いたら 5 と同じく「隊商を届ける」。村の蔵に兵器が入ります。
9. **A: 取り消して閉じる**: 「権利を取り消す」→「取り消し済み」（B の開いている予約は戻ります）→「権利を閉じる」→
   「閉じた」（賃料が戻ります）。取り消したあとは、B はもう予約できません。

知っておくこと:
- 霧の決まり：欄に出るのは自分が出したか受けた権利だけです。ほかの人どうしの権利や、ほかの人の貯蔵庫の中身は出しません。
  A から見た B の貯蔵庫は「（国）の貯蔵庫（マス N）」とだけ出ます。
- 相手の欄に反映されないときは「権利の一覧を読み直す」を押します。
- 権利を出す・取り消すは、ウォレット（このブラウザの試験用の鍵）だけができます。AI 住民や代理には任せられません。
  （プログラムは取り消しだけセッションの鍵でも受けます。ローカルでは中継が断ります。devnet に出す前に直す項目です）
- 隊商は道の上で略奪されることがあります。届けたあとの知らせ「…到着しましたが、入った量は確認できません…」は
  長い文ですが、失敗ではありません（蔵の上限を超えた分は切り捨てられる、という意味です）。村あての隊商では
  「…決着しました。入った量はまだ確かめられていません…」と出ることもあります。これも失敗ではありません（村の蔵に入っています）。
- 普通の世界（`--coexist` なし）では、工房は建てられず、隊商を届けるボタンもありません（着いた隊商は届けられないままです）。
- ページのない旧ノードは `--coexist-node` です（開発用）。
