# ローカルで遊んで確かめる（TEST 専用・ワンコマンド）

devnet に出す前に、手元の Mac で遊べる版（遠征・広い土地・砦の奪取）を自分で確かめるための手順です。
使うのは手元のローカルチェーンとテスト鍵だけです。本物の鍵・SOL・devnet・有料 API は一切使いません。
2026-11-26 時点の main（#244 と #243 まで）に合わせています。「」の中は日本語の画面の文です。画面の主な言語は英語で（右上のボタンで
日本語 ⇄ English）、英語の画面の文は英語版 [PLAY-LOCAL.md](PLAY-LOCAL.md) にあります。

世界は続きます。シーズンはなく、世界に終わりもありません。限りがあるのは、ここで使う試験の世界だけです
（`--minutes`。`--demo` と `--wide` の世界は、プログラムが命令を受け付けるターンにも限りがあります。§4・§6）。

前回（#222）からの変更（とくに書いていなければ `--wide` の世界の話です）: 村のカードに**自分の土地**が出ます
（持っているマスの数、次のマスの値段、土地の維持費、維持費が払えていないあいだの知らせ。#231。#242 からは世界の herald の
記録を読みます → §4.1 の 1）。**地図がプレイヤーの土地を 1 マスずつ描きます。** 自分のマスはいつも、ほかのプレイヤーのマスは
見えているあいだ描き、見えなくなると薄く残ります。州をまるごと国の色で塗ることはなくなり、州の持ち主は砦で分かります
（#234・#240 → §4.1・§5）。土地の維持費は初めの値の 30 倍です（#233・#235 → §4.1 の 5）。最初の村の食料の毎時は、
維持費を引いたあとの量で出て、土地の分が横に付きます（#244）。同じプレイヤーが 2 つめの砦を奪ったときも、砦といっしょに
マスが動くようになりました（#233 → §4.1 の 7）。どの世界でも、「隊商を送る」の行き先は、自分の場所、自分の国の場所、
いま見えている場所だけです（#244 → §5）。AI 住民は兵のための鉱石を残し、最初に鉱山を建て、広い土地の最初の村のために
ためます（#236・#241 → §4.1）。`--ai-near` で AI を 1 人、隣に置けます（#237 → §4.0）。外部の住民も自分の土地を読み、
マスを取ります（#227 → §11）。loop-play15 と loop-play16 で見つかった問題は直りました（#223・#225・#237 → §3 の 6・§4・
§4.1・§12）。最初に出る世界全体の地図が、また速く動きます（#239）。残っている問題は §8。
食料で 1 ターン分の土地の維持費を払えないときは、最初の村にある食料が取られ、「払えていない」が続くようになりました
（#243。r0ze の決定 Q-LP17-1 (b) → §4.1 の 6。ターンごとの進み方と断りの表は #245）。#245 ではほかに、訓練の画面に
「100人に満たない分も100人分かかります」と出るようになり、1 ターンの上限や維持費の未払いで断られたマスの取得には
「もう一度」が出なくなり、参加カードの 2 つの残り時間が 10 分きざみ（「あと約 1 時間 40 分」）になりました。
#247（loop-play18）では、空きのない州の「1マス取る」が理由つきで押せなくなり、維持費の未払いで手放されたマスはカードで
また取れるようになり、減っていく食料に「空になるまで …」が出て、隊商の行き先に出発地そのものが選ばれなくなりました（§4.1・§5）。
devnet の遊べる版の遊び方は [PLAY-DEVNET.ja.md](PLAY-DEVNET.ja.md) です（devnet の自分の土地は §7）。

## 1. 最初に一度だけ入れるもの

スクリプトは何もインストールしません。足りないものがあれば、名前と入れ方を表示して止まります。

| もの | 版 | 入れ方の例 |
|---|---|---|
| Rust（rustup） | 1.89.0 と 1.95.0 | `rustup toolchain install 1.89.0 1.95.0 --profile minimal` |
| cargo-build-sbf と platform-tools | 3.1.9 / v1.52 | `sh -c "$(curl -sSfL https://release.anza.xyz/v3.1.9/install)"` |
| Node.js | 20 以上 | `brew install node`（`node -v` が v20 以上ならそのままで構いません） |
| git・python3 | macOS 標準 | 入っていなければ `xcode-select --install` |
| 空きディスク | 初回 20 GiB 以上 | |

初回のビルドは crate を取りにネットワークを使います。世界の開始のとき（最初の種）と遊んでいるあいだも、公開の drand 乱数を HTTPS で読みます。

## 2. ワンコマンド

リポジトリの一番上で実行します。道具の確認 → ビルド（変更がなければ省きます）→ 世界の起動 → ブラウザで
`http://localhost:41920/` を開く、まで進みます。初回のビルドは約 3 分、2 回目以降は数秒です。

```bash
scripts/play-local.sh                 # 保存する世界（1 ターン 10 分。止めても --resume で続き）
scripts/play-local.sh --demo          # 15 分の攻略デモ（×60、1 ターン 10 秒。保存なし）
scripts/play-local.sh --wide          # 広い版（辺境と広い土地。×60。保存なし）→ §4
scripts/play-local.sh --coexist --demo --two   # ② 権利（在庫の交換）を二人で一周（×60。保存なし）→ §10（⑨⑩ は §12、① の依頼は §13）
scripts/play-local.sh --demo --external <アドレス>   # 外部の AI 住民を入れる（×60。保存なし）→ §11
```

広い版は `--wide` だけで起動します（`--demo` `--resume` `--fresh` `--two` と一緒に付けると、どれを付けたかを言って止まります。`--coexist` とも一緒には使えません。`--external` は使えます。
`--ai` `--ai-peaceful` `--random-map` `--speed` `--minutes` `--port` `--no-coop-board` は一緒に使えます）。

世界は 3 種類です。どれも霧（§5）がかかり、AI 住民は既定で戦争をします。`--coexist` は 4 つめの世界ではなく、
保存する世界か `--demo` を ②+⑨+⑩ つきのプログラムで動かす指定です（② 権利 §10、⑨ 工房貸し・⑩ 預かり・奪取 §12、① の依頼の配達 §13）。
`--external` も世界の種類ではなく、保存する世界・`--demo`・`--wide` に外部の AI 住民を受け入れる指定です（§11）。

| 世界 | 時計 | 保存 | 向いている確認 |
|---|---|---|---|
| 保存する世界（既定） | 通常（1 ターン 10 分） | あり（`.local/play-local/kept/`、テスト鍵はブラウザ） | 参加・村・建設・訓練・編成、止めて続ける |
| `--demo` | ×60（`--speed` で 10〜60） | なし | 砦へ進軍・衝突・奪取を 15 分で |
| `--wide` | ×60（`--speed` で 10〜60） | なし | 辺境の村 → 広い土地の村 → 遠征 → 広い土地の中の進軍 |

指定:

| 指定 | 意味 | 一緒に使えないもの |
|---|---|---|
| `--resume` | 最後に始めた保存する世界を続けます（同じブラウザ・同じポート・同じ AI の数） | `--fresh` `--demo` `--wide` `--random-map`、違う `--port` / `--ai` |
| `--fresh` | 保存する世界を新しく始めます（何も付けないときと同じ） | `--resume` `--wide` |
| `--demo` | 15 分の攻略デモ | `--resume` `--wide` |
| `--wide` | 広い版（§4） | `--demo` `--resume` `--fresh` `--two` `--coexist` |
| `--random-map` | 新しい世界に、その世界だけの地図。付けないと**ローカルの世界は毎回同じ地図**です | `--resume` |
| `--ai N` | AI 住民の数 0〜4（既定 2）。**既定で戦争をします**: 届く他国の砦へ進軍・包囲（1 人 1 ターンに 1 行動） | |
| `--ai-peaceful` | AI は砦へ進軍しません（建設・収穫・訓練・編成。`--wide` では辺境と広い土地の村・遠征もします） | |
| `--ai-near` | `--wide` と `--ai 1〜4` と一緒に（既定はオフ）: AI 住民の 1 人が、あなたの最初の村が建つのを待ってから、いちばん近い**ほかの**国に入り、あなたのそばの辺境に村を出して（標準の地図では 3 州先）、あなたのほうへ広い土地を広げます（§4.0） | `--wide` 以外 |
| `--two` | 二人で一つの世界（§3.1） | `--wide` `--external` |
| `--coexist` | ②+⑨+⑩ つきの世界（§10・§12。① の依頼の隊商もこの世界だけ、§13）。保存する世界か `--demo`。`--ai` `--two` `--random-map` `--resume` `--external` と使えます | `--wide` |
| `--external ADDR[,ADDR]` | 外部の AI 住民を 2 人まで、**公開アドレス**で受け入れます（§11。鍵は渡しません）。読み取り専用の MCP サーバーも 127.0.0.1 で起動します。保存する世界・`--demo`・`--wide`。`--ai` `--random-map` `--coexist` `--resume` と使えます | `--two` |
| `--no-mcp` | `--external` のとき、MCP サーバーを起動しません | `--external` なしでは使えません |
| `--no-coop-board` | ① 協力の板と ⑮ の「称号と記録」のカードを付けません（付けるのが既定、§13） | |
| `--no-world-goals` | 世界の目標を判定しません。「世界の目標」の札も金の旗も出ません（旗の砦の判定は既定で付きます。§14） | `--flag-keeps-hold` `--flag-keeps-need` |
| `--flag-keeps-hold N` | 試験専用: 旗の砦を持ち続けるターン数 1〜100000（既定 144 = チェーンの時計で 24 時間。§14） | `--no-world-goals` |
| `--flag-keeps-need N` | 試験専用: 一つの国が持つ必要のある、**奪った**旗の砦の数 1〜12（既定は旗の砦の半分、切り上げ。ほかの国の旗の砦の数より多くはなりません。§14） | `--no-world-goals` |
| `--speed N` | `--demo` / `--wide` の時計 10〜60（既定 60） | 保存する世界 |
| `--minutes N` | 世界のプロセスが止まるまでの分 15〜240（既定 90）。`--wide` でもこの時間で止まります。`--wide` を最後まで試すなら `--minutes 240`（§4） | |
| `--port BASE` | ページのポート（既定 41920）。BASE から 22 個（`--ai 0` なら 14 個）を使います。`--external` はさらに 8 個と、MCP サーバーの 1 個（既定なら MCP は 41950、`--ai 0` なら 41942。`--no-mcp` なら使いません）。41000〜41999 の中で、41904〜41907 と 41970 を含まないこと | |
| `--lang ja\|en` | スクリプトの表示の言語（ページは右上のボタンで切り替え） | |
| `--no-open` `--no-build` `--rebuild` `--check-only` `--print-plan` | 開かない / ビルドしない / 必ずビルド / 確認だけ / 設定と起動コマンドを表示して終わる | |
| `--cluster NAME` | `localnet` だけ受け付けます（ほかの名前は断って終わります。devnet・mainnet にはつなぎません） | |
| `--coexist-node` | ページのない ②⑨⑩ のノードだけ（開発用。遊ぶ用ではありません） | `--port` 以外のすべて |

- AI 住民が入る国は決まっています: 1 人目ボレアリス、2 人目エンバー、3 人目シンダー、4 人目フィヨルダル。
  **AI のいない国**（`--ai 4` ならアステルかダンマール）を選ぶと、村の場所の取り合いになりません。
  「国を選ぶ」の画面では、AI 住民のいる国の旗に、教義の下の小さな札 **「AIあり」** が付きます。選んだ国の説明には
  「この国にはAIの住民がいます。選ぶと、そのAIは同じ国の仲間になります。」が出ます。その国に入っても遊べます（AI は
  国の届く範囲と砦を共有します）。（`--ai-near` では 1 人目の AI は、あなたが選ぶ時点ではまだ国に入っていないので、
  印はエンバー・シンダー・フィヨルダルです。旗の下の 1 行がそう説明します。）
- `--random-map` は、ランダムに選んだ過去の時刻から世界を始め、プログラムが変更なしのルールで別の創世シードを導きます。
- ページを開けるアドレスは `http://localhost:<ポート>/` と `http://127.0.0.1:<ポート>/` の 2 つだけです（ほかの名前や別のマシンからは開けません。§9）。
- 止めるのは端末の **Ctrl-C** です（§6）。

## 3. 15 分のチェック

`--demo` で 1〜8 を通せます。保存する世界では 1〜5 をして、§6 の手順で止めて続きから再開します
（1× では、編成した軍勢が動けるのはターンが決着してから＝約 17 分後です）。

1. **参加**: 「世界を開始（保存された世界は続きから）」（`--demo` では「新しい世界を開始」）→「国を選ぶ」→ 旗を一つ選び、
   「（国の名前）で始める」を押します。最初の村は自動で置かれます。鍵のカードやウォレットの確認は出ません。
2. **村**: 「ここが、あなたの村です。」が出たら成功です。地図の上の「鉱石 +2」を見てください。
   「地形の鉱石なし」の村は、兵を 600 人ほどまでしか増やせません。
3. **建設**: 「最初の建設を選ぶ」→ 農場の「建てる」。約 1 分（ゲーム内）で完成します。
4. **訓練**: 下のバーの「訓練」→「最大 500」→「槍兵 500 を訓練する」。すぐ終わります。
5. **編成**: 下のバーの「編成」（右上のガイドが「軍勢を編成する」なら、それを押しても同じ）→「全部」（送るときの控え全部です。カードを開いたあとに入った訓練の兵も含みます。fix-loop9 LP9-5）→
   「槍兵 N をここに集める」。「この州はまだ前のターンの決着が済んでいません」と出ていても**押して構いません**。
   送信待ちになり、整い次第 1 回だけ送ります（押し直しは不要。兵種・兵数が変わると取り消します）。
   ×60 の `--demo` でも、この待ちはまれになりました（#146: 自分の州が編成できる状態にある時間は約 8 割。前は約 3 割。
   verify-pr146 では文が出ずにすぐ送られました。§8.2）。
   村の画面の「兵」の「編成する」は、決着待ちのあいだ押せません（送信待ちになるのは下のバーの「編成」だけです）。
   軍勢が整列するまでのあいだ、右上のガイドは「ガイド 3/7 軍勢の整列を待つ」と出ます（その間にできることがあれば
   「待つ間に：建設をひらく」のように添えます）。「軍勢の準備を確かめる」か「届く砦を見る」になれば編成できています。
6. **砦へ進軍**: 右上のガイドが「届く砦を見る」になったら押します（「軍勢の準備を確かめる」のままなら、下のバーの
   「国と領土」を一度開きます）。砦の行を選んで「確認した命令で出発」。決着待ちのときは、同じ命令のまま整い次第 1 回だけ
   送ります。「最初の出陣」が出れば出発しています。
   砦の行は、いま出した進軍がいつ着くかを命令の札と同じ言い方で示します：「13 マス · 3 州 · 到着はターン 36（試験の時計で約 28 秒後）」
   （ふつうの時計では「…到着はターン 6（約 48 分後）」）。進軍は到着ターンのはじめに着くので、歩く時間そのものより長くなります
   （fix-loop15 より前は行が歩く時間「約 40 分」を示し、命令の札の「約 48 分後」と食い違っていました。loop-play15 LP15-9）。
   - 始まったばかりの保存する世界（1 ターン 10 分）では、ターン 2 のはじめに押すと、世界の最初のターンの決着がそろうまで
     （ターン 2 に入って 1〜2 分）「届く砦を調べています…」と「始まったばかりの世界では、最初のターンの決着がそろうまで（数分）
     届く砦の一覧は出ません。」が出ます。そろえば 30 秒ほどで一覧に変わります（#195。loop-play13 では 3 秒）。
   - 一覧が「届く砦 0」（「見えている他国の砦で、この軍勢がいま届くものはありません。」）のときは、村のまわりから他国の
     砦が見えていません（`--random-map` ではよくあります）。右上のガイドと一覧のカードに「進軍で地図から選ぶ」が出ます（#130）。
     それを押すか下のバーの「進軍」を押し、地図で第1輪の州の砦のマス（霧で白紙でも押せます）を行き先に選んで「確認した命令で出発」で
     攻められます（行き先は「見えていない土地」と表示されます）。進軍は 1 回ごとに体力を 74
     使います（道の長さによらず同じ額で、短い道でも戻りません。上限 120）。体力は 1 ターンに 1 戻ります。遠い白紙のマスへ先に偵察に出すと、
     体力が戻るまで（満杯から出たあとなら 28 ターン）砦へ出発できません（loop-play6 では約 30 ターン待ちました）。
   - **軍勢が村にいないとき**（#176）: 進軍に出したあと、右上のガイドは「いま村に軍勢はいません。進軍の記録が締めくくられると、
     生き残った兵が村に戻ります（全滅していれば戻りません）。」と「進軍の結果を見る」を出します。軍勢が戻らなかったとき
     （全滅した、または砦を奪って守備兵になった）は「前の軍勢は（州）で壊滅し、戻った兵はいません。」か
     「進軍できる軍勢がいません（前の軍勢は戻りませんでした）。」に続けて「砦へ進軍するには新しい軍勢が要ります：まず兵を訓練します。」
     （控えに兵がいれば「…控えの兵を編成します。」）と、「次の軍勢の兵を訓練する」か「次の軍勢を編成する」のボタンが出ます。
     押すと「訓練」か「編成」が開くだけで、何も送りません。全滅の文は実際の世界ではまだ見ていません（単体テストだけ。verify-pr176）。
   - **送った進軍に返事が来ないとき**（中継の返事がページの待ち 30 秒より遅れたとき。まれで、負荷の高いときに起きます）: 知らせに
     「進軍は送信済みですが、まだ確認できていません。同じ進軍は送り直しません。しばらく自動で確かめます（「もう一度」でも確認できます）。署名 …」
     と出て、ページが約 2 分のあいだ自分で聞き直します。記録されていれば、ふつうの進軍として出ます。記録されていなければ
     「できませんでした」と「進軍は期限までに記録されませんでした。これから記録されることはありません。」が出ます
     （あとで分かったときは「送信済みだった進軍は期限までに記録されませんでした（これから記録されることはありません）。軍勢は村にいます。もう一度命令できます。」、
     チェーンに断られていたときは「送信済みだった進軍はチェーンで断られました。軍勢は村にいます。もう一度命令できます。」）。
     軍勢は村にいて、ガイドは「ガイド 4/7」に戻ります。「もう一度」で進軍のカードが開くので、「確認した命令で出発」を
     押し直します（#193・#200。verify-pr193 と verify-pr200 が日本語と英語の画面で確かめました）。残っている問題: 2 分が
     過ぎたあとは、聞き直すボタンがありません（§8.1）。
7. **衝突の確認**: 着いたターンに「戦闘 … 衝突が決着しました」が出ます。「報告」→「このブラウザで確かめる」で
   「一致：このブラウザで計算し直した結果はチェーンの記録と同じです」が出れば確認できています。
   `--coexist` の世界でも同じです（fix-loop14 LP14-4 までは「確かめられませんでした（足りない記録があります）」と出ていました）。
   記録に片方の「残り」がない報告（砦のマスに立っている軍勢の、前のターンの戦いなど。「316 → —」）は、開いたときに
   この確認を自動で行い、数字と「一致」を出します。
   お知らせが消えたあとも、下のバーの「その他」の一覧に「報告」ボタンが残っています。
8. **奪取**: 砦のマスを 72 ターン保つと奪取です（×60 で約 12 分以上、1× では約 12 時間）。地図の砦の上の「砦を保持中」と
   丸い数字、または衝突の報告の「（国）が包囲中：N/72 ターン（すべて満たすと奪取）」で進み具合を見られます。保持のターンは、州が決着しても
   飛ばされても 1 ターンに 1 つ数えます（#120 の確認: ×60 の `--wide --ai 4` で AI が 11 回奪取、どれも保持 72 ターン）。
   砦の一覧と右上のガイドの文は 72 ターンの長さも言います（1× では「約 12 時間」、×60 では
   「この世界の実時間で約 12 分」）。保存する世界で砦を奪ったあとのガイドは「この世界は続きます。戦期の勝敗と集計は未決定です。」
   と言います。**シーズンはなく、世界は終わりません。** 国が目指すのは期限のない「世界の目標」で、最初の一つである旗の砦の札が
   「国と領土」に出ます（§14）。試しのプログラムに終わりのターンがある `--demo`・`--wide` の世界では、ガイドは
   「この試しの世界は決まったターンで新しい命令の受付を終えます。試しの世界の上限で、勝ち負けの決まりではありません。」と言い、
   「国と領土」はそのターンを「この試しの世界が新しい命令を受け付けるのは第Nターンまでです（残り：…）。試しの世界の上限で、勝ち負けの決まりではありません。」
   と書きます（#208。終わりの勝者を言う文はもうありません）。そこで終わるのは試験の世界そのものだけです（§6）。

知っておくこと:

- **中央はありません（ローカルの世界だけのルール、#88）。** 第1輪の 6 州は普通の土地で、それぞれどこかの国が砦を持って
  始まります（いつもの地図では 6 つの国が 1 州ずつ）。本国（第2〜3輪）の砦は守られていて奪えませんが、**第1輪の砦は奪い合えます**。保存する世界でも AI 住民は
  ここへ進軍し（#98 の確認では開始から 8 ターンめに出発、12〜13 ターンめに衝突）、自分の国の砦が攻められると知らせ
  「州 P,Q の砦を （国）が攻めはじめた／あなたの国が守っている」が出ます。「国と領土」の「他国が占拠を進めている、あなたの国の砦
  … 守りに向かう」には、あなたの軍勢が届かない砦も出ます（「いまのあなたの軍勢では届きません。」と付きます。#130）。真ん中の 1 州 (0,0) だけは「第0輪（中央・州なし）」で、
  行き先にも通り道にもなりません。最初の村は第2輪より外にだけ置けます。
- **霧のため、砦の一覧に出るのは見えている他国の砦だけです**（§5）。「見えている他国の砦で、この軍勢がいま届くものは
  ありません。」は不具合ではありません。
- 1× の保存する世界では、包囲は見られますが、奪取（72 ターン＝12 時間）まではまず見られません。奪取は `--demo` か
  `--wide` で確かめてください。

### 3.1 二人で一つの世界（`--two`）

ふつうは、ブラウザ（アドレス）ごとに別の世界になります（同時に 2 つまで）。二人で同じ世界に入るには `--two` を付けます。

```bash
scripts/play-local.sh --two            # 保存する世界を二人で
scripts/play-local.sh --demo --two     # 15 分の攻略デモを二人で
```

1. 1 人目は `http://localhost:41920/` で「世界を開始」を押します。「もう一人のプレイヤーを待っています」と出て、待ちます
   （約 4 分。過ぎたらもう一度押します）。
2. 2 人目は、**別のブラウザ**（または別のプロファイル）で同じアドレスを開くか、同じブラウザなら
   **`http://127.0.0.1:41920/`** を開いて、同じボタンを押します（テスト鍵はブラウザとアドレスごとに一つです）。
3. 二人がそろうと一つの世界が始まり、それぞれが国を選んで村を置きます。
- `--resume` で同じ二人の世界に戻ります（`--two` は付けなくて構いません）。前回と同じブラウザ・同じアドレスで開いてください。
- 一人用で始めた保存する世界は、あとから二人用にはできません（`--fresh --two` で新しく始めます）。
- どちらかが「世界を終了」すると二人とも止まります。3 人目は入れません。`--wide` は一人用です。

## 4. 広い土地を確かめる（`--wide`、約 60〜90 分）

```bash
scripts/play-local.sh --wide --ai 4 --minutes 240
```

広い版は `--wide` だけで起動します（`--fresh` `--resume` `--demo` `--two` は付けません。§2 の表）。

世界の準備（約 20 秒）のあいだに、プログラム自身の命令で地図をリング 128（辺境）まで広げ、その外の広い土地
（リング 129〜131、108 州）を開きます。ゲームはターン 140 ごろから、×60（1 ターン 10 秒）で始まります。
広い土地は**中立**で始まります。広い土地の砦はどれも誰のものでもありません。土地はプレイヤーが **1 マスずつ**持ち、
地図が色を付けるのはそのマスだけです（持ち主の国の色）。州の持ち主は砦で分かります。どちらも、下の 4 つの手順のあとの
§4.1 に書いてあります。
既定の 90 分では下の 2 にも届かないことがあるので、`--minutes 240`（上限）を付けてください（広い土地の村の費用がたまるまでに
36〜75 分、砦を 72 ターン保つのに 12 分以上かかります。fix-loop10・verify-pr173・verify-pr175 の実測、load 60〜160）。
`--wide` の世界は試験の世界で、それ自身の限りがあります。プログラムが新しい命令を受け付けるのは、決まったターンまでです。
参加のカードにそう出ます（「この試しの世界が新しい命令を受け付けるのは第1,008ターンまでです（あと約 2 時間。試しの世界の上限です）。」。
ゲームはターン 140 ごろに始まるので、×60 で約 145 分ぶんです）。これは試験の世界の限りで、ゲームの決まりではありません。
本番の世界は続きます。
広い版では、ページを開いて「新しい世界を開始」を押すたびに**そのページだけの世界**ができます（2 つめのページは 1 つめの世界に
入れません。同時に 2 つまでで、3 つめは「WorldLimit」で断られます。verify-pr176）。

1. **辺境の村**: 「国を選ぶ」で AI のいない国（`--ai 4` ならアステルかダンマール）を選び、「（国の名前）で始める」。
   場所は選びません。ページが**辺境（リング 128）の州**に村を申し込み（「辺境の村を申し込んでいます…」→
   「辺境の村の申し込みを送りました（ターン N、M ターン前）。世界の進行役がターンの終わりに決めます。…このページは待ち続けます。
   押し直す必要はありません。」）、数ターン（verify-pr130 では 3〜5 ターン。負荷が高いと約 60 ターン・約 10 分）で「（名前）の集落ができました」と出ます。
   村の名前に「仮」が付いているあいだは、村の画面の「収穫する」を一度押すと確定します（「…が確定しました」）。
   辺境の村には「初めての建設」（1 分）はなく、農場も 1 時間 30 分（×60 で約 1 分半）かかります。
   - 「（国の名前）で始める」は 1 回押せば通ります（#130。verify-pr130 では 8 回の参加がどれも 1 回）。村の場所を読んでいる
     あいだはボタンが「村を準備しています…」になって押せません。
   - 最初に「留守のあいだ：この端末では、この世界とウォレットで確認した記録がありません…」のカードが出たら、
     「確認した」を押して閉じます（世界がターン 140 ごろから始まるためで、不具合ではありません）。
2. **広い土地の村（×60 で 30〜60 分。負荷が高いと 75 分）**: 村の画面の「広い土地に村を出す（テスト）」に費用
   （プログラムが取る額。2 つめの村は「費用（村の蔵から）: 食料 800 · 木材 800 · 石材 400 · 金 200」）と候補の州が出ます。
   蔵がこの額までたまると「ここに村を出す」が押せます（足りないあいだは「足りません: …」と出て押せません）。
   **2 回押します**（#209。村は自分のマスの上にだけ建ちます）。1 回目はその場所のマスを鉱石ですぐに取ります（最初は 10。§4.1）:
   「広い土地（P, Q）のマスを自分の土地にしました。もう一度押すと、そこに村を出します。」。2 回目で村を申し込みます:
   「広い土地（P, Q）に村の申し込みを出しました。ターンの終わりに決まります。」。マスを取れるのは 1 ターンに 1 つです。
   同じターンにもう「1マス取る」を押していたら、1 回目は断られます（§4.1「押しても断られたとき」）。次のターンにもう一度押します。
   申し込みはターンの終わりに決まり、地図にその国の印で描かれます。申し込んだ直後から、同じカードは次の（3 つめの）村の費用
   「食料 1,200 · 木材 1,200 · 石材 600 · 金 300」を出します。いま払った額ではありません（loop-play13）。
   - 最初の村の名前に「仮」が付いたままだと、プログラムはこの申し込みを断ります（NotFinal）。先に「収穫する」を一度押して
     確定させます（1 のとおり。カードは確かめません）。
   - **家の近く以外の州**（#206）: 「国の土地（P', Q'）から」と付いた行は、自分の村からではなく、国の土地を通って届く州です（§4.1）。
   - 州の行ごとに「1マス取る」もあります（#209）。自分の土地を 1 マスずつ取るボタンです（§4.1）。

   村ができたあと（「W2」はふつう申し込みから数ターンで出ます。負荷の高いときに一度、約 80 ターン遅れました。loop-play12）の
   いちばん簡単な開きかたは、左下の村の札の下に出る「W2」を押すことです（「遠方の村 第129輪（枠 2）」が開きます）。
   地図でその州を調べて「あなたの村（広い土地）」→「この村を開く」でも開けます。
   - 訓練（§3 の 4）は蔵の食料と金を使います。先に広い土地の村を出してから訓練すると、待ち時間が短くなります。
3. **遠征（辺境 → 広い土地）**: 辺境の村で訓練・編成し（§3 の 4〜5）、下のバーの軍勢（「槍兵 500」など）を選んで
   「境界への道を準備」を押します。
   1. 方角のボタン（東・北東・北西・西・南西・南東）か地図の破線のマスで一歩ずつ道を引き、「道から決まる終点」が
      広い土地の州（リング 129 以上）になるまで伸ばします。開いている広い土地は、地図に描かれる州だけです（最初はリング
      129〜131 の帯。国の村や奪った砦のまわりに、あとから開いていきます）。開いていない州が終点になると、カードにすぐ「終点の州 P,Q は、この世界ではまだ開いていません…
      いちばん近い開いた州は …（N 州先）です。」と出ます。
      道は 32 マスまで、入る州は 4 州までです。カードが歩数と「入る州」の数を両方出します（loop-play16 では 27/32 歩・4/4 州で止まりました）。上限に着くと、
      押しても道は伸びず、カードに理由が出ます（fix-loop16、LP16-6）:「道の形は 32 マス・4 州までです。 この一歩は足せません。
      「一歩戻す」で道を変えるか、もっと近い砦を選んでください。」（一歩戻すと消えます）。それより遠い砦には遠征では届きません。
   2. 「地形・時間を確認」。「山や水のマスには進めません (N)」と出たら N 歩めが通れません。「一歩戻す」か「道を消す」で
      別の道にします（道は地形を見ずに引けてしまいます）。通れる道なら「到着候補：ターン A〜B」と、到着ターンを入れる
      ボタン（次の 3）が出ます。結果はカードの中で見える位置まで自動で送られます。読み取りの途中で世界の時計が進むと、
      ページが 2 回まで自動で読み直します（「…読み直しています（1 / 2 回目）…」）。それでも間に合わないと
      「読み取りの途中で世界の時計が進んだため… もう一度押してください。」と出るので、押し直します。
      読み取った結果は「この道を読み取った結果です。道を変えるまで出ています。」と添えて、道を変えるまで残ります（#137。
      loop-play8: 通れない道の「山や水のマスには進めません N 歩め（西）のマスで止まります。…」が 15 秒たっても出ていました）。
   3. 「間に合う候補（ターン N）を使う」を押します（×60。1× では「最も早い候補（ターン A）を使う」）。×60 では最も早い
      ターン A に、確認して送るあいだに時計が進む分（3 ターン）と、州の決着の遅れの分を足した候補が出ます。最も早いターン
      そのものは、次の「出発条件を確認」が終わるころにはもう過ぎていて、毎回断られていました（loop-play6 LP6-1、#130 で修正。
      verify-pr130 では 5 回の出発で、到着ターンを断られたのは 0 回）。押すと到着ターンの欄に入り、ページが道を読み直します。
      到着ターンを自分で入れる欄は、カードの下の「詳細」の中です（ふつうは要りません）。
   4. 「出発条件を確認」→「この読取時点では、軍勢と村の出発条件を満たしています。」が出たら「出発する（ローカルプレイ）」。
      - ×60 では「…満たしていません。 (NotResident)」がよく出ます（州の決着がターンの一部の時間しか整っていないため）。
        **ここだけは押し直しが要ります**: 1〜2 秒おいて「出発条件を確認」をもう一度押します。この確認は読み取りだけで、
        何も送りません（中継の送信の上限にも数えません）。verify-pr130 では 5 回の出発のうち 3 回が 1 回めに断られ、
        2〜3 回めで通りました（#130 の前: loop-play6 で 17 回・18 秒、fix-loop5 で 16 回・27 秒）。
      - ×60 では、確認の結果は世界の時計を読むたびに画面から消えます（0.3〜2 秒。verify-pr117 V117-1）。消えた直後でも、
        道と到着ターンを変えていなければ「出発する」は効きます: ページが出発条件を読み直し、整っていれば出発します（#130）。
        ボタンが見えなくなったら「出発条件を確認」から押し直します。
      - うまくいかないとき:
        「到着ターンの候補が、記録から計算した範囲に入りません。」＝ 到着ターンが早すぎます（3 のボタンを押し直すか、
        「詳細」の欄にもう少し先のターンを入れます）。「到着ターンはまだ入っていません。「地形・時間を確認」を押すと…」＝
        到着ターンの欄が空です（2 から）。
   5. 「出発が確定しました（ターン N に到着予定・移動枠 0）」が出れば出発しています。
      - **「送信しました。確定はまだ確認できていません。署名 …」のまま変わらないとき**は、ページが自分で確かめるのを待つか
        「結果を照合する」を押します。送ったあとでチェーンに断られたとき（確認と送信のあいだにターンが変わったときの NotResident。
        loop-play11 LP11-1）の表示と出し直しかたは、下の「送ったあとにチェーンが出発を断ることがあります」にあります（#184 から、
        断られた遠征は「進軍」の一覧に残りません）。
   - **封は世界の進行役が開けます。** 到着のあと、地図の札は「ターン N に到着」→「到着 · 開封を待っています」→
     「到着 · 封は開きました · 結果の確定を待っています」と変わり、行き先の州が追いつくと進軍の画面に
     「結果を受け取りました　留まる：軍勢は広い土地の州に立っています（兵 500）」と出ます。待つだけで構いません
     （fix-loop5・verify-pr117・loop-play6 の 3 回とも、進行役が期間内に開けました）。
   - **広い土地の砦のマスに着いた遠征は、その砦を占拠します**（72 ターンで奪います）。進軍のカードが占拠を追います
     （fix-loop9 LP9-2。その州だけを約 1 ターンごとに読みます）:「遠征の軍勢が州 P,Q の砦を占拠中です：n / 72 ターン。…」→
     「砦を奪いました：軍勢は砦の守備兵になりました（砦の守備兵 N・ターン T の記録）」と「結果：遠征の軍勢が州 P,Q の砦を奪いました。…」、
     または「結果：州 P,Q の砦は奪えませんでした。…」。括弧の数は、チェーンの砦の記録にある守備兵です（fix-loop10 LP10-5）。奪うと、占拠していた軍勢の半分が守備兵になり、残りが 100 に満たない
     ときは全員が守備兵になります（loop-play10: 1,289 で着いて守備兵 644。fix-loop10 の確認: 189 で着いて守備兵 177）。
     結果は、画面の上の知らせとしても 1 回出ます（LP10-6 で確認。次の知らせが出るまで残る 1 枠の表示で、あとから読み返す
     一覧はありません。見逃したら進軍のカードで確かめます）。砦を奪ったとき・遠征が全滅したとき（「全滅：軍勢は失われました」）・砦のマスからいなくなったときは、その下に次の遠征には新しい軍勢が要ることと「村で次の軍勢を作る」ボタンが出ます（その村の「編成」か「訓練」を開くだけで、何も送りません。w2-wipeout）。砦を奪ったときの兵が 200 以上だと、守備兵にならなかった半分はその砦のマスに軍勢として残りますが、ページからこの軍勢に命令は出せません（広い土地にいる辺境の村の軍勢への命令がありません。verify-pr176: 488 で着いて守備兵 242、マスに 242。使えるようにするかは未決です）。軍勢はそのマスから見えるので、州は地図に描かれます（#197 から、広い土地の各州の砦
     〈持ち主の国の旗〉、立っている軍勢の姿と兵の数、砦の持ち主を言う札「砦：アステル」「砦：あなたの国」「砦：どの国のものでもない」も描かれ、奪われかけている砦には「〇〇が砦を奪取中 n/72 ターン」が付きます（#234 の前は土地の名前の札「〇〇の土地」でした。土地の色は、いまはプレイヤーが持つマスです。§4.1）。霧の中では見えているマスの軍勢だけです。持ち主を一度も見ていない州には札も砦も出ず、最初の村ができるまでは軍勢と砦の奪取中は描かれません。verify-pr197）。「国と領土」では「あなたの軍勢が着いている砦（自分の国のもの以外）」に出ます。#197 から、遠征の列は到着まで村に立ったままではなく、出発のターンから地図の道を歩きます（verify-pr197: ターン 189 → 193、途中の 191 で道の半ば）。
   - 予備として、到着のターンにはこのページでも封を開けられます（境界のカードの中の「封を開けるか確認する」→
     「封を開く（ローカルプレイ）」）。負荷の高いマシンの ×60 では、進行役が約 10 秒の期間を逃すことがあり得ます（§8）。「封を開ける期間が終わっています。(RevealWindowClosed)」と出たら、その遠征はもう決着しません。
   - カードが「送信しました。確定はまだ確認できていません」のあいだは、次の軍勢の「出発する」は出ません。fix-loop11 から、
     ページは画面を読み直すたびに結果を自分で確かめ、確定か断られたかに変わります（verify-pr184 では押さずに数秒で確定）。
     変わらないときは、その下の「結果を照合する」を一度押します。

### 4.0 AI の隣人（`--ai-near`、テスト専用。オーナー決定 Q-LP16-2）

これを付けないと、AI のいない国（`--ai 4` ならアステルとダンマール）は辺境で隣どうしに始まるので、ほかの国のマスが遠征の道
（32 マス・4 州）に入ることがなく、マスの持ち主が変わるところを見られません。
`scripts/play-local.sh --wide --ai 4 --ai-near`（既定はオフ。`--ai 1`〜`4`）は、AI 住民 **1 人**の住む場所だけを変えます。
ルール・費用・届く範囲は変わりません。

1. 1 人目の AI 住民は、はじめはどの国にも入りません。「国を選ぶ」の画面の旗の下に
   「起動オプション --ai-near：あなたの最初の村が建つと、AIの住民が1人、いちばん近いほかの国に入り、近くに村を出します（その1人は、上の「AIあり」の印には入っていません）。」と出ます。
2. あなたの最初の村が建つと、その住民は、辺境の村の場所があなたの村にいちばん近い**ほかの**国に入り、その場所を申し込みます。
   標準の地図で、アステルの (-68, -60) に村を持ったとき、ダンマールの (-65, -63)（3 州先）に、参加の 2 分後（×60）に入りました。
   AI 住民のログ（世界のディレクトリの `operators.out`）に `"step":"near","outcome":"chosen"` と距離が出ます。
3. そのあと、**あなたのほうへ**広い土地を取ります。実際に、村の隣の州 (-68, -61) で 100 ターン以内に 24 マス取りました（1 ターンに 1 マス）。
   AI の鉱石の取り置き（#236）が入ってからは遅くなり、およそ 8 ターンに 1 マスです（はじめの 40 ターンで 3 マス。verify-pr237）。
4. その州の砦へ遠征を出し（§4 の手順 3）、72 ターン占拠します。砦があなたの国のものになると、その州で AI が持っていたマスが
   あなたのものになります（§4.1 の 7）。実際にターン 264 で 24 マスすべてが移りました（このときはチェーンの領土の記録で
   確かめました）。#234 からは地図で分かります。移ったマスは、あなたの国の色で描き直されます（verify-pr234: アステルの
   プレイヤーの 8 マスが、それまで見えていなかった 5 マスも含めて、砦を奪ったターンに奪った側のマスとして描き直されました）。

この隣人も、ほかの AI 住民と同じく戦争をします（`--ai-peaceful` で止まります）。あなたの近くの砦へも進軍します。

### 4.1 中立の広い土地と、自分の土地（プレイヤーの領土。`--wide` だけ。#206・#209）

`--wide` の世界はすべて、この決まりで動きます。保存する世界と `--demo` には、広い土地も自分の土地もありません。数字は r0ze の
2026-11-24 の決定（12:09・13:15）です。読み方がまだ r0ze への質問になっている点もあります（VQ-1〜VQ-6）。ここには
プログラムがいま行うことを書いています。このまま変わらないという約束ではありません。

**広い土地は中立で始まります（#206）。**

- 始まったとき、広い土地の砦（リング 129〜131、108 州）はどれも誰のものでもありません。地図はその州の土地に色を付けず、
  砦の札は「砦：どの国のものでもない」です（見たことのある所だけです。霧、§5）。国が奪った砦はその国の色で描かれ、札は
  「砦：アステル」（自分の国なら「砦：あなたの国」）です。土地そのものに色が付くのは、プレイヤーが持つマスだけです（下）。
- 中立の砦を守るのは 50 人です。ほかの砦と同じように奪います。軍勢を砦のマスに置いて 72 ターン保ちます
  （×60 で約 12 分、`--speed 15` で 48 分。1× なら 12 時間）。辺境の村からの遠征（§4 の 3）か、広い土地の村の軍勢（§4 の 4）で行います。
- 広い土地の**国の土地**は、自分の国の村（自分・仲間・AI 住民の村）がある州と、国が**奪った**砦の州です。村の申し込みも
  マスの取得も、最初の村から 3 州以内か、国の土地から 3 州以内に届きます。カードは国の土地から届く州を下側に
  「国の土地（P', Q'）から」と付けて並べ、「自分の国の村がある州や、国が奪った砦の州から 3 州以内にも村を出せます。国の土地が広がるほど、遠くへ出られます。」と書きます。
  数えるのは仲間の広い土地の村（リング 129 以上）だけで、仲間の辺境や本国の村は数えません（質問 VQ-6）。
- 世界は、国の村や奪った砦のまわりに新しい広い土地を開きます。1 ターンに 3 州まで、リング 136 までです
  （verify-pr206-209、×60、`--ai 4`: 始め 108 州、約 150 ターン後 114 州、約 280 ターン後 137 州）。
  設計: docs/design/expansion/01-reach-from-land.md

**自分の土地: この順に押します（#209）。** 確定した辺境の村（§4 の 1）と、その蔵の鉱石 10 が要ります。
新しい村ははじめ「仮」です。そのあいだも「1マス取る」は押せますが、押すと「できませんでした」「村がまだ確定していません」と
断られます（何も送られません。devnet では先に費用と「署名して取る」が出て、署名したあとに断られます。PLAY-DEVNET.ja.md）。プログラムは、そのターンの村がすべて置かれたあと、その村であなたが次に何かをしたときに村を確定します
（world3-local-replica では「収穫」1 回ですぐに確定しました）。ページはそれを教えてくれません。
（verify-pr206-209 の世界では、辺境の村の鉱石は 26/時 でした。×60 では 1 時間が 1 分です。「地形の鉱石なし」の村は
ずっと少なくなります。）

1. **辺境の村**を開き（下のバーの「村」）、「広い土地に村を出す（テスト）」のカードまで下へ送ります。カードが出るのは最初の村の
   画面だけです。1 行が 1 つの州で、「州（P, Q）」「村の場所 N」のあとに、「1マス取る」と「ここに村を出す」の 2 つのボタンがあります。
   行の上に、いま持っている土地が出ます（territory-card）:「**あなたの土地**: 持っているマス N · 次の1マス: 鉱石 N · 土地の維持費: 食料 N/時」。
   自分の土地だけです。ローカルの世界ではおよそ 10 秒ごと（devnet では 60 秒ごと）と、マスを取った直後に読み直します。読む先は世界の herald です
   （`/h/world/wide/territory/player/<自分の住民>`。herald が記録したチェーンの記録）。herald にこの道がないときだけ、中継に聞きます。
   カードに並ぶのは、最初の村に近い州が 4 つまで、国の土地を通って届く州が 6 つまで（近い順）です。届く州が全部は並ばず、
   土地がひらくと行が入れ替わります。ただし、自分のマスがある州（「あなたのマスがある州」）と、自分の軍勢が砦を奪っている州・
   奪った州（「あなたの軍勢が砦を奪っている州」「あなたの軍勢が砦を奪った州」）の行は必ず残ります（マスは、このページを開いてから取ったものです）。
2. どれかの行の**「1マス取る」**を押します。村の鉱石が次の1マスの値段（土地の行の「次の1マス」の数。はじめは 10）以上あれば
   押せます（上の村の費用の行とは関係ありません）。足りないあいだはどの「1マス取る」も押せず、カードに理由が出ます:
   「鉱石が 10 に足りないので、いまは「1マス取る」を押せません。」、5 マスめからは
   「鉱石が次の1マスの値段（N）に足りないので、いまは「1マス取る」を押せません。」。その州の
   マスが 1 つ、**すぐに**自分の土地になり（ターンの終わりを待ちません）、「広い土地（P, Q）のマス N を自分の土地にしました。」と
   出ます。鉱石は村の蔵から減ります（同じ画面の「鉱石」）。
   - マスは選べません。ページが、その州のマスのうち、村の場所でも砦のマスでもなく、まだ自分のものでもない、いちばん番号の
     小さいマスを取ります（1 つの州は 61 マスで、番号は 0〜60）。
   - **1 ターンに 1 マス**です（どの州でも合わせて 1 つ）。次のターン（×60 で 10 秒）を待って、もう一度押します。
3. 毎ターン押して広げます。**1 マスの値段**は鉱石 10 で、持っているマス 1 つごとにその 2% が加わります。鉱石は整数に切り捨てます（切り捨ては r0ze への質問 VQ-2）。

   | 持っているマス | 0〜4 | 5〜9 | 10〜14 | 15〜19 | 20〜24 | 50 | 100 |
   |---|---|---|---|---|---|---|---|
   | 次の 1 マスの鉱石 | 10 | 11 | 12 | 13 | 14 | 20 | 30 |

4. **自分の土地に村を建てる。** 村は自分のマスの上にだけ建つので、「ここに村を出す」は 2 回押します（§4 の 2）。1 回目で
   その場所のマスを取り（そのターンの 1 マスに数え、ほかのマスと同じく鉱石がかかります）、2 回目でいつもの費用の村を申し込みます
   （2 つめの村: 食料 800 · 木材 800 · 石材 400 · 金 200）。
   - 同じ州の 2 つの村のあいだには、空いた村の場所が 1 つ以上要ります（プログラムは 3 マス以内の場所に村があると近すぎると
     数えます）。村は 3 つまでです（辺境の村と、あと 2 つ。3 つになるとカードは「村はもう3つあります。」と出し、州の行には
     「1マス取る」だけが残ります）。
   - 自分の広い土地の村がある州は、「州（P, Q） あなたの村がある州」という行としてカードに残り、「1マス取る」だけが押せます
     （その州に 2 つめの村は出せません）。自分の村のまわりの土地を、ページから取れます（loop-play15、#223。それより前は、
     その行もボタンも消えていました）。
5. **維持費。** 土地には食料がかかります。世界の進行役が、**最初の村**の蔵から、およそ 1 ターンに 1 回取ります。
   - 1 マスにつき食料 0.99/時。
   - いちばん近い自分の村（最初の村か、自分の広い土地の村）から 3 州より遠いマスは、1 州遠くなるごとに +0.48/時。
     距離を測るのはマスを取ったときの 1 回だけで、あとから変わりません。
   - 例: 家の近くの 10 マスで 9.9/時、100 マスで 99/時。いちばん近い村から 5 州のマス 1 つは 0.99 + 2 × 0.48 = 1.95/時。
     始めの村は食料を約 40/時 作るので、家の近くでも 41 マスで作る量を超えます（41 マス取るのに鉱石は合計 558）。
     食料を兵や建物に使って蔵が少ないと、もっと早く払えなくなります（r0ze の決定 Q-CUF-1 (b)、11-25 12:04: 最初の値の
     30 倍。最初の値では約 1,200 マス、Q-LP15-1 (b) の 10 倍でも約 120 マスまで払えなくなりませんでした）。
   - 最初の村の食料の「毎時」は、土地の維持費を引いたあとの量です。土地の分を横に出します。家の近くに 73 マス、村が
     40/時 作るなら、上の帯と村の画面の「毎時」の列は「−32.27/時（土地 −72.27）」です（上の帯が毎時を出すのは幅
     1,600 px 以上の窓だけ。帯に重ねたときの文と資源の一覧にはいつも出ます:「食料 11 / 2,000 · 毎時 −32.27（村 +40 ·
     土地 −72.27） · 空になるまで 20:28」。減っていく蔵は、その速さで空になるまでの時間を出します。増える蔵の
     「満杯まで…」と同じです）。蔵の量は記録のままです。「毎時」が 0 以下になると、カードの土地の行の下に
     「食料の増え方はもう 0 以下です（−5.54/時）。次の1マスの維持費は、本拠地が毎ターン作る食料では払えません。」と
     出ます。「1マス取る」は押せるままです（蔵から払えているあいだ、ルールは取ることを受け付けます）。
6. **食料で払えないとき。** 最初の村の蔵にある食料が取られ（全部。払う分より多くは取りません）、そのターンから「払えていない」状態に
   なります（r0ze の決定 Q-LP17-1 (b)、11-25 21:22。前は何も取られず、次のターンの食料で 1 ターン分を
   払えてしまい、「払えていない」が続きませんでした）。
   - すぐに: マスを取れなくなります（断りの文は下の表）。
   - 払えないまま 24 ターンたつと（**×60 で 4 分**、`--speed 15` で 16 分。**1× なら 4 時間**）、**いちばん遠い**マスが
     誰のものでもない土地に戻ります。払えないあいだ、**1 ターンに 1 マスずつ**です（×60 で 10 秒に 1 つ。1× なら 10 分に 1 つ）。
     自分の村が建っているマスも手放されることがあります（質問 VQ-4）。
   - 進行役が次に見たとき、最初の村の蔵に 1 ターンぶん以上の維持費があれば終わります。払えないターンには蔵の食料が取られるので、
     実際には、村が 1 ターンに作る食料が土地の 1 ターン分の維持費以上になったとき（マスが減るか、食料が増えたとき）に終わります。
     そのあいだに払えなかった食料は、あとから取られません（質問 VQ-5）。
   - **カードが知らせます**（territory-card）。チェーンの記録が「払えていない」のあいだ、土地の行の下に出ます:
     「土地の維持費（本拠地の食料）が払えていません。新しいマスは取れません。あと N ターン払えないままだと、遠いマスから1ターンに1つずつ手放されます。」
     （N は 24 から減ります）。そのあとは「土地の維持費（本拠地の食料）が払えていません。遠いマスから1ターンに1つずつ手放されています。本拠地の毎ターンの食料が土地の維持費に足りるようになると止まります。」。
     プログラムは兵の食料を取らないので（大きな軍勢が食料を食べるルールがあるのはシミュレーターだけです。loop-play15、
     オーナーへの質問 Q-LP15-1）、村の食料は自分が使った分しか減りません。ほかに使わなければ、家の近くで約 41 マス
     （1 ターンに 1 マスなので 41 ターン以上）取ると、土地の維持費が始めの村の 40/時 を超えます。
   - **進み方**（loop-play17 の場合をプログラムのテストで追ったもの: 家の近くに 73 マス、村の食料は 40/時、蔵に食料 510）。
     土地の維持費は 72.27/時 なので蔵は減り、94 ターンで空になります。第 95 ターンから毎ターン「払えていない」です
     （そのターンに作った食料は取られますが、足りません）。第 119 ターン（24 ターン後）から 1 ターンに 1 マスずつ、
     全部で 33 マスが戻ります。40 マス（39.6/時）になると 1 ターン分をまるごと払えるようになり、そこで止まります。
     Q-LP17-1 (b) の前は、同じ土地で「払えていない」と「払えた」が 1 ターンおきに入れかわり、マスは 1 つも減りませんでした。
   - 動いている世界で見たもの: 知らせと断りの文は loop-play17 が実際のページで読みました（日本語と英語。(b) の前のルール）。
     (b) の全体（毎ターン払えていない、24 ターン後に手放す、カードと地図からマスが消える）は、#243 の P18 がローカルの
     チェーンで確かめました。そのあと動いている世界でも見ています（verify-pr243、loop-play18。実際のページで、1 ターンに 1 マスずつ手放す）。
7. **砦といっしょに土地が動く。** ある国が広い土地の州の砦を奪うと、その州で**ほかの国**のプレイヤーが持つマスは、奪った軍の
   持ち主に移ります。その持ち主と同じ国の仲間のマスと、村が建っているマスは移りません。進行役が移します（verify-pr234 では砦を奪ったターンのうちでした）。
   #233 からは、同じプレイヤーの軍が 2 つめの砦を奪ったときも移ります（前は、その移動をプログラムが毎回断っていました）。
   知らせは出ません。地図が、移ったマスを新しい持ち主の色で描き直します。その国が砦を持っているあいだは、あとからほかの国のプレイヤーがそこで取ったマスも、同じように
   移ります（質問 VQ-3）。

**押しても断られたとき。** マスの申し込みが断られたとき、下の表の初めの 3 行はその場面の文で答えます（#223。verify-pr223 が
動いているページで日本語と英語の 1 行目と 3 行目を読み、「払えていない」は loop-play17 が読みました）。初めの 2 行には
「もう一度」のボタンが出ません（fix-loop17）。同じターンに押しても、また断られるだけだからです。次のターンに、または
払えるようになってから、カードの「1マス取る」を押してください。ほかの行は
プログラムの一般の文で、場面に合わない文もあります（コードから読んだものです）。

| 起きたこと | 出る文 | すること |
|---|---|---|
| 同じターンに 2 つめのマスを取ろうとした | 「このターンはもう1マス取りました。マスは1ターンに1つです。次のターンにもう一度押してください。」 | 次のターンを待つ |
| 土地の維持費が払えていない | 「土地の維持費（本拠地の食料）が払えていないので、新しいマスは取れません。本拠地に食料が戻ると、また取れます。払えないまま24ターンたつと、遠いマスから1ターンに1つずつ手放されます。」 | 進行役が次に見たとき、最初の村の蔵に 1 ターン分の維持費がまるごとあるようにする（食料を増やすか、マスを減らす。手順 6）。そのあとでもう一度取る |
| 鉱石が足りない（いまはまれです。次の1マスの値段に足りないあいだ、ボタンは押せません） | 「鉱石が足りません。1マスは鉱石 10 で、持っているマス1つごとに 2% 高くなります（本拠地の蔵から払います）。」 | 鉱石を待つ |
| そのマスはほかのプレイヤーのもの | 「その場所はすでに使われています」 | もう一度押す（ページが次のマスを試します） |
| そのマスはもう自分のもの（ページが覚えていなかった） | 「すでに済んでいます」 | もう一度押す（ページが覚えて先へ進みます） |
| その州に届かない | 「前哨地の条件を満たしていません。町と州の支配状況を確認してください」 | もっと近い行を選ぶ |
| その州に空いたマスがない | ページが分かった時点で、その行の「1マス取る」は押せなくなり、横に「この州に取れるマスは残っていません。」と出ます（自分のマスはいつでも、ほかの人のマスは見えているものだけで判断します）。分かる前に押したときは、同じ文が知らせに出ます（「もう一度」はありません） | 別の州にする |
| 州を読めなかった | 「この州ではマスを取れません（自分の土地のない世界か、州が読めませんでした）。」 | もう一度押す |
| 同じ州のほかの村に近すぎる（「ここに村を出す」の 2 回目） | 「その場所は予約されています（第0・第1輪）」 | もう一度押す（ページが次の場所にします。その場所のマスを先に取ります） |

**マスの場所。** 地図は、プレイヤーの土地を 1 マスずつ、持ち主の国の色で描きます（#234）。自分のマスはいつも、
ほかのプレイヤーのマスは見えているあいだ描きます。見えなくなったマスは、最後に見たときのまま薄く残ります（#240）。
村を置ける場所と砦のマスは空いたままです。カードの土地の行で、マスの数・次の値段・維持費が分かります。カードの段落
（「自分の土地：「1マス取る」はその州のマスを1つ、すぐ自分の土地にします（鉱石 10、持っているマス1つごとに +2%、1ターンに1マス）。…」）が
決まりを短く書いています。カードの最後の行「申し込みはターンの終わりに決まります（同じ場所を選んだ人がいれば抽選）。」は
村の話です。マスはすぐに取れます。

**AI 住民**もマスを取ります（同じ決まり、同じ値段）。自分が出す村の下のマスと、次の村の費用をためるあいだにときどき 1 マスです。
ただし**兵のための鉱石を先に残します**（ai-ore-reserve、オーナー決定 2026-11-25）。マスを取るのは、マスの値段を払ったあとに
訓練 1 回分（槍兵 100 人: 鉱石 20）と、次の軍勢に足りない兵の分が残るときだけです。近くの自国の砦が攻められているあいだは
マスを取りません。軍勢 1 つ分の兵（300 人）がそろったあとは、マスと訓練を交互にします。倉庫で払えない訓練は頼まなくなりました。
×60、`--ai 4`、プレイヤーの村ができてから約 39 分で、変更前の同じ世界と比べた数（verify-pr236、土地の維持費 ×30）: 訓練の断り 0 回（前は 274 回）、訓練成功 54 回（24 回）、
砦への進軍 17 回（1 回）、取った端の砦 6（0）、取ったマス 30（79）、広い土地の村 4（4）。1 時間後には広い土地の砦も 1 つ取りました（0）。どちらの世界でも AI 住民の維持費の未払いはありませんでした。
この変更だけでは、AI の国は土地が減り、戦いが増えました（下の、村のための貯金で土地はまた増えます）。霧のため、AI のマスが見えるのは、あなたの視界に入った所だけです（§5）。
AI 住民は**最初に鉱山を 1 つ建てます**（ai-early-mine、オーナー決定 2026-11-25 17:58）。村の最初の命令が、プレイヤーと同じ「建てる」
（食料 40・木材 80・石材 20、鉱石が 1 時間に +6）で、1 回だけです。近くの自国の砦が攻められているあいだは建てません。
また、**最初の広い土地の村ができるまでは、その村のためにためます**（オーナー決定 2026-11-25 20:03、22:28）。兵は 1 部隊（300）まで
（村にいる兵・部隊の兵・進軍中の兵の合計。失った兵の分だけ訓練し直します）、マスは次の村が建つ 1 マスだけ取り、ほかの新しいマスは取りません。
こうして食料と金を村にまわします。村を取ったあとは自由に訓練し、マスも広げます。
測った数（verify-pr241、×60、`--ai 4`、同じ地図、変更あり／なし。かっこ内は変更なし）: AI の広い土地の村 4 つは 309・309・309・312 ターン
（313・313・337・395）、プレイヤーの村から約 26 分後。38.5 分では AI の村 4 つの鉱石が 1 時間に合計 46（22）、訓練成功 52 回（50 回）、
取ったマス 72（19）。66 分では訓練 85 回（73 回）、マス 95（28）、持ち主が変わった砦 12（10）、取った広い土地の砦 4（1）。
どちらの世界でも AI の維持費の未払いはありませんでした。鉱山だけでためる決まりがないと、この時間内に広い土地の村は 1 つもできませんでした。
⑬ のクライアントで動かす外部の住民（§11）もマスを取ります。次の村の場所のマスが先で、そのあとは自分のゆっくりした進め方で隣のマスを取ります。

**何もしていない最初の村は、`--wide` の世界では取り上げられません。** 長く命令のない村を空ける決まりには、命令のない
ゲーム内の 7 日が要ります。試験の世界が命令を受け付ける期間（§4）より長いためです。

## 5. 霧（ローカルの試験世界すべて、#93）

Civ のようなプレイヤー視点です。表示だけの霧で、ローカルチェーンの記録は公開のままです。devnet のページにも同じ霧が
かかります（fog-devnet、ランブック §7 P5）。

| | 見えるもの |
|---|---|
| いま見える | 自分の村と軍勢のまわり、自分の国の村と、自分の国が持つ州のまわり。同盟国とは視界を分けません |
| 前に見た | 最後に見たときのようすが薄く残ります（村、砦とその持ち主）。このブラウザに保存 |
| まだ見ていない | 地図でも「全体図」でも白紙。地形も村も砦も国の色も出ません |
| プレイヤーの土地（`--wide`。#234・#240） | 自分のマスはいつも描きます。ほかのプレイヤーのマスは、そのマスがいま見えているあいだ描きます。見えなくなると、最後に見たときの持ち主のまま薄く残ります。一度も見ていないマスは描きません。こうした土地が画面にあるあいだ、小さな凡例「土地の持ち主」が色の意味を言います（「あなたの国（アステル）」、ほかの国の名前、「国のわからないプレイヤーの土地」）。薄く残ったマスが画面にあれば「薄い色：前に見たときの持ち主（いまは見えていません）」の行が、国の砦が画面にあれば「城の色：その州を持つ国」の行が付きます（この行は、マスが画面になくても砦だけで出ます） |
| 他国の軍勢・進軍・衝突・争奪 | いま見えている場所でだけ。残像は残しません |
| 自分の村へ向かう敵 | 見えている場所から出発したとき、または到着の 3 ターン前から「来襲」として知らせます |

- 砦の一覧、調べる画面、年代記、知らせ、ミニマップも同じ決まりです。
- **他国どうしの衝突の報告と「戦いを再生」**は、その州の砦のマス（砦がなければ州全体）がいま見えているときだけ
  出ます。州の端の数マスが見えているだけでは出ません。自分の村の州と、自分の進軍が着いた衝突はいつでも見られます。
  見えていない衝突の報告を開こうとすると「この場所はいま見えていません。…」と出て、何も読みません。
  地図の衝突の印（赤い輪・ミニマップの点・「このターンに衝突あり」）、年代記の「…で衝突が決着した」と「最近の衝突」、
  他国どうしの砦の争奪・奪取の知らせも同じ決まりです（自分の国が関わる砦の知らせはいつでも出ます）。
  地図の上の他国の出来事（「…の新しい村」、出発、到着、野営地の消滅）は、そのマスがいま見えているときだけ出ます。
  進軍の「近くの行き先」の野営地は、測量したことのあるマスのものだけです。
- **「隊商を送る」の行き先**（r0ze の決定 Q-LP17-4、11-25 21:22）: 並ぶのは、あなたの場所、あなたの国の村と貯蔵庫、
  いま見えているほかの村と貯蔵庫だけです。前に見ただけの場所や、見たことのない場所は並びません（以前は、ページが
  読んだ州の村を、州とマスの番号つきで全部並べていました）。フォームにもそう書いてあります。見えなくなった場所は
  行き先から外れます。フォームを開いてから「隊商を送る」を押すまでの間に外れた場合は、何も送りません
  （「行き先の一覧が変わりました…行き先を選び直してください。」。この知らせに「もう一度」はありません。欄で選び直して
  「隊商を送る」を押します）。出発地が 1 つだけのとき、その村は行き先に並びません。自分の送り先がないときは、欄は
  「（行き先を選んでください）」から始まります（ほかの人の場所が勝手に選ばれることはありません）。「① 依頼の届け先」（§13）は、見えていなくても
  並びます（依頼した人が板に公開した場所だからです）。
- 霧の世界では、地図右下の「記録」（記録された世界の全州）と、観戦ページへのリンク（凡例と設定の「観戦ページ」）は、

## 6. 止める・あした続ける

1. 止めるときは、スクリプトを動かしている端末で **Ctrl-C** を押します。世界を閉じてから終わり、ログの場所を表示します。
   世界を閉じるのは最大 20 秒待ちます。それでも閉じない世界があれば、残った世界をログに書き、自分が起動したプロセスを止めて終わります。
   待ちたくないときは、もう一度 **Ctrl-C** を押すとすぐに終わります（世界の時間切れのあとでも同じです。loop-play6 LP6-3、fix-loop6）。
2. 保存する世界は、次の日に同じ Mac・同じブラウザで続けられます。止めていたあいだ、世界の時計は止まっています。

   ```bash
   scripts/play-local.sh --resume
   ```

   同じアドレスが開くので、「世界を開始（保存された世界は続きから）」を押すと前回の村に戻ります。
   進軍に出したまま止めて続けると、ページは封をした行き先を覚えていません（行き先は到着のターンに明かされます）。
   右上のガイドは「ガイド 4/7 進軍を見る」で、「軍勢は進軍に出ています。行き先は封をしたままで、到着のターン N に
   明かされます。…」と出ます（fix-loop12）。ページがどの州にも自分の軍勢を見ないときは「いま村に軍勢はいません。…」と
   「進軍の結果を見る」です。
- `--demo` と `--wide` の世界は保存されません。止めたらブラウザのタブを閉じてください。遊んでいる途中で**ページを
  再読み込みしないでください**（テスト鍵はメモリにだけあり、その世界に戻れなくなります）。
- `git pull` などでプログラムが変わると、前の世界は続けられません。スクリプトがそう表示するので `--fresh` で始め直します。
- `--resume` が開くのは最後に始めた保存する世界だけです。前の世界に戻すには、`.local/play-local/last-kept` の中身を
  そのフォルダ（`…/.local/play-local/kept/<日時>`）に書き換えます。
- **一時停止した保存する世界（#218）。** 世界は既定で 90 分たつとプロセスが止まります（`--minutes`）。保存する世界は、そのとき
  **終了ではなく一時停止**になります。ダイヤルは「ターン N · 一時停止」、帯は
  「この世界は止まっています。進行は保存されています。止まっているあいだはターンが進まず、命令も送れませんが、止まったところから続けられます。続けるには、開始ページを開き直して「世界を開始」を押してください（開始サービスを止めたときは、先にターミナルで scripts/play-local.sh --resume を実行します）。」
  と出ます。続け方は 2 つです。
  1. スクリプトがターミナルでまだ動いているとき: `http://localhost:41920/` を開き直して「世界を開始（保存された世界は続きから）」を押します。
  2. スクリプトを止めていたとき（Ctrl-C、またはターミナルを閉じた）: `scripts/play-local.sh --resume` を実行してから、同じボタンを押します。

  どちらでも、止まったターンの自分の村に戻ります（verify-pr218 が両方を英語と日本語の画面で確かめました）。
  開始ページの一覧で保存する世界を自分で止めたときも同じです: 「この世界を止める…」→「止める」→
  「世界を止めました。進行は保存されています。その世界は、同じブラウザで「世界を開始」を押すと続きから再開します。」。
  （`--demo` と `--wide` の世界が止まったときは「このテスト用の世界は終了しました（保存しないテスト用の世界で、時間などに限りがあります）。…」と
  出ます。続きはありません。）AI 住民の多い世界は、ログがランチャーの大きさの上限に届くと、`--minutes` より前に止まることが
  あります（loop-play14: `--demo --ai 4` の世界が約 71 分で停止）。保存する世界なら、そのときも同じ一時停止です。
  `--resume` は `--minutes` を覚えていないので、長く遊ぶときは `--resume --minutes 240` のように付け直します。
- **終わるものと終わらないもの。** ゲームにシーズンはなく、世界は終わりません。保存する世界はそのとおりで、最後のターンはありません。
  止まるのはプロセスだけで（`--minutes`）、`--resume` で続けられます。`--demo` と `--wide` の世界は使い捨ての試験の世界です。
  `--minutes` のほかに、プログラムが新しい命令を受け付けるのは決まったターンまでで、そのターンは参加のカードに出ます
  （「この試しの世界が新しい命令を受け付けるのは第Nターンまでです（あと約 …。試しの世界の上限です）。」。`--wide` の世界では 1,008）。
  そのあとは新しい世界を始めます。
- テスト鍵を消すには、ページのパネルの「このブラウザに保存した試験用の鍵を消す」。世界のフォルダは自分で消すまで残ります。

- `--wide` の世界では、右上のガイドは広い土地の砦の奪取を数えません（ガイドが見るのはリング 128 までの砦です）。W2 の村や遠征で
  砦を奪っても、ガイドは前の段のままです（w2-wipeout: 奪ったあとも「ガイド 1/7 建設をひらく」）。
- ⑨ と ⑩ の選択肢の短い住所（「4dkm…7rAz」など）は、持ち主のウォレットではなく住民の記録（Citizen）の住所です。ページには
  自分のどちらの住所も出ないので、村の名前とマスで見分けます（loop-play11 LP11-5。§12）。
- W2 のカードの記憶（進軍の回数と結果）はページに 1 つです。広い土地の村を 2 つ持つと、2 つめの村も 1 つめのカードを出します
  （verify-pr173。#206 から 3 つめの村も出せるので、起きることがあります。その後は確かめていません）。
- 負荷が高い（load 12〜31）と、広い土地の村の州が 200 ターン以上遅れたまま数十分動かないことがあります（loop-play8 LP8-4。
  負荷の問題で、#149 では測っただけです）。

### 8.2 ×60 のふるまい（#102・#105・#109・#117・#120 のあと）

- **争っている州は、負荷が高いとチェーンより遅れます。** ×60 では、ふだんはどの州もターン表示より 2〜4 ターン遅れです
  （runner-throughput の確認、`--wide --random-map --ai 4`）。その変更の前や、負荷のとても高い Mac では 10〜24 ターン
  遅れることがあります（#102 の確認）。そのあいだ編成や出発は「送信待ち」になり、ページは「この州の決着が N ターン
  遅れています。このマシンの負荷が高く…」と言って、追いつき次第 1 回だけ送ります。押し直す必要はありません。
- **ふつうの進軍が封を開ける時間（×60 で約 10 秒）を逃しても、州は止まりません**（#105）。キーパーは各パスの最初と
  各村のパスの前に、期限の来た進軍の封をすべて先に開けます。それでも逃した進軍（重い負荷での 3 ターンの進軍で見られました）は、
  プログラムが開かれなかった進軍を決着させるとおりに決着します：行き先の州のターンはその進軍なしで決着し、そのあと
  SettleTransit（結果はプログラムが決めます：敗走して村に戻る、または押し戻し）。ランナーの stderr に `reveal-missed` と
  出ます。拒否で止まった村の進軍ドライバーは、6 ステップ（倍々で最大 96。パスではなくドライバーのステップの数です。保存される世界では 1 パスに 1 ステップ、
  `--demo` と `--wide` ではパスの 1 巡ごとに最大 4 ステップ）待って
  からチェーンを読み直して続け、そのあいだその村の軍勢が立つ州は世界の巡回が決着させます。到着ターンを 2 ターンより
  多く過ぎた軍勢の地図の札は「軍勢の到着ターン N から M ターン · 結果の確定を待っています」です。広い土地への遠征が
  逃した場合の決着はプログラムに無く、r0ze の判断待ちです（§−2.4f (d)）。
- **×60 では自分の州は 1〜2 ターンの遅れです**（runner-throughput の確認: ページでの中央値 2、最大 3〜4）。キーパーは AI の村の番の前に毎回あなたの州を決着させ直すので、編成や進軍はたいてい 1 回押せば数秒で
  送られます（確認: 編成 1.8〜5 秒、進軍 2〜14 秒。作者の回では取り消し 0 回、verify-pr109 の回では進軍 12 回中 2 回が
  自分の州が 3 ターン遅れていたときに取り消され、どちらも次に押して送られました。ターンの最後の 1 秒に押した編成が
  1 回断られ、3 秒後に押し直して送られました）。それでも取り消されたとき
  （「送信待ちを取り消しました…」）は、もう一度押してください。
- **`--demo`（と `--external`）の ×60 では、自分の州が編成できる状態にある時間は約 8 割で、外部の住民の州もほぼ同じです**
  （runner-throughput-2、BREAK-143-1）。「編成できる状態」とは、住民の命令（編成・駐屯・解散・探索）についてのプログラムの決まり
  で、州が 2 ターン前まで決着していることです。この変更の前は自分の州で約 3 割、外部の住民の州で 0〜6% でした。デモのキーパーは
  何も送らなかった回のあと 10 秒（×60 の 1 ターン）待ち、デモの 60 州を 1 件ずつ決着させ、外部の住民の村はまったく受け持って
  いなかったからです。いまは縮めた時計（`--demo`、`--wide`）では、すべての住民の州（あなた、AI の住民、外部の住民）を 1 つの
  ブロックでまとめて、最初に、そして順番が来るたびに決着させ、次のターンの区切りで起きます。測った値（デモ ×60、AI 1、外部 1）:
  あなた 79%、外部の住民 86%（前は 30% と 6%。verify-pr146 の測り直しでは 82% と 88%）。×15 では 93% と 96%（前は 79% と 60%）。100% にはなりません。ターンは次の
  ターンが始まってからでないと決着できないからです。どの州も同じバッチで同時に決着させます。残る差は州そのものの状態です。
  村のマスに軍勢を編成した（または到着がある）ターンは静かなターンではないので、同じブロックの早送りではなく、次の公開 drand の回
  の本当のシードが要ります（×60 で約 2 秒）。この測定では、あなたは訓練と編成を 23〜27 回しましたが、外部の住民は 1 ターン 1 命令
  なのでほとんど収穫でした。79% と 86% の差はこれです。国を入れ替えても、差は役割や場所ではなく軍勢についてきました（verify-pr146）。整っていないあいだは、これまでどおりページの「編成」が待って 1 回だけ送ります。
- **広い土地への遠征は、封を開ける期間を逃すと二度と決着しません**（プログラムに決着の道がなく、r0ze の判断待ち）。
  進軍の画面は「到着しました。封が開けられるのを待っています」のままで、その辺境の村からは次の遠征も出せません
  （「出発できませんでした（DepartRolesUnavailable）」）。#105 より前の確認（verify-pr106、負荷の高い Mac の ×60）で
  1 回起きました（`runner.out` に `never revealed: transit 0: the reveal window of bell 262 closed unrevealed`）。
  そのあとの fix-loop5・verify-pr117・loop-play6 では、進行役が毎回期間内に開けています（`reveal-missed` 0 件）。
  心配なときは、到着のターンに §4 の 3 のとおり自分で「封を開く」を押せます。
- **包囲されている州もチェーンについて行きます**（runner-throughput の確認: ×60 でどの州も 1 分に 5.9〜6 ターン。
  チェーンは 6）。キーパーはほかの州と包囲の州のターンを、同じブロックにまとめて送って決着させます。
  記録の表の「第Nターンまでの州・時間の参考記録。」は、いちばん遅い州のターンです。ターン表示より数ターン遅れです（変更の前は
  数百ターン。例: ターン 495 で第 251 ターン）。
- **辺境の村が「仮の村」のまま**のときは、自分の操作（「収穫する」など）を一度すると確定します。画面の「遅くとも…」の
  時刻どおりには確定しません。
- **AI 住民は多くのターンを断られた送信に使います**（蔵が足りない訓練など）。動きが遅く見えますが、ルールどおりです。
  AI は 256 回送っても止まりません（#117。loop-play6 では約 3,000 回送って、中継に断られたのは 0 回）。
- **押しすぎで世界が送れなくなることは、もうありません（#117）。** ランチャーの中継は、**まだ決着していない**命令を
  1 つの世界で 256 件まで覚え、送った命令は取引の有効期限（ローカルのチェーンで約 1 分。負荷が高いともう少し）が
  過ぎると数えなくなります。上限に届くと「送ったばかりの命令がまだ多く決着していません。送っていません。1 分ほど
  待ってから、もう一度押してください。」と出て、1 分ほどで戻ります。進軍の中継（上限 64）も同じです。
  #117 より前は送った命令をすべて数えたので、256 回送るとその世界では二度と送れず、「今日送れる操作の回数を
  使い切りました…」という誤った文が出ました（loop-play5）。それでも**待つと書いてある場面では押し直さないでください**:
  編成・進軍の「送信待ち」と「次の一手（広い土地）」は、ページが自分で待って 1 回だけ送ります。押し直しが要るのは、
  境界のカードの「出発条件を確認」（読み取りだけ）と、「送信待ちを取り消しました…」と出たときだけです。
- **砦の奪取は保持 72 ターンちょうどです**（#120 の確認: ×60 の `--wide --random-map --ai 4` で AI の奪取 11 回が
  すべて保持 72 ターン。州は 1 分に 5.99 ターン）。
- **遠征の結果待ち**: 封が開いたあとは、地図の札が「到着 · 封は開きました · 結果の確定を待っています」に変わります。
  結果（「留まる：…」など）は行き先の州が追いつくまで出ません。
- 広い土地の村を出す場所は、空いている場所だけが候補に出ます。`--wide` の世界では、先にその場所のマスを自分のものにします（2 回押します。§4.1）。3 つめの村の費用は食料 1,200・木材 1,200・石材 600・金 300
  です（プログラムの額。#183 からカードもこの額です）。
- 遠征のカードは地形を見ずに道を引けます（「地形・時間を確認」で「山や水のマスには進めません (N)」と出ます）。
- 「記録」の画面は霧の世界では出ません（`LOCAL_FOG` を `false` にすると出ます）。

## 9. 困ったとき・知らせ先

- ログの場所:
  - 保存する世界: `.local/play-local/kept/<日時>/`（`launcher-<日時>.log`、`persist/<アドレス>/starts/<回>/` に
    runner・herald・relay・operators のログ）
  - `--demo` と `--wide`: `.local/play-local/worlds/<日時>/`（`launcher-<日時>.log` と世界ごとのフォルダ。
    `--wide` では `wide-land.json` に広げたリングと開いた州、`runner.out` の 1 行めの `local_rules` に
    プリセットから変えたバイトが書かれます）
  - 起動コマンドは同じフォルダの `command.txt` です。
- **開けるアドレスは 2 つだけです**: `http://localhost:<ポート>/` と `http://127.0.0.1:<ポート>/`（`--two` の 2 人目が使うのは後者です）。
  ランチャーも世界も 127.0.0.1 でだけ待ち受け、Host がこの 2 つ以外の要求を断ります。`http://[::1]:41920/`、`http://<Mac の名前>.local:41920/`、
  LAN の IP アドレス、別のマシンやスマートフォンからは開けません（127.0.0.1 以外のアドレスでは待ち受けていないので、ふつうは接続そのものが
  できません。別の名前で 127.0.0.1 に届いた要求には、ページの代わりに 403 `{"error":"HostDenied"}` が返ります。世界の読み取りは
  `WorldOriginDenied`）。#164 からは世界の中継（relay）も同じ決まりです: Host が `127.0.0.1:<その中継のポート>` か `localhost:<同じ>` で、
  **Origin ヘッダーのない**要求だけを受け、ほかは 403 `LocalPlayHostNotAllowed` です。ページ・AI 住民・付属の外部の住民（Node）はこの形なので、
  ふつうに遊ぶぶんには何も変わりません（verify-pr164: `--two` の二人とも 403 は 0 回）。当たるのは、中継のポートをブラウザのページから直接呼ぶ
  自作の道具（ブラウザは Origin を付けます）と、`curl -H 'Origin: …'` や別の Host 名を付けた手書きの要求だけです。
- **ページのファイル（`permutation-server/web/`）を書き換えたとき**は、スクリプトの再起動は要りません。ランチャーは要求のたびにディスクから
  読み、コードとページはブラウザに保存させません（`no-store`。絵とフォントは毎回確かめます）。ブラウザを再読み込みすれば新しいファイルです。
  ただし `--demo` と `--wide` は再読み込みでテスト鍵を失うので（§6）、再読み込みのあと「新しい世界を開始」で世界を作り直します
  （前の世界は時間切れまで動いたままです。世界は同時に 2 つまでなので、開始の画面の一覧で前の世界を「この世界を終了…」で止めてください。
  `--two` は前の世界を止めてからでないと始められません。保存する世界は再読み込みしても続きます）。#170 の herald の配信キャッシュはローカルの世界では使いません（ページを配るのはランチャーで、
  世界の herald は `--web` なしで動きます）。herald にページを配らせる構成（devnet 用）でも、書き換えたファイルは大きさか時刻が変われば次の要求で
  読み直すので、再起動は要りません。再起動が要るのは、ランチャーや中継のコード（`permutation-gateway/src/`）と Rust のコードを変えたときです
  （Ctrl-C して `scripts/play-local.sh` をもう一度。保存する世界を続けるなら `--resume` を付けます。変わったものだけビルドし直します）。
- 「ポートがふさがっています」と出たら、別の `--port`（例 `--port 41450`）にするか、前の世界を止めてください。
- 知らせ先は GitHub の Issue（r0ze998/wylls）です。画面のスクリーンショットと、上のフォルダの場所を添えてください。

## 10. ② 権利（在庫の交換）を遊ぶ（`--coexist`、試験専用）

オーナー決定 ② A の形です: 工房の村の持ち主が、同じ州にある相手の貯蔵庫に「在庫を交換する権利」を出します。相手は
自分の鉱石と木材を、工房が作った兵器に替え、その兵器を**隊商でだけ**運び出します。権利を出すのはウォレットだけです。

```bash
scripts/play-local.sh --coexist --demo --two --ai 2     # ×60。一周は約 10 分。保存なし
scripts/play-local.sh --coexist --two                   # 保存する世界（通常の速さ。貯蔵庫の費用にほぼ一日）
```

- **二人要ります。** 権利の相手は別のプレイヤーでなければなりません。一人で確かめるときは、ブラウザの窓を 2 つ使います:
  A は `http://localhost:41920/`、B は `http://127.0.0.1:41920/`（§3.1）。以下、**A ＝ 工房の村の持ち主**、**B ＝ 相手**。
- `--coexist` は、保存する世界か `--demo` を ②+⑨+⑩ の**共存の線**（プログラム版 0x7805、`RULESET_HASH_V4`）で動かします。
  `--ai`・`--two`・`--random-map`・`--resume` と使えます。`--wide` とは使えません。⑨⑩ は試験用のカードがあります（§12）。
- 最初の `--coexist` はビルドに 1〜2 分かかります。そのあと普通の世界を始めると、スクリプトが自分のバイナリを数秒で
  作り直します（#128。作る場所が同じ `frontier-node/target/debug` のため）。

手順（「」はページのボタンと表示そのままです）:

1. **同じ州に入る**: A も B も「世界を開始」（`--demo` では「新しい世界を開始」）→「国を選ぶ」で**同じ国**（AI のいない国。`--ai 2` ならボレアリスと
   エンバー以外）を選びます。`--two` の二人が同じ国を選ぶと、村は同じ州の別の場所に置かれます（#130。verify-pr130 で 3 回中 3 回、
   verify-pr133 で 1 回中 1 回）。
   州は、村の画面のいちばん下の「村の詳細」を開くと出ます（例「州 -2,0」）。違う国を選ぶと州が離れ、隊商が届きません
   （道は 32 マス・4 州まで）。
2. **A: 工房を建てる**: 村の建設の一覧で「ほかの建物（6）」を開き、「工房」の「建てる」（費用は食料 60・木材 120・石材 80・鉱石 40）。
   工房が出るのは `--coexist` の世界だけです。ふつうの世界の一覧には代わりに「工房はこの試験世界では建てられません（…--coexist でだけ建てられます）。」と出ます（fix-loop9 LP9-3）。
   「工房の建設を始めました」と出ます。
   工事は約 1 時間半（9 ターン。×60 で約 1 分半）です。その村の最初の建設として建てても同じです。1 分で建つ「初めての建設」は
   生産の建物 6 種だけの決まりで、工房の行は「1 時間 30 分」と出ます（プログラムの決まり。fix-loop14 LP14-6 までは、工房の行にも
   「1:00 初めての建設」と出ていました）。どちらの場合も、6 の「権利を出す」が
   通ったのはターン 18〜20 ごろからでした（verify-pr133・loop-play11）。建ち上がると、その村が「工房の村」になり、兵器を 1 時間に 4 作りはじめます
   （工房を建てられるのは `--coexist` の世界だけです）。
3. **B: 貯蔵庫を建てる**: 地図で、A の村と同じ州の空いたマスを選び、「ここに建てる」→「貯蔵庫を建てる」
   （費用は木材 200・石材 200・金 50。選んでいる村の蔵から）。「貯蔵庫を建てました」と出ます。
   山や水のマスでは「この建物はこのマスに建てられません（通れない土地、…）」と出て押せません。平地のマスを選び直します。
4. **B: 鉱石と木材を貯蔵庫へ運ぶ**: 貯蔵庫のマスを選んで「ここへ隊商を送る」（または村の画面の「交易と防備」→
   「隊商を送る」）。「出発地」が自分の村、「行き先」が貯蔵庫になっているのを確かめ、木材と鉱石の数を入れて
   「隊商を送る」。兵器 1 につき鉱石 2・木材 1 が要ります（例: 木材 20・鉱石 40 で兵器 20 まで）。
5. **B: 着いた隊商を届ける**: ローカルの試験世界には隊商を届ける係がいません。村の画面の「権利（在庫の交換）」に
   「着いた隊商（あなたが届けます）」が出ます。はじめは「通った州（P, Q）の決着が到着のターン N を過ぎるのを待っています。
   過ぎると届けられます（数ターン）。」と出ていて、ボタンはありません（#130）。1〜2 ターンで「隊商を届ける」が出るので押します
   （「隊商が届きました」。手数料は戻ります。verify-pr133 では 2 回とも 1 回めの押下で届きました）。
6. **A: 権利を出す**: 村の画面の「権利（在庫の交換）」→「権利を出す」を開き、「工房の村と相手の貯蔵庫」で B の貯蔵庫を
   選び、「交換の回数」（初期値 3）・「兵器の上限」（30）・「有効な日数」（1）を入れて「権利を出す」
   （費用：工房の村から金 25）。A の欄に「あなたが出した権利 有効 … 交換 0 / 3 回 · 兵器 0 / 30」と出ます。
   - 「工房のある村の州に、ほかの人の貯蔵庫が見えていません。…」と出るときは、B の貯蔵庫がまだ無いか、別の州です。
     「権利を出すには、工房のある村が要ります。」は 2 がまだか、工房がまだ工事中です（verify-pr133: ターン 11 では出て、ターン 18 には出せました）。
7. **B: 交換する**: B の欄で「権利の一覧を読み直す」→「あなたが受けた権利 有効」。数を入れて「交換を予約する」
   （「予約中 N」。貯蔵庫から鉱石と木材が、工房の村から兵器が出ます）→「交換を実行する」（「交換しました。兵器は
   あなたの貯蔵庫に入りました」）。予約をやめるときは「予約を戻す」。
8. **B: 兵器を隊商で村へ運ぶ**: 貯蔵庫のマス →「ここから隊商を送る」。フォームは「出発地」が貯蔵庫、「行き先」が自分の村で
   開き、数の欄の上限は貯蔵庫にある分です（#130。verify-pr133: 木材 18・鉱石 36・兵器 2）。兵器の数を入れて「隊商を送る」。
   着いたら 5 と同じく「隊商を届ける」。村の蔵に兵器が入ります。
9. **A: 取り消して閉じる**: 「権利を取り消す」→「取り消し済み」（B の開いている予約は戻ります）→「権利を閉じる」→
   「閉じた」（賃料が戻ります）。取り消したあとは、B はもう予約できません。

知っておくこと:
- 霧の決まり：欄に出るのは自分が出したか受けた権利だけです。ほかの人どうしの権利や、ほかの人の貯蔵庫の中身は出しません。
  A から見た B の貯蔵庫は「（国）の貯蔵庫（マス N）」とだけ出ます。
- 相手の欄に反映されないときは「権利の一覧を読み直す」を押します。
- 権利を出す・取り消すは、ウォレット（このブラウザの試験用の鍵）だけができます。AI 住民や代理には任せられません。
  （プログラムは取り消しだけセッションの鍵でも受けます。ローカルでは中継が断ります。devnet に出す前に直す項目です）
- 隊商は道の上で略奪されることがあります。届けたあとの知らせ「…到着しましたが、入った量は確認できません…」は
  長い文ですが、失敗ではありません（蔵の上限を超えた分は切り捨てられる、という意味です）。村あての隊商では
  「…決着しました。入った量はまだ確かめられていません…」と出ることもあります。これも失敗ではありません（村の蔵に入っています）。
- 普通の世界（`--coexist` なし）では、工房は建てられず、隊商を届けるボタンもありません（着いた隊商は届けられないままです）。
- ページのない旧ノードは `--coexist-node` です（開発用）。

## 11. 外部の AI 住民を入れる（`--external`、試験専用）

外部の住民は、あなた（または別の人）が自分のプロセスで、自分のテスト鍵を使って動かすプログラムです（⑬ 独立した住民／⑤ 案 B）。人と同じ規則で、新しく来た住民としてあなたのローカルの世界に入ります。運営側は特権を与えず、鍵も見ません。ページには普通の住民として出ます（AI の印はありません）。

1. 住民のテスト鍵を一度だけ作り、ファイルを持っておきます（`0600`。外に出るのは表示される公開アドレスだけです）。

   ```sh
   cd workstreams/03-composability/mcp && npm ci --ignore-scripts
   node -e "import('./examples/external-resident/key.mjs').then(m => console.log(m.createKeyFile('/path/to/resident.json').address))"
   ```

2. そのアドレスを付けて世界を起動します（2 つまで、カンマ区切り）。MCP サーバーは gateway のクライアントを読み込むので、一度 `(cd permutation-gateway && npm ci --ignore-scripts)` を実行します。まだ入れていなければ、確認の段階で「足りないもの」に出ます。

   ```sh
   scripts/play-local.sh --demo --external <アドレス>
   ```

   `--external` を付けると、③ の**読み取り専用**の MCP サーバーもこの世界のために起動します。待受は 127.0.0.1 だけで、ポートは世界のポートの次です（既定の `--port` と `--ai` なら 41950、`--ai 0` なら 41942。「読み取り専用の MCP (③): http://127.0.0.1:<port>/mcp」と表示されます。`--lang en` では `Read-only MCP (③): …`）。読むのは最初の世界だけです。使えるのは読むツールだけで、つなぐのは住民自身です（住民の財布がつなぐ文に署名します）。`--no-mcp` を付けると起動しません。スクリプトが動いているあいだ動き続け（世界の時間が切れたら次の世界を待ちます）、Ctrl-C ですべてと一緒に止まります。

   `--wide` の世界では、読むツールがもう 1 つあります。**`get_territory_status`**（ws13-territory）です。つないだ住民の自分の土地（§4.1）を、その住民に見える範囲で返します。持っているマス、次に取るときの鉱石の値段、1 時間あたりの食料の維持費、維持費が未払いかどうか、このターンに取った回数、そして取れる範囲の州ごとのマス（自分の・空き・他人の・見えない）です。霧（§5）：「空き」と「他人の」は住民に見えているマスだけに付きます。見えないマスは `unseen` です（空きかもしれず、他人のものかもしれません）。サーバーは今までどおり何も送りません。このツールが読むのは herald の公開の領土の道（`/h/world/wide/territory` と `/h/world/wide/territory/player/<自分の住民>`）です。herald にその道がないときだけ、ページと同じ「読むだけ」の中継の読み取りを使います。

3. いつもどおりページで開始を押してから、住民を起動します（早すぎたときは、あなたの世界ができるまで待ちます）。

   ```sh
   node workstreams/03-composability/mcp/examples/external-resident/agent.mjs --launcher http://localhost:41920 \
     --key /path/to/resident.json --mcp http://127.0.0.1:<port>/mcp
   ```

   住民は一歩ごとに JSON を 1 行出します（`discover`、`mcp`、`act` … `landed`／`refused`）。命令はページと同じ 6 つ（Join・PlaceHome・Harvest・Build・Train・Muster）です。どれも自分の鍵で署名し、自分の relay から送ります。運営側の AI 住民と同じく、行動は 1 ターンに 1 回です（Join は数えません。同じターンの 2 回目は `ResidentAlreadyActed`）。あなたのページにはこの上限はありません。自分の AI をつなぐには、`examples/external-resident/rule.mjs` の `decide()` を差し替えます（そのフォルダの README を見てください）。

   **⑬ の住民**も同じように動かせます。参照の規則の代わりに ⑬ の目標・上限・記憶で決めます（モデルも有料 API も使いません。`workstreams/13-citizens/resident/local/README.ja.md`）。

   ```sh
   node workstreams/13-citizens/resident/local/client.mjs --launcher http://localhost:41920 \
     --key /path/to/resident.json --dir /絶対パス/resident-state [--goal village-first|surplus-use] [--nation 0-5] \
     [--mcp http://127.0.0.1:<port>/mcp]
   ```

   `--wide` の世界では、この住民は**自分の土地**（§4.1。あなたと同じ決まり、同じ値段）も扱います。広い土地に村を出す前に、その村の場所の下のマスを取ります（記録には `"order":"TerritoryClaim"` と出ます。マスは 1 ターンに 1 つで、住民の行動も 1 ターンに 1 回です）。次に自分のマスの上に村を出し、そのあとは自分の土地の隣のマスをときどき 1 つ取ります。隣のマスを取るのは、使い道のない鉱石があるときだけです（建物の計画・蓄え・訓練 100 人ぶんを超えた鉱石）。多くて 6 ターンに 1 つ、24 マスまで、土地の維持費が最初の村の食料（1 時間あたり）の 1 割以内のあいだだけです。次の村の場所の下のマスは、最初の村の鉱石でマスの値段を払っても訓練 100 人ぶんが残るとき（最初のマスなら鉱石 30）に取ります。（これらは住民自身の進め方で、世界の決まりではありません。運営の AI 住民も ai-ore-reserve から兵のための鉱石を残します（§4.1）。それより前の loop-play15 では、鉱石が足りればすぐマスを取り、そのあと訓練ができなくなりました。）

   判断は `<dir>/decisions.jsonl`（一歩ごとに JSON 1 行）に、記憶は `<dir>/state.json` に残ります。再起動した住民は前の命令を署名でたどり、同じターンに 2 回行動しません。`touch <dir>/HALT` で一時停止します。
   `--key` のファイルがまだ無ければ、`--new-key` を付けるとその場所に作ります（手順 1 の代わり。アドレスは最初の行 `start` の `wallet` に出ますが、世界はそのアドレスを `--external` で受け入れてから起動するので、ふつうは手順 1 で先に作ります）。

4. **数ターンの計画（`--plan`、④ の実行、#148）**: ⑬ の住民に `--plan --runexec <runexec の絶対パス>` を付けると、村ができたあと、住民は自分の村の次の命令を 12 手の計画にし（建物 → 収穫 → 訓練 → … → 部隊の編成）、④ の計画の記録（SQLite、既定は `<dir>/plans.sqlite`）が 1 ターンに多くて 1 手ずつ実行します（次の手の費用が村に足りない間は、その手は待ちます。`decisions.jsonl` の `"what":"wait"` の行に、足りない資源と待つターンの目安が出ます。verify-pr156 では 6 手めの建設が木材を十数ターン待ちました）。`--plan` は `play-local.sh` の指定ではなく、この住民（`client.mjs`）の指定です。

   ```sh
   (cd workstreams/04-execution && cargo build --release --locked --bin runexec)   # 一度だけ
   (cd workstreams/03-composability/mcp && npm ci)
   node workstreams/13-citizens/resident/local/client.mjs --launcher http://localhost:41920 \
     --key /path/to/resident.json --dir /絶対パス/resident-state \
     --plan --runexec "$PWD/workstreams/04-execution/target/release/runexec" [--plan-db /絶対パス/plans.sqlite] [--plan-steps 12]
   ```

   - `--runexec` は絶対パスで、`--plan` と一緒にだけ使えます（`--plan-db` も絶対パス。`--plan-steps` は 4〜64、既定 12）。
   - 見るところ: `<dir>/decisions.jsonl` の計画の行（`planStep`）。意図は署名の前に、署名は送る前に ④ に書かれるので、途中で止めて（Ctrl-C でも強制終了でも）同じ指定で起動し直すと、署名をチェーンで読んで続きから進み、同じ命令を二度送りません（verify-pr148: 12 手が部隊の編成まで着地、二重の行動 0）。
   - 同じ `--dir` で 2 つめのプロセスは動けません。起動し直したプロセスは、前のプロセスの持ち時間（20 秒）が切れるまで待ちます。
   - チェーンに断られたり世界が変わったりすると、計画を止めて今の村から作り直します（1 つの世界で 24 個まで）。
     資源が足りないとチェーンに断られた建物は、その建物にかかる資源がどれも断られたときより増えるまで送り直さず、新しい計画の最初の手にもしません。自分の建物が着地したのに herald の記録にまだ出ていないときは、作り直さずに記録を待ちます（fix-loop9、LP9-4）。S1 の世界では、鉱山を村の地形の鉱石より上の分で数えます（プログラムと同じ。LP9-4）。
   - 計画に入るのは 6 つの命令と、`--wide` の世界では広い土地の命令（下）です。隊商・ふつうの進軍は入りません（隊商は r0ze の判断待ち、Q4）。

- `--demo` の ×N の時計は、**あなた**の最初の村が置かれてから動きます。それまでは 1 ターン 10 分なので、住民の 2 つ目の命令はあなたを待ちます。
- `--two` とは一緒に使えません。保存する世界・`--demo`・`--wide`・`--ai`・`--random-map`・`--coexist`・`--resume` では使えます（続きから遊ぶときも `--external` をもう一度付けます）。
- **`--wide` の世界では**（external-wide）ランチャーが住民にも「広い版」だと伝えます（開始の答えの `wideLand`。あなたのページに伝えるのと同じです）。⑬ の住民は最初の村を、ページと同じ選び方で選びます。外側から先に、自国の、入植済みの辺境の州の空いた地を、遠い環から探します。中心地より外では一か所の申し込み（`FileTicket`。ページの「辺境の村を申し込みました」と同じ）で頼み、世界がターンの終わりに決めるのを待ちます（最大 72 ターン。そのあいだ 2 つ目は出しません）。申し込みがそのターンの行動です。そのあとは辺境の村を 6 つの命令で遊び、**広い土地の命令も、あなたのページがそこで使えるのと同じものを使います**（external-wide-orders）。広い土地の取得（0xD9、村の画面の「広い土地に村を出す」）、広い村の訓練・編成・となりの州の砦への進軍（ページの広い村の計画と同じ）、辺境の村の整った軍勢の遠征（ページの出発の道）です。決まり（モデルも有料 API も使いません）:
  - **貯めてから取る。** 3 州以内に開いた広い土地があり、広い村がまだなければ、入植の費用をページのカードと同じ額、つまりプログラムが取る額で貯めます（2 つめの村：食料 800・木材 800・石材 400・金 200。verify-pr178 までは 1,200・1,200・600・300 を貯めていました。D-external-wide-orders-8、verify-pr183 で修正）。足りない分を生産で 240 ターン以内に満たせるなら、それを使う建設と訓練は待ちます（収穫と編成は何も使いません）。蔵に費用がそろったら、いちばん近い州の空いている最初の場所（herald の公開の道の記録。ページのカードと同じ読み方）を取り、世界がターンの終わりに決めるのを最大 12 ターン待ちます。決めるときにその場所が取られていたら村はできず、費用は戻りません（プログラムの決まり）。それが 3 回続いたら取得をやめます。プログラムは最初の村が**確定**していないと取得を受けません（`NotFinal`、Custom 24。送る前に断られます）。辺境の村の確定は、仮の期間のあとの持ち主の次の行動で行われるので、貯めるだけだった住民はまず収穫（何も使いません）をしてから取得します。あなたのページのカードはこれを確かめません（D-external-wide-orders-7）。
  - **広い村。** 自分の `/h/me` に広い村が出たら（ページの広い村の読み取りと同じ）、ページの計画の一手をそのターンの行動にできます。100 人の訓練、300 人までの編成、となりの州の砦への広い土地の中の進軍（ページと同じく 2 回まで）。着地した訓練は 12 ターンのあいだ頼み直しません。
  - **遠征。** 開いた広い土地に接する辺境の村（環 128）は軍勢を作り、ページの道の確かめで通れる道があれば 1 回遠征します。通れる道がなければ（実走で見た `RouteImpassable`）その村からは遠征しません。控えに 100 人以上いれば貯める前に編成し（何も使いません）、いなければ訓練は取得のあとにします。
  - `--plan` ではこれらも ④ の計画の手です（`WideClaim`・`WideTrain`・`WideMuster`・`WideDepart`・`Expedition`）。貯めているあいだは計画の最初の手が取得で、貯めた費用を使う建設があれば計画を作り直します。
  どれもそのターンの 1 つの行動で、住民の中継の「1 ターン 1 行動」を通り、中継がバイト単位で作り直し、プログラムがあなたのページと同じに判定します。読むのはランチャーの `wideLand`（あなたのページも同じものを受け取ります）、自分の世界の入口からの公開の herald、自分の中継の読むだけの広い土地の読み取り（ページの `frontier-local-play-act-wide-read-v1`）だけです。住民の中継は運営の AI 住民と同じ中継です。verify-pr163 の `--no-wide-orders` はランチャーが付けなくなりました（中継の選択肢としては残っています）。
  参照の住民（`agent.mjs`）は今も中心地（環 2〜3、PlaceHome）しか読まず、これらは送りません。
  例: `scripts/play-local.sh --wide --random-map --ai 2 --external <アドレス> --speed 60`、続けて `node workstreams/13-citizens/resident/local/client.mjs --launcher http://localhost:<ポート> --key <鍵> --dir <絶対パス> --plan --runexec <runexec の絶対パス>`。
- 外部の住民の村の州も、世界の進行役があなたの州と同じ組で決着させます（#146。保存する世界でも同じ）。×60 の `--demo` で住民の州が編成できる状態にある時間は 8〜9 割です（前は 0〜6%。§8.2）。
- 付属の 2 つの住民が送るのは 6 つの命令（と、`--wide` の最初の村の申し込み。⑬ の住民は上の広い土地の命令も）です。隊商・ふつうの（中の円盤の）進軍は送りません。① の板も使いません。住民の中継そのものは、ふつうの進軍の道と、どの世界でも遠征の道を開けています（自作の住民なら送れます。verify-pr163 D-2。外部の住民に中の円盤での進軍を許すかは r0ze の判断待ちです）。住民の中継は Host が自分のアドレスで Origin のない要求だけを受けます（#164。Node の住民はそのままで通ります。§9）。世界の時計を止める・速さを変える操作は、ランチャーの合言葉が要るので住民にはできません（#137）。
- ローカルだけです。devnet には外部の住民の受け入れも MCP サーバーもありません（公開の MCP の方針 MCP-1..11 は未決です）。

## 12. 試験：⑨ 工房を貸す・⑩ ほかの人の貯蔵庫に鉱石を預ける（`--coexist`、試験専用）

2026-11-21 の決定どおりです。⑨ は ② A の貯蔵庫と隊商の上に作る試験版で、占領されたら中身は占領者がすべて取ります。⑩ は ②
A の貯蔵庫に合わせ、運んでいる途中の荷は運び手のもので、運び手が負けると失われます。預けた人の兵は守りません。奪われたこと・
失ったことは画面に出します。預けられるのは鉱石だけです。devnet には何も出ていません（coexist の世界のプログラムの命令を
ページが送り、プログラムが確かめます）。

`--coexist` の世界の村の画面には、② のカードの下に 「預かりと工房貸し（試験）」 があります。準備は §10 の 1〜5 と同じです。

⑨ 工房を貸す（A が工房の村の持ち主、B はその州に貯蔵庫あり）:
1. A: 「工房を貸す」 を開き、数を入れて 「工房を貸し出す」。「工房を貸し出しました」。
2. A: 「使わせる相手（この州に貯蔵庫がある人）」 で B を選び（#149 から、選択肢は「ダンマール の村 ○○（貯蔵庫 マス N · 4RLP…cWEN）」のように村の名前・マスで見分けます。最後の短い住所は持ち主の住民の記録の住所で、ウォレットの住所ではありません。loop-play11 LP11-5）、工房の数・「兵器の上限」・「有効な日数」 を入れて 「工房を使わせる」（ウォレットで署名）。
3. B: 「使える工房」 の 「使う工房の数」 と 「作る兵器の数」 を入れて 「予約して材料を入れる」。予約と、兵器 1 につき鉱石 2・木材 1 の投入が一度に行われます。
   材料は先に B の貯蔵庫に入れておきます（村から隊商で運ぶ）。fix-loop15 から、カードに「あなたの貯蔵庫（マス N）：鉱石 X・木材 Y」と出ます。
   空のときはボタンが押せず（「あなたの貯蔵庫（マス N）に材料がありません…」）、貯蔵庫の中身より多い数を押すと、署名の前に
   「あなたの貯蔵庫（マス N）の材料が足りません。兵器 10 には 鉱石 20・木材 10 がいります（いま 鉱石 6・木材 3）。…」と出ます
   （以前は「チェーンのノードがこの命令を実行前に受け付けませんでした。送られていません。」だけでした。loop-play15 LP15-8）。
4. B: 「あなたの作業」 の 「兵器 N / M」 が増えます（工房 1 で毎時 4。×60 なら 10 個で約 2.5 分）。「貯蔵庫へ受け取る」 →
   「兵器と残りの材料が貯蔵庫に入りました」。家へは §10 の 8 と同じく隊商で運びます。
5. A: 「取り消す」 で権利を終え（予約済みの作業は続きます）、「空いた工房を戻す」 で村に戻します。

⑩ 鉱石を預ける（B が貯蔵庫の持ち主、A が預ける人）:
1. B: 「鉱石を預かる」 を開き、A の村（#149 から村の名前・マス・短い住所が出ます。短い住所は上と同じく住民の記録のものです。選べる人が複数いると、一覧は「（預ける人を選んでください）」か、前に選んだ人から始まります。fix-loop9 LP9-7）と 「鉱石の枠」 を選んで 「預かりの枠を開く」（ウォレット）。
2. A: 「預けた鉱石」 に貯蔵庫が出ます。量を入れて 「鉱石を預ける」。着いて、通った州の決着が済んだら 「鉱石を届ける」 →
   「預ける鉱石が届きました」（② のカードはこの隊商を出しません）。
3. A: 「引き取る」 で家へ。届いたら ② のカードの 「隊商を届ける」。空になったら 「枠を閉じる」。
4. B には 「あなたの貯蔵庫の預かり」 だけが見えます（国と量）。

失ったとき（一度だけ警告を出し、カードにも残します。ただし道中で奪われた隊商の行「隊商 N：道中で奪われた」は、「帳簿を確かめる」を
押すとカードから消え、残るのは地図の知らせの履歴だけです）: 貯蔵庫を奪われた、預けに向かう隊商が奪われた、工房の村が奪われた。
#145（fix-9-10-followups）から、上の 2 つ（貯蔵庫・道中の隊商）は `--coexist --two` の世界で実際の命令として起こせます（プログラムが
もともと持つ SeizeVault・RaidDomestic・RaidCaravan。チェーン側は何も変えていません）。村の占領はまだ起こせません（テストのみ）。
ふつうの世界（`--coexist` なし）では、これらのボタンは出ません。軍勢は 100 人以上で編成します（それより少ない編成はプログラムが断ります）。
×60 では止めてから決めるまでが約 20 秒しかないので、`scripts/play-local.sh --coexist --demo --two --speed 15`（1 ターン 40 秒）が楽です。
- **道中の隊商を止める**（B が A の預ける鉱石を奪う）：二人は同じ国で、衝突は自国の隊商を襲わないので、B が自分で止めます。
  隊商がマスに「立つ」のはターンの始まりだけ（平地でおよそ 1 ターン 5 マス）なので、1 ターンの中で出発して着く隊商は止め
  られません。検証では州 (-1, 2) の A の村がマス 28、B の貯蔵庫がマス 22 で、ターンの残りがゲーム時間で約 5 分半（×15 で約 22
  秒）のときに 「鉱石を預ける」 を押すと、隊商はマス 20 に立ちました。手順：B は先にそのマスに軍勢を置きます（村の画面の
  「編成」、盤面でマスを選ぶ）。隊商が立ったターンの決着がついたら、B はそのマスを押し、軍勢カードの ⓘ（マスの欄）で
  「隊商を止める（ターン N まで）」→「隊商を止めました。…」、同じ欄で 「奪って運ぶ」 か 「焼き払う」（立ったターンから 6 ターン
  以内）。×60 でもできます（loop-play16：B の軍勢がターン 27 からマス 20 に立ち、A がターン 31 に「鉱石を預ける」、
  B のマスの欄にはターン 33 から「隊商を止める（ターン 37 まで）」が出ました）。軍勢は、隊商が出るターンにはもうそのマスに
  立っている必要があり、止めるボタンは州の決着がそのターンを過ぎてから（出してから約 2 ターン後）出ます。
  A には 「預けに向かった鉱石 N は道中で奪われました。」（または 「…焼き払われました。」）と出て、「帳簿を確かめる」
  （ReconcileLot）で枠が空きます。奪われた隊商は B の村へ向かい、B が ② のカードの 「奪った隊商」→「隊商を届ける」 で届けます
  （鉱石は B の村へ）。まだ道中のあいだは ② のカードの「奪った隊商（あなたの村へ向かっています）」に「ターン N に着きます。…」と出て、地図の札も着くターンを示します（奪った場所から村まで近いと、すぐ着いて「着いた隊商」にだけ出ます。verify-pr162 では奪ったターンの次のターンに「着いた隊商」に出て、地図の札は「略奪された隊商 ターン 108 着」でした）（fix-loop9 LP9-6）。焼かれた隊商は空のまま進み、A が 「鉱石を届ける」 で届けます。
- **貯蔵庫を奪う**：もう一人が貯蔵庫のマスに軍勢を置き（持ち主の軍勢がいると奪えません）、マスを押して ⓘ →
  「貯蔵庫を奪う」（持ち主の軍勢がいてもボタンは押せますが、プログラムが断ります）。預かる側には 「あなたの貯蔵庫が奪われ、預かっていた鉱石も奪われました。」 と出ます。二人だけなので奪う
  のは預けた本人で、そのカードは 「あなたが奪った貯蔵庫」 と出て損失は出ません。「帳簿を確かめる」 で預けた分は、いま自分の
  ものになった貯蔵庫に入ります（奪った側がすべて取る）。第三者による奪取と、預けた人の兵が守らないことの確認は 3 人目の席が要り
  ます（未実装）。
- 届けた預かりの隊商は、記録係（herald）が地図から消します（#145）。

## 13. ① 国をまたぐ依頼の板と ⑮ 称号「依頼に応えた」（試験専用、#149・#152）

`play-local.sh` は、どの世界にも workstream 01 の協力の板（ランチャーの `--coop-board ws01-board-v1`）を付けます。
付けたくなければ `--no-coop-board` を付けます。板があると、村の「交易と防備」に「国をまたぐ依頼を開く」が出て、
下のバーの「その他」に ⑮ の「称号と記録」のカード（「国をまたぐ協力の達成。勝敗・得点・賞金には関わらない」）が出ます。
板はゲームのページと同じ言語で出ます（#171。ゲームのページの右上のボタンで英語にすると、開いている板の窓も英語に変わります。
板の窓にも切り替えのボタンがあります。日本語の表示は前と同じです。以下の「」は日本語の表示です）。

依頼から配達まで（隊商を送れるのは `--coexist` の世界だけです。ふつうの世界の村は隊商を送りません）:

```bash
scripts/play-local.sh --coexist --two --demo --ai 0      # ×60。二人で一つの世界（§10 と同じ。`--ai 0` は AI なし）
```

**称号まで確かめるなら、A と B は違う国を選びます**（同じ国の依頼は配達はできますが、称号は付きません）。verify-pr152 では
いつもの地図（`--random-map` なし）で A ＝ アステル、B ＝ ボレアリスにして届きました（隊商の道は 32 マス・4 州まで）。

1. **A（依頼する人）**: 村 → 交易と防備 → 「国をまたぐ依頼を開く」。別の窓に板が開きます。「このウォレットで署名する」
   （このページのテスト用ウォレットが、板の記録だけに署名します）→ 木材・石材の量を入れて「依頼を出す（署名）」。
   届け先は A の村です（例「木材 20・石材 20 → …（アステル・申告。判定には使わない）の村 (-1,2) 村5 受付中」）。板の「自分の国」は
   ゲームと同じ国の名前で、ウォレットを接続するとチェーンで確かめた国に合わせます（申告であることは変わりません。
   fix-loop9 LP9-8）。
2. **B（届ける人）**: 同じように板を開き、「このウォレットで署名する」→ その依頼の「応じる（送るつもり。義務はない）」。
3. **B**: ゲームの村 → 交易と防備 → 隊商を送る。15 秒ほどで行き先に「① 依頼の届け先：村（-1, 2 · マス 28）」が出ます
   （後ろに「 · アステル」のように国の名前が付きます）。この行き先が出るのは**その依頼に「応じる」と答えた人だけ**です。
   依頼した人が板に公開した場所だけで、まわりの土地は見えないままです（霧はそのまま）。量を入れて「隊商を送る」→
   「ほかの人の村か貯蔵庫へ送る隊商は、ウォレットで署名します…」→「隊商が出発しました」。
4. **B**: 板を読み直して「隊商 #0（木材 20・石材 20）をこの依頼に結び付ける」→「結び付けた。数えるのは確定した到着だけ」。
5. 着くと、B の「権利（在庫の交換）」のカードの「着いた隊商（あなたが届けます）」に「隊商を届ける」が出ます
   （通った州の決着が到着のターンを過ぎるまで待ちます。×60 で数十秒）。押すと「隊商が届きました」。
6. 板の依頼の「隊商と到着」に「到着（確定）・届いた 木材 20 以上・石材 20 以上（規則から）・Fulfilled」と出て、
   「依頼の充足：依頼量に届いた（数えた量の下限で証明）」になります。一部だけ届けたときは「依頼量に届かなかった
   （すべて終わり、上限で証明）」と出ますが、依頼は「受付中」のままで、残りを届けて結び付ければ「依頼量に届いた」に変わります。
7. **⑮ の称号「依頼に応えた」（#152、オーナー決定 Q1-⑮）**: 依頼が依頼量に届くと、届けた B のページの「その他」→「称号と記録」に
   「ターン N あなたが称号「依頼に応えた」を得た」と出ます（英語の画面では “Answered a request”。N は依頼量に届いた到着のターン。
   板を読むのに少し時間がかかります）。依頼した A の札には出ません（「まだ称号はありません」のまま。称号は本人にだけ見せます）。

称号が付く条件（⑮ の規則 B 版 4。`workstreams/15-coop-outcomes/src/rulesets.mjs`）:
- **他国の人**の依頼に、**自分の隊商で届け**、その依頼が**依頼量に届いた**こと（板の、数えた量の下限での証明）。依頼量には、数えられたすべての届け物が入ります。依頼した人と同じ国の人の届け物も入ります（オーナー決定 2026-11-26、Q-TG2-2）。例: A が木 20 を頼み、A と同じ国の C が 15、ほかの国の B が 5 を届ける → 依頼量に届き、B に称号が付きます。C には付きません。
- 付かないもの: 「応じる」と答えただけ、一部だけ届けて依頼量に届かなかった依頼、同じ国の人の依頼、自分の依頼（板がそもそも受け付けません）。
- 称号と記録だけです。世界の目標の達成・得点・賞金には何も加えません（オーナー決定 ⑮ B。2026-11-24 の決定でも、協力は「世界の目標」に入りません）。
- ほかにいま取れる称号は P-raider（「他国の隊商を襲った者」。ほかの国の隊商から奪うと付きます。国内の襲撃は数えません）で、依頼とは関係ありません。
  - 他国の隊商から奪った量を、すべての襲撃で資源ごとに足し、どれか一つの資源が最小量に届く必要があります: 食料・木材・石材・鉱石は 100、武具は 10、金は 20
    （`rulesets.mjs` の `minQty`、`goals.mjs` の raider）。
  - 他国の隊商が襲われるのは衝突の中だけで、隊商がその州の衝突に加わるのは、州の守備隊が 12 未満のときだけです（拠点の村と自由都市、
    賊の野営、兵の入った要塞。契約 `S1-1B-CONTRACT.md` §3.5、`clash_model::build_v2`）。拠点のマスにいる隊商は守られます。
    `--demo` の世界（固定マップ）では Aster の本拠の州 (-1, 2) が最初の数ターンで村 12 で埋まるので、そこでは隊商は決して襲われません
    （loop-play20 の LP20-3 はちょうどそこで試しました）。`--wide` の世界ではそこにその村は置かれません。
  - `--coexist --demo --two` で A = Aster、B = Borealis のとき通った手順（caravan-raid-investigate、×60）: B が板で依頼を出し、A が応じて
    「① 依頼の届け先：村（-2, 2 · マス 6）」へ木材 120 を送る。B は (-2, 2) での隊商のマスを読み、隊商がそこに立つ前にそのマスへ槍兵 100 を編成する。
    B のマスの欄に「奪って運ぶ」が出て、「その他」→「称号と記録」に「ターン N あなたが称号「他国の隊商を襲った者」を得た」と出ます。
- カードの「まだ判定できない達成 N」は、すべての住民の未判定の数の合計です（自分のものとは限りません）。

## 14. 世界の目標：旗の砦（試験専用・最初の一切れ・お金は動かない）

世界は続きます。シーズンはなく、世界に終わりもありません。代わりに、期限のない 4 つの目標があります（[設計](../design/win-conditions/01-proposal.ja.md)、r0ze が 2026-11-24 に了承）。いま判定するのは最初の 1 つだけです。

- **旗の砦（覇権）。** 各国の、取り合える砦（中核地ではない砦）に旗が立ちます。国ごとに 2 つ、国境の砦を先に、世界の drand の種で順番を決めます。ある国が、**ほかの国から奪った旗の砦**を**旗の砦の半分**の数だけ、それぞれ **144 ターン**（チェーンの時計で 24 時間。×60 の試験の時計なら 24 分）続けて持つと、その回を達成します。**その回の初めから自分の国にある旗の砦は数えません**（r0ze の決定、2026-11-24 22:00。数えると、必要が 2 のとき、どの国も何もせずに達成していました）。奪われて取り返した自分の国の旗の砦も、自分の国の旗の砦のままで、数えません。ほかの国が持てば、その国には数えます。次の回はすぐに掲示されます。次の回の旗の砦は、そのとき各国が持っている砦から選ぶので、奪った旗の砦を持って回を始める国はありません。
- 世界初の技術・大建造物・未踏の印は「準備中」と出ます。

play-local の世界には判定器が付きます（`--no-world-goals` で外せます）。ランチャーが自分のプロセスで、チェーンの外で判定します。世界の Province と Citizen の口座を読み、結果を `/goals-world/<世界のプロキシのポート>/goals/state` で読み取り専用で出します。「国と領土」を開くと「世界の目標」の札が出ます（「期限のない 4 つの目標。どの国も、いつでも狙えます」）。4 つの目標、その回の条件（「第 N 回：ほかの国から奪った旗の砦 3 個を、同じ国がそれぞれ 144 ターン（24 時間） 続けて持つと達成（旗の砦は全部で 6 個。初めから自分の国にある旗の砦は数えません）」）、旗の砦ごとの持ち主と、奪われた砦なら保持の残り時間（初めの国が持ったままの旗の砦には「初めからこの国の旗の砦です（達成には数えません）」）、自分の国の進み具合（「あなたの国：奪った旗の砦 0 / 必要 3、うち 0 が保持の時間を満たした」）、各国の奪った数（始まりは「まだどの国も、ほかの国の旗の砦を奪っていません」）が見られます。地図では、見えている旗の砦の旗のそばに金の旗が出ます。×60 の試験の時計では、札の時間は実時間の分で出ます（「72 ターン（この世界の実時間で約 12 分）」。1× ではターンと時間。#208）。霧（見えない土地）の中では、札も地図と同じように出します。いま見えている旗の砦は持ち主・保持の残り時間・包囲を、前に見た砦は前に見たときの持ち主だけを、まだ見ていない砦は場所だけ（「この州の砦は、まだ見ていません。」）を出します。自分の国の旗の砦はいつも出ます（`--wide` でも同じ。ページの砦の一覧に遠い辺境の砦がなくても、判定器の持ち主で出します。#208）。自分の国が持っていて奪われた旗の砦は、奪った国つきで札に残ります（「持ち主 エンバー · あなたの国が失ったとき（第92ターン）の持ち主です」）。保持の残り時間と包囲は出しません。奪われたことは知らせで伝わっていますが、そのあとのことは見えていないからです（fix-loop14 LP14-3）。各国の数は、支配する州の数と同じく、誰にでも見えます。

達成すると札に出ます（「第 1 回：アステルが達成（ターン 162）」）。そのあと札に「賞金が有効なら、あなたは X テスト USDC を受け取っていました」と出ます。これは試算です。賞金庫は、人ひとりにつき 25 テスト USDC の参加券、その 80% が賞金、1 回の達成で覇権の賞金庫の 30% を払う、として計算します。国の中は貢献の点で分けます（奪取 10 点、増援は砦の上の兵 100 につき 1 点）。運営の AI 住民は点を得ますが、お金は受け取りません。外部の AI 住民も受け取りません（札:「外部の AI 住民の賞金は法務の確認の後です」）。達成の 24 時間（144 ターン）前より後に国民になった人は、その回は受け取れません。何も払わず、何も送らず、チェーンも変えません。賞金のプログラムの目標の賞金庫（#202。テスト USDC だけ）は、`play-local.sh` にはつながっていません。
ページを開いているあいだに達成があると、知らせと記録の行にも出ます（#208。「世界の目標：第 1 回の旗の砦を エンバーが達成しました（ターン N）」。自分の国なら「世界の目標：第 1 回の旗の砦を、あなたの国（アステル）が達成しました（ターン N）。賞金が有効なら、あなたは X テスト USDC を受け取っていました」）。ページを開いた時点ですでにあった達成は、記録の行にだけ静かに入ります。

ローカルの世界では環 2〜3 が中核地で、第 1 回は始まりに、環 4 が開く前に掲示されます。そのとき取り合える砦は環 1 だけなので、旗の砦は国ごとに **1 つ**、全部で 6 つ、必要は 3 です（環 4 が開くと、その 24 の砦も旗なしで取り合えます。開く時は世界ごとに違い、×60 のある回ではターン 13 までに、別の回ではターン 60 でもまだでした。後の回は、その掲示のときに開いている砦から選びます。loop-play13 の `--wide` の世界では旗 12、必要 6 でした）。早く試すには、試験用の `--flag-keeps-need N` と `--flag-keeps-hold N`（ターン）を使います。例：`scripts/play-local.sh --demo --ai 0 --flag-keeps-need 1 --flag-keeps-hold 72`。隣の旗の砦を 1 つ取り（72 ターン）、さらに 72 ターン持ち続けます（`--flag-keeps-need 2` なら 2 つ奪う必要があります。自分の国の旗の砦は数えません）。

**AI 住民と旗の砦。** `--ai N`（戦争あり）の AI 住民は、自分の国の人と同じ「世界の目標」の札を、同じ霧の中で読みます。掲示と各国の数は見えます。旗の砦ごとの持ち主と包囲は、自分の村・自分の部隊・自分の国の州から見える所だけです（見えない砦について判定器の答えを読むことはしません）。自分の国の旗の砦が包囲されていれば、他のどの砦より先に守りに行きます。奪った旗の砦を「必要の数 − 1」個以上持つ国があれば、その国が奪った旗の砦を先に攻めます（砦の兵の 1.5 倍がいる時だけ、は変わりません。その国の初めからの旗の砦は、ふつうの旗の砦として扱います）。それ以外では、見えている旗の砦は、ほぼ同じ強さの候補の中で選ばれるだけです。旗の砦にすでに 1 つ進軍している住民には、この差がもう付きません（勝ちそうな国の旗の砦なら 2 つまで）。他の部隊はふつうの戦争をします。環 4 が開けば、その砦も取り合えますが第 1 回の旗はありません。AI 住民はそこでもふつうに戦います。理由は記録（`operators.out`）の進軍の行に `defend-flag`・`stop-rival`・`flag` と出ます。
