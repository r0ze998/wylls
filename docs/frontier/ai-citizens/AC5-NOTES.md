## Deviations, assumptions and choices the contract did not pin

1. **Cache rule vs mutable council files.** 8.3 makes `<digits>-<digits>.json` immutable, and `council/<k>-<f>.json` has that shape; if AC6 rewrites it while period k is open, a browser keeps the first copy for a year. `serve.mjs` follows the contract. AC6 should write that file only when final (use `council/current.json` for the live one), or the integrator should change the rule.
2. **Extra serve routes** (not in 8.3): `GET /serve-health` (the run script waits on it), `/` redirects to `/council.html`, the page is served at `/council.html` and at `/frontier/council.html` (so its relative imports of the web files resolve to `/frontier/...`, which are forwarded to the herald), `/h/ws` upgrades. The CSP is the herald's own web CSP plus `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`, `font-src 'self'`; it keeps `'wasm-unsafe-eval'` for the read-only web imports that load wasm.
3. **Files and shapes the contract left open.** `PUB/anchors/commit.json` records the commit memo and the audited/unaudited verdict. The commitments file is the canonical JSON of the signed object (including `sig`, base64); its sha256 is what the commit memo carries. `slots_root` = sha256 of the canonical JSON of `slots`; `flags_sha256` = sha256 of the canonical JSON of the flags array; `candidate_generator_tree` = sha256 over the sorted `path\0tree\n` lines of the git trees of `bots/src` and `agents/src` (`combinedTreeHash` is exported); `episode_kinds_sha256` = sha256 of the canonical JSON of the sorted top-level keys of `memory/templates.en.json` (my reading; AC2 and AC8 should confirm or give the exact definition); a part that does not exist in this tree (page tree, memory tree, prompts, library, deck, corpus) is `null` in the file, visibly. Roster: `tag` is the 16-digit lowercase hex of the citizen tag (`identity.mjs` `tagKey` of the Citizen address's first 8 bytes), `name` is `{en, ja}` (`displayName(identityOf(tag), {full:true})`). All signatures are base64 ed25519 over canonical JSON without `sig`; `verifySigned` is exported for AC8.
4. **Season-end trigger.** The contract names none. `registrar publish` writes `PUB/anchors/index.json` (signed: anchored bells, gaps, the commit record) and the private `STATE/season-end.json`; the run script calls it when the stack's `state.json` says `complete`. AC8 or the server should watch the file, or the integrator wires another trigger.
5. **RUNS.md format** (the contract leaves it to AC5): a header, then per run a `## <run_id> — <time>` heading and a `RUN {json}` line (`run_id, start_unix, commitments_sha256, configs, arm, rep`); an `END {json}` line (`run_id, end_unix, status, detail`) is appended at the end of the file when the run ends; no `END` means aborted or still running. `parseRunsMd` is exported for `report.mjs`. The RUNS entry commit is `Wylls AI run: <run_id>` (no trailer, it is made by the script); END lines are not committed by the script.
6. **ai-hook-check.sh.** Besides the four hook files it treats `frontier-node/crates/bots/Cargo.toml` as a hook file (the `# AI hook` `sha2` line of 11.2); it allows the integrator's files (`DECISIONS.md`, `.gitignore`, the lockfiles, the gateway `package*.json`) even when they are on the MC list (`DECISIONS.md` is), because G10 must pass at every integration; it requires a `//` marker in `.rs` and `#` in `.toml`/`.sh`. The contract's literal G10 `git diff --stat` command lists `DECISIONS.md` too, so the integrator's part X edit will appear there; this script does not count it.
7. **The run script guesses the other units' interfaces from the contract.** The citizens service gets exactly the 8.4 flags and the permission-model read list of 1.3 C1 built in the script (filtered to what exists; `AI_PERM_EXTRA` adds paths; AC1a "pins the list in the run script", so AC1a should adjust `perm_read`); the config keys it reads are `llm.url`, `llm.alias`, `serve.port`, `ports.mind`, `ports.social` (defaults 41980, 41981, 41902); the fleet gets `--ai-slots`, `--brain`, `--brain-token-file`, `--follow-council`, `--export-seat-key` (8.4) plus the stack's own flags and `--personas off` and `--control 127.0.0.1:41971` (my choice: AC3a decides how a slot roster and personas interact); the A/B seat script is started as `ab/seat.mjs --arm A|B --rep N --ai-dir --herald --social --key-file --config` (AC9 must accept these or the script changes); `registrar deal` imports `persona/deal.mjs` (`deal(seed32, deck, slots)` with slots `[{index, faction}]`), reads `persona/library.json` (an array, `{personas: [...]}` or an object by id) and `persona/decks/deck-<k>.json` (an array or `{personas|deck: [...]}`) and says which is missing.
8. **The stack lock** is per worktree (`.local` lives in each checkout), so two worktrees do not see each other's lock; what stops them is the busy-port guard on the 41900 block. `AI_STACK_LOCK` points every worktree at one shared lock file; the integrator may want to set it for I-A.
9. **Stack tomls.** `chaos` and `adversary` are explicit and off; no `season_end_at_play_end` (the contract lists none), so a 3-day run ends play at day 3 and the stack pauses, while the season itself keeps its default end bell. The run id is per invocation (`--run-id`, default the toml's; a used id is refused); the A/B copy is `ai-ab-<arm>-<rep>` with bot_seed and season_id 32 + rep.
10. **Guards.** The refused variable list is the named paid-API keys and tokens plus any `ANTHROPIC_*` or `OPENAI_*` name ending in `KEY` or `TOKEN`; `ANTHROPIC_BASE_URL` and `CLAUDE_CODE_*` are not refused. `--no-busy-check` exists for tests only. The mind's own `guards.mjs` (AC1a) is separate; `serve.mjs`, `registrar.mjs`, `census.mjs` and `run-guards.mjs` carry their own small loopback checks because `serve.mjs` runs inside the sandbox and cannot import `bin/`.
11. **Test port.** One run-check test binds 127.0.0.1:41999 for a fake llama (never 41901, which AC1a and the slice gate own) and does nothing if the port is taken.

- AC3a: the two blank lines outside hook blocks above (or accept `--blank-ok`). The tomls pass `--follow-council` to the stack's script bots, so a stack started with an M1 `frontier-bots` crash-loops its bots (observed); build the stack binaries from the merged tree before the I-A smoke.
- AC1a: `server.mjs` must accept the 8.4 flags and write `STATE/mind.token`; its config files need the keys read above; `mind/guards.mjs` should refuse the same URLs as `run-guards.mjs`.
- AC2/AC8: the exact definitions of `episode_kinds_sha256` and `candidate_generator_tree`, and `deal.mjs`/`library.json`/deck shapes (items 3 and 7).
- AC6: council file finality (item 1); AC8/AC1a: the season-end trigger (item 4).
- The commit memo must come before genesis. The margin is the preseason: 24 chain hours at 2000 times, about 43 s of wall time after the localnet starts (contract 7.1). The registrar starts before the stack, polls `getHealth` every 0.5 s and sent its memo at chain slot 4, within a few seconds of the localnet's start (block time g0 + 12 s; genesis was g0 + 87,801 s). A localnet that took longer than the preseason to answer would turn the run into an `unaudited` one; the verdict is written to `PUB/anchors/commit.json` either way and the run is never cited for audit claims then.
