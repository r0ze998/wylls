# 甲：手で回す試遊（キット）

2026-10-29。計画は `audits/2026-10-29-wylls-launch-plan.ja.md` の 13〜14 章にあります（作業フォルダ、リポジトリ管理外）。

## 何を確かめるか

核は、オーナーの決定 D1 のとおりです。

> **文明を育てながら、文明の機能そのものも住人が増やしていくゲーム。**（`docs/design/redesign/27-design-v1.ja.md` §1）

段階 2（S2）の 4 つの部品を渡したときに、次の 3 つが起きるかを見ます（同 §1「確かめるべきこと」）。

1. 運営が指定しなかった使い方が生まれる。
2. 別のプレイヤーがそれを使いたくなる。
3. その成果が、さらに組み合わさる。

あわせて、乙（S2 の画面を作る段階）で先に作る 2 つを選ぶ材料を集めます（決定 D11）。4 つの部品のうち、実際によく使われたのはどれか、を見ます。

## 遊び方の形

| 項目 | 内容 |
|---|---|
| 場所 | 運営の Mac 1 台。参加者ごとに `pN.localhost` を使う（10-22 に決めた hot-seat の形） |
| ルール | main の S1。倉、荷車、工房、襲撃、構造物、国の投票、封をした進軍 |
| S2 の 4 つの部品 | ゲームにはまだないので、**運営が台帳と札のカードで手で回す**。部品は、持ち分の札・受け取りの札・使用権の札・引き換えの預かり |
| 運営の住人 | 運営が 2 つの村を動かす。組合が 1 つ、工房の貸し出しが 1 つ。**運営が動かしていることは、参加者に告げる**（D5 の「運営の住人」と同じ考え） |
| 人数 | 人間 4〜6 人、加えて運営の住人 2 |
| 時間 | 2 夜 × 3 時間。10 倍速なので、1 ターンは現実の約 1 分。夜の間は時計を止める |
| お金 | なし。参加費も賞金もない世界にする |

## 設計（段階 2）との違い

手で回すために、次のところを単純にしています。乙ではどれも設計どおりに作ります。

| 項目 | 設計（`20-stage2-play`、`32-stage2-build-plan` の L1〜L9） | 甲での扱い |
|---|---|---|
| 札で引き出す | 札を持つ人が、他人の倉から自分で荷車を出す（L3） | 倉の持ち主が、決めたターン数のうちに荷車を送る。遅れたら記録に残す |
| 使用権の「1 回」 | 工房と同じ州にある自分の倉の材料で、その場で変換する。持ち主の生産は減らない（L4） | 使う人が、材料を工房の持ち主の村へ送る。持ち主が兵器を送り返す。持ち主の生産は、その分だけ減る |
| 受け取りの札の期間 | 1 日（L5） | 6 ゲーム時間（36 ターン、現実の約 36 分） |
| 札を出す費用 | ゲーム内の金を払い、その金は消える（L8） | 取らない |
| 預かりの中の物 | 出す側の倉の中で押さえる（L6） | 運営の住人の倉「預かり所」へ実際に送る。そろったら運営が渡す |
| 札の受け渡しの署名 | 預かりを通した交換はゲーム内の鍵、贈与はウォレット（L7） | 台帳への記入と、両者の口頭の確認 |

**変えないもの**（`20-stage2-play` §5 の決定）
- 倉が奪われたら、その倉の札は無効になる。
- 足りないときは、札の割合で均等に減らす。
- 札は国と関係なく残る。
- 札は物を瞬間移動させない。物は必ず荷車で地図の上を動き、襲われうる。
