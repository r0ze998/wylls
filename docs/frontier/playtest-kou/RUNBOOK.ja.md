# 甲 運用手順（運営用）

## 役割

| 役 | 人数 | すること |
|---|---|---|
| 進行役 | 1 | 時計、説明、困りごとへの対応 |
| 台帳役 | 1 | 4 つの部品の受付と台帳（`HAND-RULES.ja.md` §3） |
| 住人役 | 1（台帳役と兼ねてもよい） | 運営の住人 2 つを動かす（`RESIDENTS.ja.md`） |
| 観察役 | 1（進行役と兼ねてもよい） | 観察シート |

台帳と住人を 1 人で回すのは重い作業です。運営は 2 人以上いると安心です（決定 D11 の注意）。

## 前日までの準備

1. **始める前に必要なこと**（`README.ja.md`）：他人の村や倉へ荷車を送る操作が、画面から行えること。
2. **ビルド**：main（PR #17 を含む）のリポジトリのルートで、`docs/RUNNING.md` §2 の 4 行を実行します。
3. **ディスク**：空きが 30 GB 以上あること。
4. **印刷**：
   - 札のカード：各種 20 枚
   - 参加者ガイド：人数分
   - アンケート：人数 × 2 夜分
   - 観察シート：1 部
5. **国の割り当て**：
   - 人間 4〜6 人を、2〜3 か国に分けます。1 か国に 2 人以上を置きます（国の中の相談と、国の投票を起こすため）。
   - 組合（r1）と工房の貸し出し（r2）は、参加者と別の国に置きます。
6. **Mac**：電源につなぎ、スリープしない設定にします。

## 1 夜目：世界を立てる

```bash
S=frontier-node/target/release/frontier-stack
```

```bash
$S up --conquest --mode accel --beacon test-key --preseason-scale 2000 --scale 10 --game-hours 72 --season-end-at-play-end --bots 0 --personas off --run-id kou-1 --base-port 41700 --season 120
```

- `up` は前面で動き続けます。ほかの操作は、別の端末で行います。
- 参加費も賞金もない世界です（`--prize-so` を付けない）。
- run id と season は、立てるたびに新しくします。同じ番号の世界は、もう一度は立てられません。
- 10 倍速なので、1 ターンは現実の約 1 分、72 ゲーム時間は現実の約 7.2 時間です。

**参加者の画面**：`http://pN.localhost:41740/frontier/frontier/`（N は 1〜6）。**運営の住人**：`http://r1.localhost:41740/…` と `http://r2.localhost:41740/…`。

- 名前ごとに別のテスト用ウォレットになります。
- 2 夜とも、同じブラウザで同じ名前を開きます。シークレットウィンドウは使いません。
- 開幕まではボタンが押せません。最初のターンが来たら、割り当てた国で参加します。
- 運営の住人は、開幕と同時に参加し、`RESIDENTS.ja.md` の最初の準備を始めます。

## 進行の目安（1 夜目、3 時間）

| 現実の時間 | すること |
|---|---|
| 0:00〜0:15 | 参加者ガイドの説明と、運営の住人の掲示の読み上げ |
| 0:15〜0:30 | 参加。最初の建物を建てる |
| 0:30〜2:45 | 自由に遊ぶ。台帳役が受付をする。36 ターンごとに受け取りの札を集計する |
| 2:45〜3:00 | アンケート。時計を止める |

```bash
bash scripts/demo-clock.sh 41700 pause
```

## 2 夜目

```bash
bash scripts/demo-clock.sh 41700 resume
```

- 世界は 1 夜目の続きです。台帳も続きから付けます。
- 国の投票ができるのは、参加から 288 ターン（10 倍速で約 4.8 時間）たった村が、同じ国に 3 つ以上あるときです。2 夜目の後半から使える見込みです。
- 最後の 30 分は、全員で振り返ります（`SURVEY.ja.md` の最後）。

## 止める

```bash
$S verify --run-id kou-1
```

```bash
$S down --run-id kou-1
```

台帳（`ledger.csv`）、観察シート、アンケートは、世界の記録と一緒に保存します。

## 困ったとき

- **「WasmHashMismatch」と出たとき**：キャッシュを使わずに再読み込みします。
- **「この州はまだ前のターンの決着が済んでいません」と出たとき**：数秒待って、もう一度押します。
- **途中で `up` が止まったとき**：`$S resume --run-id kou-1` で再開します（`docs/RUNNING.md`）。
