# Wylls 奪い合い（MC）オーナー判断シート（PO-1〜PO-8）
2026-10-02 / 実験ブランチ exp/cq-e1〜e4 と、独立した検証役（スケプティック）の再現結果、追加の組み合わせ測定 P1 をもとにまとめました。

まえがき
・Gate CQ1 は品質の関門です。シミュレーターの検査を全部通らないと、次の Wave 2（オンチェーンのプログラム作り）に進めません。
・オーナーは 10/1 に「おすすめで進めて」と方向を承認済みです（DECISIONS CQ-G、frontier/cq-integ の 5c470d9）。このシートでは具体的な数値を決めます。また、承認済みの方向から変える点が1つあります（PO-8 の「+0.006」）。
・数字の印：［確認済］＝検証役が再現した数字、または統合担当が測った数字。［P1・未検証］＝今回の組み合わせ測定で、検証役はまだ再現していない数字。
・ルール側の変更はすべて、MC（征服モード）だけに効きます。M1 のルールとハッシュは変えません。D9（最初の領地は持ち主が変わらない）はすべての測定で 0 件でした（P1 だけで 630 シード行）。

PO-1 地図が十分に動かない（7日・1,000人の検査で不合格）
何が問題か：ボットが「相手の本拠地を包囲して占領する」をほとんどやりません（占領 0 件）。もう一つの指標 10e（2日目以降に中盤リング 132 州の色が変わった割合）も床の 10% に届きません。原因はシミュレーターの不具合で、包囲を手伝いに来た部隊が到着するとすぐ家に帰ってしまいます。
おすすめ：(a)+(b) の組み合わせです。ゲームのルールは変えません。
 1. ボットの作戦に「占領」の目標を加えます（E1）。各陣営1つの作戦枠で本拠地を狙い、包囲中は部隊がその場に残ります。帰還の不具合もこれで直ります。
 2. 物差しを直します（E2）。10e は、2日目以降に開く外側リングも含めて数えます（新しい名前は 10e′）。床の値は次のとおりです：10e′ 6%、10a 45回、10c 13%、占領 10件、解放 1件。「p10 が床の2倍以上」のルールは残します。
理由（数字）：
・E1 で占領・解放が出るようになりました。p10 で占領 36.8 件、解放 25 件（以前は 0 件）。別のシード2組でも 37.4/22.2、37.8/24.4［確認済］。
・E1 だけでは 10e が直りません。p10 0.074（2倍の基準は 0.20）［確認済］。旧基準のままだと新しいシードでも 10e が 20 シード中 10 で不合格です［P1・未検証］。
・新しい基準と E1 を合わせると、cq ボットで 4 組のシード（5、20、20、5 シード）すべて合格します。m1 ボットも 20/20 で合格し、比較用の「動かない地図」2つはどちらも不合格です。p10 は床の 2.08〜2.17倍（10a）、2.13〜2.22倍（10c）、2.37〜2.63倍（10e′）、3.4倍以上（占領）［P1・未検証］。
・10c を 14% にすると、あるシード組で 1.98倍になり2倍を割ります［確認済］。そのため 13% にしました。
・代償：ボット1体あたりの出撃回数が 5〜12% 増えます（0.158→0.177 回/日）［確認済］。
ほかの選択肢：
・§3.12 のルールレバー（自由都市を外側に置く、など）を足す方法。2つのシード組のうち1つで不合格がありました［確認済］。ルール変更の作業も増えるため、勧めません。
・占領を人間プレイの行だけで検査する方法（E2 の当初案）。E1 で不要になりました。

PO-2 ドクトリン（陣営の個性）のバランスが崩れる
何が問題か：MC では行軍が M1 の約5倍に増えます。騎兵の陣営 B・F は行軍のたびに追加コストを払うので、勝率が 11% 前後まで落ちます（帯は 16.7±2%）。
おすすめ：MC だけ、騎兵ユニットの追加コスト（鉱石・金）をなくします（K2）。チェーン上では「訓練時の費用」（catalog::train）で直します。出発時（Depart）の費用ではありません。あわせて、MC では Knight 系ユニットを選べないようにします。
理由（数字）：
・CI 代理検査 6/6、最大ずれ 0.100%（修正前は 3/6）［確認済］。
・1,500 シーズンの夜間検査 6/6。シード組 10000、20000、30000 で再現し、別の実装（E4）でも同じ表が出ました［確認済］。シード 40000 も 6/6 ですが、B の勝率 14.8% は帯の下限ぎりぎりです［確認済］。
・対称キープと組み合わせても夜間 6/6、最大ずれ 0.102%［P1・未検証］。
・比較用の悪いドクトリン3種は、どれも正しく不合格になります［確認済・P1］。
ほかの選択肢：
・包囲の保証金や前哨地を変える案（E4）。どの値でも帯に戻りません。前哨地を止めるとボット基準まで壊れます（1.068 > 1.0）［確認済］。
・訓練時だけ課金する「チェーンに忠実な」計算。2/6 で不合格でした［確認済］。

PO-3 28日・1万人の検査がわずかに不合格
何が問題か：床の値（1日あたり旗の交代 5回、Marches の 15%）は、もともと単独プレイ前提で測った値です。キャンペーン方式で遊ぶと、ちょうど境目に乗ってしまいます。
おすすめ：床を 1日 3.5回 / 10% にします。夜間検査には比較用の対照（--controls）を加えます。
理由（数字）：基準の実行で p10 4.65/日・0.138、最悪のシードで 4.43・0.130［確認済］。E1 を入れても 2 組のシードで 4/4 合格、対称キープでも合格。対照の Marches は最大 0.046 で、きちんと落ちます［P1・未検証］。
注意：旗の交代回数だけでは対照（weightmap）を落とせないことがあります（5.21/日のシードあり）。落とす役目は Marches の項目が担います［確認済］。
ほかの選択肢：4/日・12%。余裕が 1.08〜1.16倍しかなく、勧めません。

PO-4 大人数の陣営（3倍の人数）が地図の 22% を超える
何が問題か：陣営は自由に選べて、人数の上限もありません。そのため1陣営に人が集まる可能性があります。
おすすめ：ルールは変えません。7日検査で人数 2:1 を合否の対象にし、3:1 は報告だけにします。28日検査では両方を合否の対象にします。（将来、陣営選択画面に人数を表示することを UI の候補として挙げておきます。）
理由（数字）：2:1 は人間混合で 20/20・20/20、cq で 19/20・17/20 合格［確認済］。E1 でも 10/10、9/10［P1・未検証］。3:1 は 7日で 6/10・3/10 にとどまりますが、28日では 10/10 で、終わりのシェアは約 20% です［P1・未検証］。人数 37.5% の陣営でも、地図のシェアは 20〜24% にとどまります。

PO-5 キープの位置が陣営ごとに違う
おすすめ：keep_tile_symmetric を採用します（6陣営とも同じ位置）。
理由（数字）：組み合わせ全体にこれを入れても、7日検査（5 と 20 シード）、28日検査、夜間ドクトリン 6/6 がすべて合格しました。数字はほとんど変わりません（10a p10 93.8→98.4）［P1・未検証］。CQ2-A が州を開くコードを書く前に決める必要があります。

PO-6 v1 の WASM ファイルのバイト列が変わった
おすすめ：受け入れます。動作は同じです（記録済みベクタはバイト一致、再生 6/6）。M1 用に別ビルドを用意しても、得るものがありません。

PO-7 支配度の計算に「仮の領地」を数えるか
おすすめ：契約 §3.10 を直して、仮の領地も数えます。コードとデータ配置は変えません。差は新しい領地1つあたり最大 24 ベルで、全陣営に同じ条件です。データ配置は Gate CQ1 で固定されるので、今決める必要があります。

PO-8 ボットの最適行動の上限（M1 比 +0.005）を 0.000059 だけ超えた
何が問題か：シードを変えると、M1 との差だけで 0.00003〜0.0098 も揺れます。+0.005 や +0.006 という線は、この揺れの中に埋もれてしまいます。
おすすめ：比べ方を変えます。MC の最悪値に絶対の天井 0.995 を設け、M1 との差は報告だけにします（「1.0 未満」の元の検査はそのまま残します）。
理由（数字）：MC の最悪値は 4 組のシードで最大 0.992770 です。差は修正前で +0.00003 / +0.0051 / +0.0077 / +0.0098、E1 で +0.0023 / +0.0058 / +0.0074 / +0.0080 でした［一部確認済、50001 と 30101(E1) は P1・未検証］。承認済み CQG8 の「+0.006」では、E1 が 4 組中 2 組で不合格になります。

計画への影響（見積り）
・Gate CQ1 は全部やり直しが必要です。カーネル変更とハッシュの再固定があるためです。夜間の検査も含め、計算機時間で約半日です。
・追加の作業は Wave 2 の前に約 3〜4 人日です。内容は、契約 v1.3 の文案、シミュレーターへの取り込み、MC の訓練費用表と対称キープのカーネル化、RULESET_HASH_V2 の再固定、ベクタの再生成です。ほかに CQ2-F で、プランナー移植と項目一致テストに約 0.5 人週を見込みます。
・カレンダー上は、エージェントの並列ペースで +1.5〜2.5 日です。人間チーム換算なら +約1週です。
・残るリスク：P1 の数字はまだ検証役が再現していません。床の値は同じシードを見て決めました（ただし新しいシード 4 組で確認済み）。B の勝率がいつも少し低めです（−0.08〜−0.11%）。人間混合のキャンペーン行は依然として地図を動かしません（OD-14 の論点）。
