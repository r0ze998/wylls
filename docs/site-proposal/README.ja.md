## ファイルと使い方

- 元のソースは、作業フォルダの `wylls-site/` にあります（リポジトリ管理外）。元のファイルは変更していません。
- このフォルダの `index.html` は、元の `index.html` のコピーに文言の修正だけを加えたものです。
- 差し替えるときは、元の `wylls-site/index.html` をこのファイルで置き換えます。`app.js`、`style.css`、`media/` はそのまま使えます。
