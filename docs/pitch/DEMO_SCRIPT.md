## Recording rules for the AI block (contract §9.4)

1. Beat 1 (S7a) comes from the main run: after its last bell the stack and the council page stay up with no new play and the page is recorded against the retained run, naming the run id. Beat 2 (S7b) is a live run of the AI configuration with the presenter (contract §9.4). Record only the council page, an audit page: contract §9.4 item 3 allows another page only if the AI display has shipped in the main client, and today the main client shows no AI mark and no AI citizens (decision Y2 is [Design only]).
2. Show the council page as it draws itself, with its fixed banner; do not crop out its own labels, and add no caption that says AI is "always labelled", "marked" or "badged" [Confirm Q2: the page and contract gate G9 still use labels; if the owner removes them, the page changes and this rule is revised]. Check the finished cut for both.
3. No wallet or key text on screen. Test keys are derivable from a public seed; do not describe them as secret.
4. Keep the run's `PUB` files and `verify-minds.json`; cite run id and commit on the results card and in the video description. The first and last 3 s carry the banner with "the presenter is the operator".
5. Say only what the claims list allows after the run (contract §12.2): n AI citizens (n from the run) powered by Gemma 4 locally play beside script bots under the same keys, relay quotas and fog as people, plus safety limits; the code offers, the model chooses, the code checks; the autopilot runs economy and duties only and never starts a march; the model never sees keys (never "AI never holds keys"); measured figures with run id and commit; the `by: model` share beside any "the AI decided", and Y with its n; report every run, aborted ones too.
6. Footage rules (contract §9.1): the memory line on screen is the code text of an episode actually cited in a recorded decision, never invented, and is captioned "cited:", never "remembers"; "earlier in the season" is said only if the cited episode is older than 72 bells (12 game hours); if the featured decision was seeded by the operator seat, the caption says "seeded by the operator seat"; the one-decision ablation (the stored request re-sent without the Remembered lines, with its rerun and control) is shown or noted, and if the choice changed the only allowed caption is "with this line removed, the choice changed"; "next bell" is never said (about 3 to 4 real minutes at 10x for a 12-hex march, longer for a farther target).
7. The presenter is the operator. "A human and AI citizens decide for the same nation" may be said only of nation 0 in the live recording, and the sentence names the human as the operator. Evidence from the A/B test is worded "adopted with an operator-scripted seat ballot" (contract §9.2).
