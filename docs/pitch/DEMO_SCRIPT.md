## Recording rules for the AI block (contract §9.4)

1. Beat 1 (S7a) comes from the main run: after its last bell the stack and the council page stay up with no new play and the page is recorded against the retained run, naming the run id. Beat 2 (S7b) is a live run of the AI configuration with the presenter (contract §9.4). Record only the council page unless the AI badge has shipped in the main client.
2. Every frame that shows an AI actor shows its badge. Check on the finished cut.
3. No wallet or key text on screen. Test keys are derivable from a public seed; do not describe them as secret.
4. Keep the run's `PUB` files and `verify-minds.json`; cite run id and commit on the results card and in the video description.
5. Say only what the claims list allows after the run (contract §12.2): labelled, the same keys, rate limits and fog as people plus safety caps, code offers, model chooses, code checks, the autopilot never starts a march; measured figures with run id and commit; the `by: model` share beside any "the AI decided". Report every run, aborted ones too.
6. Footage rules (contract §9.1): the memory line on screen is the code text of an episode actually cited in a recorded decision, never invented, and is captioned "cited:", never "remembers"; "earlier in the season" is said only if the cited episode is older than 72 bells (12 game hours); if the featured decision was seeded by the operator seat, the caption says "seeded by the operator seat"; the one-decision ablation (the stored request re-sent without the Remembered lines, with its rerun and control) is shown or noted, and if the choice changed the only allowed caption is "with this line removed, the choice changed"; "next bell" is never said (about 3 to 4 real minutes at 10x for a 12-hex march, longer for a farther target).

## Must not appear (on screen, in narration, in captions)

- **Claims:** devnet or mainnet for Wylls; a human playtest, registration, waitlist, demand, traction or revenue; money, prizes, payouts, USDC, token, play to earn; AI indistinguishable from humans, hidden, stronger than people or the rule bots; pacts, betrayal, alliances or binding promises between AIs (deferred by decision X2, not built); that the AI "remembers", "wants" or "intends", that memory makes it play better, or that its reason is verified; that the council commands an AI's own march; exact replay of every AI decision; thousands of AIs per machine (state only the estimate with its assumptions); AI earns money; "5,000 viewers" without "simulated"; "1,000 players" (they are rule bots); "ran on Solana" without "local test chain"; the 85 audit findings fixed; lines of code or commit counts as quality; conquest, keeps or sieges as working.
- **Words:** say nation, village, hamlet, bell, AI citizen, Strike Order (never "Call", which is only the code name), Wylls. The old terms to search for are in the checklist at the end.
- **Footage:** any trailer, clip or still of the earlier prototype; any recording with the old names burned in; any frame that shows the old words "faction" or "holding"; any person or character of the earlier prototype (Hypatia, Aoi, and Aster the character; the nation Aster on the map is fine); AI-generated illustrations presented as game footage.
- **The earlier prototype** is not in this video. If one line is needed, speak it once: "Our earlier prototype, a different game, ran a full season on Solana devnet (rules v8, season 1790355636798) and re-verified 14 of 14 checks." Show no footage.
