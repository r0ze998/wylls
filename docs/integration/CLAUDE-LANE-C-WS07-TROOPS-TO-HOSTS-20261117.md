## 実際の欠落

1. 「編成する」を押したあと、できた軍勢は、村の画面のどこにも出ませんでした。控えの数が減るだけでした。
2. 「兵」のカードから、軍勢の一覧へ行く入口がありませんでした。進軍の計画は軍勢の一覧から立てるので、本人は、下のタブから「軍勢」を自分で探す必要がありました。
3. 村の命令の一覧は、編成の命令を、州が同じなら「この村から出した命令」として並べていました。編成の命令の記録は、軍勢を並べるマスを持つだけで、出した村を持ちません（前の束の訂正で確かめたとおりです）。
