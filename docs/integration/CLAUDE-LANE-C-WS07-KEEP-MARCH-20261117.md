## 実際の欠落

1. 砦へ軍勢を送ったあと、砦のカードは、残りの軍勢について「この砦へ送る軍勢を選ぶ」を出すだけでした。もう一つ向かっている軍勢があることも、いつ着くかも、カードからは分かりませんでした。
2. 砦のカードから、その進軍の追跡へ行けませんでした。
3. 追跡の行から、その砦のマス（カードが出る場所）へ直接戻れませんでした。

## 場合ごとの結果（静的な逆レビュー）

| 場合 | 結果 |

| 砦へ軍勢を送り、進軍の一覧が読めたあと、砦のカードを開く | 「この砦へ向かっているあなたの軍勢」に、その軍勢と着く予定のターン |
