## 完成させた導線

地図で村や軍勢を選ぶ → 札で自分の軍勢を知る →「進軍させる」→ 下書きがその軍勢の村から開く → 行き先を選ぶ → 道のり・着くターン・条件を読む → しまう／選び直す、という一続きです。

## 実際の断線・欠陥

1. **ほかの村の軍勢は、札から出せませんでした。** 札（`inspectActions`）は、開いている村の軍勢にだけ「進軍させる」を出していました（`ownHostsOn` → `hostRows` は開いている村だけを見ます）。複数の村を持つ人が、別の村の軍勢がいるマスを選ぶと、軍勢は札に出るのに、出すためのボタンがありませんでした。
2. **入口そのものも、開いている村の軍勢しか見つけませんでした。** `ACTIONS.compose` の `hostRow` は、開いている村だけを見ます。次の入口は、先に村を切り替えていました：
   - 地図からの命令
   - 「村へ戻す」（手の中の軍勢から）
   - 砦への進軍

   しかし次の入口は切り替えず、別の村の軍勢については、押しても何も起きませんでした：
   - 札
   - 軍勢の一覧
   - 手引き
   - 通知からの行軍
3. **行き先を選んだあとの道のりが、古い下書きや古い行き先に書かれることがありました。** `setDestination` は、規則のモジュールを待ったあと、下書きと行き先が今も同じかを確かめずに、道のりを書いていました。
4. **世界が変わっても、下書きと手の中の軍勢が残りました。** 前の世界の軍勢・村・道のりのまま、新しい世界に出ていました。

**直したこと**（`controller.mjs` の `march-home` だけ）

- `compose` の戻り値 `c` を受け取ります。次のどれかなら、**何も書かずに戻ります**：
