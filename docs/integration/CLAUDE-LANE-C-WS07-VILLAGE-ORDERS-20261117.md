## 実際の欠落

1. **送信済み・結果が未確認**の命令が、村の画面では何も残りませんでした。`actOnce` は、追跡が答えを得られないとき（`Unconfirmed`、`TxUnqueryable`）、命令を `state: 'refused', sent: true` と記録します。通知が消えると、ボタンは元に戻ります。本人は、送られたのかどうかを知らないまま、同じ建設や訓練をもう一度押せます。
2. **受け付けられた**命令が、次の読み込みが失敗している間、列にも在庫にも出ません。画面は「受け付けられた」ことを言いませんでした。
3. **ローカルプレイの保留**（`unconfirmed`）は、通知だけでした。同じ押下で結果を確認できることが、村の画面に残りませんでした。

## 場合ごとの結果（静的な逆レビュー）

| 場合 | 結果 |
|---|---|
| 建設を押し、追跡が答えを得られない | 「送信済み・結果は未確認」。記録に出ていれば「記録には出ています」に変わる |
| 上のあと、読み直しを押す | 純粋な読み込み。採用できれば、列と上の文が変わる |
| 同じ建設を二度押し、どちらも同じ番号 | 先の命令から順に、記録の数で確かめる。あとの命令には一つ多い数が要る |
| 訓練の結果が未確認 | 記録の印がないので、どちらとも言わない。読み直して下の数で確かめるよう言う |
| 送る前に断られた | 「送られていません」と理由 |
| チェーンが失敗と答えた | 「送信しましたが、成立しませんでした」と理由 |
| ローカルプレイで保留 | 同じ押下で結果を確認する、と言う（送り直さない） |

## 訂正（2026-11-17、同じ日、ブランチ `claude/lane-c-ws07-village-orders-fix-20261117`。起点 `f1532698`）
