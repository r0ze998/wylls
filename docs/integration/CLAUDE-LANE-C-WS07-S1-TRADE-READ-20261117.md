## 訂正（2026-11-17、同じ日、ブランチ `claude/lane-c-ws07-s1-trade-read-fix-20261117`。起点 `804de205`）

### 誤り 1：前の一覧を残したままの `NotFound` を、最新の成功として扱っていた

- `refreshS1` の `NotFound` の枝は `s1[n] ??= s1Fresh(n)` です。一覧を持っていれば、その一覧を残します。
- 初版は、この場合も印を `'missing'` とし、カードは「読めている」と同じに扱いました。前の読み込みが失敗していたときの注記も、消えました。残っている一覧は、今回の読み込みのものではありません。
- 直し方（持っているデータの決まりは変えていません）：
  - `s1.fresh[n]`：持っているのが、`NotFound` で立てた空の一覧かどうかの印です。
  - 何も持っていない、または空の一覧を持っているときの `NotFound` → `'missing'`（空の一覧として読めた扱い。これまでどおり）。
  - **読めた一覧**を持っているときの `NotFound` → `'missingKept'`。カードは「最新の読み込みでは見つかりませんでした。下に出ているのは、前に読めたものです。いまもそのとおりかどうかは、分かりません」と言い、読み直しを出します。
  - 良い読み込みが来れば `'ok'` に戻り、空の一覧の印も外れます。

| 持っているもの | 今回の読み込み | 印 | カード |
|---|---|---|---|
| なし | 成功 | `ok` | 一覧を出す |
| なし | `NotFound` | `missing` | 空の一覧（これまでどおり） |
| 空の一覧（前の `NotFound`） | `NotFound` | `missing` | 空の一覧 |
| 読めた一覧 | `NotFound` | `missingKept` | 前の一覧を出し、最新の読み込みのものではないと言う |
| 読めた一覧 | 失敗 | `failed` | 前の一覧を出し、最新の読み込みが失敗したと言う |
| なし | 失敗 | `failed` | 「読み込めませんでした。ないという意味ではありません」 |
| 三つのうち一つだけ失敗 | — | 失敗したものだけ `failed` | その一覧だけ、そう言う。ほかは読めた扱い |

- 読み直しが実際に読むもの・書くもの（静的に照合しました）：
  - 読むもの：`herald.caravans`、`herald.structures`、`herald.nations` を一回ずつ。
  - 書くもの：`FS.s1` の三つの一覧、その印（`read`、`fresh`）、`FS.s1.error`、`FS.s1Reread`。画面の描き直し。
