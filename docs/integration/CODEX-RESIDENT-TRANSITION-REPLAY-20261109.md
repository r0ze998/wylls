# Original-origin resident transition replay (2026-11-09)

## Delivered scope

The opt-in `verify::wide_expedition_resident` module independently stages the
private original-origin Dissolve and Return effects, then checks exact before
commitments, complete after accounts, both emitted bodies, and account-chain
heads. It does not call program handlers. It uses the verifier's existing
independent bucket and Holding arithmetic, and restates entry, roster and
whole-reserve effects. Canonical address, authority and receipt definitions are
shared with the ABI rather than redefined as a second wire format.

The public API is `stage(Context, before)` for conditional expected output and
`verify_transition(Evidence)` for a supplied invocation. Exactly eight ordered
Dissolve roles or six Return roles are accepted. Effective actor/payer aliases
must agree in every byte, metadata item and privilege. Other aliases, executable
accounts, noncanonical identities, unsupported versions, mismatched source
ownership/generation/issuance, capture locks and open authoritative transit are
refused. Return requires resolved voluntary Leave with all four raw operation
payload fields zero, checked whole-unit reserve credit and exact row/reference
release. Unaffected roles and all lamport balances must also match.

Before economic replay, the verifier checks the exact raw pre-state receipt
commitment. The ABI's extracted `input_digest` helper preserves existing
context/manifest domains, lengths and field order; it confers no authority or
admission. A malformed economic field cannot be normalized before this check.

The feature is the existing `wide-economy-experimental`. No new dependency,
manifest, feature, public dispatch route or default season-verifier path was
added. The default whole-season result remains fail-closed for unmodelled wide
history; this module cannot turn it into PASS.

## Deliberate proof boundaries

Successful transition checking is conditional on caller-supplied snapshots,
effective privilege claims and Clock. It does not authenticate signatures,
account provenance, historical freshness, original issuance/founding, earlier
Resolve/combat/capture, invocation log attribution, bank rollback, SBF behavior
or the full season. Initial native accounts and public proof vectors are
synthetic fixtures, not live-chain evidence. The explicitly returned
`full_season()` is always false, with the unsupported claims listed in the API.

No new private keys, keypairs, private-key derivation, signing, real
transactions, RPC, SBF, deployment, CI or public gate activation were performed.
Earlier public-vector symmetric recovery remains confined to the already
audited native fixture path. No unpublished private prize material is included.
The read pipeline, original UI and keeper observer are complementary readers;
none makes this private lifecycle publicly playable.
