## 実際の欠落

- 地図で貯蔵庫や村を選んでも、その場所を隊商の行き先にできませんでした。村の画面に移り、「村（p, q · マス n）」の一覧から、座標で探す必要がありました。
- ほかの人の場所は、いまの村に近い 24 件だけが一覧に入ります（`OTHER_PLACES`）。それより遠い場所は、地図で見えていても、行き先に選べませんでした。
- 自分の要塞を地図で選んでも、兵を入れるフォームへは渡せませんでした。

## 変更

### `screens/s1.mjs`

- **新規 `s1PlaceAt(FS, sel)`**：マスにある、隊商の出発地・行き先になれる場所を、フォームの一覧と同じ形で返します。読めていなければ `null` です。
- **新規 `s1PlanNow(FS)`**：計画を、いまの世界・読み手・一覧で確かめ直します。
- **新規 `s1PlanOffers(FS, sel)`**：マスのカードが出せるボタンを答えます。
- **`renderS1Tile`**：ボタンと、理由・注意の文を足しました。ほかの行動は変えていません。
- **`s1VillageModel`**：計画の行き先が一覧になければ、末尾に足します。`plan`（行き先・出発地・要塞の番号、または「確かめられない」）を返します。
- **`renderS1Village`**：選択の初期値、折りたたみの開閉、注記と「選択を外す」。カードに `id="hp-trade"` を付けました。数量の欄は変えていません。

### `controller.mjs`

- **新規 `planS1Place(d)`、`clearS1Plan()`**：`FS.s1Plan` を置く・外すだけです。同期で、読み込みも送信もありません。
- **`s1Caravan`**：準備の二つの待ちのあとに、世界・herald・読み手・ウォレット・選んでいる村の確認を足しました。変わっていれば、送らずに止めます。`act('SendCaravan')` の引数は変えていません。
- **`FORMS['s1-caravan']`**：受け付けられたときに計画を外す `.then` を足しました。フォームから読む値は同じです。
- `resetViewer`、`useHerald`、`adoptPinnedWorld` に `FS.s1Plan = null`。

### `app.mjs`

- 行動 `'s1-plan'`：計画を置き、村の画面を開き、交易のカードへ移ります。フォームは送りません。
- 行動 `'s1-plan-clear'`。import に二つの名前。

## 場合ごとの結果（静的な逆レビュー）

| 場合 | 結果 |
|---|---|
| ほかの人の貯蔵庫を地図で選び、「ここへ隊商を送る」 | 村の画面の交易のカードが開く。行き先にその貯蔵庫が入る（一覧になければ末尾に足す）。「着いた荷はその人のもの」と出る。数量は 0 のまま |
| 自分の貯蔵庫を選び、「ここから隊商を送る」 | 出発地にその貯蔵庫が入る |
| いま選んでいる村そのものを選ぶ | 貯蔵庫があれば、出発地は貯蔵庫が初期値になる。ほかに出発地がなければ、ボタンを出さず、理由を言う |
| 自分の要塞（選んでいる村の州）を選ぶ | 要塞のフォームが開き、その要塞が入る。人数は、もとの初期値のまま |
| 一覧や州を読めていないマス | ボタンを出さない |
| 計画を置いたあと、世界が変わる・読み手が変わる | 計画は使わない（controller でも外す） |
| 計画の場所が、あとの読み込みでなくなった | フォームには入れない。「確かめられません」と「選択を外す」を出す |
| 計画を置いたあと、別の村を選ぶ | 行き先はそのまま（場所は村によらない）。要塞は、その村の州になければ「確かめられません」 |
| 送信の準備の間に、世界・ウォレット・選んでいる村が変わる | 何も送らない。そう言う |
| 隊商が受け付けられた | 計画を外す |
| 送る前に断られた・失敗・結果が未確認 | 計画は残る（やり直しのため）。結果は、前の束の表示が言う |
| フォームで本人が行き先を選び直したあと | 同じ画面の描き直しでは、本人の選択が残る（既存の描き直しの決まり） |

## 本人の判断が要るもの・つながっていないもの

- **別の自分の村を、出発地にする**：出発地の「村」は、いま選んでいる村だけです。地図で別の自分の村を選んで出発地にするには、選んでいる村を替える必要があります。この束では、しません（行き先にはできます）。
- **別の州にある自分の要塞**：要塞のフォームは、いま選んでいる村の州の要塞だけを扱います。別の州の要塞には、ボタンを出しません。
- **行き先までの道があるかどうか**：ボタンの時点では、確かめません。フォームを送るときに、既存の道探しが答えます（「そこまで隊商の道が届きません」）。
- **村の画面が、広い在庫のカードを出しているとき**（`FS.wideSelect`）：交易のカードは出ないので、移った先に何も見えないことがあります。広い在庫の選択は、この束では外していません。
