## 先に読んだ、いまの経路の副作用

`refresh()` は、読み手の記録のほかに次を行います。そのため、読み直しには使いません。

| `refresh()` の中 | 何をするか |
|---|---|
| `refreshPrize` | 賞金の読み込み |
| 自動の追いつき | `shouldAutoNudge` → `io.nudge`（中継への依頼） |
| `refreshMarches` | 行軍の読み込み。公開の送信と、帳面の保存を伴う |
| `io.quota`、`refreshConquest`、`refreshChronicle`、`refreshHomes` | それぞれの読み込み |
| 末尾の `autoTicket` | 自動の申請（送信と端末への保存） |

`applyMeResult()` も、名前のとおりの「採用だけ」ではありません。

| `applyMeResult()` の中 | 何をするか | 読み直しでの扱い |
|---|---|---|
| `saveLandPatch`（3か所） | 端末への保存（土地が終わった理由、その消し込み、申請を見た記録） | 3か所とも走らない答えだけを採用する |
| `refreshDelegation` | 鍵が合わない間だけ、公開の代理人の一覧を読む（間隔つき） | 読み込みだけなので、そのまま（通常の読み込みと同じ） |
| `fwide.adoptWide`、`reconcileExpedition`、`sessionProblem`、`quota` | メモリの中の採用 | そのまま |
| 失敗の枝：`fwide.failWide` | 広い在庫を落とす | 失敗は渡さない |
| 「なし」の枝 | 市民・村を空にする | 何も持っていないときだけ渡す |

## 変更

### `controller.mjs`

- **新規 `plainMeAnswer(me)`**：採用しても端末に保存しない答えかどうかを答えます。土地の段階が同じ（または未保持）、消し込む「終わった理由」がない、「申請を見た」の記録待ちがない、の三つです。この三つで、`applyMeResult` の `saveLandPatch` の3か所はどれも走りません。`readLand` は端末の記録を読むだけです（`applyMeResult` 自身が最初に行うのと同じ読み込みです）。
- **新規 `rereadVillage()`**：`/h/me` を一回、押したときの村の州を一回、読みます。待ちは二つだけです。
  - 入口の条件：herald、時計、ウォレットがある。試作の決まりの世界ではない。`play` である。読み直しの最中ではない。
  - 押したときに控えるもの：要求そのもの（`run`）、herald、ローカルプレイ、ウォレット、読み手の鍵、世界、`viewerRefresh` の値、選んでいた村。
  - 答えのあと：自分の要求でなければ何も書かない → 新しい通常の読み込みが始まっていれば捨てる → 別の鍵の市民・失敗は「失敗」と言うだけ → 保存が要る答えは「変更あり」と言うだけ → 採用 → 州の読み込み。
  - 例外：読み手の記録の部分なら「失敗」、州の部分なら「州が来なかった」とします。
- **`refresh()` の1行**：`if (request > meNewerThan && applyMeResult(me) === 'error') return;`。読み直しが採用した時点より前に始まった通常の読み込みは、その `/h/me` の答えを採用しません。`return` はせず、残りはそのまま続きます。
- **`loadEnvelope` の成功側に1行**：その州の良い読み込みで、「州の記録は読み直せませんでした」の注記を消します。
- **`resetViewer`、`useHerald`、`adoptPinnedWorld`**：`FS.villageReread = null` を足しました。
- **`ACTIONS['village-reread']`**：`rereadVillage()` を呼ぶだけです。

### `screens/holding.mjs`

## 場合ごとの結果（静的な逆レビュー）

| 場合 | 結果 |
|---|---|
| 読んでいる間に、もう一度押す | 何も始めない（`'loading'`） |
| 失敗のあとに、もう一度押す | 新しい要求。前の要求の遅い答えは書かない |
| 読んでいる間に、別の村を選び、また同じ村に戻る | 読み直しは押したときの村のまま続く。戻れば、その状態が見える |
| 読んでいる間に、村を別のものに替えたまま | 読み手の記録は採用する。州は押したときの村のもの。「州が来なかった」は、その村を選んでいる間だけ出す |
| 読んでいる間に、ウォレット・NFT・herald・世界が変わる | 何も書かない。注記も残さない |
| 世界 A→B→A | 世代が違うので、前の要求は書かない |
| 押す前に始まった通常の読み込みが、あとで答える | 採用済みなら、その `/h/me` は採用しない。残りは続く |
| 押したあとに通常の読み込みが始まる | 読み直しの答えは捨てる。注記なし |
| 読み直しが失敗 | 持っている値はそのまま。`meStatus` も変えない。符号を出す |
| 土地の段階が変わっていた | 採用しない。通常の読み込みに任せる |
| 村を持っているのに「市民なし」 | 採用しない（読み直しで村は消さない） |
| 何も持っていなくて「市民なし」 | 採用する。「まだ村がありません。」になる |
| 読み手の記録は来て、州が来ない | 記録は採用。州についてそう言い、ボタンを残す |
| あとで通常の読み込みが成功 | 「失敗」「変更あり」の注記は消える。州の注記は、その州の良い読み込みで消える |
