# ゲーム本体UI・分散配置・NFT住民の統合候補

基点は UI `32abdfc6`（map/memory `dd568a6a`を含む）と、担当20 `b2f7becc`。統合commitは `a85da63f`。

## 今回の実装

- 初期村を置けるリングを共通化。拡張して開いた外周は、heartland上限を越える初期村の候補・空き地数・待機マークには含めない。領域表示と探索用地図は外周も表示する。
- NFT住民に、programが拒否する通常住民用SetSessionを要求しない。既存のResidentAct送信経路へ進める。
- NFT参加反映待ちに通常のwallet Joinを発行しない。参加国の再確認を維持。
- 選んだ初期村と未決入植の保存先を、walletだけでなくプレイ中NFTごとに分ける。

## 確認

最終UI変更後の限定Node試験67/67。新規はhome-rings 6件、resident-home 4件。既存dispersed-map、join-free、world、camera、wait、mapを含む。構文・差分検査通過。

統合時、固定バイトの共通holder 3/3、検証器V26・V27・V28は各5/5、分散入植/拒否/休眠解放を本物dispatchへ通すホスト試験3/3を確認。後のRust変更は古いコメントの訂正のみ。

鍵ペア生成・秘密鍵導出・署名は実行していない。公開PDA/with_seed計算は許可範囲で使用。NFT UI試験はwalletとrelayを代替し、実送信直前で停止する。ホスト試験は署名者フラグとCPI代替を使う。実チェーン・実署名・SBF・全試験・ブラウザ目視の確認ではない。
