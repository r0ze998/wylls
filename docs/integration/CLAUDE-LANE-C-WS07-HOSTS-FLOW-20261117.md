## 訂正（2026-11-17、同じ日、ブランチ `claude/lane-c-ws07-hosts-flow-fix-20261117`。起点 `95eceb9e`）

独立の逆レビューで、二つの誤りが見つかりました。村 → 軍勢 → 計画・追跡 → 戻る、の全体を見直しました。

### 誤り 1：「分からない」を「ない」に落としていた

- `unreadHostPlaces` は、一覧がいまのページのものでないとき `known: false` を返していましたが、画面は、読めていない州の**数**だけを見ていました。数は 0 なので、「読めていない州はない」と同じ扱いになりました。
- herald を替えた直後（一覧は捨てられ、村の州の記録は残っている）や、一覧をまだ読めていないとき、軍勢が出ていなければ、画面は「軍勢はいません。村で兵を訓練し…」と言いました。
- 直し方：
  - 一覧が「いまのページのもの」と言えるのは、**文脈の番号**と**世界（世代つき）**が合うときだけです（世界の照合を足しました）。
  - 合わない・ない（`null`）ときは、**分からない**として扱います。軍勢が出ていなければ、「…一覧をまだ読めていないので、軍勢がいない、という意味ではありません」と言います。軍勢が出ていれば、一覧の下で「出ていない軍勢が、いないとは限りません」と言います。
  - 「軍勢はいません」は、一覧が読めていて、読めていない州がなく、軍勢がないときだけです。
  - 一覧の印をまったく持たない古い作りの入力（`undefined`）は、これまでどおりです。

| 一覧（`FS.hostPlaces`） | 読めていない州 | 出ている軍勢 | 画面 |
|---|---|---|---|
| いまのページのもの | なし | なし | 「軍勢はいません」 |
| いまのページのもの | あり | なし | 「読めていない州があるので、いない、という意味ではありません」 |
| いまのページのもの | あり | あり | 一覧と、読めていない州の注記 |
| ない／別の文脈／別の世界 | 分からない | なし | 「一覧をまだ読めていないので、いない、という意味ではありません」 |
| ない／別の文脈／別の世界 | 分からない | あり | 一覧と、「出ていない軍勢が、いないとは限りません」 |

### 誤り 2：送信中でないことを、「まだ送っていない」と言っていた

- 初版は、その軍勢の計画（`FS.compose`）が立っていて、`sending` でなければ、「まだ送っていません」と言いました。
- controller を読むと、計画は、**受け付けられたとき以外**、送信が終わっても立ったままです。断られた、失敗した、結果が未確認（ローカルの保留、通常の経路の未確認）のどれでも、`sending` は偽に戻ります。送信待ち（`pending`）の計画もあります。
- 直し方：分かっていることだけを言います（`hostPlanState`）。
  - 送信（`sendTheMarch`）は、始めるときに計画に印（`step`）を付け、消しません。計画を作る場所は一つで、その作りに印はありません。**印のない計画だけ**を、「まだ送信を試していません」と言います。
  - 送信に入った計画は、その軍勢の最後の進軍の命令の記録で言い分けます：結果未確認／送信して断られた／送る前に断られた。記録がなければ、「送れたかどうかは、ここでは分かりません」。
  - 結果未確認は、起点の形（`unconfirmed`＝ローカルの保留、`refused` で `sent`）と、採用済みの主の連なりの形（通常の経路も `unconfirmed`）の、どちらも読みます。
- あわせて：計画が送信中・送信待ちの間は、軍勢の画面から別の「村へ戻す計画」を開けないようにしました（ボタンと、行動の確かめの両方）。その計画は、送信のものだからです。送信とやり直しの決まりは、変えていません。
