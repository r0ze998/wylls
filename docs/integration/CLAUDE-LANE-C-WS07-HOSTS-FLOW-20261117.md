## 実際の欠落

1. 村が複数あると、軍勢の画面がどの村のものか分かりませんでした。ほかの村の軍勢を見るには、いったん別の場所で村を選び直す必要がありました。
2. 進軍中の軍勢のカードから、その進軍の追跡へ行けませんでした。追跡の行から、軍勢の一覧へも戻れませんでした。
3. 村の外に立っている軍勢を、軍勢の画面から村へ戻す計画に進めませんでした。
4. 軍勢がいる州の読み込みが失敗していると、その軍勢は一覧から黙って消えました。ほかに軍勢がなければ、画面は「軍勢はいません。村で兵を訓練し…」と言いました。

## 本人の判断が要るもの・つながっていないもの

- **ほかの村の軍勢の数**は、読めている州の分だけです。読めていない州にいる軍勢が、どの村のものかは、ページは知りません（記録の一覧は州だけを言います）。
