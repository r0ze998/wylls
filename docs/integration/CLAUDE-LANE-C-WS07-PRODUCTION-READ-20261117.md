## 実際の欠落

1. **州の記録がないだけで、すべての行動が「この州はまだ前のターンの決着が済んでいません」と出ました。** 決まりの写しは、`!ctx.province` のとき `NotResident` を返します（判定としては、安全側で正しい動きです）。しかし画面は、それをそのまま理由として出し、「追いつかせる」のボタンまで出していました。州の記録を**読めていないだけ**でも、プレイヤーには、州の処理が遅れているように見えました。読み直す手段も、この画面にはありませんでした。
2. **村の記録を読めていない間も、「まだ村がありません。」と出ました**（読み手の記録が答える前や、失敗の間）。
3. **読み込みが失敗している間の数が、いつの記録の数かわかりませんでした。** 在庫と生産は、最後に読めた記録から計算し続けます。そのことが、画面のどこにもありませんでした。
4. **世界が変わったあとも、前の世界の村が、次の答えまでそのまま出ていました。**

## 変更（`screens/holding.mjs` の二か所と、英語の辞書の末尾）

- **`holdingRead(FS)`**（新しい関数。読むだけです）：次の二つを返します。
  - 読み手の記録の状態：`none`・`unread`・`otherWorld`・`stale`・`ok`
  - 村の州の記録の状態：`held`、または `FS.provinceReads` の状態、または `idle`
- **`renderHoldingRead(FS)`**（新しい関数）：読めていないものがあるときだけ、見出しの下に出す文を作ります。
  - **州を読めなかったとき**：符号と、「下の行動が『この州はまだ前のターンの決着が済んでいません』と出るのは、記録を読めていないためのことがあります」。「もう一度読み込む」（`province-reread`。純粋な読み込み）も出します。
  - **州を読み込み中・順番待ち・まだ頼んでいないとき**：「読めるまで、下の行動は…と出ます」。まだ頼んでいないときと、記録がないときは、ボタンも出します。
  - **最後の読み込みが失敗しているとき**：「下の数は、最後に読めた記録から計算したものです」。
  - **別の世界の村のとき**：「前に読んだ世界の記録です」。
- **`render`**：
  - 「まだ村がありません。」の行を、読めていないときは、「村の記録をまだ読めていません。村がないという意味ではありません。」にします。
  - 上の文を、既存の見出しの札に付けて返します。札の数は、変わりません。
- **英語**：五つの文を、辞書の末尾に加えました。引用する行の英語は、既存の訳（`en-frontier.mjs`）と同じ文です。
