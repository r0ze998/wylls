## 実際の欠落

1. 警告を見ても、対象の村を開く、守りを増やす、その村の軍勢を戻す、のどれにも進めませんでした。本人は、警告の村の名前を覚えて、別の画面で探す必要がありました。
2. 警告は、村を場所と区画だけで持っていました。地図の印（`app.mjs` の `threats`）は警告の村のマスを読みますが、警告はマスを持っていませんでした。
3. 「まだ調べていない」と「調べて、何もない」が、同じ「出ていません」でした。世界が替わったあとも、前の世界の警告が残りました。
4. 出発地の持ち主を読めていない出発は、黙って数から外れていました。できごとの記録の読み込みが失敗していても、そのことは出ませんでした。

## 場合ごとの結果（静的な逆レビュー）

| 場合 | 結果 |
|---|---|
| 警告の村を開く | その村を、場所・区画・世代で探して選ぶ。村の画面が開く |
| 警告のあとで、その村を失った／同じ区画に新しい村ができた | ボタンを出さない。「いまの記録にありません」 |
| 押す直前に村の並びが変わった | 押したときに探し直すので、別の村には行かない |
| 村の外に軍勢がいる | その軍勢ごとに「村へ戻す計画を開く」。計画が開くだけで、送らない |

| 軍勢のいる州を読めていない | その軍勢は数えられない。そう言う |
| 読み手・世界が替わった直後 | 「まだ調べていません。出ていない、という意味ではありません」 |
| ルールを読み込めていない | これまでの文 |

| 出発地の持ち主が未読の出発がある | 件数と、「数えていません（来ない、という意味ではありません）」 |
